## 4. 技术栈

| 组件 | 选择 | 理由 |
|------|------|------|
| **语言** | Python 3.10+ | 生态丰富、维护简单 |
| **数据库** | SQLite + DuckDB | 零配置、文件存储 |
| **调度** | APScheduler | 轻量级、够用 |
| **回测** | 向量化回测 | 单机性能足够 |
| **配置** | YAML | 配置驱动、版本控制 |
| **API** | FastAPI (可选) | 轻量级、可扩展 |

## 5. 快速入门

### 5.1 目录结构

```
quant_system_v4/
├── config/                          # 配置文件
│   ├── system.yaml                  # 系统全局配置
│   ├── data_sources.yaml            # 数据源配置
│   ├── factors/                     # 因子配置
│   ├── strategies/                  # 策略配置
│   ├── risk/                        # 风险配置
│   └── workflows/                   # 工作流配置
│
├── src/                             # 源代码
│   ├── modules/                     # 15个核心模块
│   ├── core/                        # 核心基础类
│   ├── utils/                       # 工具函数
│   └── api/                         # REST API
│
├── data/                            # 数据存储
│   ├── raw/                         # 原始数据
│   ├── processed/                   # 处理后数据
│   ├── factors/                    # 因子数据
│   └── backtest_results/            # 回测结果
│
├── logs/                            # 日志文件
├── tests/                           # 测试代码
├── notebooks/                       # Jupyter分析
├── docs/                            # 项目文档 ← SPEC文档体系
└── docker/                          # Docker配置
```

### 5.2 开发流程

```
1. 阅读ARCHITECTURE.md → 了解系统架构
2. 阅读MODULES.md → 了解模块规格
3. 阅读API.md → 了解接口约定
4. 阅读CONFIG.md → 了解配置方式
5. 开始开发 → 按模块逐一实现
```
