## 三、逐条展开说明

**1. 分区逐时预报（00900269）**：369.7 万条、按日更新、无条件开放，是全库数据量最大的气象资源。已订阅气象族以日度为主，本资源把颗粒度推进到"小时×行政区"，可直接构造高温/暴雨小时暴露度，服务电力负荷、航空延误、零售客流的天气因子精调。边际价值在于颗粒度而非覆盖面，与既有订阅互补不冲突。

**2. 公租房申请获批信息（01900906）**：134 万条事件级记录（申请、获批），更新及时。公租房申请热度是深圳中低收入群体与新市民流入的实时温度计，可按月聚合申请量构造"住房需求压力"因子，与楼市价格因子形成对冲视角。

**3. 公租房轮候数据（01903488）**：46.2 万条轮候记录。轮候人数变化=保障房供需缺口的高频刻度，轮候消化速率还能侧面反映竣工交付节奏，是楼市族里少有的"政策性需求侧"数据。

**4. 招聘岗位信息（01100977）**：人社局官方招聘池，17.2 万条、持续更新。按行业/岗位聚合可得就业景气领先指标，对 A 股消费、地产链条的就业敏感度建模有用；与前轮已评的大鹏/光明区级招聘岗位形成全市+区级双层。

**5. 二手住房成交参考价格表（01903516）**：7653 个小区的官方参考价横截面。虽然参考价机制已淡化，但其小区级价格锚定价值仍在——可与已订阅楼市族（新房网签等）组成"新房-二手"双价格体系，也是地理编码房价因子的底表。

**6. 保障房租赁合同（01900912）**：17.7 万条租赁合同记录。真实成交量的微观样本，可观察保障房租赁的户型、租金分布与成交节奏，为租赁市场因子提供官方微观数据（市场化租赁数据深圳官方渠道稀缺）。

**7. 菜篮子平均零售价（04303266）**：发改委价格监测条线，"有数据更新时"意味着频率高于月度（约周度）。食品价格是 CPI 高频代理的标准做法，3126 条历史可回溯，性价比高。

**8. 政府采购意向公开（02203175）**：1.5 万条采购意向。意向公开先于招标与支出执行 1-3 个月，是财政支出力度的前瞻指标；按采购人单位聚合还可观察各条线（基建/信息化/医疗）的支出切换。

**9. 存量住宅用地（00303565）**：规自局按季度公开的存量宅地清单（608 条，动态更新）。地块开工/竣工状态是新房供给的先行库存指标，与楼市族的价格需求侧数据配对成供需框架。

**10-11. 月度蔬菜/肉蛋零售价（04303279/04303278）**：发改委月度价格族（同族还有水产品 04303280、牛奶 04303281、活鲤鱼 04303328）。单条序列不长但历史连贯，适合直接做食品分项 CPI 代理；若订阅建议整族打包。

**12. 深圳交易集团项目预算（05403021）**：3.2 万条交易项目预算，政府采购业务的落地侧镜像。与 8 号采购意向构成"意向→预算→成交"三级前瞻链，可交叉验证财政支出脉冲。

**13. 未来10天天气预报（00900278）**：14 万条预报记录。提供提前量维度，用于构造"预报-实况偏差"序列本身也是可建模信号（预期差）；灾害性天气预期对旅游、保险、农业链条有映射。

**14. 城市更新单元计划（00303355）**：742 条旧改计划。城市更新是深圳住宅与产业用地供给的独特管道，计划公告到实际供给周期 3-5 年，适合做中长期供给结构因子与地产股主题映射。

**15. 保障房售房合同（01900913）**：9.6 万条安居型商品房合同。政策性购房需求样本，与公租房族共同构成完整保障房体系视图（申请→轮候→租/售成交）。

**16. 南山区商品房预售许可（04003643）**：3485 条预售证发放记录。预售证发放节奏是新房有效供给的最高频官方信号；当前为区级，若各区分资源可后续拼全市（前轮已评资源中未见同类市级资源）。

**17. 市本级预算/决算（02200319+02200321）**：一般公共预算+政府性基金预算的收支结构。政府性基金支出波动隐含土地财政力度，是财政力度因子的年度基准锚。

**18. 盐田区规上服务业-交通运输仓储（03700774）**：盐田港直接腹地的行业营收面板。口岸族已订阅吞吐量类数据，本资源补"企业经营侧"视角，港航景气交叉验证。

**19. 大鹏规上服务业营收（03001128）**：月度频率、640 条。区级月度面板是统计局月报之外的补全维度，与前轮"宏观统计(月度面板补全)"评级思路一致。

**20. 大鹏景区接待总人数（03001231）**：月度去重客流（41 个月序列）。同族还有国内/入境/过夜游客、省内外旅游收入等 10+ 个兄弟资源（03001222-03001242 簇），可拼出区级文旅月度全景，是消费族里少见的实物量高频数据。

## 五、方法附注

- 评分维度权重：因子相关性 45% + 频率 14% + 数据量/历史 10% + API/可得性 26% + 热度 5%，负向词（名录/点位/处罚等）最高罚 30 分；终选阶段叠加人工校准（家族重叠折减、衍生类剔除、同族合并）。
- 目录中 apiContext 字段大量为空，与资源实际 API 可用性可能不一致（前轮档案同样记录 api 为空但实际可订阅），故 API 权重上限压低，以开放方式（无条件/有条件）为主要可得性判据。
- 本轮所有结论仅基于目录元数据，未做 appKey 探测或接口调用；订阅前建议按既有接入流程逐资源验证字段结构。
- 中间产物：sz_round3_candidates.json（目录池 top80）、sz_round3_delta_candidates.json（delta 池 top100）。
