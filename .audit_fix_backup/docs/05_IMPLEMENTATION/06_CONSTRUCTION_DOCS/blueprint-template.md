## 📝 文档结构



### 1. YAML头部



```yaml

```---


version: [版本号]

status: [状态]

created_date: [创建日期]

last_updated: [最后更新日期]

owner: [负责人]

standard_type: 专业量化机构蓝图

applicable_scope: [适用范围]

compliance_level: 专业标准

layer: "[Layer定位]"

```---

```



**字段说明**：

- `module_id`: 模块唯一标识，格式：[模块名称大写]_[三位数字]

- `version`: 版本号，格式：主版本.次版本.修订版本

- `status`: 文档状态

- `created_date`: 创建日期，格式：YYYY-MM-DD

- `last_updated`: 最后更新日期，格式：YYYY-MM-DD

- `owner`: 文档负责人

- `standard_type`: 文档类型，固定为"专业量化机构蓝图"

- `applicable_scope`: 适用范围

- `compliance_level`: 合规级别，固定为"专业标准"

- `layer`: Layer定位，格式："Layer X (层级名称)"



```---
