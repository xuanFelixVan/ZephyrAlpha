## 📋 使用指南

### 新用户入门
1. **阅读规范**: 查看 [README.md](./README.md) 了解完整规范
2. **选择模板**: 访问 [模板库](./00_TEMPLATES/INDEX.md) 选择合适模板
3. **创建笔记**: 复制模板到相应目录，按规范命名
4. **开始研究**: 遵循模板结构进行研究分析

### 命名规范
- **文件命名**: `YYYYMMDD_描述性名称_v版本.py`
- **示例**: `20260403_market_analysis_v1.py`
- **目录命名**: `两位序号_英文描述` (如 `01_EXPLORATORY_ANALYSIS`)

### 代码质量
- 遵循模板中的代码结构
- 添加必要的文档和注释
- 确保结果可重复
- 定期备份和版本控制

## 🔄 工作流程

### 1. 研究规划
- 确定研究目标和范围
- 选择合适的研究目录
- 准备所需数据和工具

### 2. 笔记创建
- 从模板库复制对应模板
- 按规范命名新文件
- 更新YAML头部和元数据

### 3. 分析实施
- 加载和预处理数据
- 执行核心分析逻辑
- 生成可视化结果

### 4. 结果总结
- 整理主要发现和结论
- 提出建议和下一步计划
- 保存输出结果

### 5. 文档归档
- 清理中间文件
- 确保代码可重复运行
- 提交Git版本控制
