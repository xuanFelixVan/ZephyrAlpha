4.3 badge 六族（语义映射唯一表）
b-pass 通过/正常 b-fail 未过/失败 b-warn 警告/待办 b-na 演示/占位 b-buy 买/多 b-sell 卖/空

4.4 alert-row 族（v6 去框化：err/warn/info + .bad=err 别名，Owner 2026-08-28）
err：风控/数据异常（红 7% 底 22% 边——只给最重要最紧急）10:41
warn：警告/待处理（黄字无框——无底无边，🟡 emoji+黄字担语义）系统状态
info：中性提示（灰字无框——中性=--dim，不抢焦点）昨 23:51
规格：padding 8px 10px · radius 6 · 12px；时间戳右置 .t 11px --faint；第四族 .bad（禁做清单）=err 别名同规格（v6 补 CSS 定义，此前规范有实现无）。禁止：自定义第五色；实色底；warn/info 加框（v6 新规——红框唯一，视觉焦点只留最紧急）。

内容 13px · th 12px/500 #b3b3b3 · td padding 8px 12px 无行边框 · 行 hover #1A1D21 · 数字 tabular-nums 右对齐倾向 · 首列名称可 600。禁止：行边框线、斑马的第二种底色。

激活 tab未激活　主按钮　次按钮

4.7 顶栏导航与下拉
一级 14px/400 #fafafa，激活=白字+白下划线 2px（禁蓝色）；下拉=白底卡（radius 0 0 8 8）：项=标题 13px/600 #000 + 描述 12px #8A8D91，padding 9px 12px，hover #f0f1f3，active #e8f1ff+#0a7cff；品牌点击回总览；结构=市场轴（2026-08-27 Owner 拍板）：一级=全景总览/A股/币圈/数据/系统 5 组，A股=mega 双列下拉（.tb-mega 660px，左实盘右研究），组内分段=.tb-sec 组标题（13/700 黑+下发丝线）+.tb-sub 小段标（11/600 #8A8D91）；共享页=双挂制（技术分析/事件日历/宏观/外盘速览 4 页两市场下拉同现，同页不复制，高亮跟随点击侧）；规划页=.tb-di.dis 灰化+b-na badge+navDis toast 负反馈（不造假页面）。
4.8 ⓘ 注解悬浮组件（版面简洁化核心）
规则：页面副标题「——」后注解、卡标题 >14 字注解必须收 ⓘ !；保留可见清单=演示数据 badge/关键状态 badge/核心一句。禁：同一标题超 1 个 ⓘ。
4.9 ticker 横条 / toast / 状态灯
ticker：11px，涨项 --up 跌项 --down，编辑态白底搜索面板；toast：底部居中 12px --panel2 卡；状态灯：.dot 8px 圆点 g=--down（正常）r=--up（异常）y=--yellow（警告）——灯色语义锁死，禁反。
