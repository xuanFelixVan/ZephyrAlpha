## 📖 快速导航

### 核心功能

1. **AI虚拟研究实验室**: 模拟研究团队协作（GLM-4多角色）
2. **创新孵化器**: 新想法快速验证与评估
3. **学术前沿追踪**: 论文自动检索与解读（arXiv API + GLM-4）
4. **研究知识管理**: RAG知识库（ChromaDB + Embedding）

### 技术栈

- **AI研究助手**: GLM-4.7-Flash
- **论文检索**: arXiv API, Semantic Scholar
- **知识库**: ChromaDB, LangChain
- **实验管理**: MLflow, Weights & Biases
