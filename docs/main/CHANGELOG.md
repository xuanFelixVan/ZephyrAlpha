## v3.1 优化详情

### 策略目标升级

| 指标 | 原v3.0目标 | v3.1机构目标 |
|------|-----------|--------------|
| 年化收益率 | >15% | >18% |
| 最大回撤 | <15% | <12% |
| 夏普比率 | >1.0 | >1.5 |
| 索提诺比率 | - | >2.0 |
| 信息比率 | - | >0.8 |
| 胜率 | >55% | >58% |
| 盈亏比 | - | >1.8 |

### 核心架构升级

| 项目 | v3.0 | v3.1 |
|------|-------|------|
| 流水线层数 | 7层+前置 | 8层(Layer 0-7) |
| 市场判断 | 前置层 | Layer 0(独立) |
| 数学表达 | 文字描述 | 公式化定义 |
| 技术栈 | 传统技术 | 现代ML/DL/RL |
| 机构标准 | 部分参考 | 完整对标 |

### 新增内容

- 隐马尔可夫模型(HMM)市场状态识别
- Barra因子模型标准化
- Black-Litterman组合优化
- TWAP/VWAP执行算法
- 压力测试场景库
- Brinson归因分析
- 贝叶斯优化/强化学习策略迭代
