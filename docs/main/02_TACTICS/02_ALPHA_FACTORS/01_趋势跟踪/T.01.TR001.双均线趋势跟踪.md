## 战术定义

### 核心逻辑

基于短期均线与长期均线的交叉判断市场趋势，当短期均线从下向上穿越长期均线时形成金叉（买入信号），当短期均线从上向下穿越长期均线时形成死叉（卖出信号）。

### 数学表达

```
短期均线: MA_short = (1/N_short) * Σ Price_t
长期均线: MA_long = (1/N_long) * Σ Price_t

金叉条件: MA_short_{t-1} < MA_long_{t-1} AND MA_short_t > MA_long_t
死叉条件: MA_short_{t-1} > MA_long_{t-1} AND MA_short_t < MA_long_t
```

### 适用市场

- 适用场景: 趋势明确的单边市场（牛市/熊市）
- 不适用场景: 震荡市、波动剧烈的混沌市场

## 交易规则

### 入场条件

```
金叉信号 AND 市场状态 != 混沌市 AND 波动率 < 阈值
```

### 出场条件

```
死叉信号 OR 回撤 > 最大回撤阈值 OR 市场状态变为混沌市
```

### 仓位管理

- 初始仓位: 30%
- 加仓规则: 趋势延续且无背离时，每次加仓10%
- 减仓规则: 死叉前出现MA角度放缓则减仓50%

## 风险控制

### 风险指标

| 指标 | 阈值 | 处理方式 |
|------|------|----------|
| 单日最大亏损 | -3% | 自动减仓50% |
| 回撤警戒线 | -8% | 降低仓位至20% |
| 波动率上限 | 30% | 暂停新开仓 |
| 最大持有周期 | 30日 | 强制平仓 |

### 应急处理

1. 触发波动率熔断时，关闭所有趋势跟踪仓位
2. 连续3日亏损时降低50%仓位
3. 市场状态切换至混沌市时，全部平仓

### 组合建议
