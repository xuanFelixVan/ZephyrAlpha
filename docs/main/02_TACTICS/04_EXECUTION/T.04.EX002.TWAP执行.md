## 战术定义

### 核心逻辑

时间加权平均价格(TWAP)执行，将大单拆分为多个小单，在设定时间窗口内均匀分布。

### 适用场景

- 大额订单执行
- 流动性较好标的
- 对冲击成本敏感

## 参数配置

| 参数名 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| execution_hours | 4 | 1-6 | 执行时间窗口(小时) |
| num_tranches | 20 | 10-50 | 拆分批次数量 |
| max_participation | 10% | 5%-20% | 最大成交量占比 |

## 执行算法

```
每批数量 = 总订单量 / num_tranches
批次间隔 = execution_hours * 60 / num_tranches (分钟)

for each tranche:
    execute_at_current_price()
    sleep(批次间隔)
```

## 风险控制

- 市場極端波動暫停: VIX > 30
- 成交量異常暫停: 實際成交量 < 預期50%
- 價格偏離閾值: 相比開盤價偏離 > 2%
