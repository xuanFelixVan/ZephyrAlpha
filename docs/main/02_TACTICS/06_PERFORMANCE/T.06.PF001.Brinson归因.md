## 战术定义

### 核心逻辑

Brinson归因模型将组合收益分解为配置效应、选股效应和交互效应三个部分。

### 数学公式

```
总主动收益 = 组合收益 - 基准收益

配置效应 = Σ(基准权重 × (行业收益 - 基准行业收益))
选股效应 = Σ(基准权重 × (组合行业收益 - 基准行业收益))
交互效应 = Σ(主动权重 × (组合行业收益 - 基准行业收益))

总主动收益 = 配置效应 + 选股效应 + 交互效应
```
