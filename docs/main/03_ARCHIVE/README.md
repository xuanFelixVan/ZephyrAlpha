## 归档操作规范

### 归档时机

1. 主版本升级时，旧版本归档
2. 重大重构时，当前版本归档
3. 策略框架重大变更时归档

### 归档操作

1. 将旧版本文件移入 `03_ARCHIVE/{版本号}/`
2. 创建归档索引 `README.md`
3. 更新主索引 `main/README.md` 的版本信息
4. 更新 `CHANGELOG.md` 记录归档

### 归档保留

- 所有历史版本永久保留
- 便于版本对比和回溯
- 满足审计合规要求
