# L4 对比段骨架卡

## 职责一句话
一切进化提案与现状基准实打实比：产出"好在哪"的可验证证据（预注册判据下），够好才许进 L5
排产。评估者独立于施工者——运动员不兼任裁判的进化论版。

## 输入/输出
- 输入：L3 规格卡 + 现状基准（对应模块/算法的现行版本+其历史成绩）
- 输出：对比裁定（胜/平/负+证据包）→ L5 排产 或 L2 记阴性库

## 业界对应
AlphaEvolve/DGM 自动评估器（evaluators+基准实测，Sakana 论文同时记录了 objective hacking
教训=对比器必须独立且判据预注册的反面实证）；MLOps 模型评估环。

## 已有件
E4 考尺/C4 双窗批考（策略级对比器，全项目最严格的件）；基准对比=回测体系的强项；
预注册判据纪律（任务书 schema）。

## 待挖矿清单

3. 公平性规则：新候选与现状的算力/数据窗口对齐（防"新候选吃更好资源"的假胜）
4. objective hacking 防御：评估者独立性检查清单
