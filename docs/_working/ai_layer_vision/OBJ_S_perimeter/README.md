# OBJ_S 红线与自由域骨架卡（Owner 2026-09-17 口述新增）

> **Owner 总原则（原话要点，建议升格为核心定调 #13）**：所有的东西都可以让 AI 自动化，
> 只有一个东西不能碰——付费。在确保我的项目安全、且至少不亏钱（可以不赚钱，但项目至少
> 不要亏钱）的前提下，给予项目 AI 层**最大的自由**。

## 自由域定式：默认自由 + 负面清单

- 红线只列"绝对不可触碰"，**红线之外全自由**——与定调 #10"配额内门位外自由"互补：
  配额管资源，门位管权限，负面清单管禁区，其余一切都是 AI 的自由域。
- 设计含义：新增自动化能力**不需要审批**，只需要过负面清单检查（机检）+配额内。

## 负面清单 v1（绝对不可触碰）

1. **付费动作**：充值/订阅/授权的唯一确认人=Owner（AI 管预算智慧，OBJ_M M5；不碰支付按钮）。
2. **实盘资金凭证**：AI 会话环境永不发放实盘 API/QMT 实盘密钥。
3. **宪法权限语义**：§5 门位条目变更走等长替换+Owner 批准。
4. **审计链**：events.jsonl 及 HMAC 密封逻辑。
5. **验收判据自改**：施工会话无权改自己的判据。
6. **删除红线**（本轮新增设计，删除分级三档）：
   - **物理删除=Owner 门位**：生产数据删除（RULE-DATA-OPS 三步验证已有）、注册表净删
     （REGISTRY-MASS-DELETION 闸已有）、审计链、git history 重写（RULE-GIT-SAFE 已有）。
   - **退役/墓碑=AI 自动**：deprecated 链墓碑法已在案——老东西退役不删（与 L6 A/B 的
     "A 组退役不删除"同一纪律）。
   - **临时物=TTL 自动清**：.runtime/tmp 24h 已有。

## "不亏钱"的操作含义（可度量）

- **运行成本面**：账单受配额池硬约束（防进化引擎/挖矿自我加码烧钱）+日成本告警。
- **资金面**：模拟盘先行（策略不碰真钱）+五级交易熔断+实盘密钥物理隔离——全部已有，
  接进新环节即可，不发明新刹车。
- 双指标看板：日运行成本 × 模拟盘回撤——任一越限=自动降档（重活停、便宜模型顶上）。
