# OBJ_M 模型对象线骨架卡（Owner 2026-09-17 口述新增）

> **Owner 定调原话要点**：用什么 AI 也很重要。AI 升级 AI 不光升级模块，还要升级模型——
> ①API 线：全网搜有多少 AI、每家最便宜的 API 在哪、有什么活动（实战先例：ZCode 夜间
> Flash 免费=Owner 自搜到的福利）；功能满足的用免费/便宜模型，核心功能用贵模型。
> ②本地线：同样流程——搜索、清洗、入库，给 API AI 分析，再切换，A/B 组一样。
> 切换之后怎么考试、怎么证明 B 比 A 强，要有一套流程。

## 职责一句话

让系统永远跑在"当下性价比×性能最优"的模型组合上：模型情报扫描→模型库→模型考试→
A/B 切换→预算分析——**同走七段循环，模型只是循环里的又一类"被进化对象"**。

## M1 模型情报扫描（感知段的模型轨）

- 全网搜索三件事：新模型发布 / 各渠道 API 价格 / **活动与免费窗口**（免费窗=纯福利，
  实战已验证：夜间 Flash 免费支撑了 2026-09-17 通宵班）。
- 双轴评价（Owner 定调）：**性价比×性能**——功能满足的活用便宜/免费档，核心功能用贵档。

## M2 模型库（收集段的模型分表）

- 每模型登记：渠道/价格/上下文长度/强项弱项/基准成绩/免费时段/活动史/实测成本。
- 这就是分库分表里的"模型表"——与原材料库同规矩（生熟分离、查重、配额）。

## M3 模型考试（对比段——怎么证明 B 比 A 强）

三把尺，判据预注册（目标常数纪律）：

1. **能力考试**：model_capability_exam 模块已在档（蓝图在册）——标准化题型库测推理/代码/长文。
2. **同任务双跑**：真实工单抽样（如挖矿任务/翻译任务/审查任务各 N 件），A/B 干同样的活，
   比成功率/时延/返工率——这是最贴近实战的尺。
3. **成本审计**：同等产出的单价对比（结合免费时段打时间差折扣）。

## M4 模型切换（切换段）

- A/B 影子双跑→赢了才切；分场景**路由表**：什么任务路由到什么档——挖矿 SOP
  "模型分派二维法（输入体积×推理密度）"从人工经验升级为数据驱动路由。
- 本地模型线同流程（Owner 原话）：搜索→清洗→入库→API AI 分析→切换；
  本地线额外尺=显存/推理速度（GPU 排班咬合）。

## M5 预算分析机制（AI 管自己的付费）

- **AI 管付费的智慧**：日消耗分析/预算增减建议/性价比报告/免费窗口利用建议→推前端。
- **Owner 独占付费的动作**：充值/订阅/授权（四类事之一，永不代行——红线卡重申）。
- 与配额池（定调 #10）咬合：预算是配额的钱包面——配额管"能不能用"，预算管"还剩多少"。
