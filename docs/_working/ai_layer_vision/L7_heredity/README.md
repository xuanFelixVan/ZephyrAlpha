# L7 传承段骨架卡（V2 挖矿新增提案）

## 职责一句话
把每一代进化的经验结构化回写、喂回下一代：坑集/缺陷模式库（别再踩）、精英档案（胜者与
其判据）、判据档案（"当时为什么算它赢"）——六段切完不断环，闭环的关键边。

## 输入/输出
- 输入：L6 每次切换的留档（胜者/败者/判据/差异）；工单流关单记录（缺陷模式三字段）；
  红蓝对抗发现
- 输出：→ L1 感知（定向搜索的先验：哪类矿脉历史上富矿/贫矿）；→ L2 收集（查重基线+组合
  素材库）；→ L4 对比（历史判据先验，防重复考古）

DGM 代理档案库（archive 支持从任意祖先分支=回流的进化论标配，Sakana AI 2025）；
MAP-Elites 精英档案（防进化遗忘）；PDCA Act 环的标准化回写（改善不写回标准=没发生）。
