# 作战地图完善 → 四图对齐 → 施工 前置总计划

> 本文档是长篇讨论的沉淀载体，持续追加。目标是：在写第一行业务代码前，把"我们怎么赚钱"的完整流程在作战地图上补全到"细枝末节"级，再对齐，再施工。

## 0. 流程顺序纠正（2026-08-05 讨论结论）

**错误顺序**（上一轮 AI 回复隐含的）：边补功能边做四图对齐。

**正确顺序**（三阶段，严格串行）：

```
阶段A. 作战地图功能完善（含可行性标注）
   ├─ A1 缺失模块/管线完整性补全
   ├─ A2 执行顺序/流程/降级路径补全
   ├─ A3 盲点检查（业界基准对比）
   └─ A4 每个环节标注"自建/开源替代/弃用"可行性
         ↓ 地图补完整后
阶段B. 四图对齐（depgraph/dataflowgraph/decisiongraph/blueprint）
   ├─ apply_depgraph.py 登记设计态（=L1依赖先行）
   ├─ sync_panorama_module.py 派生其余3图
   └─ align_panoramas.py 验证四类问题干净
         ↓ 对齐干净后
阶段C. 施工（写业务代码，planned→production）
```

**为什么必须这个顺序**：四图对齐是验证"已有设计态之间是否一致"。作战地图不完整时对齐，结果是"一致地不完整"——假阴性，比不对齐更危险。

## 2. 阶段A：作战地图功能完善任务

### A1. 缺失模块 / 管线完整性检查

**目标**：确认 330 个环节的"⑥降级/中止""④数据流""⑤代码映射"三字段无空缺，每个环节都有上下游闭环。

**方法**：
1. 跑 `align_panoramas.py` 先拿一遍当前对齐问题清单（虽然地图还不完整，但能先暴露孤儿环节和状态漂移，作为"待补"清单的起点）。
2. 对每个设计态/候选态环节，核对：
   - ①触发条件 是否明确（含阈值）
   - ②消费数据/因子 上游环节是否真的产出
   - ③参数 是否完整（含范围、当前值、状态）
   - ④数据流 输入→处理→输出→下游 四段是否闭环
   - ⑤代码映射 模块 ID 是否在 depgraph 有对应节点
   - ⑥降级/中止 降级路径是否真能跑通（不是写了一句"降级到X"就算）

**已知缺口示例**（来自 [battle_map_04_simulation_validation.md](file:///d:/ZephyrAlpha/docs/02_enterprise_architecture/07_trading_decision_architecture/battle_map/battle_map_04_simulation_validation.md)）：

#### A3-B. A 股 T+1 特有盲点（2026-08-05 用户实战经验补充）

> **背景**：业界基准盲点（上 8 项）是通用量化系统标配，但 A 股有 T+1 机制 + 涨跌停 + 集合竞价等特殊性，催生了一批**美股/加密货币开源项目里绝对没有、必须自建**的决策环节。以下来自用户主观交易实战经验。

##### 🔴 盲点 9：明日情景预案引擎（跨日决策闭环枢纽）—— 最高优先级

**大白话**：A 股 T+1 机制下，今天能不能买/要不要卖，强依赖"对明天的预判"。主观交易老手每天都会做"明天高开/低开/平开 × 真涨/假涨/洗盘"的 N 情景应对矩阵，盘中实时重算，盘后复盘定次日方案，次日盘前加载执行。**作战地图目前把这个功能拆成 5 个碎片散落各处，缺一个把它们串成闭环的枢纽环节。**

**三段式运作**：

```
① 盘中实时推演（影响今天剩余操作）
   每15分钟重算：今天压力位过了没？尾盘走稳没？→ 明天高开/低开概率
   例：今天切过压力位 + 尾盘收好线 → 明天可能高开 → 今天加仓博明天
       今天冲高回落 + 15分钟见顶 → 明天可能低开 → 今天只卖不买 / 转防御板块

② 盘后多情境预案（明天每种走势怎么办）
   高开 × {真涨(黄线在上/科技领涨/放量), 假涨(白线在上/银行护盘/科技下砸)} → 不同出牌
   低开 × {真跌, 洗盘, 假跌} → 不同出牌
   平开 → 对应方案
   产出：明日N情景应对矩阵

③ 次日盘前应用（预案变成今天的初始策略）
   昨晚预案"如果明天高开就卖昨天加的仓" → 9:25竞价看高开 → 自动触发卖出分支
```

**作战地图现状（碎片化，缺枢纽）**：

| 实战动作 | 现有环节 | 状态 | 缺什么 |
|---|---|---|---|
| 次日高开低开概率 | BM-SEL-04 次日8态走势预测 | 🟧设计态 | 8态是否覆盖"真涨/假涨/洗盘"**质量**分类？可能只预测方向不预测质量 |
| 指数白黄线结构 | BM-SEL-03 市场状态感知 / BM-SEL-06 跨市场传导感知 | 🟧设计态 | A 股特有的"白线(权重) vs 黄线(小盘)"结构分析维度未显式登记 |
| 明天涨了/跌了怎么办 | BM-SELL-07 卖出情景预案 | 🟧设计态 | **只覆盖卖出侧**，缺买入/持仓/换防御板块预案 |
| 盘中15分钟算高点 | （无显式环节） | 🔴缺失 | 盘中微观节奏推演 |
| 盘前应用预案 | （无显式环节） | 🔴缺失 | 盘前预案加载/调度 |

**建议**：新增横切环节 **BM-PLAN-01 明日情景预案引擎**，作为跨日决策闭环枢纽。归位选择：
- **方案A（推荐）**：放 12 横切阶段，作为新环节 BM-PLAN-01，跨买入/卖出/仓位/风控
- **方案B**：作为 BM-REC-03 闭环优化反馈的"前馈"分支（闭环=复盘改进过去，前馈=预案指导未来）

**为什么必须自建**：A 股 T+1 + 涨跌停 + 集合竞价组合全球独有，开源量化项目（美股 T+0、加密货币 7×24）根本不需要这个能力，无开源替代。

##### 🔴 盲点 10：盘前预案加载与竞价响应

**大白话**：昨晚做的预案，今早盘前怎么自动加载成今天的初始策略？9:25 集合竞价出结果后怎么自动触发对应预案分支？

**现状**：作战地图无显式环节。买入/卖出阶段都默认"盘中"起点，缺盘前冷启动 → 竞价响应 → 切换到盘中模式的衔接。

**建议**：补环节 BM-PLAN-02（盘前预案调度器），或作为 BM-PLAN-01 的盘前分支。

##### 🟡 盲点 11：尾盘决策环节（14:45-15:00）

**大白话**：A 股 14:45-15:00 是黄金决策点——博明天高开就尾盘加仓，防低开就尾盘减仓，做 T 的尾盘平仓。这 15 分钟的决策逻辑和盘中其他时段不同。

**现状**：作战地图买入/卖出环节未显式区分"尾盘"子阶段。

**建议**：在 BM-BUY / BM-SELL 下补尾盘子阶段，或独立环节 BM-PLAN-03（尾盘决策）。

##### 🟡 盲点 12：涨跌质量分析（A 股指数结构维度）

**大白话**：同样是"涨"，分真涨假涨——
- 真涨：黄线在上（小盘领涨）、科技/成长板块带头、放量配合
- 假涨：白线在上（权重护盘）、银行/保险带头、科技下砸、缩量

**作战地图 BM-SEL-04 次日8态可能只预测涨跌方向，不预测涨跌质量**。

**建议**：在 BM-SEL-04 或 BM-SEL-03 补维度：

| 维度 | 指标 | 含义 |
|---|---|---|
| 白线黄线关系 | 权重指数 vs 等权指数 | 白上黄下=权重护盘假涨；黄上白下=普涨真涨 |
| 领涨板块属性 | 科技/周期 vs 银行/保险 | 科技领涨=情绪真回暖；银行护盘=防御假涨 |
| 量能配合 | 放量 vs 缩量 | 真涨需放量配合 |

##### 🟡 盲点 13：盘中微观节奏推演（15分钟级）

**大白话**：你说的"15分钟线算今天走到最顶点要回落"——这是盘中实时版的节奏推演，比日级"次日8态"粒度更细。

**现状**：BM-SEL-04 偏日级，缺盘中实时微观节奏推演。

**建议**：BM-SEL-04 的盘中实时版，或独立环节 BM-PLAN-04（盘中节奏推演）。

#### A3-C. A 股实战盲点第二批（2026-08-05 补充）

##### 🟡 盲点 14：板块轮动与接力感知

**大白话**：A 股是板块驱动型市场——今天科技涨，资金明天可能切消费；龙头股打板，跟风股接力。板块轮动节奏和接力情绪是选股和择时的核心维度。

**现状**：BM-SEL-23 游资接力情绪周期有"接力情绪4+1阶段"，但偏情绪打分；缺"板块轮动路径预测"（今天涨的板块明天还能不能持续？资金会切到哪个板块？）。

**建议**：在 BM-SEL-03 市场状态感知或 BM-SEL-06 跨市场传导感知补"板块轮动感知"维度，或独立环节。

##### 🟡 盲点 15：龙虎榜与主力席位数据消费

**大白话**：A 股盘后龙虎榜数据——机构席位买了啥、游资席位（赵老哥/章盟主等）进了哪个票。这是次日选股的重要信号源。

**现状**：grep "龙虎榜" 确认作战地图是否登记为数据源/因子。BM-SEL-23 游资接力情绪偏情绪模型，可能没消费龙虎榜席位数据。

**建议**：确认龙虎榜数据是否进 L1 因子层；若未进，补为 L1 因子（机构席位净买/游资席位识别/席位胜率）。

##### 🟡 盲点 16：涨跌停板生态专项处理

**大白话**：A 股涨跌停板是全球独有的微观结构——封板/炸板/撬板/排队/次日溢价。打板策略、接力策略、跌停出货策略都围绕这个生态。

**现状**：BM-SEL-22/23 有连板/封板/打板评分（运营态），BM-SELL-07 有"涨跌停排队预案"，但缺"涨跌停板生态全局感知"——比如今日炸板率、连板梯度、首板/二板/三板晋级率、跌停家数（情绪冰点信号）。

**建议**：补"涨跌停板生态感知"环节，作为市场情绪的硬指标，喂 BM-SEL-03 市场状态感知。

##### 🟡 盲点 17：融资融券与北向资金实时监控

**大白话**：两融余额变化、北向资金净流入流出是 A 股两大主力资金信号——融资客加仓=情绪乐观，北向流出=外资减仓。

**现状**：grep "融资融券\|北向\|沪股通\|深股通" 确认是否登记为因子。

**建议**：确认是否进 L1 因子层；若未进，补为资金流因子（两融余额变化/北向净流入/行业资金流向）。
