## C. 工具失败 ≠ 阴性结论

| # | 纪律 |

| **C1** | 判负前**先看 exit code**：`exit 0` + 空输出 = 真零命中（**唯一**允许读作"不存在"）；`exit 1` = rg 无匹配；`exit 2` = 路径不可读（结论作废，绕障重跑）；`exit 143/SIGTERM` = 超时（结论作废，换方法）。**pipe 用法默认吞退出码 ⇒ 工具失败会伪装成阴性结论**（gp-7 原话） |
