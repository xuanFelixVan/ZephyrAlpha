## 0. 结论速览（一页版）

1. **图谱真源资产比 assumed 的厚**：PostgreSQL depgraph 库 14 张 ig_* 表。皇冠资产=`ig_company_edge`（58,207 行，公司→公司供给边，带方向/权重/revenue_pct/transmission_type/容量/独占性/PIT 三时间戳）+ `ig_io_edge`（16,859 行，官方 153 部门投入产出系数）+ `ig_node_company`（18,819 行，公司×环节×角色×PIT）。**这些是有方向、有强度、有 PIT 的真数据，不是画出来看的图。**
2. **交易侧消费现状：几乎没消费，但半成品比想象多**。真消费仅 4 处：MOD-SIG-118（production 档传导动量因子模型，未挂策略）、TDM W3/W4 新闻事件链两模块（已通线、`strategy_mounts=[]`）、`three_high_screen.py`（E1D 车道研究候选）、`backtest_supply_leadlag.py`（客户→供应商方向 lead-lag 回测原型）。**结论：本方案不是开新战场，是把已有半成品接进 E4 考试管线拿证据。**
3. **因子化路径按可信度排序：传导链（P1）> 催化剂事件（P2）> 链位置拓扑（P3 降级）**。核心约束=图谱时点：边表有 PIT 列（可用），但链条目 valid_from 多为 2026-09 录入日，**静态拓扑因子的历史回测有前视硬伤**，只配模拟盘前哨+横截面辅助，不进 E4 历史正考。
4. **最可量化的链=生猪养殖链**（仓内唯一自有商品价格三件套：`hog_spot_index` 周度+`hog_futures_core` 期货日频+`hog_province_spot` 分省现货），其余链的上游价格用"上游龙头股票组合/申万指数"代理（零新增数据即可开工）；碳酸锂/硅料等现货采购本期不做（登记不动手）。
5. **战略价值定位**：链因子单兵大概率弱（预期 IC 0.02-0.05 量级），价值在**给 Sharpe1→2 组队（A2 任务）供低相关 sleeve**——产业链暴露与价量/财报/情绪因子相关结构性低，是组队弹药库的正确补货方向。
6. **算力总账：全 CPU 工种，小时级**。因子构造与快检分钟-小时级；E4 考试复用现有 WFA 通道（整装回测实测 36.8s/次量级，8 折全窗）；**零 GPU 需求**。瓶颈不在算力，在 E4 队列排队与 Owner 门位。

## 2. 因子化路径（假设→数据表→可信度）

### 2.0 横切总约束：图谱时点（PIT）

- 边/落位表带 valid_from/valid_to/as_of（可用），但**链条目 valid_from 多为 2026-09 录入日**：任何"用今天拓扑回测五年前"的做法=前视。
- 处置口径：①传导链因子对拓扑误差最不敏感（只需"谁是谁的上游"，结构变化慢），边样本按 `ig_company_edge` 披露滞后规则取（year=Y 自 Y+1-05-01 可用，原型已实现）；②事件因子只用事件时点当时已入图的链做映射，历史段用前哨滚动验证补足；③静态拓扑因子降级（§2.3）。
- **可信度总排序由此决定：传导 > 事件 > 拓扑。**

### 2.1 传导链因子（P1：主力，先开工）

**ICA-1 上游成本冲击因子（上游→下游方向，leadlag 原型的反向补全）**
- 假设：上游组合 20 日收益（涨价冲击）经链暴露传导，高暴露下游公司未来 5-20 日相对收益承压（β<0 组）；转嫁能力强（毛利率稳/提价能力）者不承压。与已有"客户→供应商"原型合成双向传导谱。
- 数据表：`ig_company_edge`（revenue_pct 作暴露权重）+ `ig_node_company`（上游龙头组合成分）+ `kline_daily`/`kline_index`（收益与行业中性化，`industry_class` 申万映射）。
- 可信度：**中**。成本传导有文献与常识支撑，原型基础设施全在；但 A 股定价快、传导常被提前交易，预期单因子 IC 弱-中，更适合做条件因子（配合上游大波动 regime）与异常预警（MOD-SIG-118 已有 2σ 标记位）。

**ICA-2 成本挤压事件因子（涨价×无转嫁的交集）**
- 假设：上游组合 20 日涨幅>阈值 且 下游公司毛利率同比下行（无转嫁证据）→ 未来 5-20 日负超额显著大于仅满足一条者。
- 数据表：同 ICA-1 + `ig_company_metric`（毛利率 PIT）或 fingov M1 派生层（DS-230，已落 297,535 行）。
- 可信度：**中低**。方向明确但复合条件样本薄，财务 PIT 对齐要过 LookAheadBiasDetector；预期作为 ICA-1 的增强层而非独立因子。

**ICA-3 生猪链量价传导（自有独家数据的差异化因子）**
- 假设：猪价（现货/期货/分省）趋势与斜率 → 养殖/饲料/动保/屠宰各环节分层响应，猪价上行期养殖股弹性结构可分层；出栏均重/仔猪-生猪价差等结构信号有领先性。
- 数据表：`hog_spot_index`+`hog_futures_core`+`hog_province_spot`+`kline_daily`+`ig_node_company`（养殖链环节锚定成分）。
- 可信度：**中-中高**（P1 里最高）。商品逻辑最干净、数据独有免费、产业链环节清晰；代价是猪周期宏观属性强，**更可能产出 regime/择时因子而非选股因子**——这恰好是组合层（regime 输入）稀缺货。

**最可量化链排序（开工顺序建议）**：①生猪养殖链（价格自有 100% 就绪）→②动力电池/锂电链（图谱质量最好：变体归并收官+IO 强档实证，上游价=上游龙头组合或 `futures_kline_qmt` 碳酸锂合约若覆盖）→③电子/半导体链（IO 系数最强档：电子元器件→计算机 0.52/通信设备 0.38/零部件→整车 0.30，上游价=申万电子/龙头组合）。

### 2.2 催化剂事件因子（P2：次优，依赖事件质量）

**ICC-1 链上硬事件→关联标的响应窗**
- 假设：链上"硬事件"（涨价/停产/缺货/大额订单/产能投放，**排除软情绪类**）D0 发生，经 `chain_impact_resolver`（BFS≤2 跳）映射关联标的，D+1~D+5 存在超额响应且随跳数衰减。
- 数据表：`c1_market.calendar_event`（带事件日期）+`fund_news_data`（publish_time）+ig_*（映射）+`kline_daily`（事件研究）；抽取通道=`graph_enrich_staging`（MOD-BT-193，新闻→LLM 抽供应链关系→暂存台账，入正图须 Owner 另批）。
- 可信度：**中**。事件驱动在 A 股证据较多、映射器现成；**两个已知雷**：①热度传导已被证伪裁定（月 IC=-0.029）——本假设只做硬事件、不做热度；②新闻表历史回溯深度/PIT 完整性未验——开工前先做数据就绪检查，不达标则事件回测从入库日向前滚（前哨模式）。

**ICC-2 关联半径衰减标定**
- 假设：一跳响应显著、二跳减半以上、三跳归零 → 用衰减曲线给 `supply_chain_momentum`/事件映射定 association 半径（调参证据件）。
- 数据表：同 ICC-1。
- 可信度：**中低**。是"标定件"不是独立因子，但直接影响 P1 因子的边权设计，值得顺手做。

**ICC-3 供给冲击方向因子**
- 假设：同一事件对链上不同位置标的方向相反（上游涨价利好上游/利空下游），方向×敞口加权组合能分离出纯净的链暴露溢价。
- 数据表：ICC-1 事件集+`ig_company_edge` 敞口+`ig_product_revenue`（产品营收占比定方向）。
- 可信度：**中低**。依赖事件抽取质量与方向标注，建议随 ICC-1 同批出证，不单列排期。

### 2.3 链位置因子（P3：降级，不进 E4 历史正考）

**ICB-1 链核心度/议价权拓扑溢价**
- 假设：PageRank/核心度/上下游度比高的公司（链主/卡脖子环节）长期超额。
- 数据表：`ig_edge`+`ig_company_edge`+`ig_io_edge`（拓扑即可）。
- 可信度：**低**。PIT 硬伤（§2.0）+A 股静态网络因子实证弱。**处置=不进 E4**：改做两件便宜事——(a) 当前横截面分层画像（给 E7 前哨与人工复盘用）；(b) 随模拟盘滚动积累样本，攒够前哨证据再议。
**ICB-2 议价权财务因子（链条件版）**：占用上下游资金强度（(预收+应付-应收)/营收 类）×链位置条件。可信度**中**（财务证据较硬），但**归属 F2 财报八因子线**做增量（§3），本方案只供暴露矩阵。
**ICB-3 IO 系数行业传导先验**：`ig_io_edge` coefficient 作行业轮动/风险预算的传导先验（非个股因子）。可信度**中**（官方数据硬、2020 表时滞 5-6 年=慢变量），适合做组合层输入而非考试因子。

## 3. 与既有线的分工边界

**判据一句话**：信号只需要"一张表+时序算子"=另类数据挖矿线；需要"表×图的关联"（谁是谁的上游、事件波及谁）=本方案（图）。

| 边界对象 | 归属 | 本方案动作 |
|---|---|---|
| 单表另类数据（千股千评/运价/水库/恐贪/BDI/涨停情绪等） | 另类数据挖矿线（C-1 五件套已建） | **不碰**；本方案产出暴露矩阵供其"价格类信号向下游扩散"时做握手 |
| 价量技术指标（tilib 指标库）/K 线形态（图形库） | 各自既有线 | 不碰 |
| 财报因子（F2 八因子：含议价权/账期类） | F2 线 | 本方案供 `ig_company_edge` 暴露矩阵作链条件；ICB-2 若 Owner 批由 F2 线施工 |
| 软情绪/热度类链上信号 | 另类数据情绪线 | 不碰（热度传导已证伪在案） |
| 硬事件抽取与链上映射（涨价/停产/产能） | **本方案**（复用 MOD-BT-193 暂存台账+链映射器） | 施工时走既有通道 |
| 链暴露矩阵（stock×链环节×方向×强度，派生数据件） | **本方案唯一新增基础设施** | 唯一需要新建的公共件，一次建成三方共用（P1/P2/F2 条件层） |

**本方案在工厂图上的位置**：不新建车道——E1D 车道（产业链三高/BOM/ig_fact 供应链图谱）已存在，本方案=E1D 的因子化施工方案与升级路线（数据源从 CKG2021 ig_fact 升级到 ig_company_edge 系）。

## 4. 落地路径与算力预算

### 4.1 复用管线（不建新考尺、不建新通道）

```
假设登记(mining_sop 台账/lane CSV) → E2 预审(factory_intake_pipeline)
→ E3 构造(factor_mining_whitelist 白名单算子) → E4 考试(f06_e4_wfa_exam
MOD-BT-211: IS 2020-2023 冻结窗+OOS 2024-2026, 8 折, DSR/PBO)
→ C6 晋升(intake: BH-FDR q0.10→ρ>0.6 聚类→strategy_registry 追加 candidate)
→ PP-001 配比 → E7 模拟盘前哨 → Owner 门位(入库/挂策略)
```

### 4.2 每类因子步骤账

**P1 传导链（约 4 步/类，1 个新基础设施件）**
1. 链暴露矩阵构建件（唯一新件）：ig_node_company+ig_company_edge+ig_io_edge → 派生表（stock×上游源×方向×强度×PIT）。数据侧脚本+DDL 登记，1-2 个工作日。施工前走 RULE-DEPGRAPH `--add-design-node` 登记。
2. ICA-1/ICA-3 因子件+单因子快检（IC/分层/容差样本感知，复用 leadlag 原型骨架）：2-3 个工作日。
3. E4 排队考试：按现有考尺，单配方全窗 8 折（整装回测 36.8s/次量级实弹），墙钟以 E4 队列为准；与 A1 重考任务共队列需错峰（登记 process_reaper_keep+排班表）。
4. C6 晋升/组队建议书输出（对接 A2 低相关组队任务）。
- 谁做：因子施工=本线施工班（flash 班规格）；考试=E4 通道自动；入库/挂载=Owner 门位。
- 排期建议：生猪链先行（数据零依赖），W1 暴露矩阵+W2 因子快检+W3-4 E4+晋升评审；锂电/电子链随后滚动。
