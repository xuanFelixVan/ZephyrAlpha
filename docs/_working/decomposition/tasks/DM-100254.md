## description

**原任务（已过时）**：对齐 SQLite depgraph.db 架构三表（domains/arch_domain_layers/arch_domain_capacity）域数。P2 PG 迁移后 `arch_domain_layers`/`arch_domain_capacity` 表在 PG 中不存在，原任务目标不适用。

**重新定义（2026-07-03）**：对齐 PG depgraph 所有含域引用列的表的域引用一致性。PG 实际含域引用列的表（动态发现 9 张）：
- `domains`（domain_id 主键）
- `nodes`（domain_id 引用）
- `arch_path_mappings`（domain_id 引用）
- `arch_directory_tree`（domain_id 引用，有 FK 约束）
- `domain_mapping`（domain_id 引用）
- `domain_dependencies`（from_domain/to_domain 引用）
- `arch_constraints`（from_domain/to_domain 引用）
- `domain_events`（source_domain/target_domains 引用）
- `rule_bindings`（domain_id 引用）
