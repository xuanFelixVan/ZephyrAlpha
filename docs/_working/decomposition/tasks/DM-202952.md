## description

根因：PG depgraph 的 rule_bindings.domain_id 列 DEFAULT ''::text（schema 默认值设计为空字符串而非 NULL），导致全表73行 domain_id 全为空字符串（覆盖 TRAE-001~053 共53个规则绑定，全是横切操作不归属单一域）。治根：修改 schema 默认值为 NULL 消除根因，并将73行空字符串更新为 NULL。施工步骤：先 git commit 备份depgraph全景图(铁律)，再执行 ALTER TABLE rule_bindings ALTER COLUMN domain_id DROP DEFAULT 消除根因，然后执行 UPDATE rule_bindings SET domain_id=NULL WHERE domain_id='' 清理73条脏数据，最后运行 check_pg_domain_consistency.py 验证空字符串脏数据归零。验收标准：check_pg_domain_consistency.py 报告空字符串脏数据=0 且整体健康度 PASS，rule_bindings.domain_id 无空字符串默认值。风险极低：domain_id 无 FK 约束、rule_bindings 未被任何表引用、横切规则本应 NULL。
