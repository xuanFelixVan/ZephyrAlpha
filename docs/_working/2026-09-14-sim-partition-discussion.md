# 模拟盘分仓专题·讨论材料（Owner 关切直答版）

> 2026-09-14 班备稿｜背景：恐慌反弹（STR-VREV-025）已批入 sim 名单，未来多策略排队等模拟盘。
> Owner 核心关切原文：**"钱全部混在一起，没办法知道哪个策略赚钱还是亏钱"**——本文全部围绕这一句。

## 1. 一句话目标

每个策略一个**独立核算的钱包**：各自的入场资金、各自的虚拟盈亏曲线、各自的衰减监控——
合并报表看总账，拆开报表看谁行谁不行。

## 2. 分仓模式三选一（核心决策点）

| 方案 | 做法 | 优点 | 缺点/风险 |
|---|---|---|---|
| **A. 单实盘账户+虚拟子仓（推荐）** | QMT 模拟账户还是一个，账本层（DB）按策略拆虚拟钱包，每笔成交挂策略号 | 不动 QMT 侧、施工量最小、天然支持几十个策略并存 | 撮合是真实账户合并的（同一时刻两策略买同一只票会合并持仓）——归因需按"虚拟成交对"拆 |
| B. 多模拟账户 | 每策略开一个 QMT 模拟子账户 | 隔离最彻底，各账户独立资金曲线 | QMT 模拟子账户数量/开卡流程受限（需实机验证），桥接改造大 |
| C. 纯账本模拟（无实盘撮合） | 完全不碰 QMT，信号产生后按次日价格虚拟记账 | 最快上线、零桥接风险 | 少了真实撮合/滑点/废单检验——**检验力弱一档**，更像回测加长 |

**推荐**：先 C 后 A 两步走——第一步用 C（账本模拟）立即让恐慌反弹跑起来（数据质量足够回答
"信号在活行情里对不对"）；第二步做 A（虚拟子仓+真实撮合）作为基建升级，供后续策略复用。
B 仅当 A 验证后归因仍有争议才考虑。

## 3. 资金分配规则（Owner 提的 100 万/50 万怎么定）

- **初始额度建议**：恐慌反弹 100 万（三窗全绿+体检通过，给第一档）；后续策略按
  双窗口门槛成绩分档：双绿+DSR≥0.3 → 100 万档；双绿但 DSR<0.3 → 50 万档；仅单窗绿 → 不入模拟盘；
- **额度即仓位上限**：策略虚拟钱包最多用满自己的额度，禁止越界（等价于回测里的 max exposure）；
- **再平衡**：模拟阶段不建议（干扰归因）；额度调整=Owner 批次的册子动作。

## 4. 归因口径（必须先钉死，否则白测）

1. 每笔成交挂 `strategy_id`（虚拟钱包键）；
2. 盈亏=钱包内 T+1 可实现口径，与回测同成本公式（冻结土规：2.5bp+10bp+5bp）；
3. 每日收盘出三张表：分策略日收益 / 分策略累计曲线 / 全账户合并曲线；
4. **回测 vs 模拟盘对照线**：模拟盘跑满一个月即生成"偏离报告"（信号一致性、成交价偏差、
   漏单率）——这是模拟盘存在的意义。

## 5. 与 QMT HTTP 桥的对接

- 现状：桥已通（行情/交易 HTTP 化），实盘终端 Owner 手动登录；
- 模拟盘复用同一桥：下单接口打模拟账户标识即可（方案 A/C 甚至初期不用下单接口——C 完全不碰桥）；
- 桥断线处理：模拟盘信号照常产生、记账照常，成交回报缺失的时段标记 degraded（宁缺毋错）。

## 6. 施工路径（按 construction_workflow_sop 15 步走）

第一步（账本模拟 C）= 1 个新模块（sim_paper_ledger：信号→虚拟成交→钱包记账→日报）+1 张新表
（sim_pocket_daily：策略×日期×虚拟持仓×盈亏），涉及 3 张既有表只读引用——标准 15 步施工，
预计一个夜班班次；第二步（虚拟子仓 A）= 桥接层改造，另立批次。

## 7. 请 Owner 拍板的决策点清单

1. 分仓模式：接受"先 C 后 A"两步走，还是直接上 A/B？
2. 恐慌反弹初始额度 100 万是否认可？
3. 模拟盘成绩与实盘资格的挂钩规则（跑多久、偏离多少算过/废）是否授权我起草？

## 附：模拟盘→实盘晋升规则（v0.1 草案，Owner"继续施工"授权起草，2026-09-14）

> 三决策点之③落地。晋升判定全部工具化可查（bothwin/bothwin+sim 段），非纸面条文。

### 晋升硬门槛（sim → paper 实盘跟单候选，全部满足）

1. **模拟盘在跑时长 ≥ 3 个自然月**（不足不评）；
2. **双窗口门槛持续成立**：IS+OOS+第三窗 Sharpe>0 且年衰减率<0.5（bothwin 通过）；
3. **模拟盘偏离报告合格**（每月出一次，三项全过）：
   - 信号一致性：模拟期触发信号与回测同窗口信号重合率 ≥ 90%；
   - 成交偏差：实际成交价（模拟盘撮合价）与回测假设收盘价偏差 ≤ 0.5%；
   - 漏单率 ≤ 2%；
4. **回撤约束**：模拟盘期间钱包最大回撤 ≤ 回测同期最大回撤 × 1.5；
5. **无人工干预记录**（期间未因 bug/数据问题手工修账——修过则计时重置）。

### 降级/废规则（任一触发）

- 年衰减率 ≥ 0.5 → 降 monitoring（观察），连续两月 ≥ 0.5 → 废；
- 模拟盘亏损超过回测最大回撤 × 1.2 → 废（回测说最坏 -12%，模拟盘 -20% = 课本没写的风险出现了）；
- 连续 3 期偏离报告不合格 → 废。
