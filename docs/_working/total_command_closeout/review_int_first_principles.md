## §三 唯一根因陈述 + 只留 5 个工序

### 3.1 四个症状是同一个病的四个投影

方案把"提交链慢 / 死信 701 / 热册蒸发 / 交接书失真"当四个病分族治（族 2、W-27、W-121、W-28）。第一性原理下它们是**同一个根**：

> **唯一根因陈述：本系统的"状态真值"由叙述载体（交接书、台账、自述绿、车道盘面）承载，而唯一的机械真值面（git HEAD + 注册表）被多写者以"整文件快照 + 单写者串行队列"方式共享，且全链不存在任何事件触发的"声称↔库内"机械对账器。**

拆开是三个耦合缺陷，缺一不可地共同产出全部四症：

| 缺陷 | 机制 | 产出哪个症状 | 方案内自证锚 |
|---|---|---|---|
| D1 全文件快照式合并 | 热册以整文件为合并单元（ours/整覆写），无键级保护 | **热册蒸发**（16 条 token 被陈旧快照抹掉）、毒袋（同 id 双条整册撞身份键） | 02 册 X-13；00 册 W-121/W-20；车道纪律 §4"缺省=无基底校验，整文件快照会静默回退他人条目——R-074 实测 13 件、C-16 六次复现" |
| D2 单写者串行 + 全仓扫描型门禁 | 一切落地挤一条队列，每袋付全仓门禁成本；袋死因对袋主不可见不可修 | **提交链慢**、**死信堆积**（701 封；pending=0 而 25 条车道 dirty 数百项零 commit——不是没活，是活不敢进队列） | 00 册 §一行 22；10 册波 1.5；02 册 X-01（7 袋死因 13 类）；02 册 §七 |
| D3 叙述型状态载体 + 零对账 | "已完成/已批准/已接入"写在散文里，无机械尺在落地事件上核对 | **交接书失真**（取号器/对账尺"已在册"vs HEAD 查无——本审 `git show HEAD:` 复测两者确不在 HEAD；"12 项已批项已实现"vs 31 件不存在；"Owner 已批准"册上查无） | 01 册 X-7/X-1；02 册 X-29；94 册 §三"40 处改判里 26 处同根" |

关键推论：**D3 是 D1/D2 的放大器**。因为状态靠叙述，车道才敢囤积数百 dirty 件不落地（叙述上"已完成"）；因为不落地，才需要波 0 快照抢救；因为抢救靠人读案卷，才有 41 把尺里大量"命令+期望读数"人肉三元组。**方案在 00 册行 12 已写下正解（"落地只认 git show HEAD: 的字节"）、在 94 册 §三 已自己指认 G-05 为"最治本一条"——但只把它当一把验收尺（人跑），没有把它升格为事件触发的常设对账器**。这是全方案最大的"知道病根却开症状药"。

### 8.2 为什么会积累 11 份互相矛盾的交接书（结构因，非态度因）

1. 交接产物=手写散文，无机器生成约束（写"已完成"零成本、零核验）；
2. 车道囤积不落地（25 条零 commit），交接书描述的是他人不可见的工棚面；
3. "完成"声称与 HEAD 无机械对账（D3）；
4. 工作项无单一注册表（W-xx/ARCH-xxx/各战役册三套编号并行，X-57 实证同域双册）。
⇒ 每班产出一份"以本班视角、对本班盘面、无对账义务"的叙述，11 班=11 个平行真源。**合并这 11 份的方案自己又产出了 5+4 册散文与一层 override（02 册）——形态学上它是第 12~20 份交接书**，只是纪律更好。

### 8.3 防重演的机制级处方（非"下次仔细点"）

1. **交接书=生成器产物**：会话收尾事件触发，从 claim 台账+队列回执+git log+G-05 对账结果机生"事实段"；手写只准出现在"分析/建议"段且段落头标注"未对账叙述"。"已完成"三个字只能由对账器写出（fail-loud）。宿主：§四-4 的 reconciler。
2. **车道账龄尺**（新，方案没有）：dirty>N 且自有 commit=0 且账龄>24h ⇒ warn（>72h ⇒ block 该车道新写入）。先例同构：stash_accumulation_gate（>20 warn/>40 block，头注实测）。它从源头消灭"抢救"这个工序类别——波 0、族 1、波 2 未来都不再需要。
3. **W 册 YAML 化并入议题册宿主**，W↔#ARCH 双向键；G-70 读机生面。工作项从此只有一个可机检的真源。
4. **口径覆盖链机械化**：改判事件（X-xx 落盘）触发在被改条目原位追加指针行；"当前生效口径"可一键生成。消灭"读 01 §2 拿到已撤案 Z-07"这类陷阱（§六-1）。
5. **保留方案已有的两件正解**：取号器（W-55）与"落地只认 git show HEAD:"判读铁律——后者升格为工序 1（§三）后即不再是纪律而是机制。

做完 1+2，"N 份交接书合并"这个战役类别整体退役：不存在需要合并的叙述，因为叙述不再承载状态。
