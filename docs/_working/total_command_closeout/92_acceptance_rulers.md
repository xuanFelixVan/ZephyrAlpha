## 五、尺自身卫生（防"用假尺量出真结论"）

1. **三套 hash 口径不可互引**：bytes-sha ≠ git-blob-sha ≠ 文本 `content_sha256`；引用他人登记的 hash 前先双口径复算。
2. **worktree 内裸 python 导入主区包＝假绿源**：任何在车道里跑的尺，必须先 `export PYTHONPATH="$PWD/src"` 并 `python -c "import zephyr;print(zephyr.__file__)"` 自证。
3. **量纲先验**：判"矛盾"之前先确认两数是否同一对象（本窗四例：122/132/151、52/73、99/103/96、10/9/12）。
4. **静默失败面禁用**：`ch_writer.query` 异常返回 `""` 的读数一律降一级证据；`-q` 叠加会吞 pytest 计数；`| tail` 吃退出码。
5. **活树上两轮一致不算认证**：终验必须冻车道后在**落地面**复跑。
6. **自审不能替自述签字**：执行者报的凭据必须复核（本窗实测两条自述与盘面不符、一处"脚本存在"实为不存在）。
