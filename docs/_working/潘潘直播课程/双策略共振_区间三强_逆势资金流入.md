## 0. 摘要（TL;DR）

| 维度 | 区间三强策略 | 逆势资金流入策略 | 双策略共振 |
|---|---|---|---|
| **本质** | 多时间尺度相对强弱（板块筛选） | 大盘下跌时的逆势资金捕捉（个股时机） | 强势板块 × 逆势个股 = 高置信度买点 |
| **回答的问题** | 买什么板块？ | 什么时候买、买哪只？ | 板块强势 + 个股逆势 = 同时确认 |
| **时间尺度** | 日级（N日收益、均线系统） | 3秒 Tick 级（实时） | 日级筛选 + 3秒级触发 |

## 1. 策略一：区间三强策略

### 1.1 原始口诀定义（来源：分析师语音）

> **强于大盘的板块判断标准——"区间三强"，三者同时满足：**

| 维度 | 口诀判断标准 |
|---|---|
| **区间强** | 阶段涨幅大于大盘 |
| **结构强** | 突破关键压力位（如 3·20 大阴线高点），5/10/20 日均线多头排列 |
| **单日强** | 当日涨幅强于大盘 |

> 三者同时满足时，在该板块中走出强势龙头、连板、主升浪结构的概率全面增大。

### 1.2 量化映射（专业机构做法）

"区间三强"本质是**多时间尺度相对强弱**——在不同时间尺度上跑赢大盘。专业机构用 Relative Strength (RS) + Cross-Sectional Momentum Rank 量化，而非"三强"口诀。

| 功能点 | 量化方法 | 阈值/判定 |
|---|---|---|
| 区间相对强弱 | `RS = 板块N日收益 / 大盘N日收益` | `RS > 1.2` = 区间强 |
| 结构相对强弱 | 价格 vs 均线系统（5/10/20 日多头排列）+ vs 前高突破 | 均线多头 + 突破前高 = 结构强 |
| 单日相对强弱 | `Alpha = 当日板块收益 − 大盘当日收益` | `Alpha > 1%` = 单日强 |
| 综合 RS 评分 | `Score = w1×RS + w2×结构得分 + w3×单日Alpha` | IC 加权（非等权） |

### 1.3 延伸因子：历史新高因子

创历史新高的板块/个股 → 左侧无压力位 → 大资金阻力最小。

> 大资金的审美是阻力最小的方向，只有散户才觉得越低越安全。

### 1.4 板块内选股流程（5步漏斗）

1. 在大盘阳线时找涨停的个股（强于大盘）
2. 从中筛选 5 日均线 > 10 日均线的（均线多头）
3. 再找昨天阳线力度比大盘强的（身位优势、结构强）
4. 叠加"区间三强"板块条件进一步压缩范围
5. 板块内个股区间涨幅 > 板块指数区间涨幅的为板块内强势股

### 1.5 实战示例（语音原文）

当时仅 3 个板块满足"区间三强"：
- **通讯设备** — 已创历史新高（左侧无压力位）
- **光通讯** — 已创历史新高
- **CPO/光模块** — 突破 3·20 高点，距历史新高还有差距

算力板块内部分化：
- 数据中心/算力租赁：仅单日强，未突破 3·20 高点 → 一把梭哈后芭比Q
- 液冷：已突破 3·20 高点 → 算力内部走连板龙、高度龙概率最大

### 1.6 系统归属

| 维度 | 值 |
|---|---|
| 来源 | 分析师语音 |
| 优先级 | 高 |
| 分类 | 新增功能（架构文档原无） |
| 建议归属层 | L1 因子计算层 + 选股流 |
| 跨域编号 | A1·L2-C → `MultiDimensionalRS(区间RS+结构RS+单日Alpha)+IC加权` |

### 1.7 单策略局限

- 仅日级筛选，无法捕捉盘中入场时机
- 不区分"抗跌"与"逆涨"
- 缺乏资金流验证（板块强势可能已被主力出货）
- **解法**：与逆势资金流入策略共振，由后者提供实时资金流验证

## 2. 策略二：逆势资金流入策略

### 2.1 核心逻辑

> 当大盘指数在 3 秒级别持续下跌时，绝大多数标的跟随下跌，但少数标的的资金流向与大盘方向相反——这些逆势标的背后是**主力资金在主动买入**。
>
> 逆势越强、持续时间越长、级别越高（个股→概念→板块），信号越有价值。

3 秒级 Tick 数据使这一识别从"4分钟事后确认"升级为"3秒实时捕捉"。

### 2.2 大盘下跌状态实时判定

| 功能点 | 说明 | 示例 |
|---|---|---|
| 大盘分时下跌状态检测 | 3秒级检测上证/深证/沪深300分时走势方向 | 连续6个 Tick（18秒）绿盘下行 |
| 下跌强度分级 | 缓跌 / 中跌 / 急跌 | 急跌 = 3秒跌幅>0.1% 或连续3个 Tick 阴线 |
| 下跌持续时间窗口 | 记录下跌持续时间，用于逆势信号强度评估 | 已持续下跌15分钟 → 逆势标的含金量更高 |
| 大盘下跌 vs 震荡区分 | 下跌 = 分时低点不断下移；横盘震荡不算 | 横盘震荡中逆势信号意义不大，过滤掉 |
| **逆势扫描激活条件** | 大盘进入"中跌"及以上时才激活扫描 | 缓跌时噪音太多，不激活 |

### 2.3 个股级逆势资金流识别

| 功能点 | 说明 | 示例 |
|---|---|---|
| 个股资金流向3秒级计算 | 基于 Level-2 逐笔：3秒内主动买入金额 − 主动卖出金额 = 净流入 | 主动买500万 − 主动卖200万 = 净流入+300万 |
| **逆势强度量化** | `个股资金净流入 / 大盘同期跌幅 = 逆势强度比` | 净流入+300万 / 大盘跌0.05% = 逆势强度6000 |
| 逆势持续性判定 | 连续 N≥5 个 3秒 Tick 资金净流入为正 → 逆势持续 | 连续10个 Tick（30秒）净流入 → 持续性强 |
| **抗跌 vs 逆涨区分** | 抗跌 = 跌幅远小于大盘但仍跌；逆涨 = 不跌反涨 | 逆涨信号强度 > 抗跌 |
| 逆势个股实时排行 | 全市场7000只按逆势强度比排序，输出 Top N | 1.XX股份 2.XX科技 3.XX电子... |
| 板块归属关联 | 每只逆势个股自动关联所属板块和概念 | XX股份 → 通讯设备 / CPO |

### 2.4 板块/概念级逆势资金流识别

| 功能点 | 说明 | 示例 |
|---|---|---|
| 板块级资金净流入聚合 | 板块内所有个股3秒级净流入求和 | 通讯设备30只合计 +5000万 |
| 概念级资金净流入聚合 | 概念内所有个股3秒级净流入求和 | CPO概念15只合计 +3000万 |
| 板块逆势强度比 | `板块资金净流入 / 大盘同期跌幅` | +5000万 / 0.05% = 100000 |
| **板块逆势覆盖率** | `板块内逆势个股数 / 板块总个股数` | 30只中18只逆势 → 覆盖率60% |
| 板块逆势持续性 | 连续 N 个 3秒 Tick 板块净流入为正 | 连续20个 Tick（1分钟）净流入 |
| 三级逆势排行输出 | 板块 → 概念 → 个股 三层排行 | 板块Top3 / 概念Top3 / 个股Top10 |

### 2.5 信号分级与过滤规则

**信号强度分级**：按"逆势强度比 + 持续时间 + 覆盖率"综合评分

| 等级 | 判定 |
|---|---|
| 强 | 逆涨 + 持续 > 1分钟 + 覆盖率 > 50% |
| 中 | 逆涨 + 持续 30秒~1分钟，或抗跌+持续>1分钟 |
| 弱 | 仅抗跌 + 持续 < 30秒 |

**过滤规则**：

| 过滤项 | 规则 | 原因 |
|---|---|---|
| 流动性过滤 | 成交额 < 阈值的标的剔除 | 流动性差的逆势是噪音 |
| 尾盘逆势过滤 | 14:30 之后降权 | 尾盘可能是做市值而非真实意图 |
| 开盘逆势过滤 | 9:30-9:35 降权 | 开盘竞价数据不稳定 |
| 涨停板过滤 | 已涨停封板的标的剔除 | 买不进去 |
| **大票大单降权** | 沪深300成分股大单资金流信号降权50% | 算法拆单导致大单因子在2021年后失效 |
| **上涨时小单降权** | 大盘上涨时小单逆势信号降权 | 散户追涨行为对股价有反向预测作用 |

### 2.6 学术对标：财通证券 IRCF 因子

财通证券《股票涨跌情境中机构与散户的逆向资金流》提出的 IRCF 因子（Institutional Retail Contrarian Flow）是本策略最直接的学术对标。

**IRCF 核心构造逻辑——"情境-特征"匹配**：

| IRCF 要素 | 具体做法 | 本策略对应 | 本策略优势 |
|---|---|---|---|
| 下跌看小单卖出 | 小单因子仅在下跌区间取值，计算卖向/买向比值 | 大盘下跌状态实时判定 + 个股资金净流入 | 从日频升级到3秒Tick级 |
| 上涨看大单买向 | 大单因子仅在上涨区间取值，计算买向/卖向比值 | 板块级资金净流入聚合 | 增加了概念级聚合 |
| 大单只作用于中小票 | 大市值股票大单指标直接置空 | 噪音过滤 | 已补充"大票大单降权"规则 |
| 40日滚动计算 | 过去40交易日滚动均值/标准差/90分位 | 逆势持续性判定 | 用3秒Tick实时计算，无需40日窗口 |

**IRCF 回测绩效（2017年以来）**：
- 多空年化收益 **25.8%**
- 多头超额 9.6%
- 多头 IR **2.13**
- IC 均值 7.1%，ICIR 3.29，IC 胜率 85.2%

**IRCF 关键发现（需在实现中采纳）**：

| 发现 | 启示 |
|---|---|
| **单数 > 金额** | 成交单数占比因子的选股能力全面优于金额占比，资金净流入应优先使用**单数占比** |
| **小单卖向 > 买向** | 散户恐慌性卖出有极强反向领先意义（小单卖向多空15.7%），应增加"小单卖向占比"作为辅助确认 |
| **算法拆单使大单失效** | 2021年后大单因子在中证800年化超额从7.5%暴跌至1.3%，2025年甚至-13.2% → 必须对大票大单降权 |
| **小单因子在上涨时IC为负** | 上涨区间小单因子IC均值-3.7%，散户追涨行为对股价有反向预测作用 → 上涨时小单逆势信号降权 |

## 3. 双策略共振设计

### 3.1 共振的统计学基础

| 维度 | 区间三强 | 逆势资金流入 | 独立性 |
|---|---|---|---|
| 时间尺度 | 日级（N日、均线） | 3秒 Tick 级 | ✅ 时间尺度独立 |
| 信号维度 | 横截面（板块间比较） | 时间序列（个股vs大盘） | ✅ 维度独立 |
| 数据来源 | 日K线、均线、大盘指数 | Level-2 逐笔、3秒Tick | ✅ 数据源独立 |
| 验证角度 | "板块是否强势" | "主力是否在买" | ✅ 互为佐证 |

两个统计独立的信号同向触发，根据贝叶斯定理，联合置信度显著高于单一信号。

### 3.2 共振机制（复用项目现有架构）

参考项目里已有的 **MOD-PF-ALLOC-012 共振融合 Resonance Fusion** / **MOD-SIGNAL-019 多策略共振融合层**：

> 全部同向 → 强共振（最高置信度）
> 多数同向 → 中等
> 分歧 → 弱（需因子直通裁决）

应用到双策略场景：

| 区间三强 | 逆势资金流入 | 共振等级 | 置信度 |
|:---:|:---:|---|---|
| ✅ 满足 | ✅ 强（逆涨+持续>1分钟+覆盖率>50%） | **强共振** | 最高 |
| ✅ 满足 | ⚪ 中（逆涨+30秒~1分钟，或抗跌+>1分钟） | **中等共振** | 较高 |
| ✅ 满足 | ❌ 弱 / 未激活 | **单策略** | 中等（仅板块维度） |
| ❌ 不满足 | ✅ 强 | **单策略** | 中等（仅个股维度，需谨慎） |
| ❌ 不满足 | ❌ 弱 / 未激活 | **无信号** | 不交易 |

### 3.3 共振交易信号定义

**强共振买入信号** = 同时满足以下全部条件：

1. **板块维度（区间三强）**：个股所属板块满足"区间三强"——
   - 区间 RS > 1.2
   - 5/10/20 日均线多头排列 + 突破关键压力位
   - 当日板块 Alpha > 1%

2. **个股维度（逆势资金流入）**：该个股出现在逆势资金流Top排行——
   - 大盘处于"中跌"及以上状态
   - 个股逆势强度比 ≥ 行业Top10阈值
   - 持续时间 ≥ 1分钟（连续20个3秒Tick净流入为正）
   - 信号等级为"强"（逆涨 + 持续 > 1分钟 + 板块覆盖率 > 50%）

3. **板块-个股一致性**：逆势个股所属板块 = 区间三强筛选出的板块（必须匹配，不可跨板块）

4. **过滤通过**：
   - 个股未涨停封板
   - 不在尾盘14:30后（或此时段信号降权）
   - 不在开盘9:30-9:35
   - 流动性达标
   - 大票大单已降权处理

### 3.6 仓位与风控规则

| 维度 | 强共振 | 中等共振 | 独立信号 |

| 止损 | 跌破个股3分钟低点 -3% | -2.5% | -2% |
| 止盈 | 板块区间三强失效 OR 逆势资金流出 OR T+1未创新高 | 同强共振 | T+0必须盈利 |
| 时间止损 | T+1 必须创新高，否则减半 | T+0 收盘前必须站稳 | T+0 收盘前平仓 |
| 加仓规则 | 不加仓（首仓即终仓） | 不加仓 | 不加仓 |
| 最大持仓 | 单股 8% / 板块 20% | 单股 5% / 板块 15% | 单股 2% / 板块 5% |

### 3.7 卖出信号（共振出场）

> 入场出场逻辑必须匹配（项目铁律：D-SELL-DECISION §2026-05-24 双轨卖出决策）

| 卖出条件 | 触发逻辑 |
|---|---|
| **板块三强失效** | 板块 RS < 1.0 / 均线空头排列 / 跌破关键支撑位 |

| **时间止损** | T+1 未创新高 → 减半仓 |
| **硬止损** | 跌破成本 -3% |

## 4. 系统落地路径

### 4.1 数据层依赖（L0）

| 数据源 | 用途 | 现状 |
|---|---|---|
| miniQMT 3秒Tick | 逆势资金流计算 | ✅ 已接入（data_source_operation_manual.md） |
| Level-2 逐笔成交 | 主动买/卖分离 | ⚠️ 需券商额外权限 |
| 日K线 + 均线 | 区间三强计算 | ✅ 已接入（kline_daily） |
| 大盘指数实时 | 大盘下跌状态判定 | ✅ 已接入 |

### 4.2 因子层（L1）

| 因子 | 计算 | 归属 |
|---|---|---|
| 区间RS因子 | `板块N日收益 / 大盘N日收益` | L1 因子工厂 |
| 结构RS因子 | 均线排列 + 前高突破评分 | L1 因子工厂 |
| 单日Alpha因子 | `板块当日收益 - 大盘当日收益` | L1 因子工厂 |
| 逆势强度比因子 | `个股3秒净流入 / 大盘同期跌幅` | L1 因子工厂（3秒级） |
| 逆势持续性因子 | 连续净流入为正的Tick数 | L1 因子工厂（3秒级） |
| 板块逆势覆盖率 | `板块内逆势个股数 / 板块总个股数` | L1 因子工厂（3秒级） |

### 4.3 信号层（L2）

| 信号 | 逻辑 | 归属 |
|---|---|---|
| 区间三强信号 | 区间RS>1.2 AND 结构强 AND Alpha>1% | L2-A 信号层 |
| 逆势资金流入信号 | 大盘中跌+ AND 个股逆势强度Top10 AND 持续>1分钟 | L2-A 信号层 |
| 板块-个股一致性 | 逆势个股板块 ∈ 区间三强板块池 | L2-A 信号层 |

### 4.4 策略层（L3）

| 策略 | 触发 | 归属 |
|---|---|---|
| **双策略共振买入策略** | 区间三强信号 + 逆势资金流入信号 + 一致性校验 = 强共振 | L3 策略工厂 |
| 卖出策略 | 板块三强失效 / 逆势资金流出 / 时间止损 | L3 策略工厂（对齐 D-SELL-DECISION） |

### 4.5 共振融合层（MOD-SIGNAL-019 复用）

复用项目里已有的"多策略共振融合层"：
- 输入：区间三强信号 + 逆势资金流入信号
- 融合规则：全部同向 → 强共振 / 多数 → 中 / 分歧 → 弱
- 输出：共振置信度 + 触发指令

### 4.6 仓位与风控（L3.5 + L4）

| 模块 | 作用 |
|---|---|
| 仓位管理（L3.5） | 共振等级 → 仓位映射 |
| 风控（L4） | 止损 / 止盈 / 时间止损执行 |
