## 一、技术面（多时间级别）

### 1.1 趋势类指标
- 均线系统：MA5 / MA10 / MA20 / MA60 / MA120 / MA250（年线）
- 均线排列状态：完美多头 / 完美空头 / 缠绕 / 一阳穿多线
- 乖离率：现价 vs MA5 / MA20 / MA60 乖离百分比（±15% 以上视为极端）
- 趋势线：近端下降压力线（两点连线）、上升趋势线、突破/回踩验证
- 通道：下降通道 / 上升通道 / 箱体（上下沿精确价位）

### 1.2 动量类指标
- KDJ(9,3,3)：K/D/J 数值、金叉/死叉、超买(>80)/超卖(<20)、J 值极端（<0 或 >100）、钝化
- MACD(12,26,9)：DIF/DEA 数值与方向、红绿柱放大/收缩、零轴上方/下方、顶背离/底背离（价格新低但 DIF 未新低）
- RSI：RSI6（<20 极端超卖）、RSI14
- 布林带(20)：上下轨触及、收口/开口
- ATR14：日均真实波幅（衡量波动代价）

### 1.3 时间级别覆盖
- 日线（主判级别，≥120 个交易日计算指标）
- 分钟级：1min / 5min / 15min / 30min / 60min / 120min（用于：今日合成K线、分时结构、首30分钟量能占比、盘中拐点）
- 周线/月线（长趋势背景，60日高点距离、年内高低点）

## 二、形态图形学
- 底部形态：双底（W底，验证两低点是否抬高）、破底翻/spring（假破箱体收回）、V型反转、底背离结构
- 顶部形态：双顶（M头）、顶背离、长上影
- 中继形态：旗形、三角收敛、箱体震荡
- K线语言：反包（阳包阴/阴包阳）、跳空缺口（是否当日回补）、长下影（承接）、长上影（抛压）、涨停炸板与回封时间
- 关键位：前高/前低、缺口上下沿、斐波那契回撤位（38.2%/50%/61.8%）、整数关口、年线

## 三、量能与换手
- 量比（今日量 vs 5日均量，分时同口径对比）
- 换手率（绝对值 + 与5日均值对比）
- 半日量占5日全天均量比例（>60% 平量，>80% 放量）
- 分时量结构：首30分钟成交占比（48%-68% 为开盘集中）、午后接力量能
- 放量滞涨 / 缩量下跌 / 放量突破 的定性

## 四、资金面（多口径交叉）
- 主力净流入：东财口径 + iFinD 口径（money_flow 表，注意两口径矛盾时保守处理）
- 单子分层：超大单 / 大单 / 中单 / 小单（识别"主力买散户卖"或"对倒"）
- tick 级大单拆解：涨跌法则判定主动买/卖（单笔≥1000万为大单）
- 5日/10日累计净流入（识别持续性 vs 单日脉冲）
- 龙虎榜：知名游资席位、机构席位、买卖净额（收盘 16:30 后更新）
- 北向资金（2024-08 后无实时，仅参考历史）
- ETF 资金：ETF 成交异动（护盘识别）、折溢价（恐慌折价/抢筹溢价）、申赎
- 国家队护盘识别：510300/510050 分钟级异常放量柱 + 拉抬时段对应

## 五、主力行为定性
- 吸筹（低位持续净流入+缩量抗跌）
- 拉升（放量突破+超大单主导）
- 对倒（超大单与大单方向相反、单日±50亿级反复）
- 出货（高开冲高崩落、下跌分钟量>上涨分钟量、跌停兑现）
- 弱托底（主力净流入为正但超大单为负=中单配置盘）
- 游资快钱 vs 机构建仓的区分（换手率、持续性、龙虎榜席位）

## 六、基本面
- 业绩预告/快报：增速区间、环比趋势
- 估值：PE-TTM、2026E PE（一致预期）、PB、PEG
- 估值分位：近10年 PE/PB 分位数
- 券商共识：金股推荐家数、目标价、评级变化
- 盈利质量：扣非/非经常收益占比
- 市值与流动性：日均成交额、冲击成本

## 七、情绪面
- 涨跌停家数、跌停数（恐慌日判定，如 07-17 的 631 家跌停）
- 炸板率、连板高度、涨停回封时间
- 市场宽度：上涨/下跌家数、全A等权 vs 加权（大小盘劈叉）
- 板块涨跌覆盖率（板块内上涨家数占比）
- 恐慌指数代理：大幅偏离年线程度、千股跌停/涨停

## 八、板块与轮动
- 子板块构造：成分股等权指数（光模块/服务器/IDC/AI芯片/PCB/液冷）
- 相对强度 RS：板块 vs 上证 / 全A 的 5日/20日超额
- 轮动位置判定：首次异动 / 二次确认 / 末端补涨 / 高低切
- 防御-进攻跷跷板：银行/电力/煤炭 vs 算力/科技 的资金镜像（07-14 镜像规律）
- 板块资金：行业/概念主力净流入排名（东财行业+概念）

## 九、消息面与新闻
- 催化事件：产品发布（如 Kimi K3）、官方公告（算力紧缺）、行业大会（WAIC）、政策（证监会/央行）
- 消息分级：S级（新华社）/A级（官方公告）/B级（券商研报）/C级（自媒体）
- 国际联动：费城半导体SOX、纳指、NVDA/台积电ADR、原油（地缘）、美元/美债
- 券商晨会/金股/研报观点
- 龙虎榜盘后数据（16:30 后）

## 十、宏观与流动性
- 央行操作：公开市场净投放/净回笼、LPR
- 利率与汇率：10年期国债、美元指数、离岸人民币
- 美联储路径预期（加息/降息概率）
- 大宗商品：原油（通胀/地缘）、黄金（避险）

## 十一、共振与评分体系
- 双策略共振：区间三强（相对强度）+ 逆势资金流入（详见 双策略共振_区间三强_逆势资金流入.md）
- 三维共振：业绩（预告高增）+ 资金（主力净流入）+ 技术（形态/指标）三重验证
- 综合打分：各维度加权得分（如紫光股份 82.7 分全组第一）
- 买点成熟度排序：是 / 观察 / 否 三档 + 触发条件 + 止损位

## 十二、风控与仓位
- 止损位：前低/均线/缺口，精确到价格
- 扳机信号清单：确认买点的 2-3 个可观测条件
- 仓位分层：底仓（20-30%）/ 试错仓 / 确认加仓（50%+）
- 盈亏比评估：阻力位空间 vs 止损空间
- 情景预案：反弹/下跌/震荡三套应对

## 十三、数据源清单
- 项目 ClickHouse：kline_daily / kline_1min / kline_etf_1min / money_flow / tick_data / stock_indicator
- akshare：实时快照、板块资金流、估值分位（乐咕）、龙虎榜
- Gildata（恒生聚源）：业绩预告、一致预期、券商研报、公告
- iFinD 口径资金流（money_flow 表）
- 新闻检索：新华社/路透/财联社等分级采信

**分析铁律**：① 所有数字必须来自查询结果，禁止编造；② 多口径矛盾时保守处理并明示；③ 盘中指标为动态值，收盘后需复核；④ 任何结论必须附带触发条件和止损位。
