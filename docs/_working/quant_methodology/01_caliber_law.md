# 分册01：口径立法——两层量尺，各管各的

> **大白话开场**：看一个"条件格子"（比如"情绪沸点 × 高波动日里，打板次日高开概率"）和看一个"策略"（一整套买卖规则跑一年的净值曲线），不能用同一把尺子。格子层手里只有"赢了几次、输了几次"这种硬币式的记录，策略层手里才有连续的收益曲线。**拿硬币数据算夏普是无米之炊，拿净值曲线只看胜率是丢了方差**。

## 1. 两层的分工表（立法正文）

| 维度 | 条件格子层（cell） | 策略层（strategy） |
|------|-------------------|-------------------|
| 回答的问题 | "这个条件下有没有正期望？值不值得让策略在这个条件下开工？" | "这个策略值不值得配钱？配多少？" |
| 数据形态 | 二项式胜负记录（n 次里赢 k 次，每次盈亏比） | 连续日收益序列 |
| 主量尺 | **期望值 E = 胜率×均盈 − 败率×均赔**，且胜率项一律用 **Wilson 置信下界**（见分册03）而非裸胜率 | **夏普 Sharpe**（每承担一单位波动换多少收益）、**卡玛 Calmar**（年化收益/最大回撤）；选择偏差校正当口另加 **DSR**（分册02） |
| 辅助量尺 | 样本量 n、Wilson 区间全宽、条件胞达标（30 日地板） | 换手率、成本后口径、分六段状态表现 |
| 判定动作 | 开工/不开工（闸门语义，二值） | 转正/降权/退役评审（配比语义，连续） |
| 项目现行证据 | `src/zephyr/signal_ashare/strategy_signal/pattern_win_rate_provider.py`（`_wilson_lower_bound`，注释明记"加权输入用 LB 口径（消费班方案 v1.0 挖矿 M1 裁定）"）；`config/exam_scale_cost_gate.yaml`（成本后口径） | `config/search_space_prereg.yaml` objective.primary=`cost_adjusted_sharpe`（毛 Sharpe 仅观察项）；回测 SOP README §7 护栏（分状态报告/成本口径声明） |

## 2. 为什么格子层必须用"期望值+置信下界"而不是裸胜率

1. **胜率单独用会排出反向的名次**。设均盈/均赔比=b（赚赔比），期望 E=p×b−(1−p)×1：
   - A 格：胜率 40%、赚 3 赔 1 → E = 0.4×3 − 0.6×1 = **+0.6**（每押 1 元赚 0.6 元）
   - B 格：胜率 80%、赚 1 赔 3 → E = 0.8×1 − 0.2×3 = **+0.2**
   - 裸胜率把 B 排在 A 前面（80%>40%），期望值正确地把 A 排前面。**胜率是"对的频率"，期望值是"钱的数量"，闸门只认后者**。
   - 反向陷阱同样成立：高胜率+深赔率（赚 1 赔 3）的组合，一旦胜率从 80% 滑到 75%，E 从 +0.2 掉到 −0.05——**高胜率格子的余量往往比低胜率格子更薄**，因为它靠"连对"活着，一次黑天鹅（连赔 3 次）抹平十次盈利。这就是"卖深价外期权"式策略（类马丁格尔）在 A 股打板/高杠杆场景的死法。
2. **为什么期望值里的 p 要换成 Wilson 置信下界**：格子样本天生薄（现行 30 日地板，达标的胞实测仅 9/12，见 `config/search_space_prereg.yaml` condition_stratification 注与 `src/zephyr/backtest/regime_validation/condition_package.py` `_CELL_FLOOR_DAYS=30`）。薄样本的裸胜率是"运气友好"的——10 次赢 7 次的裸胜率 70%，Wilson 95% 下界只有约 39%。**用下界做开工判据 = 自带"运气折扣"**，撞大运的格子过不了闸。这与本仓已裁定的口径一致（pattern_win_rate_provider M1 裁定：加权输入用 LB；消费方要 raw 可经 `get()/get_detail()` 另取）。
3. **为什么格子层不算夏普**：格子层的"收益"是 0/1 事件粒，没有可复利的连续净值；硬算波动率就是把 n 次二元结果当时间序列，算出的夏普没有经济含义。机构同口径：事件研究报期望收益与显著性，不报事件级夏普。

## 3. 为什么策略层用夏普/卡玛

1. **夏普回答"每单位颠簸换多少钱"**：策略层的决策是资金配置，同样的期望收益，波动大的策略占用的风险预算（回撤容忍、kill switch 触发距离）更多。日收益序列样本充足（本仓搜索窗 2019-01-04→2025-09-09，见 prereg），均值/方差可估。
2. **卡玛回答"最坏情况多疼"**：Owner 终局一个人管全部资产，**回撤深度决定能不能睡着觉**；卡玛=年化收益/最大回撤，直接对齐 risk_limit 体系（RLM-VAR 族、回撤漂移 1.5x 退役触发器，见 `docs/_working/archive/2026-09/design_memos/55_monitoring_review.md` §3.5）。
3. **成本后口径是唯一合法口径**：现行立法已定（prereg：目标函数=成本后 Sharpe；`config/exam_scale_cost_gate.yaml`：五档滑点 [0,5,10,20,40]bp 全档存活地板 0.0、单调非增）。本册重申其方法论理由：**毛 Sharpe 的高分可以在换手成本里全部蒸发**，换手门 8x/年的推导（8x→成本拖累 ≈1.7pct/年，exam_scale_cost_gate.yaml 注释）就是这一条的数值化。
4. **策略层的夏普必须过 DSR**：裸 Sharpe 在"几万次搜索后挑最大值"的赛制下必然虚高，校正当口见分册02。本仓 DSR 唯一真源=`src/zephyr/simulation/deflated_sharpe_calculator.py`。

## 4. 两层的接口（格子期望 → 策略配置）

- 格子层的期望值产出喂给**条件配置**：策略在六段状态/条件胞上的开关与仓位（现行载体：`src/zephyr/strategy_pipeline/daily_decision_orchestrator.py` 六段预算带 BUDGET_BANDS——capitulation 0-10%、expansion 50-70%、distribution 0% 空仓，全 proposed 待实盘标定）。
- 策略层的夏普/卡玛产出喂给**转正与配比**（SOP-C C5-C6、PP-001 配比、Champion-Challenger 晋升）。
- **禁越层**：格子层不得直接调资金（闸门只给 0/1 与权重上限）；策略层不得回头改格子判据（禁挪门柱，exam_policy §1.1）。

## 5. 立法小结（一段话版）

**格子层判"有没有"（期望值+Wilson 下界，保守者优先），策略层判"值多少"（成本后夏普+卡玛，校正当口加 DSR）；两层之间只传"开工许可与权重上限"，不传资金，不传判据。** 胜率只能作为期望值的原料出现，永不开独灶。
