## 3. 算法清单

**现有实现**
- 排班：cron 槽位×executor 线程池（default 8/heavy 2/realtime 4/intraday_minute 4/intraday_sector 2，`schedule.yaml:7` 与 `resource_profile_registry.yaml:26-44` 双锚定）。
- 断点续传：last_key 游标（progress_store），incremental 任务 start=last_key（`scheduler.py:1619-1621,1892`）。
- 主备切换：fallback_sources 顺序尝试（`tasks.yaml:49-51` 样例；消费 `scheduler.py:1470-1474` sources_to_try）。
- 熔断：双层=手动 pause（policy.enabled，:1832-1837）+自动连续失败熔断（CircuitBreakerRegistry，:509,1671,1697）。
- 自愈三层分工：L10.7 对账补跑（档期维）→L10/L10.5 行数缺口补下载（数据维）→L11 完整性告警（巡检维）（`schedule.yaml:153-156` 注释明确分工）。
- 内容级校验：双源交叉秩相关（cross_source_validator.py:35）；一致预期双向对答案（consensus_crosscheck `schedule.yaml:98-106`）。

- 悬空 fallback 清理（见 第5节 缺口）。
