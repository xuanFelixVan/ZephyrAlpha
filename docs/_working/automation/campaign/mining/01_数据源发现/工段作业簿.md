## 3. 算法清单

**现有实现**
- 采集：官方 RSS 端点直拉 + 单源失败降级（`intel_harvester.py:95-109`）。
- 过滤：正则词干命中标记（:56-60, :112-120），未命中进兜底段不丢弃（:170-178）。
- 摘要：本地 LLM 单条摘要 ≤120 字中文（prompt :138-142），超时 120s，失败降级留痕（:143-146）。
- 消费：url 级 seen log + md5 内容寻址 candidate_id（`lane_g_stomach_intake.py:105-109, :111-120`）。

**候选升级**
- 源注册表化：SOURCES 硬编码 list → YAML 注册表+生成器（对齐"静态清单禁手工维护"运维红线，AGENTS.md §9 运维红线第 5 条）。
- 语义过滤：关键词正则 → 本地 LLM 打分两段式（先词表粗筛省 token，再 LLM 精筛）。
- 去重：url seen 已有（lane_g）；标题级相似去重（minhash/TF-IDF）为候选。

**业界做法（对标）**
- arXiv API 分页增量（现在整版 RSS 拉取）、Semantic Scholar 引用图扩散、GitHub trending by-language 周榜、顶会（NeurIPS/ICML/ACL）proceedings 榜单监听——均对应蓝图扩展位（`intel_harvester_blueprint.md:25`）。
