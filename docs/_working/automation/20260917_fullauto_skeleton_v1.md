## §2 五条关键裁定（Owner 已核口径）

1. **全链唯一人工门=⑧转正**；数据源上架全自动+安全带（沙箱试拉→试用期 7 天→体量上限→异常自动下架）。
2. **工段间事件传动，不排死 cron 链**（宪法 §9.3 永久系统四要素）；cron 只当日历真源。
3. **花钱纪律**：唯一持续花钱点=④API 判净；规则清洗全量免费，API 只裁抽样与疑难件。分工口径：本地 GPU 干量大的（推理），API 干判断贵的（裁决）。
4. **排班不是新系统**：每工段上线即登记 72 实体学籍表+周历+冲突闸。
5. **骨锁肉动**（挖矿裁定，详见决策骨架挖矿报告）：交易决策骨架（L1-L5×T1-T4×双态门）几十年稳定不自动改，动骨=Owner 拍板；每层血肉（数据源/因子/模型/阈值/策略包）有生命周期（业界 alpha decay 实证），复用本骨架 8 工段自动养。

- 业界主流：每周固定维护窗（DBA 周五/六夜 4h、工作站周一凌晨）或"不定期+提前一周公告"派；交易所自发布维护日历（CME）；共同警告=无人值守重启必须配开机自检。
