# 1. 挖矿对象与边界（MECE 判定范围）

- **母节点**：业务层 Alpha 挖掘全链路——从「数据可得」到「策略在产并监控退役」的闭环（含其自动化与治理面）。
- **不是本次范围**：执行/交易运维链（ex_core/ex_sor 下单细节）、治理宪法规则审判（规则处置战役在办）、前端呈现（只登记不施工）。这些只在①上游/②下游向登记边界。
- 层级（骨架 SOP §3）：大类=链路环节（本次要穷尽的"有多少环节"）→ 中类=完整性检查单元=每环节的子模块/功能面 → 叶=生产者代表（具体实现/算法/数据源）→ 数据集=施工产物。
- 停止判据三问（拆/不拆）：①生产者或来源系统变了→拆；②验证口径变了（频率/PIT 锚/量纲/成本口径）→拆；③只是标的/参数/标签变→不拆（那是实现字段）。

# 4. 每本作业簿的硬性结构（挖干判据=六向台账+自审闸三态）

每本 `c0`/`c1` 必含：
1. **六向台账表**（mining_sop §2）：①上游 ②下游 ③算法/机制 ④后端 ⑤前端 ⑥数据字段，每向 ≥1 条 signal 或明确"已查无"；**受阻≠查无**。
2. **挖矿日志表**（§7 无日志=没挖过）：轮次/矿脉/判定（signal|noise|受阻）/关键产出+来源（外部必带 URL+发布方+年份）。
3. **防噪音四闸**（§5）：来源可溯/交叉验证≥2/（A股适配：T+1·涨跌停·散户主导·无做市商）/可回测+数据可得（可得≠可用，须补质量画像）。
4. **实查证据**：表+字段+行数+新鲜度（DatabaseService.get_clickhouse_conn().execute()，只读；ReplacingMergeTree 带 FINAL、plain MergeTree 不带）；代码=文件路径:符号；禁凭印象标 ✅。
5. **自审闸三态裁定**（§6）：主判据=是否消灭一段人工参与；终局量尺不是现状量尺；「现状规模小」禁作封矿理由；富矿大候选加试反驳者一问；出口=施工/挂起排期（写解锁条件）/方案封矿（写封因）。
6. **诚实条款**：成本双口径注明（引擎现行 万0.854+¥5+印花税万5+滑点五分位 vs Owner-001 1.5bp）；日线结论因 adj_factor 恒 1 全标「暂定」；窗（IS/OOS 边界）写明；筛≠考。
