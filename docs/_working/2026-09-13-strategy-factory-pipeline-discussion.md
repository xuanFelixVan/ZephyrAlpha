# 策略工厂流水线——讨论稿（未开工）

> 2026-09-13 三段聊天（C4 批量翻译批 → 外部开源项目甄别 → Owner 提出工厂愿景）的固化纪要。
> 状态：**纯讨论稿，仓库零施工**；起步车道与开放决策点等 Owner 拍板（见 §六）。

## 一、愿景（Owner 原话的大白话翻译）

**策略工厂 = 多车道进货 → 统一标准化 → 机器量产 → 一条咽喉过考试 → 幸存者入库。**
每条车道各自并发狂奔，但所有的路最后汇到同一个咽喉：本项目已建的质检厂
（冻结阈值 + OOS + Deflated Sharpe + 台账只增 + 判定书）。车再多，考试只有一个标准。

背景事实：C1-C5 人工版流水线已实战（597 条策略收货→粗筛→35 条翻译→批测→聚类对质），
工厂的本质 = 把每一环的人肉换成机器，多车道并发。

## 二、图纸：四段五车道

```
【第一段：进货（多车道并发）】
  车道A  社区货源：聚宽/掘金/研报爬取           ← C1 人工版已有；爬虫自动化备选=Scrapling
  车道B  AI 生成：自然语言→策略（Vibe-Trading 式）← 全新；货最便宜也最杂
  车道C  因子挖掘机：公式拼装（AlphaGen/遗传规划）← 全新；Owner 点名的"自动生成因子"
  车道D  自家图谱：产业链三高查询（ig_fact 图谱）  ← 数据独家；只差查询配方
  车道E  模型基线：Kronos 类明日概率模型          ← 全新；机器学习这条线

        ↓ 所有货统一卸到：策略入库台账（已建） ↓

【第二段：标准化】
  LLM 自动翻译（C3 人肉版→机器版）：原文→权重函数+D1-D5 差异声明+因子拆解
  最费人肉的一环，全自动化的第一块积木

【第三段：量产考试（咽喉，单一标准）】
  C4 引擎批测（已全自动）→ DSR 折减 → OOS 新考卷 → 双窗口及格线
  ⚠️ 遗传算法优化=本段"特护病房"：调参是过拟合主源头，
     必须 walk-forward+冻结阈值，优化出的参数还要再上没见过的考卷

【第四段：入库（幸存者 Only）】
  C5 差异化对质 → strategy_registry → 挂图 → 衰减弱化巡检
  每件货全程带身份证：来源车道、原文、成绩单、判定书（台账可溯）
```

## 三、三条设计铁律（防止工厂变垃圾量产机）

1. **运动员不兼任裁判**：生成车道（A~E）永远无权给自己打分，考试权只在质检厂。
2. **量越大，及格线越狠**：多车道=试验数暴涨，DSR 折减更狠（35 条一起考已打折，
   500 条一起考折扣更狠）。千分之一幸存率是正常预期——工厂的意义是让"发现好东西"
   变成可复制流程，不是提高单件命中率。
3. **事件触发不搞定时器**：调度器按宪法铁律（永久系统四要素），车道干完活发事件、
   咽喉自动开工，禁 cron/sleep-loop。

# v3.1 补遗：去年笔记二次精读新发现（2026-09-13，Owner 要求彻底重读后）

## 重量级：PDF 预测因子化（直接接 factor_registry + C4 框架）

去年笔记原文：把分布预测的输出（**预期收益 E(R)、下行标准差、尾部风险**）作为
"前瞻性 Alpha 因子"加入多因子评分——在传统历史因子上叠加"基于未来预测的排序能力"。

工厂落地：分布预测模型的输出登记为因子（factor_registry 五要素流程准入），
进 C4 统一考试、进 E5 协同去重——**分布预测不再只是车道 E 的独立策略，
它同时是全厂所有策略的候选因子供应商**。这是车道 E 对全厂的乘数效应。

## 车道 E 内部五段小流水线（结构设计，v3 遗漏）

因子（信息源：微观结构/分布特征/另类）→ 特征工程（滞后/交互/频域多尺度）
→ 密度预测模型（条件分布 P(R|X)）→ 交易信号（四类型，见下）→ 策略（组合优化+成本+执行）。

## 信号四类型学（E 车道输出设计）

1. 方向信号：预测分布均值显著为正→买入；
2. 置信度信号：方差小（预测置信度高）才加仓——"均值高且方差小才行动"；
3. 尾部风险信号：预测 VaR/CVaR 破阈值→减仓/对冲；
4. 相对价值信号：横截面比较各标的预测分布，做多分布优的、回避分布差的。

## 分布评估双标准（E4 对车道 E 的考试尺）

- **校准度**：概率积分变换（PIT）图——预测分布是否如实覆盖实现值；
- **锐度（sharpness）**：在校准前提下分布越窄信息量越大。
只看校准会得出"宽而无用的分布也很好"的假阳性，两把尺必须一起用。

## TDM 候选补条目

# v5：七环节大展开（2026-09-13 五轮检索编译，第四轮仍 signal、第五轮首现噪音→封矿）

## Owner 问答存档：为什么"因子越多杀货率越高"（共振≠免死金牌）

数学三层：
1. **多重检验**：N 个因子按 95% 置信检验，纯运气就出 N×5% 个"假赢家"——500 个里 25 个
   靠运气及格。López de Prado：发表因子约 80% 是统计伪迹。
2. **冠军诅咒**：从 500 份回测里挑历史最好的，挑中的大概率是"最幸运的"而非"最强的"
   （噪音的极值>真边的极值），真边 51% 和运气 60% 上历史难分。
3. **共振的成立条件**：k 个**真边且互相独立**的因子组合，组合 Sharpe≈√k×平均
   （Grinold-Kahn：IR=IC×√breadth；相关性 1.0→0 风险调整收益提升 43%，Causeway 实测）。
   同源数据挖出的 500 个因子大多是动量变体/波动变体，相关性 0.8+，组合=把同一个赌注
   加倍，不是共振。
结论：**杀货率是共振的入场费**——先狠杀（保真）、再正交（保独立）、然后组合（共振成立）。
"至少 51% 是赢的"忽略了两件事：交易成本会把 51% 磨成负、以及你根本分不清 51% 是真边还是运气。

# v7：骨架结构宽度重大发现——下游半场（2026-09-13 第四轮结构挖掘）

## 发现：E0-E6 只是工厂的"上半场"，机构标准还有"下半场"

机构共识生命周期=**回测→前向测试→模拟盘→实盘**四道门，且资金必须渐进爬坡
（drawdown 控制+波动率目标+组合热度上限）；行业统计"多数回测夸大实盘盈亏 30-60%"
——这就是为什么机构从不让策略跳过模拟盘直接上真金。
本项目 registry 的 lifecycle_status 字段（candidate/backtest/sim/paper/live）**早已
预留这些阶段**，但工厂 E0-E6 到"入库"为止——下半场缺位。

## 下游半场三环节（结构提案，范围待 Owner 裁定是否纳入工厂）

**E7 模拟盘前哨**：registry 幸存者以 live 数据跑模拟盘 N 周，逐日对比
"预测 vs 实际"（分布校准的实盘版）+ 执行可行性（滑点/容量实测）；
前哨期不达标→退回 E6 标 decayed。对应 lifecycle_status=sim/paper。

**E8 组装与资金分配（sleeve 装配）**：多策略 sleeve 组装——regime 切换
（Markov/跳跃模型选 sleeve）+ 风险平价/等风险贡献权重 + 资金渐进爬坡；
组合数学：0.5+0.7 双 Sharpe sleeve 低相关合成≈0.85。对应 Owner 既定方针
"多策略赛马"。**这是策略工厂与实盘资金之间的最后一座桥。**

**E9 实盘运行+归因**：真金阶段（TDM 挂图消费端）——实盘归因回灌 E2 假说库
（第 8 层绩效归因），完成"生产→运营→反哺生产"的完整价值链闭环。

# v9：字段设计定稿提案（2026-09-13 第五轮讨论，全网调研后）

## 工厂产品清单定稿（生产什么）

### 防幻觉块（来源可溯闸的字段化）
evidence_refs（判定书+run 档案+外部来源 URL/发布方/年份）
cross_validated（≥2 独立来源互证？）

### 防漂移块（registry v1.x 字段已全，不重造，引用即可）
baseline_sharpe/expectancy/win_rate/max_drawdown（出生基线快照）
last_evaluated_at / decay_cause / decay_threshold / drift_psi
