#### PQ-0065 复考判据重述（并案落点）

- 原判据：CKG 产品-产品边 vs 研报抽取边一致率 ≥70% → 实测 1/81=**1.23%** ≪70% → fail + 触发题面自带降级条款
- 重述：降级为结构先验后，"一致率"这个度量**不再承载裁定力**，改判**先验可用性 a/b/c**：
  - (a) 端点可对齐率 = CKG 行业对双端可归一到在用标准行业码的比例 → 实测 **1.0000**（241/241；阈 ≥0.95，阈值借 PQ-0078 同族量）→ PASS；
    另报粒度压缩率 0.5851（241 对投影后仅 141 个一级行业对，32 对坍缩进同一级——损失 41% 结构信息，
    这正是"它只是先验"的量化表达）
  - (b) 独立侧证率 = 归一后 CKG 行业对能在**异源**官方 IO 系数矩阵（件 2 旁挂册）找到同向对的比例 → 实测 **0.8014**（阈 ≥0.60，借 PQ-0067 原值）→ PASS
  - (c) 决策独立性合规率 = 消费点已按先验档处理的比例 → 实测 **0.7619**（阈 =1.00，二元纪律项）→ 未达
  - 结论：**CONDITIONAL**（a/b 达标、c 待 5 份补丁落地）→ 先验可用但**暂不得入生产合成**
- 重述理由（写进交付件，机械判据同册）：原判据把"词系不通"当"事实不成立"——分子要产品名精确同指，
  而两侧词表不同本体（`ig_node` aliases 仅 46 行、`ig_entity_code_map` 仅 88 行），对照侧当期图谱跨行业对
  曾为**空集**（PQ-0067：ig_edge 1,726 条中跨链仅 2 条 → 类别对 0 个），且不剔除自并入边会得 58/81=**71.6% 假达标**。
  该比值对"CKG 说法是否为真"几乎不含信息；降级后唯一有信息的问题是能否对齐、有无异源侧证、下游是否只当先验用。
  **原 fail 结论与 1.23% 数字均不改**，只把"判 fail 的度量"换成"判可用的度量"。
