# S7 成本/容量/账实恒等（基线 f1144362 后；证据=S7-exp+S14 探针 stderr+S1-A8+S4）

## 1. 成本模型可信度裁定

| 件 | 裁定 | 证据 |
|---|---|---|
| 池均成本 2.7bp/日（年化 6.6%）口径 | **真实** | S7-exp 复算 2.695bp/日（年化 6.79%），62 策略样本 |
| 滑点分层标定（ADV 五分位 Q1 7.24→Q5 2.34bp） | **结构对、有一缺口** | `cost_model_calibration.py:227-267` 分层+3.79bp 回退在案；但 S14 探针 stderr 实证：PAGE-PREMISE 报警"年化单边换手 15.1×>12×——'日频低换手'前提已被证伪"——**分层滑点的立论前提（低换手）在生产路径上已被自己的监控推翻**，报警无人消费 |
| 冲击模型（Almgren-Criss） | **名存实亡（P1）** | S14 探针 stderr：`IMPACT-TERMS-UNIDENTIFIED(P1): 成交价对决策价偏离中位 2.34bp / 标准差 0.000000bp（n=396）——冲击项实际恒零，DEFAULT_PARAMS 静默旁路`。**冲击成本从未真正计费**——容量结论（capacity_profile）建立在没有冲击模型的引擎上 |
| 地板佣金（¥5 不免五） | 对 | `matching_logic.py:560-576` max(qty×price×rate, ¥5)；小额多笔下咬合正确（cost_attribution 有地板咬合占比告警 25%） |
| 001 验证口径（万0.854/地板未触发/ETF 免印花） | 对 | 常量真源与裁定 #233 一致 |

**裁定：成本模型"佣金+滑点"两条腿可信（参数实标定），"冲击"腿是摆设——所有容量相关结论（含 capacity_profile.csv 与 S5 新尺的容量腿）按"冲击=0"口径偏乐观，须标注。**

## 3. 结论

成本口径的可信度=**单条件成立、组合口径偏乐观**：单笔成本准，容量与高频场景成本被低估（冲击恒零+低换手前提已破）。全部"能赚钱"结论中含容量/换手敏感件的，按本裁定打折。

## 4. 复算反驳者

1. "冲击恒零是因标的全部巨流动（Q5 档）所以冲击真小"——错误：std=0.000000bp 证明不是"小"而是"恒定旁路"（DEFAULT_PARAMS 未标定），真标的换手上去后无保护。
2. "CLI 路径无对账=小事"——CLI 是单策略考试主路径（S14 探针就走它），考试产物不带账本闭合=钱闸缺一环。
3. "2.7bp/日已含全部成本"——只含已计费三项（佣金/滑点/过户+印花），冲击腿缺席=该数字是下限不是全量。
