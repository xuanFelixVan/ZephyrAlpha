## 复算反驳者（二档双角色加试）

1. **"F1 扩检 `#NNN` 裸号会误伤 GitHub issue 式引用"**——裁定书方案已限定文档区+三位以上数字+排除 `#ARCH-` 前缀；残余误伤面=真裁定号的裸引用本就该拦。反驳不成立。
2. **"F2 的 Timer 是盘中对账，事件源（成交回报）可能长时间不来，纯事件触发会漏对账窗口"**——裁定书方案保留 max-staleness 看门狗（事件触发+超 staleness 上限兜底一次），不是纯事件替换。反驳部分采纳进方案。
3. **"F3 的窗口只有秒级，误报无实害"**——A2 实测该窗衍生 13.1% 队列死信+常态化 TAMPERED 噪声，实害在案。反驳驳回。
