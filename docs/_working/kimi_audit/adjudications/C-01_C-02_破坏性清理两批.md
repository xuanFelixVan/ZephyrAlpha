# 裁定书草案 C-01+C-02：破坏性清理两批（合并呈签）

## 现状（含证据锚点）

- **C-01 零风险三件**：10 张空壳表 DROP / 110 个 CAS tmp 清理 / 重复 bak 二选一（`sharpe2-prep-final-report.md:87,96`；`c_audit/2026-09-17-cleanliness-audit.md:24,97`）。
- **C-02 决赛后破坏性批**：9 垃圾件归档 / 85MB forensic bak 冷存 / integrator bak / 20260526 bak，合计 ≈6860 万行（`sharpe2-prep-final-report.md:87`；`cleanliness-audit.md:22,23,26,59`）。
- **C-03 联动**：`auction_book_limit_bak_20260908` 为**唯一副本**（cleanliness-audit.md:59）——本裁定明示：**唯一副本不删**，冷存保留。

## 选项

| 选项 | 内容 | 最坏情形 |
|---|---|---|
| A. 直接批删 | 按清单执行 DROP/删除 | 某 bak 里藏着他线唯一证据（forensic bak 名字就叫 forensic）——误删不可逆 |
| B. **批准但走可逆通道** | 空壳表先 rename 隔离 7 天无引用再 DROP；CAS tmp 直接清（派生可再生）；bak 类一律冷存（归档移动不删除）；唯一副本豁免 | 存储多占 7-30 天；零不可逆损失 |
| C. 不批 | 维持现状 | 6860 万行垃圾继续拖慢备份与扫描；审计面持续噪声 |

## 依据

宪法 RULE-DATA-OPS 三步验证（必要性/真实性/可逆性）：必要性=清洁审计报告在案；真实性=空壳表零行已核；可逆性=本裁定的核心改动——**删改一律走隔离期/冷存，不做物理删除**。唯一副本豁免是血泪纪律（缺陷模式无此条但常识级）。

## 风险

rename 隔离期若他线引用空壳表会报错——这正是隔离期的目的（7 天内暴露引用再救回）。

## 建议+置信度

**建议 B，置信度高。** 执行细节（隔离期天数/冷存目录）授权 AI 按 RULE-DATA-OPS 三步验证执行，每步留证。
