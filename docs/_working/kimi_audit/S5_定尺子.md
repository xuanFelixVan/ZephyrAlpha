# S5 定尺子（基线 562a7a3e 后，班次 2026-09-17）

> 入口：`config/standards.yaml`；组合门 frozen（OOS≥1.5 / 回撤≤15% / 笔数≥30 / DSR>0，出处 owner-vision-system-mapping L57）。
> 本档所有数字为 canonical kernel 实算（`expected_max_sharpe_z`，MOD-SIM-024）。

## 1. 逐条裁定

### ① OOS Sharpe≥1.5 —— 保留，但它不是当前瓶颈
在现行 DSR 口径下它不是 binding constraint（见③）。方向合理（OOS 折半于 IS 的纪律线）。**裁定：对，保留。**

### ② 回撤≤15% —— 保留；补口径注记
15% 对组合级合理。缺陷：未声明回撤口径（日频收盘 vs 盘中极值）——`_c4_engine` 与生产引擎的 DD 口径都是收盘序列，盘中极值会更深。**裁定：对+补口径注记（draft 内写明"日频收盘序列"）。**

### ③ DSR>0 —— **错（数学上自相矛盾，必须修）**
- 现行 N 口径=全局累计（2026-09-15 裁定），账本=4562（S1 补登后；B-05 悬案若成立则 +16,070 → 20632）。
- N=4562、T=471 时：**DSR>0 需年化 SR≥2.68**；DSR>0.95 需 ≥3.89（实算表见下）。
- 于是组合门变 **"OOS SR≥1.5 且 ≥2.68"**——实际门槛 2.68，写出来的 1.5 是装饰。**严格尺放行档=0 的第一因=尺子数学上不可同时满足，不是池子全烂。**
- 且累计 N 是单调棘轮：N 只涨不跌 → E[max] 只涨 → 及格线只升不降——**任何策略随时间推移必然从"可能过"滑向"永不过"**。这不是保守，是自毁。
- **裁定：错。改族口径 N_eff**（预注册封闭族：同批 intake/同批联赛/同批网格——族成员数=N_eff；全局账本仍作研究筛选侧 C4 的折减披露位）。族口径下 DSR>0.5 所需年化 SR：N=10→1.15；N=30→1.52；N=50→1.67；N=100→1.85；N=200→2.03（T=471）。尺变得**可过且有意义**。

### ④ 笔数≥30 —— 语义错位，改双轨
- 30 笔只在胜率 ≥65% 时单侧 p<0.05（55% 胜率需 ~370 笔才达 p<0.05；实算：n=30/WR=55% → p=0.29）。**笔数证明不了显著性，只能证明容量存在感。**
- **裁定：改双轨**——笔数≥30 保留为**容量/成本计提证明**（纪律位，非统计位）；显著性全部由 DSR（族口径）承担。文字表述从"统计门"改为"容量门"。

### ⑤ 缺第三条腿 —— 补
组合门缺：组合内相关性（ρ̄≤0.7，骨架 §7 已有裁定先例）、容量证明（`capacity_profile.csv` 产物已在）、年化单边换手上限（PAGE-PREMISE 实证 12× 是旧固定滑点立论上限，`cost_attribution` 已会出声）。**裁定：补三条腿进 v2 draft。**

### ⑥ 层级关系 —— 明文化
单策略门（E4 考试：DSR 0.5/0.95 带）=研究侧准入；组合门=装配侧准入；联赛切换=STD-SWITCH-001（本班 S13）。**三门的 N 口径必须同族定义**，否则出现"单策略过了、组合挂"的假矛盾。

## 4. 复算反驳者（二档双角色加试）

1. **"族口径 N_eff 是给自己开后门——族划小一点什么都能过"**——防这个的纪律在案：族=预注册封闭集（L4 三道锁 criteria_hash），族成员含失败者（bh_filter 已强制"含已过门者防选择偏差"）；族定义造假=RULING/预注册门拦。反驳驳回，但**族定义写入修标重考报告的强制披露位**。
2. **"DSR>0.5 族口径比 DSR>0 累计口径松太多"**——方向相反才对：现行尺是"不可过"（等于没有尺），v2 是"可过且折减真实"；且 0.5 带配 review 中间带（0.5-0.95 存疑人工复核，MOD-SIM-024 既有），松恐慌不成立。
3. **"换手 12× 上限会卡死合法高换手族"**——上限语义=触发成本模型重估义务，不是判死；超 12× 且分层成本重估后仍过线者放行。反驳部分采纳（文案已写"重估"非"判死"）。
