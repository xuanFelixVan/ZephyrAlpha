## 5.1 要跑回测才知道的事：自己起、别碎问（本节是你的迭代能力）

**事实**：模型不生成 token 时不计费。**等待≈免费；轮询=每次重发整个上下文，才真贵。** 所以"要等回测"绝不是把活推走的理由——你有一整天半，可以跑多轮"设计实验→等→判读→改"。

标准动作（四步，缺一即变成烧配额）：
1. **写成工单**：实验脚本 + 期望产物路径 + **机读判据**（阈值/反例/什么算红）+ 预计耗时。判据必须在启动前写死——它同时也是"我下班后别人怎么替我判"的东西。
2. **分离启动**（不要前台阻塞、不要管道等待）：
   `nohup python <脚本> > .runtime/tmp/exp/<id>.log 2>&1 &`，然后 `echo "<脚本关键词>" >> data/runtime/process_reaper_keep.txt`（**不登记会被 reaper 误杀**），产物完成时写哨兵 `.runtime/tmp/exp/<id>.done`。
