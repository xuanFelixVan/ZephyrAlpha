# 三、为什么这是机制问题而不是"某班手滑"

- 21:44 那次是**人跑的**（考试班自报并已认罚）；00:04 那两次是**队列自动跑的**——
  同一条件反射式的通路：只要落地链执行到该测试，就写生产。
- 后果面：生产表被持续插入历史日假读数，且 `synthetic=0` ⇒ 下游按日读"当日盘前计划判断"无法识别；
  比带标记的脏数据危险。
- 与在册红线的关系：根宪法 §9 条目 6（测试禁写生产路径，输出一律 `tmp_path`）在提交/落地链上**无门可拦**——
  现有门禁看的是文件内容与暂存面，不看"测试运行时是否连了真库"。

   或②给测试轮统一注入"CH 写口 fail-closed"环境（在册尚无此开关，`ch_writer` 里读不到只读旗），
   或③把落地侧测试轮改为只跑与袋内件相关的目录。三选其一即可断源，代价各异（①最省但要名单常维护，
   ②最彻底但要新增写口护栏，③最不动语义但覆盖面窄）。
