## §2 核心归因

1. **成本绞杀是第一归因**：全谱年换手 33-39x（FACT 族日频 top20+4440 超短单票轮换驱动），
   IS 段总成本 41.3 万=初始资金 41%（佣金 27.5 万+滑点 13.9 万）。零成本对照（OOS）：
   Sharpe 0.336→**0.837**（收益 +11.9%→+29.9%，≈基准持平）——**当前组合的成本容量
   根本承载不了该池的换手强度**。
2. **regime 节流（IBT-B）四窗三负**：IS -15.6pct/OOS -5.5pct/HOLDOUT ±0（Sharpe 更差）。
   预注册映射（r4→0.5/r10→0.2）在 blind 历史段系统性"卖在低位"，与 S-OWNER-002 实测的
   r4/r10 方向失真 caveat 互证。**L1 节流在当前检测器质量下不产生正增量**。
3. **池时效衰减**：成员层 IS→OOS→HOLDOUT 逐窗恶化（FACT 族 IS 全负→OOS 全正
   →HOLDOUT 近乎全灭；e3da OOS +51%→HOLDOUT +4%）。E4 存活名单的 OOS 段
   （2024-01..2025-08）与 W_OOS 高度重叠——W_OOS 的正收益本质是"池选择窗内自证"，
   真正的盲窗（HOLDOUT）证伪。
4. **容量约束实证**：4440（超短1日轮换，Sharpe2 标定容量 77 万）单跑 IS -91.3%——
   100 万资金全仓单票+参与率约束下被滑点绞杀；OOS +43.1%/HOLDOUT -35.9% 高波动不稳定。
5. 满仓归一语义（协议 §10.1）：合成面板任意成员有信号即满仓，组合实际敞口≈100%×
   (有信号日占比)，现金缓冲仅存在于全零行。
