# 判定口径（先读，本表的价值全在口径）

**三态强制**：每法必须落进且只落进一态，禁把"不可考"写成"未通过"（那会让下一班误以为已证伪）：

| 态 | 含义 | 处置 |
|---|---|---|
| ✅ 可考 | 输入齐备 **且** 能凑 n≥30 同体往返样本 | 另立预注册卡走 E4，判卷不松 |
| ⏳ 待料 | 原理成立、输入部分在库，样本量不足 | 登记缺多少、由哪条线补；**不判死不判活** |
| ⛔ 阻断 | 关键输入在本仓/本市场**结构性不可得**（含制度性死亡） | 禁止预注册，等外部条件变化 |
| 🔧 执行层 | 收益来自省成本而非赚边际 | 归执行算法域，**不占做T 判据族**（否则重复计 n） |

**同体往返**＝本包 V3 卡 §4 的四判据（日内粒度 + 同一 run 内成对 + 日志去重 + 涨跌停可行域）。
**成本闸**＝股票腿一次往返固定 31.2bp（CST-T0-001），转债/跨境 ETF 无印花税（约 1~8bp）。

# 三、真正的瓶颈不是成本，是**极值次序与预测**（T0-CEILING 实测后改写本节）

**本节原写法（"成本闸是把可考压成可活的滤网"）已被本包容量考试否证，按实测改写如下。**

两级实测，同一批口径：

| 量 | 实测值 | 来源 |
|---|---|---|
| 日内可达毛价差**上界**（未卜先知：最低买、其后最高卖）日级 p50 的中位 | **330 bp** | `t0_ceiling_verdict.md`（1,227 交易日 / 6.15M 股票-日） |
| 往返固定成本（CST-T0-001） | 31.2 bp ＝ 上界的 **9.4%** | `cost_trio_exam.RT_COST_BP` |
| 成本 + 30bp 开仓前置 | 61.2 bp ＝ 上界的 **18.5%** | 同上 |
| `share(上界 ≥ 成本)` 在**每一个**状态分组 | **≈0.9999**（无一族被判死） | 全窗分组（本文 §2 表） |
| **先低后高**的股票-日占比 | **50.1%**（≈抛硬币） | 全窗 |
| 真实同体往返实现的毛价差 p50 | **+4.3 bp** ＝ 上界的 **1.3%**（损耗 98.7%） | `t0_conditional_e4_v3_result.yaml` |

⇒ 三条推论（顺序即 R1 的火力分配）：

1. **成本不是那道闸**。市场给的日内价差上界是成本的十倍，容量层面从不约束。
   花算力去"找更便宜的成本模型/更省的执行"救不了做T——那是在锯错那根树枝。
2. **闸在 ①次序先验五五开 ②极值不可预知**。因此每个 ✅ 可考的方法进 E4 前，
   要回答的那句话从"你挣的毛边际够不够 31.2bp"**换成**：
   **"你凭什么知道今天先低后高？信息源是什么？它在样本外还在吗？"**
   答不出信息源者，期望毛边际 ≈ 0 —— **与成本无关**。
3. **转债/跨境 ETF 仍然优先，但理由换了**：不是"那里价差更大"（上界同为日内振幅问题），
   而是"那里**允许更小的实现边际也划算**"——实现 4.3bp 在 31.2bp 成本下必死，
   在 1~8bp 费率下同一预测能力就能活。
   **它是把同一种预测能力变现的更便宜场所，不是更容易预测的地方。**

（同时立一条硬约束：容量上界**宽裕**不构成任何方法的证据——判读单向，见
`t0_ceiling_prereg_card.md` §0。故本节**只**据此排除"成本"这一项解释，不据此支持任何方法。）
