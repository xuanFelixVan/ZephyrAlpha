## 4. 材料资格判据（本卡唯一变更点，frozen 先于取数）

一条配对 **入样**，当且仅当同时满足 M-1…M-4；任一不满足 ⇒ 剔除并在产物 `material_audit` 中按原因计数。

- **M-1 日内粒度**（承 V2 §4.1）：成交记录 `str(timestamp)` 长度 > 10（含时分）。
  仅日期粒度=日线 bar，同日买卖属同一 bar 聚合，不构成往返。
- **M-2 往返同体（本卡新增，治 F-1）**：一笔"往返"必须在**同一 run_id（同一组合）内**成立。
  执行口径=对每个 run 单独调用 `build_pairs(fills_of_run)` 后贴 run 标签，
  **禁先合并 60 件再配对**。买侧 run 集 ∩ 卖侧 run 集 = ∅ 者即污染样本，必被本条剔除。
- **M-3 材料去重（本卡新增，治 F-3）**：以 `sha256(json.dumps(trade_log, sort_keys=True))` 为日志指纹；
  同一指纹只取**首个**（按文件名序）代表件入样，其余同指纹件计 `files_deduped_away` 披露。
  ⇒ 消除"同一流水换 run_id 重复计数至 7 次"。
- **M-4 涨跌停可行性硬门（本卡新增，治 F-2）**：同日内含往返的毛价差绝对值必不超过该 symbol
  所属板的单日理论极限（主板 ±10% ⇒ 极限 `1.10/0.90−1`；创业板 300/301 与科创板 688 ±20% ⇒
  `1.20/0.80−1`；ST 类 ±5% 但本卡不按 name 字段判 ST，故只采前两类板别，边界取该板极限）。
  超限者=数据/执行模型异常件，剔除并单列 `rejected_price_limit` 计数。
  该门阈值**全部来自交易所公开规则的算术推论，与本考试任何结果统计无关**。
- **考窗**：起点 **2026-06-01**（真源=第三方 frozen 卡 `t0_regime_prereg_card.md` §3 考试段起点，
  早于本卡 created，本班无拟合空间）；终点=入样材料末日（动态，禁写死）。
- **闭卷纪律**：本卡全部阈值继承自 frozen v1/V2 与 CST-T0-001，无一由材料拟合；
  产物须带 `closed_book_ok`（切点 2025-09-09）如实标记，切点后数据只参与判读不参与定档。
