# 一句话：**容量不是瓶颈，次序与预测才是**

全窗 2021-09-01→2026-09-23（1,227 交易日、
universe 6,145,008 股票-日、其中先低后高可做多 T 的 3,079,423 个）。

**判读规则是单向的**（卡 §0）：上界<成本 ⇒ 该族整族判死；上界≥成本 ⇒ **什么都不证明**。
本次结果全部落在后者 ⇒ **没有任何一族被本卡判死，也没有任何一族被本卡放行**。

## 1. 关键量（全为实测，非推演）

- 可达毛价差（未卜先知：当日最低买、其后最高卖）**日级 p50 的中位数 = 330bp**，
  日际区间 202–1314bp。
- 往返固定成本 31.2bp（CST-T0-001）只占该上界的 **9.4%**；
  加上 30bp 开仓前置（61.2bp）也仅占 **18.5%**。
- 因此 `share(上界 ≥ 成本)` = **0.9999**（1,227 个交易日的每一个分组都近似 100%）。
- **先低后高的占比 = 0.501** ⇒ 日内极值次序接近**五五开的硬币**。
  无任何信息时做多 T 的期望毛边际 ≈ 0（不是因为价差不够，是因为方向不对的一半把它抵消掉）。
- 与本包 V3 实测对照：**同体真实往返实现的毛价差 p50 = +4.3bp**，
  即从 330bp 的天花板到实际到手，**损耗 98.7%**。

## 3. 这张卡纠正了本包自己先前的一处判断（如实改，不静默）

本包 `METHOD_MINING_t0.md` 卷首曾写"**成本闸门是这一族的第一杀手**"。
本卡实测**否证了这句话的因果权重**：市场给出的日内价差上界是成本的 10 倍以上，
成本闸在容量层面根本不咬人；真正杀做T 的是
**①极值次序五五开**（无信息时期望≈0）**②极值不可预知**（实现只有天花板的 1.1%）。
⇒ 已在 `T0_SCHEME_MATRIX.md` §三 改写为实测口径，原句在矿册中标注为**已被本卡否证**。

战略后果（供 R1③ 排序用）：
- 钱要花在**预测**（哪一半日子先低后高、以及低高点在哪一分钟）上，不是花在"找更便宜的成本模型"上。
- 转债/跨境 ETF 的"成本低"仍然成立，但其意义是**允许更小的实现边际也划算**

## 4. 数据质量副产品（顺带查出，如实登记）

- `c1_market.kline_1min` 存在 **min(low)=0 的股票-日**（实测全窗 1 个）——
  本包首跑即在聚合外做 `hi/lo` 被 ClickHouse `Code 153 Division by zero` 拦下。
  行数虽小，但**任何用该表算振幅/价差的消费方都必须先挡零价**，否则要么崩、
  要么（更糟）被 if 静默吃成 0 价差而稀释统计。本件已把除法收进 `if(lo>0 ...)`
  并在 `t0_ceiling_daily.csv` 带出 `zero_lo_sd` 计数；契约测试
  `TestDivisionByZeroRegression` 钉住该回归。
- 该表是 ReplacingMergeTree，未 FINAL 时同分钟可多版 ⇒ 本件的 bar 计数用
  `uniqExact(trade_time)` 而非 `count()`（用 count() 会虚增约 1.7 倍，把不可交易日误判为可交易）。

## 6. 复算漂移实测（09-24 本班二次复算，红蓝式自我对账）

同一代码、同一窗口重跑，与首跑产物逐叶对比：**170 个叶子中 37 个变化，全部是数值叶，
字符串/判据/桶名叶子零变化**，最大相对漂移 **1.3e-5**（例：2022-09-30 `ok_n` 1555→1556、
`p50_bp` 620.4→620.0）。根因实测＝本考试读的是**活表**：`system.parts` 显示分钟表 167 个
活跃分区、`max(modification_time)`=2026-09-23T22:04Z，恰在两跑之间 ⇒ 后台 merge/入库改变了
`uniqExact(trade_time)` 与 `argMin/argMax` 的落点。本件**不钉快照**，故如实披露：

- 结论面（verdict / share 四位小数 / 1227 日 / 闭卷双门 107 日交叉核对）**不受影响**；
- 任何拿本产物做逐位断言的下游，必须用**相对容差 ≥1e-4**，禁 byte 相等硬绑；
- 若要真正冻结，需要按分区快照或 `FOR SYSTEM_TIME AS OF`（本卡未实现，登记为待料不假装）。
