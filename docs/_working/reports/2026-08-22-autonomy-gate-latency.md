# Autonomy Gate / Kill Switch 编排器 延迟实测报告（18号清单 §4.2 / 15号文 Phase 0 S0.4）

- 日期：2026-08-22
- 工单：18号清单 §4.2（15号文 Phase 0，GP0 退出项 E0-3）S0.4 延迟实测
- 实测环境：本机 Python 3.12.8 / Windows（win32），单机用户态
- 实测方法：一次性最小计时脚本（`.runtime/`，用完即删），`time.perf_counter_ns` 环绕，1000 次采样取 P50/P95/P99/max；先预热（注册表加载+索引构建+句柄打开）再采样，即"缓存命中热路径"口径
- 被测对象：`src/zephyr/autonomy_core/autonomy_boundary_gate.py`（MOD-AU-001）+ `src/zephyr/autonomy_core/kill_switch_orchestrator.py`（MOD-AU-002，内联查询真实 `security/access_control/kill_switch.py` 实例）

## 二、结论 vs 15号文 S0.4 验收口径

1. **gate 判定热路径 P95 = 313.5µs（含审计留痕）/ 111.9µs（纯判定），均 < 1ms，达标**，无需回写 15号文 §3.4"<1ms"工程语义修订建议。
2. **KS 内联拦截 P50=0.4µs / P95≤0.8µs**，与 15号文 §2.3 已登记的"决策点内联拦截微秒级"口径（P50=0.20µs/P95=0.30µs，2026-08-18 实测）同量级，复核成立——本组略高系多了编排器方法分派与适配器层，仍微秒级。
3. **BLOCK 物理拦截路径 P95=530.5µs 达标，P99=1.23ms 偶超 1ms**：BLOCK 是"拒绝+告警落盘"路径（非放行热路径），且 15号文"<1ms"语义锚定的是 Kill Switch 决策点内联拦截（组④⑤），gate 判定服务的是施工期 AI 写文件检查（分钟级粒度，15号文 §3.2），P99 偶超无资金风险敞口。
4. **max 长尾（10~15ms）**：全部测量组均有零星 10ms+ 离群点，系 Windows 文件 IO 长尾（杀软扫描/磁盘缓存刷新），非判定逻辑开销；Tick=3 秒的交易节奏下无实际影响（15号文约束四）。

## 三、过程中的性能修正（已落地）

首轮实测 BLOCK 路径 P95=1735.5µs（超 1ms），根因=告警留痕每次调用 open/write/close 文件。修正：告警句柄改为持久 line-buffered 句柄（与审计句柄同款，逐行 flush），复测 P95 降至 530.5µs。修正已并入 MOD-AU-001 本体，非探针侧规避。

## 四、与 15号文 §2.3 既有登记数据的关系

§2.3 登记的两组数据（决策点内联拦截 / 文件标志位轮询）为 2026-08-18 最小探针实测；本报告是 S0.4 对**本次新建 gate/编排器实现**的实测，两组口径互补：本报告组④⑤对应"决策点内联拦截"在新代码路径上的复核；gate 判定组①②③为新增口径（§2.3 未覆盖），建议统筹在 15号文修订时按需回写引用本报告。
