## §2 A 档·内有（16 条）

### SL-A01｜日线/分钟行情线（A）
- DS 锚：DS-MINIQMT / DS-TUSHARE / DS-BAOSTOCK / DS-TDX（kline_daily 能力迁移锚=miniqmt+baostock fallback）
- U1｜回答个股/指数价量趋势与动量能否预测 N 日收益（信号词：收盘价/成交量/振幅/均线斜率/20 日突破）。
- U2｜provider 增量拉取入库，边际成本≈零（账号内/免费接口，已运营）。
- U3｜日线日更盘后；分钟线盘后批量，延迟小时级。
- U4｜高——K 线落定不修订；除权除息须复权因子对齐，复权算子禁进 PIT 窗。
- U5｜L3 大盘状态变量 / L4 决策 / L5 执行验证（全表挂接密度最高线）。
- U6｜IC/分层回测+样本外复考；证伪=领先性样本外消失即退役。

### SL-A02｜Tick 分笔线（A）

- U3｜实时推送/日级落库；历史覆盖以包到货日为界，断档不可补。
- U4｜中——TDX 分笔仅最近交易日，历史依赖包；回填缺口风险显式登记。

### SL-B04｜电商价格线（B）

- U5｜L3（消费景气）/ L4。
- U6｜线上价格指数 vs 官方 CPI 分项；证伪=系统性背离无解释力。

### SL-B05｜招投标线（B）
