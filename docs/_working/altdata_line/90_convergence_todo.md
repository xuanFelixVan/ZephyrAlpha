## 收敛方法

对各域挖矿队列逐条打分（四格）：

| 维度 | 问法 |
|---|---|
| 数据可得性 | 零爬虫/便宜 API/地狱反爬？ |
| 信号浓度 | 机制上有没有真实传导链？学术/实证先例？ |
| 系统契合度 | 现有引擎/管道/考尺能不能直接吃？ |
| 维护成本 | 源会不会天天坏？PIT 能不能保证？ |

四格满格 = P0；三格 = P1；两格及以下进观察池。
