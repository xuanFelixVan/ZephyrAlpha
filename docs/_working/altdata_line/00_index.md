## 全局纪律（每域适用）

1. 公司主键 = 统一社会信用代码；自然人自建 person_id，**禁存真实身份证号**。
2. PIT 双轴：事实时间（valid_from）≠ 采集时间（ingested_at）；网页类源必须爬时存原文快照。
3. 隐形边/共现类（同电话、同地址、共同任职）是公开数据里有原料、平台不卖的差异化部分。
4. 结构化数据本机够；原文语料才进 20T 冷盘，**按需不全量**。
5. 每个假说先预注册（写死方向与检验），再进 E4/DSR 全流程；"最想信的想法"优先喂考尺。
6. 消歧 = 八成工作量；同名合并错误 = 假边 = 假信号。
