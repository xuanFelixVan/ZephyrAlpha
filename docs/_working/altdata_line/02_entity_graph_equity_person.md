# 02 实体图 — 股权穿透与人物节点

> 状态：已定调（底座） | 优先级建议：P0 | 更新：2026-09-17

## 1. 定位

不买"股权穿透"功能，自建**带时间版本的多边图**（股权边 + 任职边为骨干，可扩展技术/专利/亲属边）；股权穿透只是这张图的一个查询视图。范围 = A股 5000+ 上市公司的 N 度邻域子图，全市场 1.8 亿经营主体不碰。

## 2. 表结构

**node_entity — 统一节点表**

| 字段 | 说明 |
|---|---|
| entity_id | PK，自建代理键（人不存真实身份证号） |
| entity_type | person / company |
| name / name_norm | 名称 + 规范化名（消歧用） |
| uscc | 统一社会信用代码，公司的事实主键 |
| first_seen / last_seen | 首次/最近观测时间 |

**node_person — 人物明细**：person_id、姓名/曾用名（消歧金矿）、出生年份、任职轨迹摘要（hash 化，消歧核心特征）、关联公司交集。

**node_company — 公司明细**：uscc（PK）、注册资本/成立日期/注册地址/行业、年报电话/邮箱（**共现挖掘暗器**）、status。

**edge_holding — 股权边**：from_entity → to_company、比例/出资额、role（股东/GP/LP/一致行动人）、**valid_from/valid_to（变更追加新版本不覆盖）**、ingested_at、source。

**edge_role — 任职边**：person_id ↔ company、职务（法代/董事/监事/高管）、带版本区间，与股权边同权重。

**edge_link — 隐形边**：同电话/同邮箱/同地址（同一老板强信号）、共同任职/共同持股（朋友圈/利益链）、同校/同前雇主（弱信号）。每条带证据 + as_of。

**edge_tech / edge_inventor / edge_family**（续聊新增）：核心技术人员岗位、专利发明人（发明人×申请人×申请日）、亲属关系——同一 node_entity，不新建表。

## 3. 数据源四层

| 层 | 源 | 成本 | 反爬 | 用途 |
|---|---|---|---|---|
| A 上市公司股东层 | akshare（东财/巨潮源）：十大股东/十大流通/股东户数/实控人变动 | 免费 | 无 | 首批入库 |
| B 公告/招股书 | 巨潮 PDF：招股书穿透图 + 董监高简历（**人物履历最佳结构化源**） | 免费 | 无 | 复用既有 PDF 管道 |
| C 公示系统 gsxt | 官方全量 | 免费 | 地狱级（加速乐+极验，约 30 次/时/IP 触发验证） | 只按需查非上市关键节点 |
| D 商业 API | 天眼查 0.1–0.15 元/次、企查查（穿透最强）、启信宝（T+2） | 便宜 | 无 | 全市场规模化再买 |

核心技术人员数据补充：科创板强制披露（简历/认定/离职公告）；全板块股权激励名单公告（技术骨干最全名册）；专利发明人（发明专利公开延迟约 18 个月）。**官方披露只说"他走了"不说"去了哪"——去向靠专利反推+新东家新闻，是差异化空间。**

亲属关系数据补充：可见窗口=披露触发（招股书关联方章节、权益变动报告书一致行动人认定、年报董监高关系、证监会处罚文书"配偶账户"富矿）；未触发即不可见，但未触发通常也无持股联动。

## 4. 关键决策（钉死的）

1. 公司主键 = 统一社会信用代码；自然人自建 person_id 概率消歧（姓名+出生年+任职轨迹+关联公司交集）。
2. PIT 双轴：事实时间 ≠ 采集时间；网页类源必须爬时存原文快照。
3. 隐形边是公开数据里有原料、平台不卖的差异化部分。
4. 持股 ≠ 控制：一致行动/表决权委托/代持/VIE/GP 控制图上不可见，用信号时知悉。
5. 穿透到境外（BVI/开曼）即断线；工商公示可见有数天–数周延迟（事件驱动信号的时间变量）。
6. 规模：结构化图 GB 级本机够；原文语料才需 20T 冷盘（按需不全量）。

## 5. 信号用途清单

牛散跨票识别与跟风 / 龙虎榜席位→背后公司连点 / 同实控人概念联动 / 质押冻结链传导 / 定增利益链 / 人物利空新闻→名下公司→情绪接线避险 / 核心技术人员流动（领先指标=专利申请人变更）/ 一致行动人网络重建（亲属边×股权边）/ 二代接班与代际传承。

## 6. 挖矿队列（待验证）

- 人物利空传导链：新闻→实体链接→人物→公司 N 度→持仓规避（缺的胶水=别名集+实体链接；接既有新闻源与情绪线）。
- 代际传承因子：实控人年龄+二代任职/持股 → 交班窗口（数据现成，见 04 假设 #6 同源）。
- 隐形边挖掘：联系方式/地址共现、共同任职图谱。

## 7. 坑与边界

消歧是八成工作量（同名合并错误=假边=假信号）；裁判文书网 2021 后上网收缩不作主力源；专利发明人同名同理；逐股接口全市场拉取过慢（配股任务 disabled 在案）。

## 8. 施工顺序建议

股东层（akshare 零爬虫）→ 招股书董监高+核心技术人员简历（同一 PDF 同一管道）→ 激励名单 → 专利层与亲属层（第二批，门槛高但差异化最大）。
