# 06 传导链引擎 — 三层架构与 MVP 施工设计

## 1. 定位与核心命题

传导链是把"分析师叙事"变成"可回测机器"的引擎。判断标准：这套东西是"活的"还是"又一堆散文"——三个决策分界。

## 2. 决策一：传导链是三层，不是一张图

大多数传导链分析（含 Wind Alice 式文章）只有结构层——谁连谁，这种东西是散文。完整传导链三层：

| 层 | 内容 | 现状 |
|---|---|---|
| **结构层**（图拓扑） | 节点五类：商品/行业/公司/人物/宏观序列；边六类：供需/成本/股权/舆情/政策/资金 | **几乎全有**：D1 图 5,560 节点 + 16,859 IO 边是现成骨架 |
| **参数层**（定量） | 每条边三属性：时滞、方向与弹性、状态条件 | **估出来的，不是画出来的**——缺 |
| **运行层**（触发） | 真实事件 → 定位冲击节点 → 沿图游走 → 输出影响集（哪些资产/什么方向/多久传导/多大把握） | 缺 |

**对账结论**：三层里真正要从零建的只有三件——①节点挂价绑定表 ②传导参数表+IRF 估计管道 ③图游走引擎。其余全是接线（D1 图、公告线、情绪线、作战室、溯源机制全是现成件）。

## 3. 决策二：两条铁律 + 衰减制度（防散文退化机制）

**挂价铁律**：挂不上可观测价格序列的节点，不进传导图。没有观测就没有参数估计；没有参数的链条就是叙事文——好看，不可证伪。每个入图节点必须绑定 `price_series_id`（商品→期货代码、公司→行情、宏观→indicator_name）。

**证据分级制**（每条边强制声明级别）：

| 级别 | 定义 | 权限 |
|---|---|---|
| **A 级·可交易边** | 两端有价格 → 分布滞后回归/局部投影（Jordà LP，处理"冲击如何随时间传导"的标准工具）估计脉冲响应 + 样本外检验过 | 允许进自动决策 |
| **B 级·行业边** | 只有行业指数代理，弹性粗估 | 只做半自动提示 |
| **C 级·叙事边** | 只有研报支撑 | **禁止进自动决策**，只做研究提示 |

**副产品（与研报挖矿线咬合）**：E 盘 3 万份研报挖出的每条链条，落地即一条 C 级边（带证据+研报出处），数据补齐后逐级晋升 A/B。两条挖矿线就此共用同一产出格式：**边 + 两端节点挂价 + 证据级别 + 研报溯源**。

**衰减制度**：每条边带 `fit_quality` 与 `last_verified`；影响集事后对账不合格自动降级（A→B→C→休眠）。传导链会腐烂（北向就是先例：政策一改传导路径就断）——这是"会犯错但错不过夜"的边级版。

## 4. 决策三：时滞是曲线不是数字；事件双向走

- **时滞用脉冲响应函数（IRF）表示，不用单点 lag**。油价五波的每一"波"本质是一条 IRF 的峰值点：运价对油价 1-2 周见峰后衰减、化工品 1-3 月。IRF 能回答"冲击过去 45 天后还剩多少影响"，单点 lag 回答不了。
- **状态条件起步从简**：黄金-利率链已演示同一条边不同状态下符号相反（实际利率驱动 vs 期限溢价驱动）。但第一版不上 HMM——只做**滚动窗口符号翻转检测**，翻转即打"参数不稳"标记降级。够用，且不引入新的过拟合面。
- **事件双向走**：
  - 正向（预警）：事件 → 冲击节点 → 图游走 → 影响集 → 规避/受益清单；
  - 反向（归因）：持仓 → 反向扫上游节点昨日跳变 → "你为什么跌"每日归因报告。
  - 反向实现更简单（不需事件分类器，只扫跳变）但**日用价值最高**——直接接作战室/日刊。与正向同期做。

## 5. MVP：打穿一条链，不先建大图

大图是长出来的，不是画出来的。样板链选**油价五波**：

- 数据大半在库：EIA ✅、化工期货 ✅；
- 只差 3 个快赢件：公路运价、交易所仓单、肉蛋菜批发价（总图均已标【快】）；
- 叙事对照现成：那篇五波网文就是待证伪命题。

**MVP 交付物定义**：一份全自动生成的《原油跳变日 → 影响集 T+1..T+60 对账报告》。这一份报告跑通 = 三层架构全部验证；之后每加一条链都是复制粘贴的边际成本。

## 7. 冲击源映射表（批次①：从骨架 115 中类挖「谁能当触发器」，2026-09-17）

> 挖法：逐族问一个问题——这个中类的数据发生变化时，会构成对图中某类节点的冲击吗？冲击分三类注入：**价格跳变**（序列观测）、**文本事件**（实体链接后注入）、**日历冲击**（已知时点，可预演）。

### A 行情族——公司节点自身的状态序列（反向归因主源）
A1 价格跳变/量异动（Gap/异常量）→ 公司节点冲击 ｜ A2 竞价异动 → 隔夜信息的价格确认 ｜ A5 连板高度/晋级率跳变 → 板块情绪冲击（风险偏好信号）｜ A7 两融余额变化 → 杠杆资金冲击 ｜ A8 期指基差走阔 → 系统性风险前兆 ｜ A19 大中小单资金流 → 主力/散户行为冲击

### B 财务族——基本面冲击（事件注入）
B2 业绩预告/快报 → 盈利冲击 ｜ B3 财务质量恶化 → 信用/减值风险传导 ｜ B7 分析师预期修正 → 预期冲击（领先）｜ B13 附注异动（政府补助依赖/大额减值）→ 利润含金量冲击

### C 文本族——信息冲击（经实体链接注入）
C1 公告全族（03 线六因子家族）→ 公司冲击主力源 ｜ C3/C4 新闻社媒 → 舆情冲击 ｜ C13 政要/央行言论 → 宏观与行业冲击（鹰鸽打分）｜ C9 调研纪要 → 预期微调信号

### D 实体族——传导的结构载体与人物冲击

### E 宏观族——系统性冲击

### G/H/J——软冲击、隔夜第一跳、可预演冲击
G1/G5 情绪指数与文本情绪 → 风险偏好/软冲击量化 ｜ **H3 外盘商品隔夜 → 隔夜传导第一跳** ｜ H2 美股 → 全球风险偏好 ｜ H7 CFTC → 投机拥挤度 ｜ J1/J2/J9 财报/解禁/交割日历 → 已知冲击时点（可预演）

**挖矿结论**：115 中类里约 40 个可作冲击源，其中**已建✅约 22 个**（A1/A5/A7/A8/B2/B7/C2/C3/E1/E3 部分/H3 等）——MVP（油价五波）所需的注入源基本现成；**未建但关键的注入源 6 个**：A19 资金流、C1 公告、C13 言论、E8 成品油、F13 批发价、D6 板块指数——全部【快】，与 05 施工令并行接入即可。

### 工程防护（「无数传导链」的代价）
- 节点多上游多下游 → **影响集聚合**：按节点聚合所有路径的衰减贡献，不罗列路径；
- 股权/舆情边会造环 → 游走带 visited 防护 + 权重衰减收敛；
- 组合爆炸 → 最大跳数 + 最小权重截断（阈值进配置，可调可审计）。
