# 04 玄学 — 数据与因子

> 状态：已定调（实验性） | 优先级建议：压力测试实验，非因子押注 | 更新：2026-09-17

## 1. 定位铁律

玄学无因果，但"A股实控人信玄学"是真实文化现象 → 玄学字段只作为**行为代理变量**，且必须走预注册 + E4/DSR 全流程。定位 = **给防过拟合机器做压力测试**：用"最想信的想法"喂考尺，两种结果都是赢（死了=验证考尺对最想信的也会开火；活了=值得二次实验，但大概率多重检验噪声）。

## 2. 数据现实

年报只披露出生**年份**（全员）→ 只能算**年柱+生肖**（原以为年柱算不出，实为恰好相反）；月日少数可得（招股书/处罚文书/港股），时柱≈不可得；星座需月日、覆盖率更低。八字大多只有 1/4。

## 3. 假设清单（按数据可得性排序）

1. **本命年效应**：实控人本命年是否更少质押/并购/增持、更保守（只需出生年份，最干净的玄学实验）。
2. **生肖行情**：龙年"龙字辈"、蛇年"蛇概念"等生肖文化资金流——A股真实存在的玄学交易（对个股不对个人）。
3. **玄学倾向画像**：择日公告/改名蹭字/数字偏好 → 实控人玄学置信度 → 行为模式差异。
4. **逢九坎/流年不顺** → 高管离职、健康事件（样本量小，统计功效存疑，预期 DSR 毙）。
5. **颜值因子**：招股书董监高照片打分（有 CEO 面相学术文献先例，弱效应+高过拟合风险）。
6. **代际传承**：实控人年龄 + 二代任职/持股边 → 交班窗口预测（CEO succession 学术先例；数据现成，属人物节点免费赠送的治理因子——这条不是玄学，是正牌治理因子，与 02 共用数据）。

## 4. 挖矿队列

- **破冰船 = 生肖行情**：无需人物节点，事件日历+名称匹配即可回测，今天就有数据可跑。
- **正式实验 = 本命年效应**：预注册假设 → 实控人出生年份入库 → E4 → DSR 判生死。
- 传承因子随 02 的 edge_role 建成后顺路计算。
