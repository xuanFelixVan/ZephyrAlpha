# 03 公告 — 数据与因子

> 状态：已定调 | 优先级建议：P0 候选 | 更新：2026-09-17

## 3. 表设计三件套

`announcement_meta`（元数据+分类）→ `announcement_event`（结构化事件：实体×类型×公告日×关键字段×抽取置信度）→ 因子层。**PIT 锚 = 公告日。**

## 4. 因子家族

1. **减持链**：预披露 → 15 个交易日锁定期 → 窗口开启（窗口内集中竞价 90 日 ≤1%、大宗 ≤2%）→ 进展 → 完成。"高位出减持计划" = 股东自认贵的信号；计划 vs 实际完成率（忽悠式减持）。
2. **股东成本表**（核心构想，可行）：三类成本可算——原始股（≈1 元改制成本）/ 定增价（公告明码）/ 二级增持区间价（公告披露）→ 成本/现价比 → 减持意愿与出货压力位。**1 元成本股东在低位减持 = 最毒信号**（任何价位都赚却要卖=比你更悲观）；定增解禁临近+接近成本 = 抛压位。技术坑：除权除息必须复权调整历史成本，否则高送转一次成本表全错。
3. **回购/增持链**：金额占比、完成率、注销式 vs 激励式（注销信号更强）、到期未完成（忽悠式回购）。
4. **业绩链**：预告→快报→正式报告三点差异（变脸因子）、披露时点早晚（拖到最后=坏消息）。
5. **治理链**：问询函及延期回复（拖愈久愈毒）、非标审计意见、变更募资用途、立案/监管函。
6. **重组链**：预案→问询→终止/过会，失败负向跳空。

## 5. 挖矿队列（待验证假说）

- 减持窗口漂移：预披露公告后跳空 + 窗口内漂移的时变结构（市场已知规则，alpha 在算得细：谁在减、成本多少、完成率）。
- 股东成本表 → 出货压力位预测（解禁日历 × 成本距离 × 减持计划标记）。
- 兑现率家族：减持/回购/增持三类承诺的兑现率作为治理质量因子。
- 业绩披露时点效应。
- 问询函延期回复次数的定价。

## 6. 坑与边界

市场已知规则的部分只有薄超额（需算得更细）；PDF 全量下载既没必要也撑爆磁盘；LLM 抽取必须有置信度字段+抽检机制（抽取错误=假因子）。
