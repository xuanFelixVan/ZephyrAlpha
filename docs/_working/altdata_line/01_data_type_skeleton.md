## 分类学纪律（拆分停止判据，批次⑥定调）

**骨架拆分的停止线 = 数据生产者/获取渠道发生变化的那一层。** 往下不再拆，三个判据：

1. **生产者或接口变了 → 拆**（发改委调价 vs 秦皇岛现货 vs 电网公司 = 三个生产者，分开；东财能源板块一次接入煤油气全来 = 同一片叶，品种全集由接口决定，不由图预先枚举）。
2. **回测口径变了 → 拆**（频率不同/PIT 锚不同/单位量纲不同 = 必须分表）。
3. **只是标签变了 → 不拆**（「股票舆情 vs 民生舆情」是同一新闻源上的主题标签，是建表字段不是骨架节点）。

**推论**：叶层条目是**示例不是穷举**；完整性检查发生在中类层（防漏族），叶层的品种全集在建表时由接入的接口自然给全。图预先枚举到品种级 = 图会腐烂（源一变就过时）。

**按此判据的两例演算**：
- 舆情：骨架拆到「按载体」（C2 研报/C3 新闻/C4 社媒/C11 官媒/C6 互动易）为止；「按主体」（股票/宏观/行业/人物/民生舆情）是载体之上的**主题标签字段**，建表时打标，不设节点。
- 能源：骨架拆到 F6/E8（+E3 商品）为止，结构 = 品种族（煤/油气/电/新能源材料）× 环节（价格/库存/产量/进出口/开工率）矩阵；叶上列的是「不同生产者」的代表（秦皇岛≠发改委≠EIA≠硅业分会），品种全集建表时由接口给全。
