## 3. 缺口诊断（四条）

1. **消歧桥空置**：ig_entity_code_map 仅 2 行。18,819 公司映射与 14,070 非上市实体之间、以及未来研报抽取的实体，都没有可靠对齐桥梁。不补此件，一切抽取都会长假边。
2. **BOM 边类型缺位**：现有 io_edge 是公司/行业级供需，缺"产品→部件→原材料"的层级 BOM 边。
3. **边无时滞属性**：油价传导链要求边上挂 lag/弹性（价格传导时滞矩阵），当前边无此字段。
4. **抽取管道未接线**：研报→图谱的 LLM 抽取管线不存在（但 pdf_forecast_extracted 是现成先例，可复刻）。

## 4. 施工工作包（按序执行）

### WP-0 实体消歧桥（前置，最优先）
- 目标：ig_entity_code_map 从 2 行建成可用桥。
- 做法：以统一社会信用代码（uscc）为公司侧主键（对接 02 实体图线的 node_entity）；对 18,819 ig_node_company 映射做一次清洗对账；非上市实体挂自建 entity_id；同名/曾用名消歧规则落表。
- 验收：随机抽 100 条映射人工核验 ≥95% 正确；ig_entity_code_map 覆盖 ig_node_company 全量。

### WP-1 主营构成补全（第一层，可并行开工）
- 目标：ig_product_revenue 从 52,404 行补到全市场覆盖。
- 做法：akshare `stock_zygc_em`（主营构成：分产品收入/成本/毛利率）全市场 5000+ 家灌库，与存量对账后增量入库；带公告日 PIT 锚。
- 验收：上市公司覆盖 ≥95%；抽样 20 家与年报原文一致。
- 备注：零爬虫，可与 WP-0 并行。

### WP-2 研报抽取管道（第二层，主战役）
- 目标：研报 → 产业链边/BOM/公司映射的结构化抽取管线。
- 原料：E 盘 3 万份 2019 库（85GB，`E:\数据下载\研报`；用途=方法论框架抽取+叙事回测考卷）+ F 盘 6 万份（近期，实体边抽取主料）。
- 步骤：①分层抽样 200-400 份做"链条密度分型"（BOM 型/传导型/估值框架型/周报型）→ ②高密度类型定向 → ③LLM 抽取（复用 pdf_forecast_extracted 先例）→ ④抽取物登记 ig_document/ig_chunk 溯源 → ⑤经 WP-0 消歧桥挂边。
- 红线：每条边必须带 source（文档+块）+ 抽取置信度；置信度低于阈值入人工复核池，不直接挂图。
- 验收：抽 30 条新边人工核验，正确率 ≥90%；溯源链可从边反查到原文块。

### WP-3 BOM 边类型与时滞属性
- 目标：新增产品级 BOM 边（公司→产品→部件→原材料，层级属性），io_edge 补 lag/弹性字段（价格传导时滞矩阵，油价链落地）。
- 做法：表结构评审（新表 ig_bom_edge vs io_edge 加列，按 PG 侧惯例定）；时滞估计用分布滞后回归离线计算后回写。
- 验收：试点一条链（建议半导体或新能源车）全链贯通：原材料价格 → 部件 → 产品 → 公司毛利率的传导路径可查。

### WP-4 因子挂接（第三层）
- 目标：BOM 叶子挂商品期货/现货代码 → 成本传导/毛利率压力因子进回测。
- 前置：WP-3 试点链完成 + 商品期货覆盖（H3，注意贵金属等缺口已在总图挂【快】）。

### WP-5 前端可视化（后置，可选）
- chainmap 渲染 BOM 分层与新边类型；GALAXY 上区分边类型配色。非阻塞项。

## 5. 施工纪律（铁律）

1. 走仓库正门：worktree 隔离、改前 claim、提交走 git_commit.py；本仓库宪法全程适用。
2. PIT 铁律：研报抽取的边，事实时间=研报发布日；主营构成事实时间=公告日；绝不回填。
3. 消歧红线：宁缺毋假——对不上的实体挂"待消歧池"，禁止自动合并同名。
4. 抽取置信度门：低置信入人工池，图上不留无声的 LLM 猜测。
5. 每个工作包独立提交、独立验收，禁止混批。
