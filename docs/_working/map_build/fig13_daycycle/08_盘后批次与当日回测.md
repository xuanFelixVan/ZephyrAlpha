（顺带纠一处三坑风险：两查询都写了 `FINAL`，但 G1 用 `ch_reader` TSV 文本解析、G2 用 `clickhouse_driver` 对象——同一水位两个读法，替代一致性靠 `FINAL` 而非靠同一入口。）
