## §2 D11-C12 机器车道与紧急通道

### 上
- 触发：reconciler / 批处理需要 commit 但非交互——gateway `_commit_auto`（:3845）。
- 门控：`_commit_queue_serializer_enabled()`（:325，唯一点，fail-closed：设施异常=OFF 现状直提不变）读 flag `commit_queue_serializer`（gateway:316；`config/flags.yaml:81`）。
