# Kimi 深度挖矿 + 全面审查 执行方案与指令包

> **定位**：full-auto-chain 骨架（S01–S15）已施工收口，但昨晚挖矿=一层深度（flash 模型）。
> 本战役用 Kimi 按 **mining_sop v1.3.0**（矿脉枯竭终止/无轮数深度候选上限/世界地图完备优先）把全流程挖到底，并对重点代码/管线/算法做全面审查。
> **分工铁律**：Kimi=挖矿+审查+出方案（产出全是文档=**数据**）；施工与采纳裁定=主力会话（按施工 SOP）。Kimi 输出禁直接变施工指令（宪法 §9.11）。

## 1. 战役目标（北极星）

1. **世界地图完备**：全流程每个环节、每个子模块、每个算法机制挖到矿脉枯竭（六向全查无+无未挖长尾），产出完整"全流程世界地图"——哪些建/哪些合/哪些落后/哪些废，材料齐全。
2. **重点深挖**：T1=钱相关三处（见 §3 优先级）。
3. **审查四类**：核心算法数学正确性 / 管线架构 / 红蓝对抗 / flash 盲点补查（见 §4）。
4. **交付**：每节点挖矿文档+审查报告+统盘施工建议清单（建/合/废/挂四态），交主力会话裁定后施工。

## 2. 运作方式（网页投喂模式，默认）

Kimi 无仓库文件系统，采用"**分批投喂→产出 markdown→主力会话落盘**"循环：

1. Owner 按 §5 投喂清单把材料贴给 Kimi（每批一个任务包）。
2. Kimi 按下方 §6 指令产出：节点挖矿文档 / 审查报告（markdown 全文）。
3. Owner 把产出交给主力会话：落盘到对应环节子文件夹+登记 creation_token+挖矿日志核验。
4. 主力会话按产出决定下一批投喂（新矿脉=追加节点材料）；直到该环节矿脉枯竭→封矿。
5. 全环节封矿后：Kimi 出"世界地图总览+统盘裁定建议"→主力会话过挖后自审闸→施工立项。

## 4. 审查四类（与挖矿并行的独立任务线）

1. **核心算法数学审查**：增量 IC fitness（gplearn/残差 rank IC）、AST 原创性门（Jaccard≤0.8）、四闸/Wilson/FDR、整装回测权重生成与面板对账、sim 偏离判定、FSM 状态机。要求：逐个算法给出"数学上对不对/有没有隐含假设/边界条件/A 股口径适配"四问结论。
2. **管线架构审查**：双调度体系并存（Windows 计划任务 vs APScheduler）统一方案；`build()` vs `generate_target_weights` 双接口；`research/` 休眠模块去留；事件链 emit 时序单点故障；失败静默点扫描。
3. **红蓝对抗**：以攻击者视角过全链——哪里会静默失败/假阳性过关/断了没人知道/数据迟到怎么办/重复触发怎么办。
4. **盲点补查（flash 短板）**：长上下文全仓一致性核对（文档 vs 代码漂移）；中文研报/A 股语境 SOTA 增量（上轮外部对照以英文 arXiv 为主）；跨模块同类功能合并机会清单。

```
【角色】你是 ZephyrAlpha（A 股全自动量化交易系统，100% AI 开发，Owner 一人）的深度挖矿与审查专员。
系统终局：Owner 只做四类事（数据类网站账号注册/API 申请/各类充值/策略转正审批），其余全部自动化。

【总任务】两条任务线并行推进，直到全部矿脉枯竭：
A. 深度挖矿：对我投喂的每个环节/节点，按"六向寻路"挖到底——
   ①上游（还有什么信息该喂进来）②下游（输出还该喂给谁）③算法/机制（业界学界最新做法，
   必须 URL+发布方+年份，A 股 T+1/涨跌停/散户主导适配改造）④后端（代码侧缺什么，开源实现
   参考）⑤前端（怎么呈现，只登记不施工）⑥数据字段（要什么字段，我们有吗）。
   每向必须产出 ≥1 条发现或"已查无"（查无也是有效结论，记档）。
B. 全面审查：对我投喂的源码/管线，按四类审查出报告——核心算法数学正确性（数学对不对/
   隐含假设/边界条件/A 股口径）、管线架构优化（合并/统一/休眠模块去留/单点故障）、
   红蓝对抗（哪里会静默失败/假阳性过关/断了没人知道）、盲点补查（文档与代码漂移/
   中文研报与 A 股语境 SOTA 增量）。

【挖矿纪律（铁律，v1.3.0）】
1. 终止判据=矿脉枯竭：当前节点六向全部"已查无"且无未挖长尾。没有轮数上限、没有深度上限、
   没有候选数量上限——挖出子节点就在子节点上继续挖（子节点的六向），直到自然底。
   noise 轮只记档不终止（实战证明双噪音后继续挖仍能挖出新矿脉）。
2. 每条发现过四闸才算数：来源可溯（URL+发布方+年份，禁凭训练记忆断言"业界都这么做"）/
   交叉验证（关键结论≥2 独立来源，单来源标"待验证"）/A 股适配/可回测+数据可得。
3. 搜索受阻（限流/断网）如实记"受阻"，不算查无；禁把编造当引文。
4. 优先级：交易决策全景图/整装回测、验证认证链、因子策略工厂先行，只定先后不定深浅，
   最终全部挖到底。
5. 世界地图完备优先：不要建议"先施工再挖"——先把全貌挖尽，统盘给出
   建/合/废/挂四态建议，我方统盘裁定。
```
