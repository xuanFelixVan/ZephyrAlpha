### 1.3 统计量定义（含 mainline 的分类法不变化）

* `x_t` = 生产 `limit_up_count`（§1.1 已验证与生产逐元素等值）。
* `n_t` = 当日「可覆盖样本数」（同谓词下 join 到的 symbol 数，即当日**有机会**被判涨跌停的股票数）。
* `rate_t = x_t / n_t × 100`（涨停率，规模无关）。
* **候选统计量族**：`C1_static_x`（绝对家数 + 静态展开窗分位）、`C2_roll250_x`（绝对家数 + PIT 滚动
  250 日分位）、`C3_roll250_ratio`（涨停率 + PIT 滚动 250 日分位）、`C4_static_ratio`（涨停率 + 静态
  展开窗分位）。PIT 定义：`thr_t = quantile(s_{t-250..t-1}, q)`，实现为
  `series.shift(1).rolling(250, min_periods=60).quantile(q)`（`analyze_money_effect.py:73-75`），
  **严格不含当日**，无前视。
* mainline：`hhi_t` = 生产实现（`:712`）；`n_t` = 当日有可用收益的板块数（生产 `sum` 的 skipna
  语义，`share` 全行和为 0 时 hhi 为 NaN）；
  **`hhi_norm = (hhi − 1/n) / (1 − 1/n)`** —— 标准 effective-number-of-concentrators 式修正：只把
  「完全分散」时的 1/n 地板抬到 0、把上界归 1，**不**声称消除了全部分类法依赖（§2.3 实测它没有）。
* 稳定性比 `S = OOS 命中率 / IS 命中率`（逐 fold），命中率为 0 的 fold 不计入 S。
