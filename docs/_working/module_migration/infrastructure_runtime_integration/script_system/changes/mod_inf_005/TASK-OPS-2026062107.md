# 批量修复 N-01 文件名含连续大写字母(98个)

## 目标
根因: 98 个文件名含连续大写字母(如 MyClass.py),违反 snake_case 命名规范。
施工步骤:
1. 运行 check_naming_convention.py --scan --warn-only 获取 N-01 违规清单
2. 编写批量重命名脚本 fix_n01_uppercase.py,将大写文件名转为 snake_case
3. 更新所有引用旧文件名的 import/路径
4. 运行验证命令确认 N-01 违规=0
验收标准: check_naming_convention.py --scan --warn-only 输出中 N-01 违规数=0

## 验收标准
- python scripts/governance/d3_metadata/check_naming_convention.py --scan --warn-only 输出中 N-01 违规数=0
