## 3. 诚实结论

1. **Owner 论点在本考试窗、vol_pct 灰度轴上成立**：幸存者净收益显著集中于高波灰度桶（14/17 同向，POOLED 极差 2.27）。"考试不看行情状态"确实丢掉了关键条件——尤其 FACT 族 7 条在高波段的桶内 Sharpe（2.2..3.0）远高于其整窗成绩（1.3..1.9）。
2. **但条件化红利有明确边界**：a) 四条反例策略反向或失效，全员一刀切不可行；b) MID 荒漠与 U 形分布说明状态→收益不是单调关系，与 regime 层已知结论一致——波动率是风险轴而非方向轴（裁定 #229 探针：vol→fwd20 回撤双段同向；高波后的暴跌反弹溢价是市场结构性质，detector docstring 在案）——本结果更像"幸存因子吃的是高波段反弹/动量溢价"，而非"高波=该做多"。
3. **暂无证据的部分**：本卡只考了一个状态变量、一套三桶切法、一个考试窗。能否外推到 2025-09 以后、五态判定/7 维概率轴上是否同样成立、按桶切换组队是否比静态持有更优（含切换成本）——均**未考试，不下结论**。
4. 多重检验声明：17 策略×3 桶虽边界冻结，最优桶的事后选择仍可能高估 HIGH 桶效应；判读阈值（极差 0.5）是本卡自设的弱标准。故本报告结论定级为**"存在集中性证据，待下窗复考"**，不升"规律"。
