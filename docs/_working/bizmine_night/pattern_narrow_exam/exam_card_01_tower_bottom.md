## 2. 执行模型（PIT 可执行口径，与 P 的 close-to-close 不同，写死）

1. 信号日 T=anchor_trade_date（confirmed_at=T 15:00 CST 收盘，PIT 确认，P 已验 dateDiff=0）。
2. 入场=T+1 交易日开盘价 open(tseq+1)；持有 N∈{5,10,20} 交易日；出场=open(tseq+1+N)。
3. 毛持有收益=open(tseq+1+N)/open(tseq+1)−1；窗内任一 open 缺价（停牌/末尾截断）→ 该仓整仓缺测剔除。
4. 组合=等权所有在仓信号（无选股加权），日度 open-to-open 计价；无在仓信号日=空仓（收益 0）。
5. 事件表去重与映射照 P（(name,direction,sym,anchor) DISTINCT，prewired 103 cell 映射表）。

## 5. 判定门槛（写死，主窗=10 日）

## 6. 显著性三重（全部报告）

## 9. 已知局限（诚实条款）

1. 未复权→分红除权日压低 r_N，塔形底多发生于下跌后（除权密集带），方向偏保守但幅度暂定。
2. 涨跌停/停牌无法成交未建模（T+1 开盘若一字板不可买）——本 cell 信号为塔形底（非涨停），影响小，仍披露。
3. 重叠持仓的相关性由 NW+簇 bootstrap 处理，跨股残差相关不完全独立。
4. P 的 prev20 诊断显示「跌得深→反弹」贡献部分超额（corr=−0.23），本考为原始超额不做中性化（如实标注）。
