- **格子结果来源**：W2-T2 沙箱正式考（三张 frozen 预注册卡+三份考试报告，`{ofi,momentum,vwap}_prereg_card.md`/`_exam_report.md`，数字三口径见 `algo_top3_results.csv` 16 行全量）。矩阵层对沙箱结果做**矩阵纪律复核**（格映射/功效门/BH 账/N 账），不重跑不重算。
