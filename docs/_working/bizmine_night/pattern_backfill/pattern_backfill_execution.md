### 3.2 亮点与警示

1. **开收反转/向上**（PAT-CANDLE-080）：唯一三窗全正+分年 6/6 正+单调 vol 递增（高波桶 +50.3bp/10日）。
   语义=首 bar 单边推进、次 bar 反向收穿首 bar 收盘（动量衰竭反手）——与 PATX 窄考 PASS 件塔形底/双底同属
   「衰竭反转」族，建议升预注册窄考卡（走 T+1 开盘+成本协议复检）。
2. **枢轴点反转/向下**（PAT-CANDLE-082）：创昨高但收穿昨低的熊态信号后**跑赢基线**（+20.8bp/10日、6/6 年正、
   三 vol 桶同号）——假突破反向的反弹效应（与 PATX ④「拥挤突破信号更差」互为镜像证据）。
3. 中位数普遍为负而均值为正=**长尾贡献主体**（两极：极端延续），正考必须并报中位与按日组合口径（PATX §2 教训）。
4. 内包日=中性 setup 无独立边（符合定义预期，-5.3bp/10日）；低波桶 +28.2 暗示「低波内包后」异象，仅登记不展开。
5. 钩形反转双向皆负、鲨鱼32 小样本不稳——如实记负/不结论。
