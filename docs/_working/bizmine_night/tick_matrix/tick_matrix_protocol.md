# tick_matrix_protocol.md — tick 信号族小矩阵月度考试规程

> 本件是 tick 信号族（S1-S4）×聚合级×执行模型小矩阵的**唯一考试规程真源**。矩阵定义与判定纪律 frozen；tick 数据每月增量后按同协议重跑（§5）。出处：bizmine 总包令裁定「全矩阵今晚不做（裁定 #304 多重检验数学对 tick 样本更致命），改行预注册小矩阵+滚动前向考试」。

## 1. 矩阵定义（frozen，禁扩格）

- **标的（3 只，恒定）**：510300（任务锚定）+ 2 只高波流动 ETF。选样规则（先于测量写死，禁事后挑）：
  IS 窗=每年 1 月 2 日→6 月 30 日的 `kline_etf_1min`；ADV_IS（日成交额均值）≥ 2 亿元；按 1min bar 振幅
  `(high−low)/open×1e4` 全窗池化中位降序排名；取排名最先且 tick 联合覆盖（双符号变体，有效天≥100）的前 2 名。
  2026 基线选出：**512170（华宝医疗 ETF，ADV 5.81 亿/振幅 30bp）+ 512010（沪深 300 医药 ETF，ADV 5.68 亿/27bp）**。
  标的年检：每年 1 月按同规则重选一次，换标须在协议修订段登记（旧标的格子保留历史台账）。
- **信号族（只此四族，禁追加）**：
  - **S1 逐笔大单失衡**：大单阈=上一有效日逐快照增量成交量 q99（PIT）；桶内失衡比
    `imb=(Σ大买单−Σ大卖单)/(Σ+Σ)`；`imb≥+0.6` 多 / `≤−0.6` 空。方向字段（买入/卖出）可用则用之；
    否则按 tick 规则（价升=买/价降=卖/平=延续）近似**并逐格声明降级占比**。快照级语义（bdpan 3s）如实声明。
  - **S2 微脉冲**：`|桶收益| ≥ θ2`（θ2=上一有效日同级 |桶收益| q99，PIT）→ 顺信号方向入场。
  - **S3 竞价-开盘段动量**：定义=9:15-9:30 竞价段信号。**基线降级声明**：auction_book 对三标的全零覆盖、
    tick 段 9:15-9:30 无行（probe2/probe3 实测），降级为开盘段动量（开盘 5 分钟收益 vs 日开盘价，|ret|≥10bp
    才入场，9:35 首个桶收盘价入场，每日至多 1 笔）。竞价数据补齐后自动升回原生定义。
  - **S4 五档失衡**：`imb5=(Σbid1..5−Σask1..5)/(Σ+Σ)`（tick_depth_5 桶末值），`imb5≥+0.3` 多 / `≤−0.3` 空。
    **仅 tick_depth_5 覆盖内标的与日期可考；覆盖外标 `unavailable`，不算 RED 不扣分**。
- **聚合级（3 档）**：1s / 10s / 60s。有效采样节奏=源快照节奏（bdpan≈3s / miniqmt≈4s）——1s 档实为逐快照级，如实声明。
- **执行模型（2 种）**：M1 吃单；M2 被动挂单。持仓互斥（在仓忽略新信号）；持有期=60 桶（1s→60s，10s→600s，60s→3600s）；
  14:55 强平。M2 成交假设（保守，承 TICK 车道预注册）：挂单价=信号桶收盘±半个实测日中位价差；
  成交判据=120 秒内（墙钟）后续桶 low/high 穿越挂单价；成交价=挂单价（不给价格改善）；
  超时未成交转吃单（按当桶收盘价+该腿吃单成本）；14:55 未平一律转吃单。
- **总格数**：4 族×3 级×2 执行×3 标的=72 格上限（S4 受覆盖限制实际更少，如实标 unavailable）。
- **成本（frozen，口径=引擎现行）**：佣金万 0.854 双边+¥5 地板（`matching_logic.py` COMMISSION_RATE/MIN_COMMISSION）；
  M1 滑点按 ADV 五分位档（`cost_model_calibration.py` SLIPPAGE_TIER_BPS：Q1 7.24/Q2 5.69/Q3 4.67/Q4 4.00/Q5 2.34 bp/单边，
  含价差+逆向选择；档界 0.464/0.902/1.740/4.180 亿元，按当日实际成交额定档）；ETF 免印花。
  M2 被动腿仅佣金；转吃单腿加该档滑点。省价差与逆向选择经模拟成交价内生结算，另逐格披露实测 AS 统计
  （被动成交后 60s 中位价逆势漂移均值）。
- **数据源（frozen）**：`c1_market.tick_data`（双符号变体并集，带后缀优先）+`c1_market.tick_depth_5`（S4 专用）。
  有效日判据：tick 行数≥500 且去重时间戳≥300 且全部落在 09:25:00-15:00:00。
- **判定门（frozen）**：净捕获门槛 12bp/往返（承 T 车道口径）。

## 2. 判定纪律（frozen）

1. **每格输出**：往返净捕获 bp 分布（p25/p50/p75/mean）、过 12bp 天数占比（日均值≥12bp 的天数/share）、样本日数、笔数。**全部格子如实入册（含烂格）**，状态机：`ok / insufficient_data（有效日<10）/ unavailable（数据零覆盖）`。
2. **多重检验**：全格 Benjamini-Hochberg FDR q=0.10（p=日级单侧符号检验，日净值>0 占比，并列零剔除；有效日<10 的格不进 BH）。BH 通过且 p50>0 者按 p 升序取**至多 3 格标「筛出亮点」**。**禁出 PASS 判定——筛≠考**（裁定 #304 的累计 N 账：本协议每轮亮点必须计入跨轮累计 N，见 §5.3）。
3. **短窗功效声明**：逐格标样本日数与笔数；分月/分半稳定性小节（半 split：H1=当年 7 月→次年 1 月，H2=次年 2 月→6 月；基线 H1=2025-07-01→2026-01-31，H2=2026-02-01→2026-09-18），报告同号性占比。样本窗比 40-60 日更长的月份如实报更长（功效更高不是问题，少报才是）。
4. **诚实条款**：成本口径必须写明（本协议=引擎现行档）；负结果全部入册；数据缺环如实声明；禁虚报禁降断言。

## 4. 禁改条款

- 禁追加信号族/聚合级/执行模型/标的（年检窗口除外）；禁调阈值后重跑再挑好（再检验定义：只有数据管道缺陷修复才允许重跑，frozen 参数零改动，遵 T 车道先例）。
- 禁把「筛出亮点」写成 PASS/可上线；禁绕过 BH 直接叙事。
- 全部查库只读；禁写生产库；脚本/缓存走 `.runtime/tmp/bizmine/tickm/`。

## 5. 滚动复测规程（月度考试）

1. **触发**：tick 数据每月增量落地后 5 个工作日内跑一轮（同协议、同参数、同标的，窗=基线窗∪新增月份）。
2. **升池**：亮点格**连续两月存活**（两轮均进 BH 亮点集且方向一致）→ 升「待考池」，交预注册假设卡走正式考试链（sop_b_node_loop），本协议不再负责。
3. **累计 N 台账**：每轮在报告尾追加「跨轮累计 N 账」：累计已考格数、累计亮点数、亮点存活月数——引用裁定 #304 的多重检验数学（40-60 日样本上 FDR 数值与累计假阳性期望一并披露）。
4. **降格**：连续三月无任何 BH 亮点 → 协议进「低频维持」（改季跑），登记台账。
5. **年检**：每年 1 月重选 2 只高波标的（§1 规则）+ 复核成本档位真源（`cost_model_calibration.py`）是否更新。
