# T4 币圈做T研究报告：做T 的战略延伸（Owner 原话）

## 2. 与 A股做T 的结构差异（重述+t0_subjective_methods §2.1 的经济含义）

1. **成本线塌缩**：A股 15min 做T 死于往返 8.4bp vs 中位 bar 振幅 26bp（S2）；币圈 maker 挂单 0 费/返佣结构下往返成本可压到 1-2bp 量级（占位假设，须按 Owner 实际费率核实），同一根 26bp 振幅所需捕获率从 32% 掉到 4-8%——**A股做T 的死因（成本线）在币圈结构性缓解**。这是"币圈=做T 战略延伸"的第一经济学根据。
2. **时间结构重排**：无竞价/开盘脉冲/尾盘（M5-M7 全失效），改锚 funding 小时结算时点、美盘波动窗、周度资金费周期。
3. **双向对称**：永续原生做空，反T（M2）无需底仓；涨跌停缺失使尾部无限，但 maker 挂单+小仓位可离散化尾部。
4. **carry 维度**：A股持仓无持有成本，币圈 funding 是独立收益源（BTC 均值年化 14%）——"做T"从纯价差游戏变成"价差+carry+返佣"三源叠加。
5. **T+1 底仓框架消失**：M1-M3 的额度约束全失效，仓位管理改为纯风险预算问题。

## 3. 可考策略卡（只设计，不回测；卡 1 已升正式预注册卡）

### 卡 1「funding carry delta 中性配对」（已升正式卡 T0-PRERG-02）
- 假设/数据/伪码/判据见 `t0_prereg_funding_carry.md`。
- **勘误（frozen 后的数据事实修正，执行前必须生效）**：原卡写"funding 3 期（3×8h）均值/各 8h 结算"——本报告实测 Hyperliquid funding 为**小时级**结算。修正口径：信号=过去 24 期（24h）均值年化；年化系数=×24×365；其余判据不变。勘误属数据颗粒度事实修正，不触碰判定门槛，随本报告同批入册。
- 风险：funding 翻负收敛、插针清算单腿、费率占位未核实、现货/永续标的不对称（crypto_kline_daily 70 币 vs funding 234 币，交集为准）。

### 卡 2「funding 极值反转（拥挤度信号）」——设计稿，未立卡
- 假设：币对 funding 小时级滚动均值进入历史极端分位（>p99 或 <p1）后，后续 24h 价格出现均值回归（拥挤反转，融合清算链逻辑的 funding 代理版——因清算流空表，funding 极值是最接近的可考代理）。
- 数据：hl_funding_history（主）+ crypto_kline_daily（日线收益，粗粒度）。
- 伪码：`z = roll_mean(rate,72h)/roll_std(rate,720h)；z>阈值→做空方向暴露（或平多）；z<−阈值→反向；持有 24h 或 z 回 0`。
- 成本：taker 2bp/边占位；日线粒度下只能考 24h 级 holding，无法考盘中 wick。
- 风险：趋势延续期极值更极端（2024 牛市 BTC funding 长期高位是反例风险）；日线收益噪声大，功效存疑；须 IS/OOS 切分+DSR。
- 立卡条件：分钟级行情补料后或接受日线粗粒度功效上限后，先 IS 勘测显著性再决定。

### 卡 3「日线动量截面 × funding 过滤」——设计稿，未立卡
- 假设：70 币日线截面上，7/30 日动量 top-N 多头组合的收益被高 funding（拥挤多头）子集显著侵蚀；剔除 funding p90 以上币对可提升组合 Sharpe。
- 数据：crypto_kline_daily（收益）+ hl_funding_history（日聚合过滤因子）。
- 伪码：`每月（或每周）按 ret_30d 排序 top10；剔除 funding_24h_mean_annualized>p90 的币；等权持有 7 天`。
- 成本：周度再平衡 × taker 双边 × 70 币容量。
- 风险：13 个月样本=单一牛熊相位，OOS 无真外延段（同 P3-B-EXP-01 的"净段证据档"局限）；币间相关性高=伪分散。
- 立卡条件：等待日线历史拉长（≥2 年）后立卡，当前样本只够勘测不够考试。

## 4. 结论：币圈作为"做T 战略延伸"的评估（供 Owner 裁定，不替 Owner 决策）

1. **结构上成立**：成本结构（maker 0 费/返佣）、双向对称、7×24 振幅供给、funding carry 第四源——四项结构性差异全部朝"做T 可行性"正向。A股 15min 做T 的三环死因（S2 成本线/T.md 信号无效/本役条件化无效）中，**只有第一环（成本）在币圈被结构性拆除**；信号有效性仍须逐卡出证，不可假设平移即活。
2. **数据上受限**：当前家底只够考 funding carry 族（卡 1）；信号类手法（网格/wick/做市）等分钟料、L2、清算流入仓后才有考试资格——建议数据线工单优先级：①crypto 分钟线（头部 10 币即可）②hl_liquidation_raw 真实落库 ③Owner 实际费率档核实。
3. **衔接件已备**：T0-PRERG-02 卡已冻结判据（含本报告勘误），数据映射+费率核实两前置完成后即可排期执行；A股侧遗产（成本模型框架/预注册纪律/DSR 尺子/状态机灰度轴）全部可复用——7×24 量化地基的最大一块=**把 A股 T+1 底仓框架换成纯风险预算的仓位引擎**，属 pf_alloc 域（本车道未触碰）。
