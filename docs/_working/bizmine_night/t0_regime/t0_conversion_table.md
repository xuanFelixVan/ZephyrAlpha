## 3. 逐手法转换卡（伪码级）

### M1+M4 正T/分时均线偏离（合并为「VWAP 回归族」，最可考 → 升卡 §4.1）
- **数据**：`kline_etf_1min` 510300（VWAP=Σ(amount)/Σ(volume) 当日累计，纯 1min 可算）；regime 状态变量=前一交易日 `regime_state_anchored.vol_pct`（T-1，PIT）。
- **伪码**：
  ```
  每日 09:30 起算 cum_vwap
  SIGNAL: price_1min < vwap*(1-θ) 且 持续 k 根 bar（θ=0.3%，k=5，IS 冻结）
  ENTRY : 信号 bar 收盘价买入（滚动仓=底仓 1/3，≤前收持仓）
  EXIT  : 价格回归 vwap 或 EOD(14:55) 市价平仓（先到先平）
  STOP  : 入场价 ×(1-0.8%) 跌破即平
  约束  : 每日至多 1 次；regime 分桶仅作事后分解（T3 轴）
  ```
- **可考假设草案**：510300 日内 VWAP 负偏离回归信号毛边际/边 > 12bp（Q5 口径 8.4bp+3.6bp 安全边际）。
- **成本口径**：Q5 8.4bp 主判 + Owner-001 6.71bp 并行。

### M2 反T（M1 镜像）
- **数据**：同 M1。
- **伪码**：镜像——price_1min > vwap*(1+θ) 滞涨 k 根 → 卖出底仓 1/3 → 回归 vwap 买回；止损=卖价×(1+0.8%) 追回。
- **假设草案**：镜像毛边际 >12bp。注：反T 卖出后回补在 T+1 下不受额度约束（卖出释放额度），约束仍为 ≤前收持仓。
- **暂不单独立卡**（M1 结果决定是否镜像开卡，避免族膨胀）。
