## 4. 偏离判定汇总（详表=deviation_table.csv）

- **material-wrong 43**（32 显式 + 11 继承）分四型：
  1. **趋势上下文缺失**（最大族群，CDL 全家+手写塔形/搓揉线+统一引擎全部反转形态）：事件在任意位置发射，P 考的语义被稀释/翻转。P 报告 RED 名单的锤子线/流星线/Hikkake/一阳穿多线与此直接对应；prev20 诊断（三黑鸦 −8.16%、上升楔形 −14.78%、下降楔形 +22.25%）证明事件强选样于形态定义之外的运动。
