1. **上界入帽与待精算（批复③，2026-10-12 晚 Owner 令）**：成绩册点名键查无时本件**不按下界计**——取该册最大容器/计数型整数量级作保守上界计入该行，并逐件标 `pending_exact_count`（见上表'待精算'列）。判据面真值待精算后照出终值版。墙训：帽定 0 之前必须先证明是没数到还是真零，否则把测量缺陷签成治理结论。
2. **账本面与成绩册面可能重叠**（考试卡既在 `kind=exam_card` 又在成绩册行数里）：本表三面分列不合并去重，合一口径需先点名去重规则。
