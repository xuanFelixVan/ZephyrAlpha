## 三、判读（按预登记 §5 三态表 + §7 两轴分离）

1. 有效性轴（各自搜索面 N）：阳性最优 DSR=0.107158（N=12，过线=False）；阴性最优 DSR=0.002541（N=2400，过线=False）。

3. 校准结论=**部分有效，不能判 DSR 尺过严**。三件实测：①阴性（2,400 随机）在两把 N 下 DSR 全挂 ⇒ DSR 尺没有给噪声加冕（这一侧未被证伪）；②阳性一件（月频反转）对等权大盘超额为负 ⇒ 它不是合格的阳性对照；③阳性二件（小市值 total_mv q10 monthly，2021-01..2023-12）绝对 Sharpe=1.2383、超额 1.6054、PBO=0.0（过 0.05 门）——是真异象，但其单检验 t≈2.0509（T=693），DSR@自身搜索面 N=8 仅 0.709336，不过 0.95。⇒ 该阳性连学术 HLZ t>3.0 也够不着，故本案**无法**据它判'尺过严'：阳性对照在本窗本身就不达标（样本只有 730 天，多头单因子的 t 天花板就在那里）。被证据钉死的是另一条：**PBO 不能当全仓统一门**——真异象 0.0 过、2,400 噪声冠军 0.0286 也过（无判别力），而反转族 0.4714 反被挂（池构成依赖）。⇒ 晨裁 M3 的'PBO≤0.05 全仓统一门'应撤回；DSR 尺保留 0.95 但每笔候选须同时报单检验 t 与该 N 下所需 t（让'差多少'可见），并把'更长窗/月频观测的阳性对照'列为下一轮校准前置。
