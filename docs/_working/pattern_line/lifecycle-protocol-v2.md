# 生命周期协议 v2.0——图形域闭环向全交易域的推广规范（2026-09-15）

> 缘起：Owner 问"完整生命闭环是否也应全面应用于技术指标、策略、因子？"
> 裁定：**同协议、不同闸**——生命周期骨架跨域统一，认证判据按域定制。
> 本文档=协议 v2.0（跨域接线规范），交各归属域会话适配施工；图形域
> （MOD-SIG-145/147/148/149）为参考实现。

## 一、统一骨架（七环，跨域不变）

```
目录 → 实现 → 认证 → 调权 → 呈现 → 退役 → 复活观察
```

不变式（七环通用纪律）：
1. 目录条目来源权威、参数冻结、净零预算；
2. 认定代码生成禁手填、运动员不兼任裁判、Fail-Closed；
3. 阈值预注册改动=裁定留痕；
4. 退役=状态不是删除，死后观察期数据自动生长（复活证据免费）；
5. 复活闸高于初次认证（序贯 α 消耗）+ 尝试预算 + structural 死因 Owner 门位。

## 三、推出顺序（裁定，按价值/风险比）

1. **因子域优先**：因子挖掘是过拟合重灾区（多重检验=其原生病），IC 四闸适配价值最高；
   施工=IC 版 certifier（复用 148 的 BH/n_eff/收缩骨架，判据换 IC 族）；
2. **策略域补衰减侧**：晋升侧不動，补"active 策略每日滚动认证→probation→retired→复活"；
   PP-001 配比衰减调权是现成消费点；
3. **指标域最轻**：消费活性台账+零消费退役，不上统计闸。

## 四、接线纪律（边界）

- 各域施工归属各域会话；本协议文档=接线规范（同 resurrection-protocol.md 先例）；
- 邻域有归属只登记边界不越界；跨域共用件（BH-FDR/n_eff/收缩等统计核）从
  MOD-SIG-148 导入复用，禁止各域复制粘贴实现（单源纪律）；
- 每域阈值独立预注册于各自蓝图，跨域不共享阈值数值（事件频率与样本结构不同）。

## 五、不做清单

- 不做全域一次性大重构（各域按缺口独立立项，图形域协议先行验证过再推）；
- 不做跨域统一大表（各域认证落各自表，协议只统一状态词汇表与判据纪律）；
- 指标域不上统计闸（指标无预测力语义，强行认证=制造伪指标）。
