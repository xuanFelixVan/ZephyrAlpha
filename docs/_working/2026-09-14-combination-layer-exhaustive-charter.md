# 组合层穷尽网格立项稿（F-06 仓位/组合工厂 · 第一期）

> 配套：`2026-09-14-full-chain-factory-blueprint.md`（全链路方案 §四 F-06）。
> 状态：**已自裁批准（2026-09-15，见文末裁定记录），施工闭环进行中**。按施工闭环（capability_lookup → depgraph → worktree → 正门提交）执行。

## 一、为什么先做它（三条理由，按分量排序）

1. **它是全链路唯一"能被真穷尽"的环节。** 因子公式层空间 10^12 起跳、只能采样；组合层是低基数离散网格，几万条**可以一条不落全跑完**。花同样的算力，这里的确定性最高。
2. **它是全链路最大的洼地。** 仓位/组合域有 30+ 个模块、19 份蓝图（`docs/03_modules/_domain_position/`），**全是求解器，零工厂**——仓位树种（怎么定尺寸、怎么配、怎么调仓）目前只能人手写配置。仓库里最贵的一块地，从来没人系统地犁过。
3. **它不依赖任何新车道。** 完全复用已建的 E4 考试（`backtest/core/decision_gate.py` + `strategy_validation_pipeline.py`）、E5 去重（MOD-BT-086）、C4 引擎。今天批，今天就能开工，不用等车道 B/D/E，也不用等 LLM 翻译。

## 二、范围：做什么、不做什么

**做**：在**受控网格**内穷举"因子 → 组合 → 仓位 → 调仓"的配方，产出可复现的 `position_recipe`，送进现有咽喉考试。

**不做**（边界必须写死，否则会无限膨胀）：
- 不发明新因子——那是 F-02 因子工厂的活，本件只消费已有因子池；
- 不改考试标准——判定权仍在 E4/E5，本件不评分（运动员不兼裁判）；
- 不碰执行算法——那是 F-07；
- 不碰风控红线——F-08 永不自动化。

## 三、设计空间：网格维度（穷举清单）

| 维 | 取值 | 基数 |
|---|---|---|
| A1 因子标准化 | raw / rank / zscore / 行业中性 / 市值中性 / 行业+市值双中性 | 6 |
| A2 多因子合成权重 | 等权 / IC 均值加权 / IC_IR 加权 / 半衰期加权(τ=20) / 半衰期(τ=60) / 正交化后等权 / Lasso 权重 / 第一主成分 | 8 |
| B 选股截面 | Top 10 / 20 / 30 / 50 / 100 | 5 |
| C 仓位定尺寸 | 等权 / 市值加权 / 波动率倒数 / 风险平价 / 分数凯利(0.25) / 分数凯利(0.5) / 信号强度映射 | 7 |
| D1 调仓频率 | 日 / 周 / 双周 / 月 | 4 |
| D2 调仓触发 | 周期触发 / 漂移带阈值触发（偏离 >x%） | 2 |
| E 单票上限 | 5% / 10% / 20% | 3 |
| F 多策略合并 | 单策略 / 等资金 / 等风险 / 信号叠加 | 4 |

**全网格 = 6 × 8 × 5 × 7 × 4 × 2 × 3 × 4 ≈ 16.1 万条。**

量级判断：日频、三年样本、单条回测约 5–10 秒 → 单核约 9–18 天，**8 核 1–2 天跑完**。这是"真能穷尽"的量级，也正是立项的立足点。

## 四、穷尽策略：三层筛，不是一把梭

直接把 16 万条全灌进 E4 会烧掉整个 E0 算力预算。分三层：

| 层 | 筛什么 | 成本 | 预期留存 |
|---|---|---|---|
| **第一层：算术预筛**（不跑回测） | 换手率估算 + 单票上限/容量可行性 + 成本粗略估计。换手超阈值的直接死 | 极低 | ~20% |
| **第二层：快指标**（不进 C4 引擎） | 组合层 IC / IC_IR / 换手 / 最大回撤粗算 | 中 | ~5% |
| **第三层：E4 正考** | 现有 IS→WFA→OOS 三阶段 + DSR 折减 | 高 | 千分之一级 |

**关键纪律**：第一层必须在最前面——**成本是穷尽法的第一杀手**。大量配方在纸面上 Sharpe 很好看，一算手续费和冲击就归零，这类必须最先死，不能占用考试算力。

## 五、防过拟合（复用现有四件套，不另立标准）

1. **搜索空间受控** —— 本件天然满足：维度与取值全部写死在上表，超出网格的配方一律不产；
2. **一策多卷** —— 直接进 E4 现行 IS + WFA + OOS 三阶段（冻结窗口不动，锚点 D=2026-09-09）；
3. **多重测试惩罚** —— **DSR 必须按批内总试验数 N 折减**，不是按单条。本件 N 以十万计，折减会极其狠，这是应有之义（千分之一幸存率是正常预期）；
4. **经济学逻辑审核** —— 每条进 registry 的配方必须能回答"这种合成/定尺寸方式在行为学上是什么意思"，说不出机制的标 `reject_no_mechanism`；
5. **协同去重** —— 过 E5 正交化：与已有配方池相关性过高的判为同义反复，不入册。

## 六、产出与验收

## 十一、N 记账改为「有效试验数 N_eff」（替代 v1 §五-3 的"批内总试验数"）

### 11.1 更正 v1 的两处错误

1. **v1 说"DSR 按批内总试验数 N 折减"** —— 不够。**DSR 官方流程第 2 步就是"估计有效试验数 N"**，我们从来没实现这一步（现有实现按批内变体数，无任何相关性折减：`c4_deflated_sharpe_runner.py:117`、`_c4_engine.py:290`）。
2. **配套数值更正**：按 `metrics.py:368-380` 实算 ——

| N | E[max(Z_N)] |
|---|---|
| 35 | 2.2141 |
| 1102 | 3.3300 |
| **161000** | **4.5262**（此前流传的 4.90 漏了减项） |

→ N=161000 相对 N=35 抬升 **2.3121σ**（不是 2.69σ）。**结论方向不变：仍近乎不可能产出 DSR≥0.95 的幸存者。**

### 11.2 新口径

- **N_raw**（名义格点数，审计下限）与 **N_eff**（按相关结构折减）**双口径同时报告**，缺一不可；
- N_eff 估计器三选一，跑批前预注册：`effective_rank`（熵加权特征值广度，默认）/ `marchenko_pastur`（非噪声特征值计数）/ `clustering`（独立策略族计数）；
- **失活维按 1 计**（§10 折叠机制），不按其取值数计；
- DSR 仍需 `variance_trials`（跨所有试验夏普的方差）作为输入 —— **已核实并完成第 0 步重算（2026-09-15，定案详情=DSR 评估文档头部新块）**：台账链路走单位一致的官方件；台账 max 那条 0.9809 实为 **N=1 solo 重跑的零折减产物**（非 N=35）；`metrics.py` 路径量纲 bug 实测 DSR=1.0000 不可用；另实锤**数据层漂移**（重放 Sharpe 0.983→1.15）与**第 4 坑 N 未落账**；**台账 DSR（现 145 条）冻结维持，理由改写为"N 未落账批间不可比+数据漂移不可复现+solo 零折减虚高"，解冻=N 账本重建+按可考证 N 重算**。本件批次 B 正考的 DSR 消费必须在 N 账本就位后才有意义——已列入 §十二 批次 B 前置。

## 十二、执行策略：两批次（替代 v1 §四 的三层顺序筛）

v1 的"算术预筛 → 快指标 → 正考"是**淘汰流水线**，问题在于：被第一层杀死的配方再也不会为"哪个维度重要"贡献信息（统计学上的信息截断）。改为：

| 批次 | 做什么 | 量级 | 产出 |
|---|---|---|---|
| **A 普查** | 正交表 / 分层随机抽样 | ~2 万条 | 维度重要性、交互、稳健高原 → **压缩下一批空间** |
| **B 确认** | 在 A 给出的高价值子空间做全因子穷尽 | 由 A 决定 | 阴性库（带死因）+ 幸存者（双口径 DSR） |

**结构知识的计算：批次 A 跑完后，直接交给 fANOVA 做方差分解。** 依据：Hutter, Hoos & Leyton-Brown, **ICML 2014**（开源实现 `github.com/automl/fanova`）；实测在 Auto-WEKA 768 维空间中通常只有 2–3 个参数解释绝大部分方差 —— 这正是我们想要的"该砍哪个维度"的答案。
⚠️ 施工前必查 **fanova 仓库 license**（④后端未核实）。

### 12.1 算力（修正 v1 §七 的估算）

v1 按"每条 5–10 秒 × 16.1 万"估。**必须做前缀共享**：A1×A2=48 种因子侧组合只算一次并缓存，其余维（组合调配）廉价重放。未做共享的实现会把同一件事重复做上万次。
