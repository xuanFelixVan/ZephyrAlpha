# 板块指数自建合成方案（模拟通达信 880/881 板块指数）

## §0 目标与消费方

**目标**：用自库数据（成分股分钟/日K + 成分映射 + 市值权重）自建通达信 880/881 板块指数的
合成序列，经回测对拍迭代至与真实数据匹配（校准窗量化验收，见 §4），替代已死亡的 mootdx 通道。

**消费方**：
1. 逆势榜 counter_trend_board（MOD-SIG-071，四卡核心输入=板块分钟序列）——**当前已瘫痪**，
   本方案第一受益人；
2. 板块日K 消费方（regime 特征 mainline/sector_hhi 等）——kline_sector（tqcenter 活通道）
   已覆盖日K，本方案日K 级为**校准与冗余备份**，非急用；
3. 长期价值：板块数据自主可控，不再依赖通达信单一体系。

**为什么可行**：通达信 880/881 板块指数本质=成分股按流通市值加权的派氏综合指数（股本加权
+除数修正族），全部输入（成分映射/个股行情/流通市值）自库均有或可建；校准真值=mootdx 死前
的 kline_sector_intraday 历史真实分钟 + kline_sector 2020-03 起日K，对拍数据充足。

## §1 核心算法（推荐口径：t-1 权重链式）

**日K 级**（Phase 1）：
```
板块日收益 r_b(t) = Σ_i w_i(t-1) × r_i(t) / Σ_i w_i(t-1)
w_i(t-1) = circ_mv_i(t-1) = circ_shares_i × close_i(t-1)   ← stock_indicator.circ_mv 现成
I_b(t) = I_b(t-1) × (1 + r_b(t))
```
- 采用 **t-1 日权重**（权重滞后链式）：避免当日换权重引入非交易性跳变，数据依赖最小
  （pct 或 close + 前日 circ_mv），是指数工程标准做法；
- **分钟级**（Phase 3）：同公式作用于 1 分钟收益（个股 1min close 链式），分钟权重沿用
  t-1 日收盘权重（盘中不换权重，保证盘中序列与日K 收益一致可对账）。

**备选口径**（对拍不达标时迭代用，按优先级）：
- 当日权重派氏（I=Σ s_i p_i / D，每日换 s）；成分股等权；流通市值分档加权；
- 停牌股处理：停牌日 r_i=0（价格沿用停牌前收）——通达信口径实测对拍确认；
- 新股上市首日：不计涨跌幅（上市首日涨幅不纳入，次日才计入）——对拍反推确认。

### §2.1 成分历史留痕（本方案最大数据基建缺口，P0）

**现状**：sector_constituent 无 valid_from/valid_to（月度全量重建、历史成分蒸发）；
**881 系列 sector_name=代码占位符**（真名缺失，名称匹配源需 tqcenter get_sector_list 实时取）。

**设计**：新表 `c1_market.sector_constituent_snapshot`（每日快照追加，SCD 查询视角）：
- 列：snapshot_date, sector_code, sector_name, stock_code, data_source, ingest_ts
- 写入：每日盘后从 sector_constituent 全量 INSERT 一份（provider 正门，幂等按日）
- 消费：成员 as-of(t)=该日最近快照；调仓 diff=相邻两日快照差集
- **历史回溯缺口如实交底**：启用日之前的历史成分无法补（通达信成分历史无公开源），
  校准窗内用"当前成分回溯"近似+误差实测登记；启用后成员变化全留痕，越用越准。

## §4 对拍验收框架（"99% 匹配"的精确定义）

**校准窗**：mootdx 存活期（kline_sector_intraday 有数据的全部交易日 + kline_sector 日K 2020-03 起）。
**验收矩阵**（分板块逐一对拍，全板块通过才算达标）：
- 日K 级：板块日收益相关性 ≥0.99；日收益绝对差 ≤0.15pp（95 分位）；方向一致率 ≥97%；
- 分钟级（逆势榜口径）：段内板块收益排序保真——top-20 板块重合率 ≥90%、相邻排名抖动率 ≤15%；
- 长窗口：3 个月滚动累计收益差 ≤1pp。
**迭代回路**：不达标项 → 按 §1 备选口径逐项切换重拍（权重口径→停牌处理→新股纳入日→除数法），
每轮留存对拍报告；连续两轮无改善的指标项如实登记差距（不做假达标）。
**通过判定**：连续两轮全指标达标 = 合成器冻结转产。
