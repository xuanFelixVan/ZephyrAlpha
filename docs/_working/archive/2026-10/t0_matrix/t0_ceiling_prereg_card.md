# T0-CEILING：日内**先后可达价差**的上界，是否足以覆盖一次往返的固定成本

## 0. 为什么是"上界"而不是"策略回测"（本卡的全部诚实性所在）

本卡**不声称**任何方法能赚到钱。它只算一件事：

> 假设有一台**上帝视角**的机器，当天开盘后能在**当日最低价**买入、之后在**当日最高价**卖出
> （仅当最低价出现时刻早于最高价时刻，即"先低后高"，这才是可先后成交的方向），
> 那么它拿到的毛价差，是**任何同日先买后卖的做T 策略在数学上不可能超过的上界**。

判读规则是**单向的**（这是本卡唯一允许的推断方向）：

- 上界 **< 成本** ⇒ 该条件子集内**所有**先买后卖的做T 方法**全部判死**（不需逐一考）。
- 上界 **≥ 成本** ⇒ **不证明任何方法可用**（上帝视角不可得；本卡结论到此为止，禁外推）。

⇒ 本卡的用途是**廉价地杀掉整族**，把算力从"注定不可能"的方向撤出来，
交给 R1③ 矩阵去决定谁值得立正式策略卡。**它绝不给出任何 PASS。**

## 2. 判据（frozen，单向）

| 组 | 判据 | 含义 |
|---|---|---|
| 全体 | `share(gross_bp ≥ L1)` 与 `share(≥ L2)`，及 gross 分位 | 上界的总体形状 |
| 情绪六段各组 | 同上按 T-1 六段分层 | 哪个状态段的**上界**才够成本 |

- 本包 V3 实测真实同体往返毛价差 **p50=+4.3bp、均值 −5.06bp**，远低于 L1=31.2bp。
  若本卡上界在全市场层面也普遍低于 L1，则结论是
  **"做T 股票腿不是策略问题，是物理问题"**，R1③ 的火力应全部转向真 T+0 品种（转债/跨境 ETF）。

- 两种结果都不构成任何方法的 PASS，都直接改变 R1③ 矩阵的优先级排序。

## 4. 已知缺陷与本卡的处理（不藏）

1. `argMin/argMax` 在同一分钟内的先后不可分辨 ⇒ 当 `t_low == t_high`（同一分钟既是最高又最低，
   即一字板或单分钟）时本卡记 `direction_ambiguous`，**不计入可得多边**（偏保守方向）。
2. 涨跌停：涨停日无法在最高价成交、跌停日无法在最低价成交 ⇒ 本卡**不修正**，
   因为这会让上界**更大**（更不可能判死），即不修正=偏向"不杀"，与单向判读规则一致（保守）。
3. 停牌/缺失分钟 ⇒ 用 `bar_n ≥ 200` 代理可交易，登记为近似。
4. `regime_state_anchored.dominant` 实为**波动率风险四档**（非趋势标签，见本包红蓝 MAJOR-2）
   ⇒ 本卡的"宏观组"只是波动分层，**不得**读成"牛市趋势下做T 上界更高"。
5. 转债/ETF 不在本卡范围（无分钟 bar），单列"待料"，见 `T0_SCHEME_MATRIX.md` §四。
