## 2. 核心设计决策：预算数字与状态路由**分家**（治双重计算）

病根：L1 谨慎度（shrinkage）与锚定档（vol_pct 分档）**都含波动率信息**——若两者都参与仓位数字计算，波动率被双重计入（牛市双信号同时压仓 → 长期半仓）。

**推荐方案 A（分家）**：
- **仓位数字**仍由 L1 总闸独家给出（shrinkage 预算带，P0-001 已验证）；
- 锚定四档只做两件 L1 不做的事：
  1. **熔断上限**（风险档对仓位设硬顶，只减不加）；
  2. **策略路由**（高风险档停开进攻型 sleeve）；
- 映射表 **v2 灰度曲线版**（Owner 2026-09-14 修正：映射应为灰度连续缩放，非档位硬顶跳变）：
  - **仓位硬顶 = 连续函数**：cap(vol_pct) = 100% − 70% × clamp((vol_pct − 0.30) / 0.70, 0, 1)
    （vol_pct ≤ 0.30 不设顶；0.30→1.00 线性降至 30% 封顶；中间平滑过渡无跳变；
    起控点 0.30 与满压点 1.00 已冻结（Owner 2026-09-14 确定施工签字））
  - L1 预算与 cap 取 **min**（上限只在 L1 想突破时才约束，市场平静期零干预——min 结构天然去重）
  - 四档保留为**仪表盘刻度**（r3≤0.30 / r2≤0.60 / r1≤0.80 / r4>0.80，仅供人读与策略路由参考），
    机器执行一律用连续 cap，杜绝档位跳变
  - 策略路由（灰度化配套）：进攻型 sleeve 开关按 vol_pct 阈值预注册（如 >0.80 停开进攻），
    阈值同样可调为连续折减，随双轨并行期证据定稿

| 仪表盘刻度 | vol_pct | 连续 cap 曲线上的位置 |
|---|---|---|
| r3 低风险 | ≤0.30 | cap=100%（不设顶区间） |
| r2 中风险 | 0.30-0.60 | cap=100%→70% 线性段 |
| r1 中高风险 | 0.60-0.80 | cap=70%→40% 线性段 |
| r4 高风险 | >0.80 | cap=40%→30% 深度降权区 |
