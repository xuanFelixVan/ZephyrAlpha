# 4.1 N_eff 估计器预注册（立项稿 §11.2，2026-09-15 夜班锁定）

## effective_rank 估计器规格（预注册内容）

1. 对批次内 N 条试验的日净收益序列做两两 Pearson 相关（T≥60 对齐后）；
2. 特征值分解，取全部 λ_k ≥ 0；
3. 熵加权广度：`N_eff = exp( -Σ p_k · ln p_k )`，其中 `p_k = λ_k / Σλ`；
4. 输出向上取整；下限 1（完全相关），上限 N（完全独立）。
