**核心发现：**
1. **分层整体未通过**：≥30 天四阶段中三个 ρ_max>0.6，整体 ρ_overall=**0.768**（取各阶段最大值）→ 按裁定口径落 COMBINATION_INVALID 档。
2. **相关性随情绪温度单调上升**：daban-multifactor ρ 从 STARTING 0.495 → FERMENTING 0.621 → CONSENSUS 0.768——情绪越热三策略越趋同。这与"情绪是隐形驱动"假设**方向一致**（情绪确实驱动相关性），但与"分层可去相关"的期望**相反**（分层控制变量后仍 >0.6，说明趋同不是阶段异质性造成的假象，而是策略信号本身在热门期的真实趋同）。
3. **event-multifactor 是唯一的稳定低相关对**（全样本 0.391，各层 0.20-0.48）——事件驱动与横截面多因子的正交性最好，与 30 号 §2.2"打板情绪择时与横截面 alpha 正交"的预期一致。
4. **daban-multifactor 是主矛盾**（全样本 0.667）——打板（情绪敏感）与动量因子（情绪传导）在 A 股同为情绪放大器。

- **block-bootstrap 2000 次**（情绪温度 intensity vs 各策略代理收益）：observed ρ = daban 0.056 / multifactor 0.061 / event 0.150；p-value = 0.095 / 0.062 / **0.000**。仅事件驱动与情绪强度的线性相关显著——情绪对三策略的驱动主要是**非线性/分层效应**（bootstrap 打碎时序后线性相关消失），与 §2 分层结果的"温度越高越趋同"互为印证。
- **Hawkes 简化 MLE**（事件=封板数>滚动 60 日 90 分位且>20，burst_days=95）：λ₀=0.044，α=0.127，β=0.172，**分支比 η=0.738**。<1 稳定，落在"健康主升 0.5-0.8"区间——**情绪传染可控，无爆炸迹象**（4 年窗口含 2024-09 行情引爆与多轮退潮，η 未破 1）。注：简化网格估计供参考，非完整逐事件 MLE。

## 4. 方法论披露（局限与适配，全部如实声明）

1. **代理收益口径**（最重要保留）：三 sleeve 代理是"裸信号多头组合次日收益"——无择时、无风控、无仓位管理、无成本。三个全多头组合共同暴露市场 beta，会**系统性抬高**所有 ρ。本报告的"组合失效"档位判断仅在代理口径内有效；**定性结论**（高情绪段趋同加剧、event-multi 正交性最好）对真实组合的参考价值高于**绝对档位**。
2. **定位器两处回放适配**（本体零改动，脚本侧）：
   - **先验 50% 均匀混合**：原始链式先验实测锁死（2022-10 首月触发兜底后 4 年仅 EBING/FREEZING 两态——one-hot/高置信先验自我强化，evidence 无法翻转）。混合后惯性仅 1 天深，evidence 主导。
   - **兜底日标签改 evidence argmax**：定位器兜底分支把 dominant 强制改为 EBING/FREEZING 较大者——这是实盘"宁保守不激进"的**仓位收缩设计**，不是判定语义。实证：2024-09-30（924 行情引爆日）evidence CONSENSUS 0.644 最高却被兜底成 FREEZING。适配后阶段分布恢复五态合理形态。**此发现建议反馈 28 号备忘录 Owner：定位器增加"回放/打标模式"显式语义（或 evidence argmax 输出字段），否则任何长序列回放都会复现该锁死。**
3. **涨停判定近似**：pct_change≥9.8%（主板）/19.8%（创业科创）+收盘封板；ST 5% 档不可识别（涨停/跌停双漏判）；"炸板"=摸板未封（含未封过板的摸板股，较真实"曾封后开"口径高估）。量级已对 2026-08~09 真实 `limit_up_down` 表人工对照（近似涨停 39-100 家/日、连板高 4-7，符合活跃市常态）；炸板率 p50=0.334 略偏高（真实约 0.2-0.4 带）。
4. **FREEZING 样本 n=1**：4 年窗口近似涨停数长期 ≥40，FREEZING 判据区间 (0,20) 几乎不可命中（部分因 ST 漏判+近似口径）——冰点态验证缺位，如实 fail-open。
5. **龙虎榜/北向历史缺失**：两指标不参与 `_score_phase` 评分（权重 0，仅 dataclass 必填字段），对打标无影响。
