**五大功能**（每条都有文件内证据）：

   effective_from（2026-09-08）=知识层 PIT 生效日——**回测区间早于此=知识漂移，必须声明**（D120）；
4. **缺口发现器**：module_ref=null=缺口节点（warning）——地图直接显示"哪个决策环节还没有代码"；
5. **策略挂载点**：策略入库最后一步"挂图"（SOP-C §6）=把策略钉到它服务的节点上。
