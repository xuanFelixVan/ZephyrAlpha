## 1. Owner 三问与定稿结论

### 问题一：是否每个节点都需要回测？颗粒度从小到大分级回测是否成立？

**定稿：分级回测成立（五层金字塔），但"逐节点回测"修正为"按回测形态分类 + 行为合并"。**

- **五层金字塔**：节点级 → 组件级（同层树枝组装）→ 层级（L1 总闸/L2 板块/L3 个股/L4 执行整层）→ 流级（建仓/持仓/离场/组合端到端）→ 全图整装级（四流并发 × 状态矩阵 × PP-001 配比）。
- **修正一（分类）**：节点按四类器官定回测形态，判据不同不可混用：
  - 传感器/因子类 → IC / 事件后收益分布（对应 V1/V2）；
  - 闸门/判定类（L1 总闸、L1-AGG、环境开关）→ 分类准确率 × 错分代价（判对下游多赚 / 判错下游亏多少），**不产生净值**；
  - 策略链类（打板链、多因子链）→ WF + Permutation Test（对应 V3）；
  - 聚合类（双池合流、五路合分）→ 消融对比：有它 vs 没它 vs 换简单规则，增量贡献即价值。
- **修正二（合并）**：行为相同仅参数不同的子节点合并为一次参数扫描（地图 D108 拆分三条件之"行为差异可回测区分、非纯参数变化"本来就是判据）。全图 130+ 节点折算后约 **40-60 个独立可回测行为**。
- **修正三（口径）**：节点级回测必须①固定上游输入（喂历史真实数据，禁止模拟上游——误差级联无法归因）；②按六段状态分档报告（冰点/吸筹/点火/发酵/亢奋/退潮）——本体系是条件策略体系，跨状态平均数无效。
- **修正四（顺序）**：不等节点全精修完才拼大图。节点宽筛一轮后立即插一次主链 E2E 冒烟，按"对全图净值的边际贡献"排序精修优先级（节点局部最优≠全局最优；冒烟提早暴露 L2→L3 等口径断点）。

### 问题二：AI 自驱回测的 SOP 怎么建？

**定稿：拆两套 SOP + 三道护栏。**

- **SOP-A（全图编排）**：回测对象注册 → 分类合并 → 优先级排序 → 批次推进（每批 ≤5，Owner 只看批次决策点）→ 归档升级。优先级：P0 = L1-AGG 状态判定 + L1 总闸 + 成本模型（约束三生死线，识别不准 = 用错误状态切错误策略，比单策略还糟）；P1 = 主链（L2-01 板块强度 → L3 漏斗 → L4 时序）；P2 = 树枝；P3 = 持仓/离场/组合流。铁律：先上游后下游。
- **SOP-B（单节点七步循环）**：①全网算法调研（≥3 候选、写明出处，禁被项目内已有算法捆绑）→ ②数据需求声明（**needs-driven 硬规则**："需要什么数据"先行，对照 data_asset_registry 生成 DATA-GAP 缺口清单，禁"有什么数据才怎么回测"）→ ③缺口取数（缺的想办法搞；实无数据用 proxy 须降级结论；全程 PIT 时点可用性）→ ④宽回测（全量数据全参数网格、粗成本，目的=信号存在性非赚钱）→ ⑤噪音剪枝（分状态稳定性 / 信号衰减 / 相关性去重——L1-S5 日级温度计"先大而全跑数据后裁噪"模式推广到全图）→ ⑥窄回测（完整成本五项 = 约束一：佣金+印花税+滑点+市场冲击+做T成本，费率读实际账户配置；WFA/OOS）→ ⑦归档判定（达标 → evidence 落 decisiongraph L5 → 地图 confidence proposed→verified；不达标 → 修正回①；判死 → 归档出局）。
- **三道护栏（防 AI 跑飞，Owner 不逐次看的关键）**：①参数搜索空间先注册（禁无限调参）；②过拟合门禁强制（Deflated Sharpe，BM-BT-05-G 在册）；③验收阈值跑前预注册（禁事后挪门柱）。每轮参数 diff 全留痕（多重检验校正的原料）。
- **知识漂移**：回测区间早于 `effective_from=2026-09-08`（知识层 PIT 生效日）须按 D120 打标注放行声明。

### 问题三：聚宽 600 条策略怎么植入全景图？

**定稿：先入策略库，不直接挂图——且这是地图 INV-1 铁律的既定要求（策略内容禁止复制进图，只按 strategy_ref 引用 strategy_registry 条目）。**

- **SOP-C 六步漏斗**：①盘点归一（.txt 为主、年度文件夹，编码/格式/元数据登记）→ ②粗筛出局（硬排除：期货、基金定投、分钟级、配对交易、裸卖空等非 A 股日线股票策略，预估六成出局）→ ③翻译适配（聚宽 API shim → 本地数据接口；**试点先行**：按类别抽 10 条验证 shim 可行性再全量；翻译失败记清单不硬翻）→ ④快筛批测（统一区间/统一成本/统一 T+1；**Deflated Sharpe 强制**——600 条海选多重检验偏差是最大敌人）→ ⑤聚类去重 + 差异化论证（约束五：新增策略必须论证信号源/持仓周期/市场状态适配三者的差异性，同类只留最优 1-2 个）→ ⑥入库 strategy_registry → 挂图 → PP-001 配比。
- **挂载去向映射**：择时类 → L1 总闸 · 轮动类 → L2 · 打板/选股类 → L3 策略专属链（如 L3-07-1）· 做T类 → P-P2。挂载点 = state_matrix 格子（`mounted` 数组）。
- **修正**：PP-001 配比不选"收益最大"（会精准选出过拟合冠军），选风险调整后最优 + 策略间相关性互补；配比随回测归因逐 sleeve 升级（PP-001 v1.1 既定语义）。

## 2. 打通顺序（定稿）

1. **回测基建冒烟**：引擎/数据/成本三件套各跑一条已知策略对照（vectorized / event_driven 引擎已在 `src/zephyr/backtest/`）；
2. **P0 状态判定回测**（L1-AGG + L1 总闸 + 成本模型，SOP-B 七步循环首批）；
3. **主链 E2E 冒烟**（L2→L3→L4 一次粗端到端，暴露口径断点）;
4. **节点级 SOP-B 批量推进**（P1 主链 → P2 树枝；并行启动策略库 SOP-C 漏斗）;
5. **状态矩阵填格**（state_matrix cells 逐格由回测归因支撑，proposed→verified）;
6. **PP-001 配比优化**（入库策略 + 既有 8 sleeves 统一参与）;
7. **离场/做T/组合流回测**（P3）+ 全图整装回测 + 模拟盘验证（V4/V5 收口）。
