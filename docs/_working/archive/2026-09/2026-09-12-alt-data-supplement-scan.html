另类因子：免费数据源补充扫描

承接《数据分层体检报告》§2.3（L3 另类层 ≈15%）与 P2-B 建议。本轮任务：盘点与相近因子（社热 / 情绪 / 产业垂直 / 币圈影子）对位的可补充数据，全网核对机构实践与量化社区的免费另类数据源。与财报对话（P1-A）、研报对话（P1-B）不重叠。

日期 2026-09-12 范围 L3 另类层 + 免费源全网扫描 候选源 12 源 / 6 组 在跑另类管线 5 条 DORMANT 模块 15 个

§0一页结论

  1. 不缺"另类"的空架子，缺的是往 5 条在跑管线里塞同类邻居。项目已落地天气 / 生猪 / 人气榜 / 币圈影子 / 新闻情绪五条边缘另类管线；alt_data 包 15 个模块 DORMANT 但治理件齐全。补充策略 = 唤醒 + 复制模板，不新造轮子。
  2. 机构与社区验证最充分、工程成本最低的免费源：股吧 / 千股千评 / 雪球（散户情绪面）、百度指数（搜索关注度）、互动易 / e互动问答（IR 文本）、电影票房 / 航运运价（产业垂直高频）。全部有免费接口路径，大多可经 akshare / tushare 直连——两者均已在项目 provider 体系内。
  3. 机构实践印证：Robeco 把另类获取归纳为"平台代理（Neudata / Eagle Alpha）+ 自采"两条路；paperswithbacktest 把行业另类分 6 子类，其中个人项目可免费做的只有 web 注意度、社媒情绪、监管文件衍生三块——与体检报告"低成本 web 衍生试点"的裁断一致。
  4. 边界沿用同文案例：黑石系私募试过卫星停车窥屏后因"合规 + 成本 vs 阿尔法不成正比"放弃。卫星遥感、电商爬虫、付费另类平台三块明确不做。
  5. 优先级：P1 = 社热扩展三源 + 票房 / 运价两个产业垂直（每源 ≤1 天，照抄 hog_* 模板）；P1.5 = 互动易问答；P2 = 百度指数、采购 / 政策爬虫试点、百度迁徙、Google Trends。

§5与另两条对话的协作边界

财报对话（P1-A 消费端）与研报对话（P1-B 链路）范围不变。本清单 B / C 组（互动易文本、百度指数）可作研报观点的交叉验证源；D 组产业垂直与产业链 ig_* 事件传导（chain_impact_stream）天然打通——中标 / 票房 / 运价异动均可作为 chain event 的增量事件类型。
