# WYF-3 v2 预注册协议：SC 量能腿固定基准化（防事后拟合）

> 本协议在**任何 v2 网格真实数据扫描之前**写死。执行的是裁定#271 明文重跑触发条件第 1 条：
> "SC 量能腿由滚动 `volume_anomaly` z 换成固定基准量纲（钝化根因，报告 §5.3）"。
> 后续重跑/落地/复议均以本协议为验收真源。v1 协议（wyf3_preregistered_protocol.md）仍是
> 旧量能腿（vol_z）扫描的验收真源，本文不追溯修改 v1。

  pct<-3% 日 z 全部 ≤1.34）；旧腿 36 网格点 0 合格（最好 9 日/8 聚集）；bestSC 假设链
  下游复活证据；cummax 粘滞跨段占比缺陷（v1 §6）。
- **未知**（本文预注册后才允许首次计算）：C1/C2/C3 任一新量能腿在 000300 全样本上的
  取值分布、其任一阈值下的触发数、任一 v2 网格点的任何验收指标。
- 新腿阈值网格取惯例值（量比 1.5/2/2.5/3、分位 95/98/99、基准比 1.0/1.2/1.5），
  **不依据任何预扫描分布挑选**；若这些惯例值整体不合格，结论按 §6 如实登记，
  禁回头改网格。

## 3. SC 量能腿候选（预注册：构造式 + PIT 论证 + 钝化论证）

替代位：`detect_wyckoff_events` 的 SC 判定第一腿（现役 `(z > sc_vol_z)`）。其余各腿
（SC 的 pct/新低腿、PS 的 vol_z 腿、ST/Spring 缩量腿、Test 放量腿）**一律不动**。
引擎口径切换由 `WyckoffParams.sc_vol_mode` 承载，默认 `"vol_z"`（历史路径零改变）。

| 候选 | 构造式 | PIT 论证 | 钝化论证 |
|------|--------|---------|---------|
| C1 量比 | `vol_ratio(T)=V(T)/SMA(V,W_b)(T)`，W_b∈{20,60}，min_periods=W_b | SMA 向后滚动含 T；不满窗=NaN=不触发 | 无 std 除法：持续放量台阶只线性抬高分母，单日 3× 均量仍得 3.0，不被 std 爆炸吞没 |
| C2 expanding 历史分位 | `vol_epct(T)=PCT_RANK(V(T); V(1..T))`，min_periods=260 | expanding 定义域=起点至 T；首 259 日 NaN=不触发 | 基准=全部历史：rank 稳健，台阶式放量只缓慢侵蚀分位；历史级巨量日稳定逼近 1.0 |
| C3 固定分位基准比 | `vol_qratio(T)=V(T)/EXP_QUANTILE(V,0.95)(T)`，min_periods=260 | 同 C2 | 保留量级（rank 丢弃幅度）；历史 q95 随新极值进入需 5% 质量位移，缓变 |

声明的设计风险（预注册在案，不因结果好坏追改）：C3 的 expanding q95 长期随成交量
水平趋势缓升，晚样本正常日分位系统性偏高 → 晚样本可能过触发；该不对称性由 §5 验收带
与 §6 折间一致性把守，不在网格层面预调。成交额（amount）口径与跨市值标准化：单指数
时序无横截面语义，登记为 v2 失败时的下一候选方向（§7），本轮不入网格。

对照臂（不参与选优）：legacy `vol_z` 臂（z∈{1.5,1.8,2.0}），与 C1-C3 同 harness 重跑，
供四表之"新旧量能腿对照"；其 v1 网格全灭为已发表事实，v2 仅复核同 harness 可比性。

## 4. 预注册网格（跑数前写死）

- **L0 SC 根层**（mode × 阈值 × pct × 新低窗）：
  - C1：W_b{20,60} × thr{1.5,2.0,2.5,3.0}；C2：thr{0.95,0.98,0.99}；C3：thr{1.0,1.2,1.5}
  - 公共轴：sc_pct∈{-0.03,-0.04,-0.05}，sc_window∈{40,60,90,120}
  - 合计 3 新腿臂 168 点 + 对照臂 36 点 = 204 点
- **L1 AR 层**（上游冻结后条件层叠）：承 v1 §4 原样——ar_sc_window{10,15,20,30} ×
  ar_pct{0.005,0.01,0.015} × ar_breakout_window{10,15,20}（36 点；门开关 both 不消融，
  AR 门消融属判据语义改动=触发条件第 2 条，不在本次触发范围）。
- **L2 ST/Spring/Test 层**（层内顺序 ST→Spring→Test，各自独立冻结）：
  - ST：st_sc_window{15,20,30,40} × st_band{0.01,0.015,0.02,0.03} × st_shrink{0.7,0.8,0.9,1.0}（64 点）
  - Spring：spring_shrink{0.8,0.9,1.0,1.2}（4 点）
  - Test：test_spring_window{10,15,20,30,40} × test_vol_ratio{0.9,1.0,1.1,1.2}（20 点）
- **L3 评分层（新轴，唯一新增语义轴）**：memory_window∈{None,40,60,90,120,250}。
  理由：#271 latch_dichotomy 证明 cummax 永久粘滞下不存在能同时避免恒零与误爆的阈值向量；
  有限记忆窗是该结构性缺陷的机械对策，须与量能腿同批预注册。PS 参数、`_STAGE_WEIGHTS`、
  S2 confirm 门槛 60（TRANSITION_CONFIG 声明值）**一律不动**。
- 网格经 `PreRegistrationRegistry` hash 锁定（wyf3_v2_prereg.json）后才允许跑任何指标。

## 5. 验收带与机械选值（先写死）

### 5.1 校准段（v1 §3.1/§3.2 原样沿用，约 3170 交易日）

- 检出力（触发日数）：SC∈[10,100]，AR∈[10,150]，ST∈[10,250]，Spring∈[3,80]，Test∈[3,80]。
- 粘滞指标（score>=60）：**占比 ≤85% 仅适用于校准段** 且 首齐活不早于校准段第 120 交易日
  （v1 §6 教训：该两条不跨段外推，验证段改用 §5.3 事件级判据）。
- 精度/方向性：SC 事件（间隔≤5 日合并）聚集数∈[4,20]；SC 日 pct 中位数 ≤ -2.5%；
  AR 日 pct 中位数 ≥ +0.3%；结构一致性（AR 距前一 SC ≤ ar 窗、ST 距最近 SC ≤ st 窗、
  Test 距前一 Spring ≤ test 窗）须 100% 成立；Spring 聚集数∈[1,30]。

### 5.2 机械选值（分层贪心，准则先写死）

1. 顺序 SC → AR → ST → Spring → Test → memory_window；上游选值冻结后只作常量传入下游。
2. 候选须过该层全部 §5.1 判据；合格者按**该层事件日 20 日前向超额**（vs 校准段无条件
   基线）取最大；并列时依次比：网格偏离小者 → 构造简单者（C1<C2<C3）。
   （v1 用"触发数带中位最近"：v2 改信息量排序，因 v1 证伪的正是"检出达标但零信息"；
   过拟合风险由 §6 折间程序级证据独立把守。）
3. L3 排序客观量=起始事件（score 上穿 60，20 日隙合并）20 日前向超额；并列取更大
   memory_window（抗粘滞偏好，依据 #271 latch_dichotomy）。
4. 任一层无合格者 → 该层保持基线值并登记"该层重校失败"；L0 无合格者 = 终态 b
   （特征层仍不达标），**无合格即如实终态，禁凑数**。
5. 终选向量冻结（写入对照表）后才允许触碰验证段与 §6 折叠评估。

### 5.3 验证段（v1 §3.3 + §6 修正版）

- 检出力：SC ≥2、AR ≥2、ST ≥2 日；Spring/Test ≥0（有则记录，无则如实登记降级接受）。
- score>=60 事件级时序一致性（替代跨段占比上限）：
  (a) 验证段内起始事件（上穿合并 20 日隙）≥2 簇——防"校准段齐活后验证段恒在线"的
  粘滞平台（cummax 下若校准段已齐活，验证段起始事件=0 → 自动 FAIL，此即 §6 缺陷的
  机械转化）；(b) 每簇连续在线长度（自簇首日至首次 score<60）均值 ≤120 交易日；
  (c) 起始事件 20 日前向超额 >0，且事件数 ≥3 时命中率边际 >0、事件数 =2 时只裁超额
  符号并标注 low_power。

## 6. 样本外信息量门（翻转 #271 证伪态的必要条件，预注册）

#271 的证伪证据是信息量层（命中率劣于基线 17.7pp、0/5 折为正、t=-0.10、WFE=-1.25、
latch 二象性）。因此特征修复的达标判定必须同时过**检出带（§5.1/§5.3）**与
**信息量门（本节）**，二者缺一不可：

- **程序级 walk-forward**（§2 三折，折内独立选值、折 test 只跑一次）：池化裁定须同时
  满足——pooled excess20 >0；hit_edge20 >0；≥2/3 折 excess 为正；Stouffer 池化
  t ≥ 2.0；无任何折 test on_share 死区（<0.005）或爆区（>0.25）；WFE 均值 ≥0.6
  （可评折）。阈值常量沿用 lane-F 预注册（PREREG_ACCEPTANCE 同源数值），不另调。
- **终选向量验证段确认**：§5.3 全过。
- **翻转充分必要条件 = §5.1 校准全过 ∧ §6 程序级全过 ∧ §5.3 验证段全过**；
  任一不满足 → 终态 b（证伪加厚），生产维持置零。
