# 产业链 Alpha 作业区目录说明

> 四线并发挖矿作业体系（Owner 五轮令：细分类+六向寻路挖干再施工）。

## 结构

- 根目录文档=**总账层**（跨线）：industry_chain_alpha_plan.md（纳入方案）、industry_chain_alpha_mining_ledger.md（挖矿总账+裁决书）、industry_chain_data_source_expansion.md（线B 方案）、industry_chain_global_expansion_plan.md（线C/D 方案）。已入库文档不迁移（防 rename-depgraph 连锁）。
- 子目录=**各线作业区**（挖矿作业簿 workbook 所在，后续该线新文档进对应子目录）：
  - `a_batch1_construction/` 线A 批1施工（暴露矩阵+生猪因子+送考）
  - `b_data_sources/` 线B 数据源补全（锚卡接入+期货回补）
  - `c_research_feed/` 线C 研报喂链（语料+抽取+证据时点回填）
  - `d_entity_master/` 线D 实体身份证库+时点基建

## 挖矿纪律（全四线适用）

1. 每线一本 `*_mining_workbook.md`：矿脉细分类清单+六向状态台账+挖矿日志表。
2. 矿脉枯竭判据（SOP §3）：单矿脉六向全部"已查无"且长尾清空=挖干；**禁止轮数/候选数判停**。
3. 施工准入=挖后自审闸（SOP §6）：该线 workbook 全矿脉三态出口（施工/挂起/封矿）裁定完毕，才许开工。
4. 防噪音四闸过闸留痕；外部引文必须 URL+发布方+年份。
