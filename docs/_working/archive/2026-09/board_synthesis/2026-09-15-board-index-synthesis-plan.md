# 板块指数自建合成方案（模拟通达信 880/881 板块指数）

## §0 目标与消费方

**目标**：用自库数据（成分股分钟/日K + 成分映射 + 市值权重）自建通达信 880/881 板块指数的
合成序列，经回测对拍迭代至与真实数据匹配（校准窗量化验收，见 §4），替代已死亡的 mootdx 通道。

**消费方**：
1. 逆势榜 counter_trend_board（MOD-SIG-071，四卡核心输入=板块分钟序列）——**当前已瘫痪**，
   本方案第一受益人；
2. 板块日K 消费方（regime 特征 mainline/sector_hhi 等）——kline_sector（tqcenter 活通道）
   已覆盖日K，本方案日K 级为**校准与冗余备份**，非急用；
3. 长期价值：板块数据自主可控，不再依赖通达信单一体系。

**为什么可行**：通达信 880/881 板块指数本质=成分股按流通市值加权的派氏综合指数（股本加权
+除数修正族），全部输入（成分映射/个股行情/流通市值）自库均有或可建；校准真值=mootdx 死前
的 kline_sector_intraday 历史真实分钟 + kline_sector 2020-03 起日K，对拍数据充足。

## §1 核心算法（定稿口径：t-1 流通股本加权链式，2026-09-15 Phase 3 实测定案）

**日K 级**（Phase 1）：
```
板块日收益 r_b(t) = Σ_i w_i(t-1) × r_i(t) / Σ_i w_i(t-1)
w_i(t-1) = 流通股本_i = circ_mv_i(t-1) / close_i(t-1)   ← 股本不含价格，日内恒定
I_b(t) = I_b(t-1) × (1 + r_b(t))
```
- **权重口径三方案分钟级实测**（09-08/09-09 双真值日对拍，corr 中位）：**流通股本加权
  0.886/0.969 > 等权 0.806 > 流通市值加权 0.670（概念段 -0.62 负相关）**；
  行业段 8811-8814 与地区 8802 在股本加权下 corr 0.9954-0.9990 全达标=物理级铁证；
  ⚠️ 挖矿 R1 曾把"流通股本加权"误等同于 circ_mv（股本×价）加权——二者差价格因子，
  高价股（茅台）在市值口径下权重爆炸 58.9% 主导板块，TDX 真实口径为股本加权（派氏，日内除数固定）；
- **分钟级**（Phase 3）：同公式作用于 1 分钟收益；个股缺 bar 分钟沿用最后已知价，
  全程无 bar 的停牌股以 t-1 日K 收盘兜底全程参与（r=0，通达信口径）；
  分钟权重沿用 t-1 日股本（盘中不换权重，保证盘中序列与日K 收益一致可对账）。
- 成分股按 600 只/批分片查询（防 MemoryError）；写入 data_source='synth_sh'。

**备选口径**（已实测降级留档）：等权（corr 次优，作为股本缺失板块的降级路径，--weight-mode eq）；
流通市值加权（概念板块负相关实证弃用）；当日权重派氏；流通市值分档加权。
- 停牌股处理：停牌日 r_i=0（价格沿用停牌前收）✓ 已按昨收兜底实现；
- 新股上市首日：不计涨跌幅——MVP 直接从有权重日参与，精确规则待对拍反推。

## §4 对拍验收框架（"99% 匹配"的精确定义）

**校准窗**：mootdx 存活期（kline_sector_intraday 有数据的全部交易日 + kline_sector 日K 2020-03 起）。
**验收矩阵**（分板块逐一对拍，全板块通过才算达标）：
- 日K 级：板块日收益相关性 ≥0.99；日收益绝对差 ≤0.15pp（95 分位）；方向一致率 ≥97%；
- 分钟级（逆势榜口径）：段内板块收益排序保真——top-20 板块重合率 ≥90%、相邻排名抖动率 ≤15%；
- 长窗口：3 个月滚动累计收益差 ≤1pp。
**迭代回路**：不达标项 → 按 §1 备选口径逐项切换重拍（权重口径→停牌处理→新股纳入日→除数法），
每轮留存对拍报告；连续两轮无改善的指标项如实登记差距（不做假达标）。
**通过判定**：连续两轮全指标达标 = 合成器冻结转产。
