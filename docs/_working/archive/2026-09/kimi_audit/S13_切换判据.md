# S13 策略切换的统计判据（基线 f8002ed8 后，班次 2026-09-17）

## 六问裁定

**①切换信号统计量与滞后**：分两层。**regime 层**：统计量=检测器后验 max(P)+dominant 态（`regime_detector.py:247-262`，PIT 安全：builder 内置 shift(1)）；滞后=**3 交易日确认窗**（`style_regime_model.py:133` confirm_periods=3 先例平移到市场 regime）。滞后代价 vs 抖动代价的量化件目前全仓无（空白实证），裁定理由：regime 平均驻留 ≫3 日时，3 日确认窗的期望滞后损失≈3×日度 alpha 差，而抖动代价=2×往返成本×抖动率；现行查表零防抖（`framework_composer.py` 纯查表，`environment_switch.py` 同型）下抖动无上限。**策略对层**：A↔B 切换判定统计量=配对日度 P&L 差值 delta 的 **mSPRT e-process**（MOD-PF-008 已落码，anytime-valid、α=0.05、满 30 样本才终局）——序贯判定消除"偷看惩罚"，优于固定窗 t 检验。

**②切换成本必须计入考核**：现状=切换比较零计入（grep 全仓无 switch_cost；fw 动态切换"翻转日 α 全组跳变换手随行"且评估不计，`decision_kernel_mining.md:100` 在案）。裁定：**mandatory**——对照回测必须扣往返调仓成本（H2 真成本链口径），显著性检验（bootstrap CI 不含零，S-OWNER-002 卡 §五已有此规格）在**扣费后** delta 序列上做。不计成本=纸面最优，该卡作者已写明，本裁定把它升级为标准。

**③防抖三件套**：确认窗（3 日连续同向）+ 最短驻留（5 交易日，且 ≥ 成本回收期=切换成本/预期日edge）+ 置信度地板（max(P)<0.50 保持闩锁态，fail 到保守=维持现状）。**CRISIS 豁免**：overlay 危机态当日生效不等窗（风险优先，检测器危机门控 L377-383 既有）。现役 `budget_change_handler` 的 5%/10% 防抖与 2/3/4 日收敛窗是资金层同族先例，本裁定把防抖上移到 regime→权重主路径。

**④多状态仲裁=dominant_latch**：max(P)≥0.50 → dominant 态切换；未达 → 闩锁旧态；overlay 态中 CRISIS 优先级最高（覆盖一切）。弃"权重混合制"：framework_composer 查表+__base__ 回退已是生产路径且可测，改为概率混合会引入连续权重漂移（每日换手），与③防抖矛盾。r1/r2/r11 无映射=不激活（宁漏勿误，既有 strict 口径保留）。

**⑤联赛多重比较**：族=**同批联赛全体挑战者**（BHY FDR q=0.10，L4 D-L4-04 锦标赛强制条款升级为执行标准）；冠军出炉后 DSR 的 n_trials=**联赛族大小**（非全局账本——联赛是独立预注册族；全局账本管"筛"（C4 intake），联赛管"换"，两场景分治）。相关性闸 ρ>0.7 合并算额度（§7 骨架既有）。注意与 S5 联动：若 S5 采纳 N_eff 口径，联赛族大小即为联赛版 N_eff。

**⑥预注册冻结**：切换判据本身=标准库条目（STD-SWITCH-001），改判=新版本号+重考历史切换决策；联赛/切换实验沿用 L4 三道锁（criteria_hash 时序/不可变/哈希）。§7 骨架晋升规则自述"数字靠模拟盘数据校准后冻结"——在冻结前**任何切换结论只许记"未决"**（B 档未决诚实条款，L4 §2.4 既有）。

## 复算反驳者（一档双角色加试）

1. **"3 日确认窗在 2024-09-24 式暴动中会晚 3 天上车，代价巨大"**——成立但方向安全：确认窗的设计目标就是过滤单日暴动；CRISIS 豁免覆盖下行风险（下行当日生效），上行晚 3 天=少赚不是亏钱。暴动窗口的极端收益本来就不可持续捕获。
2. **"mSPRT 的 delta 契约未建成（F-4），定稿引用一个缺件是不是空中楼阁"**——正是因此 F-4 把一切判定锁在"未决"；尺子的作用是裁判而非运动员，契约件建成前无合法切换判定产生，这比"先切换后补尺"安全。
3. **"联赛族口径（n=联赛大小）与 2026-09-15 累计 N 裁定不一致"**——有意分治：累计 N 管研究筛选（防全历史考古偏差），联赛族管运行期切换（候选集封闭且预注册）。若 Owner 裁定两场景统一口径，本尺 league_family_scope 行改一字即可，不牵动其余条款。
