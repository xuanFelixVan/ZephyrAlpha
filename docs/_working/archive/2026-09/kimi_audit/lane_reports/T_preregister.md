# T 预注册卡：510300 15min 三重共振极值点出手有正毛边际？

> 本卡为「签砍之前最后一眼数据」。单假设、封闭族 N_eff=1、一次性考试。
> 实验脚本 `.runtime/tmp/exp/t/t_exam.py`，产物 `.runtime/tmp/exp/t/t_exam_result.json`，哨兵 `.runtime/tmp/exp/t/t_exam.done`。

## 1. 假设（H1，唯一）

**在 510300（华泰柏瑞沪深300ETF）上，15min 级三重共振极值点出手（maker 限价买入），单均毛边际 > 12bp/边，且统计上非运气（DSR>0.5）。**

零假设 H0：共振组毛边际均值 ≤ 12bp/边，或与无差别每日出手对照组无显著差异。

## 2. 三重共振定义（冻结，全部条件同时满足才出手）

### 腿① ETF 自身极值（15min bar 级，510300，无未来函数）

信号 bar t 收盘时满足：

- `RSI(14)`（Wilder，15min 收盘价序列，仅用 ≤ t 的收盘）**≤ 20**；
  **或** 收盘创 20 根新低（`close_t < min(close_{t-20..t-1})`）**且** 量比 > 2（`vol_t / mean(vol_{t-20..t-1}) > 2`）。

### 腿② 板块/大盘日线状态过滤（降级腿，声明）

- **已实测坐实**：880 板块分钟数据只有日线（`c1_market.kline_sector_880` 仅 period='1d'，469 板块，2020-03-17→2026-09-17）；且 510300 跟踪沪深300 宽基，880 行业/概念板块无干净的"沪深300 板块"映射。
- **降级口径（冻结）**：用 `c1_market.kline_index` 的 000300（沪深300，日线，2005-01-04→2026-09-16 满覆盖）日线状态代替板块共振：信号日 T 的**前一交易日 T-1** 000300 日线 `RSI(14)`（Wilder，日线收盘）**≤ 35**。
- 用 T-1 而非 T 日，杜绝盘中引用当日未收盘日线的未来函数。
- **局限明写**：该腿从"板块分钟级共振"降级为"宽基日线级超卖状态过滤"，共振粒度从 15min 降到 1 个交易日，灵敏度必然粗于原设计；若过线，结论只能读作"日线超卖背景下的 15min 极值点"，不能外推到"板块分钟共振"。

### 腿③ 大盘指数分钟腿（替代腿，声明）

- **已实测坐实**：000300 在 kline_1min/15min/60min 全 EMPTY（S2 裁定书 §数学与专业依据，地形实测在案）。
- **替代口径（冻结）**：第一层代理=510300 本身就是沪深300 的可交易代理（腿①已承担）；第二层确认=**510500（南方中证500ETF）同一 15min bar 的 RSI(14) ≤ 35**（确认级阈值，宽于腿①的极值级 20）。同一 bar 按**北京时间对齐**（时区归一化见 §4）；若该时刻 510500 bar 缺失，信号作废（保守处理，不递补）。
- **局限明写**：510500 是中证500 代理而非沪深300 本身，跨品种确认测的是"宽基普跌共振"而非"300 指数自身分钟形态"；000300 分钟源补全后本腿应重跑（一条命令的事，脚本在案）。

## 3. 执行仿真（maker 限价，冻结）

- 信号 bar t 触发后，挂**买入限价单 = bar t 收盘价 − 1 tick（0.001 元）**。
- **成交判据**：下一根 bar（t+1，须与 t 同一交易日，t 为当日末 bar 则信号作废）最低价 ≤ 限价 → 按限价成交；否则**弃权**（订单不滚存到 t+2）。
- **退出**：成交 bar 记为 e，退出价 = `min(e+8, 当日最后一根 bar)` 的收盘价（持有 ≤8 根 ≈2 小时，不隔夜，贴做T 日内往返语义；T+1 约束由"做T 臂仓位 ≤ 前收盘持仓"的既有框架承担，本测算只量单腿价差）。
- 同一时间只持有一笔：上一笔未退出前的信号跳过。
- **每月 ≤ 8 次出手**：每自然月按时间序取前 8 个成交信号，超出弃权（成交与否都计入当月 8 次额度，以信号计）。
- **毛边际/边** = （退出价 − 成交价）/ 成交价 × 10⁴ bp。成本口径参考线：现行参数往返 8.4bp（佣金 0.854×2+滑点 2.34×2+加成 1×2，ETF 免印花，S2 裁定书 §3 在案）——12bp 门槛已含 8.4bp 成本线 + 3.6bp 安全边际，故本考试判据用毛边际直接对 12bp。

## 4. 数据与时区处理（冻结）

- 样本：2023-01-03 → 2026-09-16 全部可得 15min bar。
- **时区劈叉归一化**（地形实测发现）：`kline_etf_15min.trade_time` 列为 DateTime64(3,'Asia/Shanghai')，但 2026-06-30 及以前的 bar 实际存的是 UTC 墙钟（日内小时 ∈ [1,7]），2026-07-20 起为北京墙钟（小时 ∈ [9,15]），2026-07-17 仅 2 根残缺 bar。规则：`toHour(trade_time) ≤ 7 → +8h`，两区间小时取值不相交，逐行规则无歧义。510500 同规则。归一化后按 (symbol, bar_time_bj) 去重（保留 ingest_ts 最新行；实测个别日有重复 bar，如 2026-09-11 双倍）。
- 腿③的 510500 对齐键 = 归一化后的北京时间 bar 戳。

## 5. 对照组（反例样本，冻结）

- **无差别每日出手对照组**：样本内每个交易日，以当日**首根 bar（09:45）**收盘为信号，套用完全相同的 maker 限价/成交/退出规则；无 RSI/新低/量比/日线/共振任何过滤，无每月 8 次上限。
- 判据：共振组毛边际均值必须**显著优于**对照组（单侧 Welch t 检验 p < 0.05）；对照组不差于共振组 = H1 反例成立。

## 6. 及格/判红判据（冻结）

| 判据 | 门槛 | 来源 |
|---|---|---|
| 毛边际均值 | **> 12bp/边** | S2 裁定书「若不同意」第 2 条（8.4bp 成本线 + 安全边际） |
| DSR | **> 0.5**，N_eff=1（预注册单假设封闭族） | S5 定尺子 §1③ v2 族口径 |
| 成交率 | **≥ 30%**（成交笔数/信号笔数） | maker 弃权过多 = 假设无实操意义 |
| 对照组比较 | 共振组显著优于对照组（单侧 Welch p<0.05） | 本卡 §5 |

**什么算红（任一即红）**：毛边际均值 ≤ 12bp；或 DSR ≤ 0.5；或成交率 < 30%；或对照组不显著差于共振组；或成交笔数 < 4（DSR 矩估计退化、不可判=红）。
全绿 = H1 成立，推翻 S2「毛边际为负」结论的第 3 条理由（仅第 3 条；第 1、2 条不受影响）。

## 7. DSR 口径（冻结）

- 收益序列 = 逐笔毛边际（小数口径），每期=一笔成交。
- `SR = mean/std`（per-trade，不年化）；偏度/超额峰度由同一序列实算。
- 调 canonical kernel：`deflated_sharpe_from_moments(sharpe, num_trials=1, num_obs=n_trades, skewness, excess_kurtosis)`（`src/zephyr/simulation/deflated_sharpe_calculator.py:327`）；`expected_max_sharpe_z(1)=0`（`:242`，N≤1 无多重折减）。
- N_eff=1 下 DSR>0.5 ⟺ per-trade SR>0——这是族口径的数学性质，如实披露；本考试的真正牙齿在 12bp 门槛与对照组。
- **口径偏差披露**：S2 裁定书原文为 DSR（N=4562 累计口径）>0.5；本 lane 按 lane 卡指令采用 S5 v2 族口径 N_eff=1。两口径并存披露：结果 JSON 同时给出 N=4562 口径的 DSR 参考值，供 Owner 对照。
