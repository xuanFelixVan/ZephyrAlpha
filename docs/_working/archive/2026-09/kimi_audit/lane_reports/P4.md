# P4 — STD-SWITCH-001（draft）历史切换回验

## 0. 判据与结论（写死判据，先给答案）

判据：切换规则净 Sharpe < 等权全池 −0.1 = **输**；≥ 等权全池 +0.1 且成本后为正 = **赢**。

**结论：赢（WIN）。** 基准参数（确认窗 N=3 / 闩锁 0.50 / 驻留 M=5）净 Sharpe **1.1297** ≥
等权全池 0.3782 + 0.1 = 0.4782，成本后总收益 +49.03% > 0；9 格敏感性网格（N∈{2,3,5}×M∈{3,5,10}）
**全格 WIN**（净 Sharpe 区间 0.9193–1.3266，下限仍 ≈ EW+0.54）。按判据，STD-SWITCH-001 draft
具备转正资格——但 §4 的 CRISIS 抖动漏损与 §5 maxDD 代价必须在转正附注中登记。

## 1. 实验设置（可复现口径）

- 数据：`c1_backtest.regime_snapshot_history`（CH 只读经 DatabaseService reader；同日多快照取最新
  ingest_ts 去重，424→窗口 403 交易日）+ `.runtime/tmp/sharpe2a_oos_nets/*.csv` 73 条 OOS 日净收益。
- 窗口：2024-01-02..2025-08-29（403 交易日，两者交集）。窗口内 dominant 分布：
  r1=161 / r3=99 / r2=69 / r10(CRISIS)=60 / r4=10 / r12=4。
- 规则实现（全条款）：确认窗 N 连续同向且每日 conf≥0.50（conf<floor 的日子=未决→闩锁并打断连计）；
  最短驻留 M（确认完成但驻留未满→挂起，满当日补评估，基准参数下发生 8 次）；
  CRISIS 豁免（r10 且 conf≥0.50 当日评估，绕过窗与驻留）；切换成本强制：单边 3.194bp
  （佣金 0.854+滑点 2.34，ETF 免印花），A→B 当日扣往返 6.388bp×权重差1；初始部署保守同扣。
- 选股择（"当期最优"的 PIT 操作化）：决策日以 ≤t-1 收益算 trailing 60 日 Sharpe（min_obs=20）
  在 73 候选取 argmax；前 60 日 warmup 持等权池。regime 只控切换时机，不参与选股。

（单元格=净 Sharpe / 成本后总收益；切换次数 24–25，全格 WIN。）

- 单调结构清晰：确认窗越短越好（N2>N3>N5，滞后损失主导抖动损失）；驻留 M=3≈5 ≫ M=10
  （M=10 挂起延迟 37–46 次，机会成本超防抖收益）。**draft 的 N3/M5 居中非最优但稳过判据**；
  网格指向 N2/M3–5 更优，可作为转正后 v2 调参方向（需新 experiment_id 预注册重考）。

## 4. 切换行为解剖（25 次切换日志全量在 switches.csv）

- regime 确认採用 19 次 → 评估 69 次 → 实切 25 次（含初始部署）；驻留挂起 8 次被 M=5 正当拦下。
- **CRISIS 豁免是双刃剑**：52 个 CRISIS 日触发 13 次切换（52%），其中 2025-04-09..05-07 出现
  CAND-e3da6fa71af1↔CAND-b1fb7e2246dd **7 次往返乒乓**、2024-11 三连切——豁免绕过驻留后，
  两近优策略在并列区逐日互切，漏损 ≈13×6.388=83bp（占总成本一半）。
  **建议转正附注**：CRISIS 下保留"禁当日回切/≥1 日驻留"兜底，或 CRISIS 段内切向低波档而非
  Sharpe argmax。
- 非 CRISIS 切换（12 次）节奏健康：平均驻留 ≈27 交易日，无高频抖动。

## 5. 局限（诚实清单）

1. "当期最优"选股规则（trailing 60d Sharpe argmax）是本方对 STD-SWITCH-001 的 PIT 操作化，
   标准本身未定选股器——结论部分承载"策略动量 alpha"，非纯 regime 条件能力检验。
2. 台账 477 个缺失单元格填 0（部分 CAND 史短）；5 个零方差策略从后验最优剔除但仍留在 EW 池
   （拖累 EW ≈ 偏袒切换规则，方向性偏差已披露）。
3. EW 基准未扣日度再平衡成本（若扣，EW 更低，结论方向不变、幅度收窄）。
4. min_dwell 的"≥成本回收期=切换成本/预期日edge"条款未实现（事前 edge 无合法估计）；
   实现只会进一步减切换，方向保守。
5. 单窗口 403 日（含 2024-09/10 暴动与 2025-04 长 CRISIS 段），单实现，无跨窗稳健性。
6. 成本取 H2 典型层 3.194bp/边，未按规模/波动分层加压；加压敏感性未测。
7. regime 快照同日多 run 取最新 ingest_ts 去重；表本身 as-of ≤t-1（PIT 安全）。
