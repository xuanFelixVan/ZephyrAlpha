# 裁定书草案 S2：做T v2 升级战战役可行性

## 现状（含证据锚点）

1. **立项依据无证**：战役设计书（`docs/_working/factory/t_v2/2026-09-17-t-v2-campaign-design.md:8`）称"S-OWNER-001 考试 FAIL（#293）已证伪小时级动量，毛边际 +2.7bp/边"。实证：
   - `#293` 在册内容实为"回测合理性收益带单一真源化收紧（+1000%→+300%）"（`ruling_registry.yaml:3435-3441`），与做T考试无关（清单 V-02）；
   - 同文档 `:28` 引用的"#304 教训"在登记表**查无此号**（registry 最大号=裁定#303，已核全表；清单 V-01）；
   - "+2.7bp/边"在全仓无任何底层考试产物支撑（strategy_screen 零 owner 行、`data/backtest_artifacts/` 无 001 档案、factory/ 目录无考试报告——001 策略卡自述"考试规格未经批次决策点冻结前禁跑"（`2026-09-16-s-owner-001-300etf-band-t.md:3`），即**考试从未正式发生**）。
2. **统计上不可能出正结论**：N 账本累计口径（2026-09-15 裁定在案，MOD-BT-200）现为 **4562**（本班 S1 补登 81 后）。在该口径下，T=471 个 OOS 交易日时 DSR>0.5 需年化 Sharpe≥**2.68**，DSR>0.95 需 ≥**3.89**（canonical kernel E[max(Z)]=3.664 实测）。而战役自己的验收线写的是 OOS Sharpe≥1.2（001 卡 §四）——**1.2 在 N=4562 下 DSR≈0.02**。战役矩阵=7 时间级别×5 因子族×3 共振层级=105 格起步，穷举只会把 N 推得更高。即便退到批内口径 N=105（Emax≈2.8），过 DSR>0.5 也需年化 Sharpe≥2.05，仍高于其自设验收线——**设计书 §二.2"多重检验惩罚如实计入"与其 §四验收线自相矛盾**。
3. **毛边际数学不过成本线**（本班 S2 实验实测算，产物 `.runtime/tmp/exp/s2_result.json`）：510300 的 15min 中位 bar 振幅=**26bp**（p25=18/p75=38，471 交易日样本）；100k 单笔、Q5 巨流动滑点 2.34bp 档的往返成本=**8.4bp**（佣金 0.854×2+滑点 2.34×2+加成 1×2；ETF 免印花；¥5 地板在 100k 未触发），所需捕获率=**32%** 的中位 bar 振幅/往返；Owner-001 口径滑点 1.5bp 档需 26%；压力滑点 7.24bp 档需 70%（红）。系统性策略可持续捕获 bar 振幅的 5-15% 已属优秀——**15min 及以下级别在现行成本参数下净边际为负**。60min（中位 54bp）所需捕获率 12-21%，仍苛刻，且 60min 已接近波段而非做T。
4. 结构约束：A 股 T+1 下做T 臂仓位 ≤ 前收盘持仓（001 卡 §一），做T 对全账户的收益贡献还要乘以额度占比——单腿边际为负时额度越大亏得越多。
