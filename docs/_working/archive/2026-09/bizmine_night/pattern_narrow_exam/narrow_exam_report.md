两个结构性发现：
1. **P 的超额有相当部分住在「确认收盘→次日开盘」的隔夜段里**。④⑤⑥在 T+1 开盘入场后毛超额即大幅缩水（⑥ +9.22%→+1.45%，长尾被开盘价截断），①②③的隔夜段反而是顺风。这就是 P 自己披露「t 膨胀只够排序」的机制层解释。
2. **逐笔加权 vs 按日等权组合的分裂**：④⑤逐笔微正但按日组合负——信号密集日（拥挤日）的后续超额系统性更差，按日等权组合给拥挤日更大权重。⑥的拥挤季分解（−25.2 vs +5.7bp/d）是该机制的直接证据。①②③两口径同向，结论对加权方式稳健。

## 3. 显著性与多重检验（两档并报）

- 严格档（最严参考线）：P 全研 4,733 项检验 → Bonferroni α=0.05/4733=**1.056e-5**。①②③的 bootstrap p²<1/500 分辨率，**4733 检验下存活=是**（三件全部标注）。④⑤⑥无正向边存活问题（方向不符）。
- 常规档（判定用）：α=0.05/103=**4.854e-4**。①②③存活；⑥ p²=0.064 不过。
- 注：bootstrap 为事件日聚类重抽，已消化重叠窗口的序列相关与同日跨股相关；NW t（lag=10）对 ①=8.42、②=4.15、③=3.54，全部 ≥2 门。普通 t（iid）仅作排序（①6.5/②3.2/③5.3）。

## 5. 诚实条款与局限（全部适用，按权重排序）

1. **未复权**（adj_factor≡1）：分红除权系统性压低持有收益，①②（下跌后事件密集带）与③（上涨后）受影响方向不同；一切幅度暂定，复权链修复后必须复核（①的 PASS 门有多大幅度的安全垫：Sharpe 2.89 vs 门 0.8，但中位数口径垫更薄）。
2. **可成交性未建模**：⑥一字板次日开盘常封板不可买（能成交的样本恰是弱势样本→真实组合比回测更差，RED 更稳）；③做空需融券（费率 8-10%/年+券源未建模，若计入，③的 +2.37 Sharpe 会被显著侵蚀——统计 PASS，可交易性待 Owner 裁定是否单独立卡）。
3. **拥挤日/现金拖累已如实入账**：空仓日超额=−基线（真实现金机会成本），弱信号 cell ①不适用（1,213/1,223 日在仓）但⑥仅 1,171 日在仓且仓次集中。
4. 重叠持仓相关性：NW+锚日聚类 bootstrap 处理主部；跨簇残差相关（同行业同题材）未完全独立。
5. 2021-09/2026-09 为部分年，分年=6 个日历年照计（预注册写死），①②③为 6/6 全正、对部分年不敏感。
6. P 的 prev20 内生性诊断（跌得深→反弹贡献部分超额，corr −0.23）本考未做中性化——①②的超额含超跌反弹成分，如实披露。
