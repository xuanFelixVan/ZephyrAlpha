## 3. 方法摘要（细节=preregistration.md）

r_N=close(t+N)/close(t)−1，N∈{5,10,20} 交易日（全市场日历 tseq）；超额=事件均值−基线均值；Welch t（⚠重叠窗口+跨股相关使 t 膨胀，仅作筛选序）；中位数/胜率并列；n<30 标功效不足；分年一致性=与全样本同号年份占比（n_year≥30）；regime=T-1 PIT 三轴：BDI（F4_BDI_MOMENTUM_Z20 三态）/dominant（r1-r4）/vol_pct 三分位（IS 2021-09..2023-12 钉死 0.212/0.532）。综合分 score=t10×(2×cons10−1)。

**验证链**：随机 3 事件×3 窗手工 SQL 复算 9/9 逐位一致；塔形顶/塔形底 2024 年效应用独立 SQL join 路径复算（塔形底 +4.5pp / 塔形顶 −5.5pp vs 主管道全期 +3.6/−3.7pp，方向量级一致）。

## 5. Regime 条件版结论（「什么行情下什么图形灵」）

**主结论：头部图形（塔形底/双底/一字板）是「全天候」的——所有 10 个状态桶超额同号，行情状态只改幅度不改方向；真正的「状态开关型」集中在 BDI 轴的少数 K 线形态。** 分轴：

- **BDI 轴（risk_on/neutral/risk_off，T-1）**：①塔形底 +3.1/+3.8/+2.5%、双底 +1.8/+2.3/+2.3%——三桶皆正。②状态敏感型：Shooting Star/向下 risk_on +1.79% vs risk_off −0.24%；Marubozu/向上 risk_off +1.34% vs risk_on −0.85%；Piercing risk_off +0.96% vs risk_on −1.22%；Hanging Man risk_off +1.88% vs risk_on −0.18%；Advance Block risk_on +2.06% 最强；三黑鸦 risk_on +6.06%（n 小）。即：**超跌反弹类看 risk_off/neutral，弱势抛射类看 risk_on**。
- **dominant 四态**：塔形底 r3 最强（+4.53%）但 r1-r4 全正；一字跌停板 r3 +6.85% vs r4 −11.68%（n=1781，谨慎）；三黑鸦 r4 +8.06% vs r2 −1.71%（n 小）。r4（第四态）对看跌形态普遍偏负。
- **vol_pct 灰度三分位（IS 钉死 0.212/0.532）**：三黑鸦 vol_high +4.78% vs vol_low +0.46%（高波兑现快）；塔形底 vol_low +4.68% 最强、vol_high +2.44% 最弱（低波里底部形态更灵）；缠论中枢唯一正桶=vol_mid（+1.26%）。R 车道「收益集中于高波桶」的结论在图形层**不成立**——图形层高波桶整体超额反而略低。

## 6. 多重检验与诚实条款

- 检验总数：主 304（103 cell×3 窗，n≥30 者）+ 分年 1,642 + regime 2,787 = **4,733**。Bonferroni 参考阈 |t|≈4.16。跨 cell 命中率：|t|>4.16 者 44/100（正 19/负 25），远超随机水平——图形事件存在真实横截面结构，非纯噪声。
- ⚠ t 值因重叠窗口+事件跨股相关严重膨胀（塔形底 t=168 不是 168σ），只用于排序与筛除；真值需 Newey-West/按事件簇 bootstrap 的窄测确认。
- **未复权**（adj_factor≡1）：分红除权日把 r_N 系统性压低；塔形底/双底的高胜率部分可能含除权摩擦，待复权链修复后复核。
- **内生性诊断**（非预注册主检验）：事件前 20 日收益（prev20）显示图形事件自带选样偏差——基线 prev20=+0.69%，三黑鸦 −8.2%、双底 −2.4%、一字涨停板 +36.8%；跨 cell corr(ex10, prev20_ex)=−0.23 → 「跌得深→反弹」贡献了一部分塔形底/双底的超额，但相关仅 −0.23，不能完全解释。窄测卡应带 prev20 中性化对照。
- 一字板对称性：一字涨停板均值 +9.2%/中位 −0.7%，一字跌停板均值 −5.5%/中位 −5.9%——涨跌停链的长尾结构使均值不可直接交易。
