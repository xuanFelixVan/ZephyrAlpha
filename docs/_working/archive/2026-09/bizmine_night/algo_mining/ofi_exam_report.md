# ofi_exam_report.md — 件① OFI 成交签名买卖不平衡 正式考

> verdict：**RED（H2 主检验）+ H1 辅助复现 MIXED**。卡先 frozen 后取数；参数零改动（一次 IS 边界 bug 修复=按卡勘误，见 §5）。

## 1. verdict 一句话

当日累计成交签名不平衡（OFI 代理）对次日开→收收益**无横截面预测力**（pooled IC −0.0088，t=−0.70，n=415 日），全部桶级检验亦不显著——文献级日内价格冲击关系（H1）在横截面上方向对半，但**未转化为日频 alpha**。

- 复现结论 **MIXED**：β 与规模（lnADV）负相关=文献方向 ✓（大票冲击斜率小）；但 β 与 Amihud20 负相关=文献预期（流动性差→冲击大→正相关）**反号** ✗。解释线索：本宇宙 20 只全是高波投机票，Amihud 变差主要由 |ret|（波动）而非深度驱动，与 ADV 不再单调一致；n=20 截面功效有限，仅描述。
- 日内冲击本身存在（β 显著为正），但**日内信息不延续到次日开→收**——H2 RED 的机制注脚。

## 4. 数字三口径

- 成本：毛口径（信号考试，不涉交易成本；升格前须另过成本门）。
- 复权：次日开→收为同日日内比率，复权链恒 1 不影响；ADV20/Amihud 用未复权量额（水平量不受价格复权影响）。
