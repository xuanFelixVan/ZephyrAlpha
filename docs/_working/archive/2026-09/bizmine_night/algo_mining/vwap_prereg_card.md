# vwap_prereg_card.md — 件③ VWAP 偏离回归·条件化做T 窄测（衔接 W3 绿区簇）

> 本卡先于实验落盘。修实现缺陷可，改 frozen 参数不可。**k 在 IS 期选定后 OOS 禁调**。筛≠考：绿区≠净边际为正；PASS 只升待考池+新单假设卡草案（走 Owner 快签），不出部署结论。

## 1. frozen 输入

- **标的（frozen 3 只=W3 绿区簇最优各一）**：588200 科创芯片（宇宙A 双窗绿 req 0.185/OOS 0.134）、513330 恒生互联网（宇宙B 绿簇最优 0.195/0.227）、300561 汇金科技（宇宙C 最优 0.141/0.196）。宇宙规则引用 W3 frozen，不改。
- **数据**：588200/513330=`c1_market.kline_etf_1min`（探针：513330 2021-02-08 起 1361 日、588200 2022-10-26 起 949 日，均至 2026-09-18）；300561=`c1_market.kline_1min`（2021-09 起）。1min close/volume。
- **窗**：σ 与 k 的 IS=2025-01-02..2025-12-31（前接 20 日 σ 预热，588200/513330 用 2024-12 数据预热）；OOS=2026-01-01..2026-09-18。
- **信号**：当日累计 `vwap(t)=cum(Σ close×volume)/cum(Σ volume)`（自 09:30 bar 起）；`dev(t)=(close(t)−vwap(t))/vwap(t)`；`sigma_dev(t)`=截至前一交易日的 20 个交易日内全部 1min dev 观测（10:00..15:00）的样本 std（PIT）。
- **入场（多头腿）**：`dev < −k × sigma_dev`，k ∈ {1.0, 1.5, 2.0}（frozen 网格）；入场窗=10:01..14:30（10:00 前留给开盘段噪声+14:30 后禁新开仓——防退化 1-bar 持仓，机械落定写死于卡）。**过滤（6.2 信号同号）**：当日全市场等权 r_first_mkt>0（件② H1 市场动量符号）才允许开仓。
- **出场**：dev 回穿 ≥0（1min close 判）或 15:00 bar close 强平。**仓位语义=T+1 底仓T（统一适用，含 513330——其虽属真 T+0 类，按 digest §6.3「禁止裸日内回转假设」统一底仓T 记账，对 513330 属保守降档，如实披露）**：开仓=买 1 单位（加仓腿），平仓=卖出同量底仓（老股合规）；同一时刻最多 1 单位，日终零额外仓位；名义 ¥250,000/单（与 W3 口径一致）。
- **成本双口径（报告必注）**：①引擎现行=佣金 0.854bp/边（¥5 地板/边→¥250k 名义下 2bp/边地板生效）+卖出印花税万5（仅个股 300561；ETF 免）+滑点五分位/边 [7.24,5.69,4.67,4.00,2.34]bp 按 ADV20 成交额档界 [0.4641,0.9021,1.7397,4.1798] 亿元（`cost_model_calibration.py` frozen）；②Owner-001=滑点 1.5bp/边+同佣金/印花。
- **k 选定（IS 期，frozen 程序）**：每标的按 IS 净边际（引擎现行口径）最大选 k；并列取更大 k（保守）。OOS 用该 k 原样跑，禁调。
- **判定（frozen）**：每标的 req_cap=1.43×RT成本（引擎现行，OOS 期实际档）/ IS 期日振幅 p50（=(high−low)/low，1min 聚合日高低）；grade：req≤0.25 绿区 / ≤0.50 脱红 / 其余 RED。**主判门（进族 3 格）**：OOS 净边际/日（引擎现行）>0 且 grade≤脱红带 → 候选 PASS-待考；OOS 日净边际序列 NW(5) t 的 p 值进全波 BH 族；OOS 有效交易日<30 → INSUFFICIENT。
- **多重检验位置（frozen 披露）**：3 标的 × 3 k × 3 vol_pct 桶=27 格全量披露（桶级条件化）；主判只 3 格（IS-best-k 的 OOS）进 12 格族。regime 桶=vol_pct T−1 三桶（0.3200/0.7040）。

## 2. 家底事实（探针在先，probe2）

- 三标的 1min 覆盖如上，bar 09:30..15:00 241 根/日；588200/513330 免印花；300561 ADV 约 7.19 亿元（W3 宇宙C 冻结值）→ Q5 档 2.34bp/边（以考试期 ADV20 实际分档为准）。
- 成本预算（引擎现行，¥250k 名义）：300561 RT≈2+2+4.68+5=13.7bp；588200/513330 RT≈8.7bp；Owner-001 档：300561≈9bp、ETF≈4bp。W3 结论照抄：最优标的清 1.43 倍安全门槛需捕获振幅 14-20%——本件考的是「k 带+动量过滤能否实际捕获到该量级」。
