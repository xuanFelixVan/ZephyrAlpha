## 3. 诚实披露

1. **族内一致性交叉验证**：ATR14 与布林收口（同族 |ρ|=0.935）净 Sharpe 完全相同（1.148）——两条独立实现互相印证，结果可信度高；其毛 Sharpe 1.33/1.39 距门差 ~0.3-0.5，是本池最接近可考的候选，但按冻结门=RED，**不放水**。
2. **稀疏因子构架退化**（同 MID 报告 §3.2）：二进三断板/UTAD 空仓退化；下方缺口不回补/假突破统计的 top 桶为「零事件」小集合（持仓 4.7/12.3 只），非退化但口径局限已如实标注——此类因子的组合层考试需要事件研究构架的新卡。
3. **成本拖累排序**：高换手因子（放量突破 0.69、缺口ATR 0.84、红多绿少 0.39）成本后由正翻负或大幅缩水——引擎现行成本口径下日频 top-10% 调仓的成本带 2-9bp/日，IC IR<0.5 的因子无一是成本对手。
4. 复权暂定/ST 未剔除/涨跌停闸未建模：同 MID 报告 §3.3-3.5。
5. N_eff=6（族聚类，冻结卡 §3）本轮未消费（无卡进 E4）；聚类表留档供后续批次复用。
6. E4 未过的唯一后路=新卡另预注册；本批零代跑、零改卡。
