3. **全状态稳健组**：低波（ATR）、天量/地量、布林收口、连板计数、缺口 ATR 五族在各桶同号且量级接近——"不看状态也活"的候选，组队时可作跨状态底仓因子（仍须走考试）。
4. **risk_off 放大组**：地量（+0.095 vs +0.025）、缩量、UTAD、RS 反转在 risk_off 桶效应 2-4 倍——风险规避期行为金融信号更值钱。
