# 馆员系统骨架挖矿台账 v0.1（三路子代并行，依 skeleton_mining_policy）

> 挖矿对象=馆员六支柱（登记协议/借阅协议/角色制度/强制面/注销退役制/对账制）×四外部维度。批次志：批1=三路并行（登记制生态/记录管理与图书馆学/AI 原生强制面），2026-09-21。

## §1 三路成果

### 路一：登记制生态（register→validate→resolve 协议学）
- **登记协议五要素**（逐要素有业界最佳参照）：①身份=命名权先验绑定（npm scope/MCP 命名空间靠 OIDC/DNS 证明，非口头声明）②出处=SLSA Provenance（构建环境签发，"从哪来"是一等属性）③验证=Backstage processor（schema 校验+关系推导本身即入库门槛）④不可变性=crates.io 永不覆盖+OCI digest 内容寻址（地址即指纹）⑤弃用制=cargo yank/npm deprecate（只断新引用不删历史；真删走 unpublish 窄门：72h+无依赖+低使用）。
- **六权最近似机制**：登记=Backstage catalog-info（**登记文件与资产同 commit**，目录自动摄取）；借阅=HF gated repo（审批+token 才给字节）；变更=DataHub/OpenMetadata 唯一 API 门+owner 必填（旁路直写=违规）；迁移=OCI digest 不变（迁移只换别名，内容寻址天然防漂移）；注销=yank 窄门制；盘点=SLSA 期望策略比对（声明 vs 实际 diff，孤儿自动现形）。

### 路二：记录管理与图书馆学（几百年"万物入册"的制度）
- ISO 15489：记录本体不可改，变更走批注；处置（销毁/移交）**必须预授权且留痕**（=我们的退役逐表批）。
- OAIS 三门：SIP（提交）→Ingest 门→AIP（唯一归档态）→Access 门→DIP（分发）——对外只经分发门。
- FRBR WEMI 四层：作品→表达→表现→载体，多版本记为一族（=同一逻辑资产的多载体挂一族）。
- Dublin Core 15 元素=最小完备字段集；MARC 控制区/描述区分离（机器控制字段 vs 人读描述）。
- **WorldCat 联合目录=真源/副本分离的历史范本**：书目主记录真源唯一，万馆只附 holdings 位置。
- DDC 增枝制：新类目须经 EPC 委员会提案+版次固化（=我们的封顶+停止判据+Owner 批）。
- **"无卡不藏书"三纪律**（可直接抄为馆员执行细节）：①流水登记先于一切动作（未领号实体不进系统）②一书双卡账实互为镜像（书卡在匣=账，借卡在手=实）③定期盘点以**双向差集清零**为准——"架上有书无卡"与"有卡无书"同等级事故（=我们的 blind/ghost 双向，图书馆学直接背书）。

### 路三：AI 原生强制面（怎么让 AI 绕不过）
- **核心判定：只有 git 服务端守卫真正绕不过**——它不活在 AI 会话进程里，改配置/禁 hook/prompt 注入都够不着。Google 公式：client-side 检查只为省时间，server-side 才算数。
- 三层漏斗模型：**宪法=降险层**（提高首过合规率，零强制）→**hook=前置滤网**（PreToolUse 拦 Edit|Write 把违规挡在发生前，但同用户可关，须防 hook 配置本身被改——配置入 git 保护+进程外核实）→**服务端守卫=唯一硬壁收口**。
- 佐证先例：CODEOWNERS 仅在保护分支/ruleset 开启时 server 强制；Terraform state lock/DynamoDB 条件写=单一执行口；agent 护栏共识=prompt 护栏可被注入绕过，确定性 pre-execution 工具钩才是控制面。

## §2 收编结论（对馆员蓝图 v0.1 的验证与修正）

1. **四层强制定位修正**：L1 硬闸=唯一收口（已有，本班实证三次拦自家）；L2 hook=前置滤网（降回滚成本，非强制）；L3 宪法=降险；L4 审计=追责。四层是漏斗不是四面墙。
2. **六流程协议选型**：入馆=同 commit 登记式；借阅=gated+token 式；变更=唯一 API 门；迁移=asset_id 不变仅 home 变（schema 已按此设计，OCI 背书）；注销=默认 deprecate、真删走窄门（与废表逐表批制同构）；盘点=双向差集清零（blind/ghost）。
3. **新收编细节三条**：①MARC 分离→总账字段分"机器控制区（指纹/时戳/状态）"与"人读描述区（ai_contract）"；②WEMI→同一逻辑资产多载体挂一族；③处置预授权→退役须 Owner 预授权（机械判定门背书）。
