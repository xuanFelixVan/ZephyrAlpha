   应用侧扩展到 ETF 轮动（BigQuant）。

   是 v3 实验的最佳载体。

**学术线**：
- arXiv:2205.15056《Model-based RL with RSRS》：RS 特征加速 MBRL 收敛（RL 应用向，非门控向）；
