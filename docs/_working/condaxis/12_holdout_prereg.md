## 1.2 参数（dampen 三件套）

| 参数 | 冻结值 | 选取理由 |
|---|---|---|
| tau（EWMA 平滑窗） | **60** | 扫描 20/30/60 全在净 Sharpe 0.985–1.057（**非孤峰**，参数不敏感）；取 tau60 因换手最低（3.52x，离 8x 门最远，HOLDOUT 上更安全） |
| min_w（剪尾阈值） | **0.001** | 沿用试点值（相对行权和的比例） |
| band（no-trade 缓冲带） | **0.004** | 沿用试点值 |

## 1.3 窗口与判据

- 窗口＝**W_HOLDOUT** `[2025-09-09, 2026-09-08]`（在册定义，禁改）。
- **主判据（协议 C 门，在册）**：**净 Sharpe > 0**。
- **副判据（在册 E7 换手门）**：**换手 ≤ 8x**。
- 同时如实记录：净收益、MaxDD、成交笔数。

## 1.4 口径声明（不可省）

1. 成本口径**沿用引擎现值**（印花 10bp 双边 / 佣金 2.5bp 每边 / 滑点 5bp 每边）——
   比协议费率保守 40–70%，但**本轮不做校准**（校准须作 revertible 实验另行处理，已裁定）。
2. 对比基准＝同窗 **FULL15 基线**（净 Sharpe −1.39，交割册在册值），
   以及本轮 FULL15 在 W_OOS 的净值（0.135）。
3. **W_OOS 的成绩（FACTONLY+tau60 净 Sharpe 1.057）不得作为最终结论**；
   它的唯一用途是"证明机制可用 + 选出待验证参数"。
