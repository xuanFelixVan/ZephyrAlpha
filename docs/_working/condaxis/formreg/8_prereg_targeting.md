# 3. 判据③：ARL 虚报率预算（呈批面，禁自拟；列公式与所需数据）

CUSUM/BOCPD 检测阈值（k/h 与 hazard）正式标定须先钉 ARL 预算（挖矿簿 4 §3.3：
延迟是预算的结果，禁把延迟当自由参数）。**数值待 P2 反推呈批**，公式与数据需求如下：

**公式**（稳态零假设下平均运行长度）：
- 设真拐点年密度 d = N_tp / T_years（N_tp=历史真拐点数，由 P-S 定案段/锚点年表供给；
  T_years=覆盖年数）；
- 设 Owner 可容忍虚报比 r = 虚警数/真警数（**呈批项**，无量纲）；
- 设监测频率 f = 样本数/年（月频=12，日频≈244，周频≈52）；
- 则 **ARL₀ = f / (d·r)**（样本数/虚警）：每年允许虚警=d·r 个 → 两次虚警平均间隔
  f/(d·r) 个样本，即零假设下检测统计量的平均运行长度目标。

**标定动作**（数值冻结后执行）：k=0.5σ 固定起点（仓内先例 correlation_drift_monitor.py:60），
扫 h 使 in-control ARL（bootstrap 零样本模拟或 Siegmund 近似）≈ARL₀；BOCPD hazard
1/250（AM2007 论文示例值）同法以 p_change 阈值版入标定面。

**所需数据**：①P-S 定案段边界（本打靶 §4 产出）；②锚点年表（§1.1）；③Owner 裁 r。
三者齐后出 ARL₀ 数值呈批——本轮缺 ③，**不产数值**。
