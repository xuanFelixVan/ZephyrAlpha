## §1 大白话结论

**这句"条件轴四域全通、端到端回测全绿"现在还不能说。**

打个比方：你要的是四个人（大盘/板块/情绪/资金）一起扛一根梁、一起过体检。实际交上来的是——
两个人（大盘、情绪）上了秤，另外两个人（板块、资金）站在旁边说是"来看看的、不算成绩"；
而且上秤的那个"大盘"，穿的是别人的马甲（F4 代理腿），本战役自己造的两态引擎只在旁边当参照物，
跟秤上那位的一致性只有 15.2%。

所以真实情况是：**机制面（程序跑得通、红蓝攻击拦得住、测试绿）是真的绿；但"四域端到端"这一条不成立。**

## §3 裁定#522（验收口径裁定，本册同批登记）

| 条 | 口径 | 理由 |
|---|---|---|
| ① | **四腿必须全入统计判据**，任一腿标"观察/不计 n/不加载"⇒本轮只可判"机制面通过"，**禁判"X 域端到端通过"** | 判据面缩水即挪门柱（G4-5） |
| ② | **各腿必须用本域本役产出**；用他域代理腿时该腿不计通过，须另立 shadow 并如实报一致率 | 代理腿过线≠本域产出过线 |
| ③ | **判据二值 PASS/FAIL**，预注册册为唯一尺；"条件性通过/基本通过"等自造词一律无效 | 判定词是门柱的一部分 |
| ④ | **禁先用后批**：结果册出具日早于裁定追认日的，该册判读作废，须在裁定后重跑重出 | 本役 03 册（10-13）早于裁定#518（10-14）属此形态 |
| ⑤ | **"落 dev"须 `git merge-base --is-ancestor <commit> dev` 实证**；分支独存、暂存面存在均不算落地 | 本役 sentiment/capital 即栽在此条 |
| ⑥ | **结果册须可复现**：运行器与原始输出至少保留到战役归档完成（可入 `.runtime/` 留档或随册归档），清掉即失去第三方复核能力，该册判读降级为"自述" | 本役 03 册的运行器 `p3_runner.py`/`p3_out2.json` 已随车道清理消失（实测 `.runtime/tmp/` 无此二件），"循环自检两轮零失败"无法复核 |
