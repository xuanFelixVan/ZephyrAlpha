# 三判据机械化环节册（"情绪无真值"的操作化——研究档 §13）

> 第一性认知：**情绪读数没有可核对的真值**，"准"只能在分布上验证（滚动窗重算），不能在单日上验证。三判据=①校准（Brier+校准曲线）②区分度（分档单调性）③事件命中率。全部可机械化。
> 判据看数前冻结纪律（Q4）：本册全部规格随大盘班 P2 同批冻结，**冻结前禁跑数选判据**。

## §2 与既有资产边界

1. **vs HMM 验证框架 B1/B2**：brier_calibration 先例继承（研究档 §13.2 明示）——但 L1 温度计的校准命题是**新命题集**（温度→次日市场面命题），禁直接挪用 L4 明日情绪的命题（对象不同：温度 vs 预测概率）。
2. **vs emotion_linkage_exam（首考）**：首考是"情绪指数→大盘 fwd5 联动"的**单序列三线考**（裁定#489③ v1）——本册区分度判据是其**分档版扩展**，禁重开同一考卷（一问一考纪律：首考管联动存在性，本册管分档单调性，两问不重考）。
3. **vs 挖矿 SOP 闭卷考试总则**：Owner 永久原则"闭卷考试=最终考试；折减抬线不替代考试"（mining_sop 总则）——三判据全部按闭卷窗跑，账面好看的灰度/事件未经闭卷禁用于实盘与候选。
4. **vs P2 冻结面（大盘班）**：Q4 建议同批冻结——本册规格文档只到"候选规格"级，冻结动作在总包 P2 包，禁本线单方定稿（防两班判据漂移）。
5. **vs correlation_sentiment_stratifier**：它是因子层条件相关检验场（D_FACTOR 域），本册"条件有效性"判据**复用其结果面**不重建计算面。

## §3 施工要点（实读代码的坑）

1. **概率含义声明的候选命题清单（呈批用）**——每命题必须可结算（T+1 事实可查）：
   - 温度 close_final 高档（>0.8）≡ P(次日上涨家数占比>50%)≥0.8 —— 结算=kline 上涨家数
   - 温度低档（<0.2）≡ P(次日炸板率>35%)≥0.6 —— 结算=daban
   - 025 灰度 P(冰点)≡ 次日温度读数仍在低档的转移概率（段际转移准确率判据，研究档 §7.1 L2 行）
   - 099 修复概率 0.7x ≡ E1 后 N 日修复频率（事件命中率判据）
   声明落位建议：判据注册册（与 prereg 卡同族）——**禁写进代码注释了事**（散文便签不构成判据证据，mining_sop §7.5 同纪律）。
2. **fwd5_off 标签法复用**：emotion_linkage_exam 的主标签 fwd5_off=close(t+5)/close(t+1)-1（t+1 起 5 日、信号日零重叠）——区分度检验的前向窗沿用同构（t+1 起），禁 t+0 起（v1"同步量无前瞻"缺陷治本先例）。
3. **月度桶<6 的 n/a 纪律**：首考窗内月桶<6→该窗 n/a 判不达不静默跳（ERROR_CONTRACT 在册）——分档版同纪律：某档样本<地板→该档 n/a，禁合并相邻档凑数（与 condition_package 30 日地板同精神）。
4. **Brier 结算的 PIT 陷阱**：结算事实必须取 T+1 收盘后可知数据（上涨家数占比=当日收盘统计）；命题声明里的"明日"锚点=下一**交易日**（非自然日）——节假日坑用交易日历结算。
5. **控制变量的增量检验**：适用域判据=控制（价格动量+波动率）后的残差解释力（研究档 §7.3-2）——实现=对预注册控制面板回归取残差 IC（增量账先例=mining_sop §8.5.2）；**族清单先登记后看数**。
6. **资格灯红灯动作=消费面 fail-closed**：红≠改读数（禁伪造），=消费面自动降权/停用（5_self §2 表）——灯位设计必须与消费方开关同批落地，只立灯不接开关=装饰。
7. **对照面禁升格**：六极端事件对照是**定性审视面**，禁计入判据分母（防"事后选事件"）——一次性脚本产出对照报告即可。

## §4 自审闸三态裁定

**裁定=挂起排期（随 P2 判据冻结同批转施工）**。理由：
- Q4 已建议与大盘班 P2 同批——判据冻结时点本线无权单方提前，**规格设计可先行（本册 §1/§3 已备呈批材料），跑数必等冻结**。
- 主判据成立：三判据机械化=终局全自动裁判的必需件（消灭"人工判断情绪准不准"环节），终局有位、时序绑 P2——标准挂起排期形态（写明解锁条件=P2 冻结批）。
- 概率含义声明（Q11）=**必钉项且呈批即决**，不随跑数等——建议总包 P1 包先批命题清单，批准即冻结声明（看数前冻结的自然时点）。
- 对照面一次性脚本=可立即施工的轻件（挂起排期降级形态，mining_sop §6 三态-2 允许）。
- 封矿面：无——三判据是契约存活的条件（研究档 §13.4"滚动判据红灯还被消费=废物"的兜底），终局必需。
