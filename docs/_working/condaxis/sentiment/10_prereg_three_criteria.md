# 1. 判据①：校准（概率含义兑现）

## 1.1 方法依据（多方）

- Brier (1950)：BS = mean(f − o)²，0=完美、**0.25=恒说 50% 的无信息基准**（多篇气象文献一致，
  含 JCLI3944.1 实测 b_clim≈0.25、QJRMS 海冰预报同口径）。
- **关键修正（多方一致警告，本册采纳）**：0.25 只在事件 base rate=50% 时成立。若事件实际发生率
  仅 10%，恒说 10% 即得分 0.09——**不看 base rate 的 0.25 门槛会误判为有技巧**。
  故本册判据用 **BSS（Brier Skill Score）= 1 − BS / BS_ref**，其中 **BS_ref = p̄(1 − p̄)**，
  p̄＝样本内事件实际发生率（climatology 基准）。BSS > 0 才是"优于恒猜基准率"。
- Murphy (1973) 三分解（BS = REL − RES + UNC）：校准质量另取 **可靠性分量 ECE**
  （分档后 预测概率 vs 实际频率 的加权偏差）。

## 1.2 冻结值

| 项 | 阈值 | 来源 |
|---|---|---|
| **BSS（相对 base rate 基准）** | **≥ 0.05** | 文献分档：0.00–0.05 精英／0.05–0.15 强／0.15–0.25 中等／>0.25 无技巧。BSS>0 仅"不比恒猜差"，须留余量 ⇒ 取"强"档下沿 0.05（保守可辩护，非乐观取值） |
| **ECE（可靠性分量）** | **≤ 0.10** | 校准误差通用容忍上限；仓内 formreg/3_grayscale.md:17 在册三档（<0.10 好／0.10–0.15 警戒／≥0.15 差）取其上沿，且该件 :29 明示"值不抄——轴不同"，故本册只借其**分档语义**不搬其数值绑定对象 |

**样本量下限**：判据①须 ≥ **120** 个观测（低于此 BSS 估计方差过大，不具判读力）。

# 2. 判据②：区分度（分档单调性）

## 2.1 依据

- Grinold & Kahn (1999) / Grinold (1989) 基本定律：IR ≈ IC·√N；IC 分档——
  **0.02 边际（与噪声难分）／0.04–0.06 真实信号／0.08–0.12 强／>0.15 可疑（多为方法 bug）**。
- 国内 Barra 系实践（券商专题／量变学院口径）：**IC 均值 >3% 有效、>5% 优秀**；
  **ICIR ≥0.5 较好、≥1.0 优秀**；**IC 胜率 ≥55% 较好、≥60% 优秀**。

## 2.2 冻结值（**全部沿用仓内在册门柱，不自拟**）

| 项 | 阈值 | 来源（仓内在册） |
|---|---|---|
| \|IC\| | **≥ 0.02** | 裁定#489③ 单序列首考三线；与 Grinold"边际"档一致（取最低可用档，因情绪为**市场级时序信号**，截面因子 IC 天然更高，不可套用 >0.03 截面口径） |
| \|ICIR\| | **≥ 0.3** | 裁定#489③ 同族（低于业界 0.5"较好"档，取仓内在册值以保持判据族一致） |
| 分档单调 \|Spearman\| | **≥ 0.6** | 考试卡判据 `mono_spearman_min` 在册值（A1 考试即以此判定，实测 0.127＜0.6 判 fail） |
| OOS 同号 | **必须同号** | 沿用资金线 `oos_same_sign` 判据（A1 即因 OOS 反号加重判读） |

**口径声明**：情绪是**市场级时间序列**（一个市场一个读数/日），非截面多标的因子——
故 \|IC\| 取时序 IC（情绪读数序列 vs 次日/未来 N 日市场收益序列的相关），
阈值沿用仓内在册 0.02 而非截面口径的 0.03，属**同族取用**不是放松（若日后改截面口径须另立预注册）。

# 3. 判据③：事件命中率

## 3.1 依据

- 随机基准 = 50%（二值事件）；业界 IC 胜率口径：**≥55% 较好、≥60% 优秀**。
- **小样本防护**：命中率点估计会被小样本侥幸抬高 ⇒ 须配区间估计。
  仓内 `sector/8_prereg_validation.md` 已用 **Wilson CI** 为先例 ⇒ 本册沿用同法（非新发明）。

## 3.2 冻结值

| 项 | 阈值 | 来源 |
|---|---|---|
| 命中率点估计 | **≥ 0.60** | 业界"优秀"档下沿（≥55% 较好，取 60% 为可用线） |
| **Wilson 95% CI 下界** | **> 0.50** | 排除"样本小、侥幸过线"；下界 >0.5 才认可"显著优于抛硬币"（Wilson 法沿用板块册先例） |
| 事件样本下限 | **≥ 30 次** | 少于 30 次 Wilson CI 过宽，不具判读力 ⇒ 该事件判"不可判定"而非 PASS |

# 4. 判读规则（裁定#522③ 二值纪律）

1. 三判据**各自独立判 PASS/FAIL**，无"条件性通过／基本通过"等中间态。
2. 样本量不达下限者判 **"不可判定"**（第三态仅用于"数据不足"，不得用于粉饰未过线）。
3. 三判据**全 PASS** 才算情绪腿具备入统计判据资格；任一条 FAIL ⇒ 情绪腿维持观察位，
   **按裁定#522① 不得计入"四域端到端通过"**。
4. 冻结后跑数，**跑数后本轮禁调门柱**（G4-5）：结果不合就如实报 FAIL。
