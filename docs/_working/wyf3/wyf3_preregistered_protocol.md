# WYF-3 预注册协议（防事后拟合）

> 本协议在**任何真实数据参数扫描之前**写死。后续诊断/重校/落地均以本协议为验收真源。

## 1. 数据源与只读纪律

- 表：`market_index_kline` -> `c1_market.kline_index`（TableRegistry 真源解析，禁硬编码表名）。
- 标的：000300 沪深300（市场代理，与生产 overlay 语义一致），2005-01-04~2026-09-15 在库 5272 日。
- 通道：`DatabaseService.get_clickhouse_conn(role="reader")`（readonly=1），**全程禁写库**。
- 衍生序列与生产同款：pct=close.pct_change()，vol_z=`market_features.volume_anomaly(volume, window=20)`。
- 数据加载起点 2009-01-01（warmup：window=60 滚动窗 + vol_z 20 日），warmup 日不参与任何事件统计。

## 2. Walk-forward 窗口划分（先写死）

| 段 | 区间 | 角色 |
|----|------|------|
| warmup | 2009-01-01 ~ 2009-12-31 | 滚动窗预热，不计事件 |

铁律：验证段数据在选值冻结前不得用于任何参数决策；全样本（校准+验证）统计只在最终复验报告出现。

## 3. 预注册验收标准（先写死，后跑数）

### 3.1 检出力（校准段，约 3170 交易日；事件日数按 flag=1 计）

| 阶段 | 下限 | 上限 | 依据 |
|------|------|------|------|
| SC | 10 | 100 | 13 年约 8~12 个显著抛售高潮区 × 1~8 日聚集 |
| AR | 10 | 150 | 每个 SC 区 1~3 日反弹确认 |
| ST | 10 | 250 | 回踩可多次发生（每区 2~10 日） |
| Spring | 3 | 80 | 吸筹区假摔 1~2 日/次，理论关键转折 |
| Test | 3 | 80 | Spring 后突破确认 |
| score>=60 | 首齐活不早于校准段第 120 交易日 | 占比 <= 85% | cummax 粘滞语义下占比=1-首齐活位置/段长；上限防"开局即齐活"退化 |

超上限=阈值松到把日常波动当阶段事件（误报爆炸）；低于下限=仍过紧（重校失败）。

### 3.2 精度/方向性约束（防"检出力达标但全是垃圾信号"）

1. SC 事件（间隔<=5 日的连续触发合并为 1 个事件）聚集数 ∈ [4, 20]。
2. SC 日 pct 中位数 <= -2.5%（抛售高潮方向性）。
3. AR 日 pct 中位数 >= +0.3%（反弹方向性）。
4. 结构一致性（实现正确性验证，须 100% 成立）：每个 AR 事件日距前一 SC 日 <= ar_window；
   ST 事件日距最近 SC 日 <= st 窗；Test 事件日距前一 Spring 日 <= test 窗。
5. Spring 事件聚集数 ∈ [1, 30]。

### 3.3 样本外验收（验证段，约 880 交易日）

- SC >= 2、AR >= 2、ST >= 2 日；Spring/Test >= 0（有则记录，无则降级接受并如实登记——
  880 日内理论关键转折可能缺席）。
- score>=60 占比 <= 85%。
- 样本外任何阶段较校准段**同参数占比**塌缩为 0 → 如实报告，不追加调参（诚实条款）。

## 5. 机械选值准则（先写死，防挑数）

1. 分层贪心：SC -> AR -> ST -> Spring -> Test（上游定，下游条件层叠扫）。
2. 每层候选=满足该层及全局全部约束的网格点；在候选中取**触发数落在验收带内**者，
   有多个则取带内**中位数最接近者**；并列取与现值偏差最小者（最小改动原则）。
3. 无任何网格点满足约束 -> 该阶段保持现值并登记"重校失败"（合法终态，禁凑数）。
4. 选值冻结（写入对照表）后才允许触碰验证段。
