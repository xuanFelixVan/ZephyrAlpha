## §G 全局设计语言讨论与裁定（2026-08-25，Owner 提四件+一拍板）

> 性质：跨 28 页的全局框架与个股大页设计，非单页审查项；Owner 提出→讨论→拍板→施工。本节为唯一事实源。

### G-一、底部快速浏览横条（同花顺式 ticker）——裁定：做（框架批）

- **形态**：固定底栏不随滚动消失；默认清单=上证/深成/创业板/科创综指+SPX（昨收）/NDX（昨收）/HSI；每项=名称+编号+现价+涨跌幅（红涨绿跌）
- **自定义**：右下「＋」图标→全项进入编辑态（每项尾部出「−」点击移除）+搜索框（搜股票/指数，结果尾部「＋」点击加入）；自定义清单 localStorage 记忆
- **交互**：非编辑态**双击**某项→跳转（指数→技术分析页对应该指数；个股→个股二级页 G-四）；右下**秒级时钟**（hh:mm:ss JS Date）；时钟旁**折叠按钮**→横条收缩只剩时间，再点弹出
- **数据**：演示源+「演示数据」badge；股指期货/纳指期货 CFD 可加入清单但**库内无数据**（futures_term_structure 未排期）→标「待接入」负反馈不造假；真实行情 I-2

### G-二、欧意（OKX）配色皮肤——裁定：做，**皮肤照抄、涨跌语义保留红涨绿跌**（Owner 拍板）

### G-四、个股二级页面（欧意式 K 线工作台）——裁定：做，**A 骨架先行 / B 画线 P2 / C 学习管道 I-2·CAND**（Owner 拍板）

**四.A（P1，纯前端演示结构，框架批后第一批）**

## §C 币圈量化扩展讨论与裁定（2026-08-25，Owner 提域扩展）

> 性质：charter 级新域扩展的**设计层预案**——原型可先行设计页面，后端落地（采集/执行/风控）属 I-2/CAND 评审，本节如实登记边界。

### C-1 结论：必须隔离，且不是"加一个页面"而是"加第 6 组「币圈」+ 镜像复用"

**规则差异根本性**（混入即噪音场）：A 股=盘前竞价/盘中/盘后复盘日频节律、涨跌停（打板/梯队生态）、T+1、只能做多、北向/两融/板块资金流；币圈=**24/7 连续**（无开收盘/无竞价/无复盘）、**无涨跌停**（打板/情绪周期/连板全部失效）、**T+0**、**永续合约多空双向+杠杆**（强平价/保证金/资金费率=核心风险）、核心数据=资金费率/OI/多空比/爆仓地图/标记价格、通道=交易所 API（OKX 公开行情免费，交易需 API key）。

### C-2 架构裁定（Owner 2026-08-25 拍板）

```

  币圈盘面      24/7 行情 ticker + 资金费率热力 + OI 曲线 + 多空比 + 爆仓地图 + 标记/指数价差
```

- **数据源**：OKX 公开 REST/WS API（行情免费无需 key——I-2；本环境直连被断但 Owner 本机浏览器可达=有通道，可达性待实测）；**交易=OKX API key（human_gated 同级，Owner 自持 key 不进代码）**
