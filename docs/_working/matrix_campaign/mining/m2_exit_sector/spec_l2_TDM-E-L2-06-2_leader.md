# 规格卡 L2-06b | 龙头识别定位（TDM-E-L2-06-2）

- 车道: M2 离场族+板块族接线挖矿 | 2026-10-06
- 接法分级: **L（登记为主）+ M 降级代理档（可选）**
- 真源: `config/trading_decision_map.yaml#TDM-E-L2-06-2`（四定位+封单不稳降级+invalidation
  回测代理=tick 买一档量 DS-195，外审 m-45）

## 1. 机制定义与可考性切分

四定位：板块强度榜第一+最先涨停=龙头；跟涨大盘股=中军；后涨小票=跟风；不上不下=中位股。
定位决定持股预期与止损宽度（龙头宽/跟风窄）。invalidation："封单不稳/率先掉队→定位实时降级"，
其回测代理 TDM 已自注=tick 买一档量（DS-195）——**tick 语义，日级不可表达**（负结果 #7）。

## 2. 日级代理档（M 降级，非全语义）

```
first_limit_up[k,t] = 板块 k 内当日封板（sealed_up）且今期为板块内 20 日窗口首个封板日的标的
leader[k]           = argmax_i( 个股 20 日动量 · 板块内 rank ) 且当日 sealed_up
middle/runner       = 板块内动量分位 30-70%=中位（禁区）/ <30%=跟风
stop_width[k]       = 龙头 1.2×基准止损宽 / 跟风 0.8×（宽度系数进 prereg）
```

"率先"的日级投影=封板先后在同日不可分辨→退化为"板块内唯一封板"或"封板家数=1 的当日唯一者"，
家数>1 时本档弃权（宁缺勿假）。

## 3. 接法

代理档并入 L2-06 传导卡（龙头定位只影响止损宽度档=喂 X-S1-02 stop_width 参数，不改排名）；
"封单不稳实时降级"不实现（负结果 #7）。原 TDM 全语义（盘中四定位+降级）归 tick 考卷/T3c
范围，本车道只登记。
