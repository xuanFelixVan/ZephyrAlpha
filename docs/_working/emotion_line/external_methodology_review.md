# 市场情绪指数构建实践——外部方法论挖矿文册

> 目标：为 A 股 0-1 灰度分位日频 emotion_index 收集外部构建实践。指数定位是**独立状态变量**
> （场内温度：冰点→沸点），不是择时信号本身，因此本册侧重成分口径、合成方法与发布纪律，
> 领先性检验单列一节。

## §1 成分选择实践

### 1.1 A 股场内微观结构成分（短线情绪温度计）

各家实践（券商金工、集思录、韭圈儿、乐咕乐股、同花顺/东财）在 A 股上收敛出一组高共识成分
[9][10][11][12][13]，口径如下：

| 成分 | 定义/公式 | 情绪含义 |
|---|---|---|
| 涨停家数 | `N_limitup(t) = #{i: close_i(t) == limit_price_i(t)}` | 赚钱效应广度，情绪最直接的计数器 |
| 连板高度 | `H(t) = max{连续涨停天数_i(t)}` | 空间高度，代表资金攻击意愿的天花板 |
| 炸板率 | `R_zha(t) = N_zha(t) / N_touch(t)`，N_touch=盘中触及涨停家数 | 封板资金分歧度，越高越弱 |
| 晋级率 | `R_promo(k,t) = N_{k+1板}(t) / N_{k板}(t-1)`；常用 2 板晋级率=今日二连板数/昨日涨停数 | 连板梯队的"接力成功率"，情绪周期核心变量 |
| 昨日涨停表现 | `X_lu(t) = mean(r_i(t) : i∈昨日涨停)`（涨停溢价） | 打板资金的隔日盈亏，乐咕"昨日涨停指数"即此类[13] |
| 成交额分位 | `P_amt(t) = PercentileRank(amt(t); 滚动 W 日)` | 增量/存量资金温度 |
| 换手率分位 | `P_turn(t) = PercentileRank(turn(t); W)` | 交易拥挤度 |
| 涨跌家数比 | `R_ad(t) = N_up(t) / N_down(t)` 或其 5 日均值 | 广度，修正单一指数失真 |
| 两融占比 | `margin_ratio(t) = 两融买入额(t) / A股成交额(t)` | 杠杆资金参与度 |
| 龙头封板/炸板 | 全市场最高板个股当日的封板成败与封单金额 | "龙头不死，情绪不灭"的经验量化 |

实践要点：
- 浦银国际指数采用 **14 个成分指标**构建 A 股情绪指数（成交量/换手率/RSI 等），覆盖场内与
  资金面指标，按冰点/过热分档用于短线判断[11]；中信建投从理性/非理性博弈框架出发合成情绪
  指标并用于择时，极端情绪预示反转[12]。
- 集思录"A股全市场温度计"是**估值类温度**而非交易情绪：取全市场 PB/PE 中位数（剔停牌、
  次新、ST）在自身历史序列的百分位作 0-100 温度（1995 年起），与交易情绪类成分互补[9]
  （本班直读复核属实）。韭圈儿恐贪指数为 0-100 综合分，参考 CNN 恐贪框架做 A 股化改造[10]。
  乐咕乐股提供涨停板情绪、市场温度计、昨日涨停指数等栏目[13]。

### 1.2 美股经典成分

- **AAII 散户调查**[4]：每周问卷统计未来 6 个月看多/中性/看空比例，常用多空差
  `BullBearSpread = %Bulls − %Bears`。反映**散户主观仓位意愿**，散户极端乐观时反向。
  自 1987 年起，多头均值约 38%、空头约 31%。
- **Investors Intelligence 投顾多空比**[7]：自 1963 年起每周统计投资通讯作者的看多/看空/
  预期修正百分比。反映**专业意见追随度**，作为反向指标（极度多头=顶部信号）。
- **CBOE Put/Call Ratio**[5]：`PCR = Put成交量 / Call成交量`，分全市场/指数/股票三个口径。
  股票 PCR 升高=交易型资金买保护=情绪转谨慎；指数 PCR 因含大量对冲盘，解释方向与股票 PCR
  相反，须分开建模。
- **VIX**[6]：S&P500 期权隐含的 30 天波动率，"恐慌指数"，反映**定价的恐惧水平**；实践常配
  VIX 期限结构（贴水/升水）区分恐慌与贪婪。
- **NYSE 短仓 interest**：空头占总流通盘比例，空头拥挤=潜在的逼空燃料，同时是知情看空押注，
  须与事件驱动区分。
- **创新高新低家数**：`NH−NL = 52周新高数 − 52周新低数`，CNN 恐贪指数七大成分之一[3]
  （本班直读复核：七成分/等权/0-100 属实）。
- **Baker-Wurgler 六成分**[1][2]：IPO 数量、IPO 首日收益、股权融资占比（equity share in new
  issues）、NYSE 换手率、红利溢价（paying vs non-paying 股的 D/P 差）、封闭式基金折价。
  每个的"为什么"：IPO 数量与首日收益高=发行窗口对乐观情绪的供给响应；股权融资占比高=
  公司择时在情绪高点发股票；换手率高=投机交易活跃；红利溢价低=投资者偏爱"讲故事"不分红股
  （情绪高）；封闭式基金折价窄=散户情绪好。共同点：对**套利难、估值难**的股票（小盘、年轻、
  高波动、不盈利、极端成长）影响最大（BW 原文题名/作者/期刊经本班直读复核属实[1]）。

### 1.3 新闻/文本情绪

- **词典法**：`Senti(d) = (n_pos(d) − n_neg(d)) / (n_pos(d)+n_neg(d))`，日度聚合
  `SENT(t) = mean_d Senti(d)`（或中位数+正面覆盖度两维）。优点可复现、可回溯；缺点 finance
  词典（L&M/知网 HowNet 中文金融词典）更新滞后，对"利好出尽"、反讽失真。
- **LLM 打分法**：对新闻标题/正文按 prompt 输出 −1/0/+1 或 0-100 打分，日度取均值与 breadth
  （正面占比）双指标；优点语义理解强、可输出事件类型；缺点成本、时序漂移（模型版本变更即
  口径变更）、须冻结版本与存档 prompt。实践建议：词典法做长回测基线，LLM 法做增量，两者
  相关性监控。（对应仓内现状：news_sentiment_window 当前全 rule 词典法，LLM 分支待接入——
  见内部盘点册 §4。）

## §2 加权与合成方案

设成分去极值（±3σ 或 1%/99% 分位）并统一方向（情绪越高值越大）后记为 `x_{i,t}`。

1. **等权 z-score**：`z_{i,t} = (x_{i,t} − μ_i) / σ_i`，`EI_t = (1/N) Σ_i z_{i,t}`。μ、σ 用
   滚动 W 日（W=1000~1500 约 4-6 年）保证分位可比。简单稳健，是默认起步方案。
2. **分位数合成（rank percentile）**：`p_{i,t} = RankPercentile(x_{i,t}; W)`，`EI_t =
   median_i(p_{i,t})` 或均值。输出天然落 0-1，契合灰度分位目标；对离群值完全不敏感；缺点
   丢失幅度信息（涨 3 倍和 1.5 倍同分）。
3. **IC 加权**：`IC_i = corr(x_{i,t}, r_{t+1})`（或 Spearman RankIC），
   `w_i = max(IC̄_i, 0) / Σ_j max(IC̄_j, 0)`，`EI_t = Σ_i w_i · p_{i,t}`。用成分对**未来收益**
   的预测力配权，样本外通常优于等权；缺点 IC 估计噪声大、权重时变引入过拟合面，建议半年
   滚动、IC 不足 1.96 倍标准误的成分降权为等权。
4. **PCA 第一主成分**：对标准化成分矩阵 `Z` 求 `F_1 = Z·v_1`。Baker-Wurgler 原文做法[1][2]：
   第一主成分不可直接观测对齐，故将其作为解释变量对 6 个代理逐个回归取拟合值，再平均成
   复合指数（顺/逆极性按符号对齐）；载荷本身就是"哪类股票对情绪敏感"的横截面证据。后续
   改进：两步 PCA——先按经济簇（一级发行类/交易类/折价类）分簇提主成分，再对簇主成分二次
   提取，缓解单一 PC1 被高相关簇绑架；或按载荷符号与稳定性筛选成分后重提。
5. **方案对比**：等权 z（透明、参数少，推荐基线）｜rank 分位（天然 0-1、抗噪，推荐目标
   方案）｜IC 加权（预测力导向、需防过拟合）｜PCA（学术正统、自动去共线，但 PC1 可能只反映
   "成交额+换手"单一拥挤维度，解释成本高）。适用条件：成分间相关性普遍 >0.6 时 PCA 收益
   有限，等权已接近最优组合。（骨架设计稿 §3 采 rank 分位合成与该结论一致。）

## §3 频率与更新时点

- **日频 vs 周频**：A 股短线情绪成分（涨停/连板/炸板）半衰期 1-3 天，周频会抹平情绪周期
  拐点；日频噪声用成分自身 3 日平滑（`EI_t^smooth = (EI_t+EI_{t-1}+EI_{t-2})/3`）处理。
  结论：**日频计算 + 可选 3 日平滑输出**。
- **盘中滚动 vs 收盘定格**：盘中滚动（实时涨停/炸板数每 5 分钟重算）适合盘中风控展示，但与
  回测口径漂移；生产指数**收盘定格**（15:00 后落库数据为准），盘中值只作诊断字段不落正式
  序列。（骨架稿 §4 stage 设计与此一致：close_final 为真源定格态。）
- **盘前时点**：盘前发布版用 T-1 收盘态（含 T-1 两融），竞价后（9:25）可追加"竞价修正字段"
  （如竞价涨停家数），但不回改 T-1 的正式指数值。
- **滞后成分对齐（两融 T+1 公布）**：原则是 **point-in-time**——每个成分使用"在该时点已知"
  的最新值：`x̃_{i,t} = x_{i, t−lag_i}`，两融余额 lag=1（按可得时点定）。严禁把 T 日两融余额
  填到 T 日指数（前视）。备选：差值外推补齐+发布纪律标注"含外推"。新闻/文本情绪注意**发布
  时间戳**：只用发布时间 ≤ 当日 15:00 的文章计当日分。（骨架稿 C5 的 as-of 对齐同此原则。）

## §4 领先性检验方法

对指数 `EI_t` 与大盘未来收益 `r_{t→t+k}`（k=1,3,5,10）：

1. **IC/RankIC**：`IC(k) = corr(EI_t, r_{t→t+k})`；稳健用 Spearman。报告 `mean(IC)`、
   `ICIR = mean(IC)/std(IC)`、`t = mean(IC)·√T / std(IC)`，|t|>2 视为显著。情绪指数常见形态
   是**尾部反向**（极高→未来负、极低→未来正）而中间段无方向，线性 IC 可能≈0，必须配合分组。
2. **分位分组多空**：按 EI 五分位分 5 组，统计各组**次日**期望收益与胜率，检验 Q1（冰点）−
   Q5（沸点）价差 `L = mean(r|Q1) − mean(r|Q5)` 的显著性（Newey-West 调整）。这是情绪指数的
   标准"温度→收益"映射证据。
3. **Granger 因果**：VAR 中检验 `H0: EI 滞后项对 r 无解释力`，F 检验；注意 Granger 是预测
   因果非经济因果，样本期须分牛市/熊市子样本。
4. **事件研究**：定义极端情绪日 `EI_t ∈ [0, 0.05] ∪ [0.95, 1]`（灰度分位），统计事件后
   1/3/5/10 日条件收益分布 vs 全样本无条件分布，bootstrap 置换检验。冰点日后反弹、沸点日后
   回撤的条件收益差是最直观的汇报证据。
5. **领先滞后互相关**：`ccf(k) = corr(EI_t, r_{t+k})`，k∈[−10,10]，峰值应在 k≥0 处且不对称
   （领先不对称）；若 k<0 处也有强峰说明指数只是价格的滞后映射（自我实现），须剔除价格镜像
   成分（如"昨日涨停表现"天然含 r_t）。

**常见坑**：① 前视偏差——成分用当日收盘后才知道的字段（两融、龙虎榜）；② 滞后错配——把
T+1 公布成分当作 T 日已知，IC 虚高；③ 样本内过拟合——成分筛选/窗口/权重全在同一段样本调参，
必须留出样本外段；④ regime 依赖——单边牛市中情绪指数对指数择时失效（沸点钝化），须报告分
regime 分组收益；⑤ 指数自身是价格的确定性函数（成交额分位、涨跌家数比都含 r_t），与动量
高度共线，检验时须控制动量。

（考试卡草案已吸收：卡A 两尾检验+五分位分组+Granger 前向；"尾部反向"形态=卡A 方向不预设
的依据。）

## §5 对标锚点清单（14 条）

1. **Baker & Wurgler (2007), "Investor Sentiment in the Stock Market", JEP**——情绪的定义
   （无事实支撑的信念）与"自上而下测量"纲领；汇总式指数+横截面敏感度证据，方法论总纲。全文免费。
2. **Baker & Wurgler (NBER w10449, 2004)**——《Investor Sentiment and the Cross-Section of
   Stock Returns》工作论文页：六代理情绪指数+主成分合成的原始出处。
3. **CNN Fear & Greed Index 官方页**——0-100 恐贪刻度的工业标准：七成分（动量/股价强度/
   广度/Put-Call/VIX/避险需求/垃圾债需求）**等权**，每成分各自标准化到 0-100 后取均值；
   实用主义合成的范本。
4. **AAII Sentiment Survey 官方页**——1987 年至今的周度散户多空中性百分比调查，多空差是
   最常用的调查类情绪序列；"调查类成分"标准化发布纪律的样例。
5. **CBOE 美国期权每日市场统计**——总/指数/股票/VIX 各口径 Put-Call Ratio 与成交量、
   未平仓的官方日度来源，附历史数据下载入口。
6. **CBOE VIX 官方页**——VIX 定义（S&P500 期权隐含 30 天波动率）、方法论文档与历史数据入口。
7. **Investors Intelligence**——1963 年至今的投资顾问多空比（多头/空头/修正三口径），调查类
   反向指标的长寿样本。
8. **Yale Stock Market Confidence Indices (Shiller)**——1984 年起的问卷信心指数族（崩盘信心、
   估值信心等），美国/中国/日本版本；"问卷型成分"与行为学锚定的范本。
9. **集思录 A 股全市场温度计**——全市场 PB/PE 中位数历史百分位作 0-100 温度（剔停牌/次新/
   ST，1995 年起），宽基可切换；分位数合成的中文实践样例。
10. **韭圈儿（jiucaishuo）**——恐贪指数 0-100 综合分的国内基金社区实践（App 内查看），CNN
    恐贪框架的 A 股化改造（股债性价比等成分）。
11. **浦银国际《A股市场情绪指数构建和运用（上）》**（2024-01-11，spdbi.com 研报栏目）——14
    个成分指标构建 A 股情绪指数并回测用于短线判断，公开度最高的 A 股情绪指数构建系列研报
    （上/下两篇）。[搜索确认]
12. **中信建投《A股和港股投资者情绪的量化与择时应用》**（王程畅，2025-09，新浪财经转载）——
    噪声交易者博弈框架下量化情绪并做 A/港择时，极端情绪预示反转。[搜索确认]
13. **乐咕乐股**——涨停板情绪、市场温度计、昨日涨停指数等 A 股情绪数据栏目聚合站；"昨日
    涨停指数"是涨停溢价成分的现成参照。[搜索确认]
