## 一、计数规则（先把尺说死，否则任何"总数"都没意义）

1. **条目＝一行表行**，且该行**第一格**（去 `*` 强调符后）以 `W-` 开头。只认 `### 族 N ·` 小节作用域内的表行；`##` 起头即关闭作用域（所以 §三/§五/§六 的散文与对账表不计入，防把"引用位"当"编目位"）。
2. **范围格展开**：`W-142..W-151` → 142,143,…,151 共 **10** 个条目（一行 ≠ 一项）。
3. **并列格展开**：`W-159/W-160` → **2** 个条目。
4. **去重后取并集**＝该族条目数；全族并集＝环节全集。
5. **状态口径**取 00 册 L13 自定图例：`✅`=已在 HEAD 且符号实测在册｜`🔨`=成品存在但未进 HEAD｜`⬜`=未开工可直接开｜`🌑`=卡 Owner 门位或外部前置。"可开工"严格读法＝⬜＋🔨（＋【快】），**不含 🌑、不含 ✅**。
6. 本册**不采信任何散文里的自报数**（如"含红队补 23 个"），只用 1–5 重算后再与散文对表。

**复跑命令（原文，本道实跑）**：

```bash
python - <<'PY'          # 作用域=### 族 N，第一格 W- 行，范围与并列展开，去重
import re,collections
lines=open('00_master_skeleton.md',encoding='utf-8').read().splitlines()
fam=None; items=collections.defaultdict(list)
for l in lines:
    m=re.match(r'^### (族\s*\d+)\s*·',l)
    if m: fam=re.sub(r'\s+',' ',m.group(1)); continue
    if re.match(r'^## ',l): fam=None; continue
    if not fam or not l.strip().startswith('|'): continue
    c1=re.sub(r'\*','',l.strip().strip('|').split('|')[0]).strip()
    if not c1.upper().startswith('W-'): continue
    ex=sorted(set(int(x) for x in re.findall(r'W-(\d+)',c1)))
    for mm in re.finditer(r'W-(\d+)\.\.W-(\d+)',c1):
        ex=sorted(set(list(range(int(mm.group(1)),int(mm.group(2))+1))+ex))
    items[fam]+=ex
tot=sorted(set(sum(items.values(),[])))
print(len(items),len(tot),tot[0],tot[-1])
PY
```
