## 📋 执行摘要







### 核心定位







操作风险管理系统是清风量化系统的**操作风险追踪器**，负责：



- 操作风险事件追踪（操作风险事件记录、分类、分析）



- 损失分布分析（损失分布统计、趋势分析）



- 操作风险预警（操作风险预警机制、预警响应）



- 操作风险报告（操作风险报告生成、报告展示）

## 三、数据流设计







### 3.1 主数据流







```



操作风险事件 → 事件采集 → 事件分类 → 事件评估 → 损失分析 → 风险预警 → 报告生成



     ↓            ↓          ↓          ↓          ↓          ↓          ↓



  事件发生     事件记录    类型分类    影响评估    损失统计    规则检查    日报生成



  事件识别     事件存储    等级分类    频率评估    趋势分析    预警触发    周报生成



  事件报告     事件归档    风险分类    风险评估    分布拟合    预警通知    月报生成



```

## 四、技术选型







### 4.1 技术栈选择







| 组件 | 技术选择 | 理由 |



|------|---------|------|



| **事件存储** | SQLite | 轻量级，个人使用足够 |



| **损失分析** | pandas + scipy | Python生态标准 |



| **分布拟合** | scipy.stats | 专业统计库 |



| **可视化** | Plotly + Grafana | 已有蓝图，易于集成 |



| **预警通知** | 邮件 + Webhook | 简单可靠 |







### 4.2 自研方案
