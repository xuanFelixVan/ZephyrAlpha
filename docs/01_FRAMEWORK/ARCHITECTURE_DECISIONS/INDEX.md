## 🔍 架构决策记录说明

### 什么是ADR？

架构决策记录（Architecture Decision Record，ADR）是一种记录重要架构决策的方法，每个ADR包含：

1. **标题**: 决策的简短描述
2. **状态**: 提议、已接受、已废弃、已替代
3. **背景**: 决策的背景和动机
4. **决策**: 具体的决策内容
5. **后果**: 决策带来的影响

### ADR模板

```markdown
# ADR-NNNN: 决策标题

## 状态

[提议 | 已接受 | 已废弃 | 已替代]

## 背景

描述决策的背景和动机...

## 决策

描述具体的决策内容...

## 后果

描述决策带来的影响...
```
