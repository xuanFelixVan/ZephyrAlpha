## 6. 使用指南

### 6.1 如何创建ADR

1. 确定决策类型（SYS/TECH/MOD/API/DATA/DEPLOY）
2. 分配编号：ADR-{TYPE}-{SEQ}
3. 复制[ADR模板](../../09_AUDIT/TEMPLATES/ADR_TEMPLATE.md)
4. 填写内容并保存到本目录
5. 更新本索引文件

### 6.2 如何更新索引

**新增ADR时**:
1. 在对应类型列表中添加条目
2. 更新统计数据
3. 更新最近更新列表

**更新ADR时**:
1. 更新对应条目的状态
2. 更新最后更新日期
3. 更新统计数据

## 7. ADR编号规则

### 7.1 编号格式

```
ADR-{TYPE}-{SEQ}
```

**说明**:
- **ADR**: Architecture Decision Record（架构决策记录）
- **TYPE**: 决策类型（SYS/TECH/MOD/API/DATA/DEPLOY）
- **SEQ**: 序号（001-999）

### 7.2 编号示例

- ADR-SYS-001: 系统架构决策记录
- ADR-TECH-001: 技术选型决策记录
- ADR-MOD-001: 模块设计决策记录
