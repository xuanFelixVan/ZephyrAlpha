## 1. 概述

### 1.1 设计背景

安全多方计算(MPC)是跨机构合作的核心隐私保护技术：

- **隐私保护**: 数据不出本地，保护商业机密
- **联合建模**: 多机构联合训练模型
- **合规要求**: 满足数据隐私法规
- **信任最小化**: 无需完全信任对方

### 1.2 业务价值

| 价值维度 | 具体收益 |
|----------|----------|
| **隐私** | 数据零泄露风险 |
| **合规** | 满足GDPR/数据安全法 |
| **协作** | 支持跨机构合作 |
| **信任** | 无需第三方信任 |
