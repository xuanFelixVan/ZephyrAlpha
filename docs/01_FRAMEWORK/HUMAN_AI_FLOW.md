## 2. 人的4个核心职责

| 职责 | 说明 | 参与度 |
|------|------|--------|
| 策略方向决策 | 什么时候用什么策略 | 高 (AI推荐，人确认) |

| 最终授权 | 确认AI的建议 | 极高 (人最终拍板) |

## 4. 双轨决策机制

### 4.1 量化系统 vs AI分析师

| 系统 | 作用 | 决策权 |
|------|------|--------|
| **量化系统** (Layer 1-6) | 执行稳定的、可回测的策略 | 系统自主执行 |
| **AI分析师** (辅助) | 提供AI视角分析 | 仅供参考 |

### 4.2 AI分析师放置位置

| 层级 | AI功能 | 具体任务 |
|------|--------|---------|
| **Layer 3** | 舆情解读 | 分析新闻情感、判断市场情绪 |
| **Layer 5** | 交易审核 | 下单前异常检测、风险提示 |
| **Layer 7** | 报告生成 | 生成每日分析，投资建议 |
| **Layer 8** | 多空辩论 | 辅助人工最终决策 |

### 4.3 双轨决策流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    双轨决策机制                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  量化系统 (Layer 1-6):                                         │
│  ├── 严格执行策略                                               │
│  ├── 自动执行交易                                               │
│  └── 不受情绪影响                                               │
│                           +                                      │
│  AI分析师 (辅助):                                                │
│  ├── Layer 3: 舆情解读                                           │
│  ├── Layer 5: 交易审核                                           │
│  ├── Layer 7: 报告生成                                           │
│  └── Layer 8: 多空辩论 ──────────────────────────────────────→ 人 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
