## 1. 数据流图

```

│                        系统主数据流图                            │
└─────────────────────────────────────────────────────────────────┘

外部数据源                系统处理                  数据存储
    │                        │                        │
    ├─→ 行情数据 ──────────→ 数据服务 ──────────→ 时序数据库
    │                        │                        │
    ├─→ 财务数据 ──────────→ 数据服务 ──────────→ 关系数据库
    │                        │                        │
    │                        ↓                        │
    │                   因子引擎                      │
    │                        │                        │
    │                        ├─→ 因子数据 ─────────→ 时序数据库
    │                        │                        │
    │                        ↓                        │
    │                   策略引擎                      │
    │                        │                        │
    │                        ├─→ 交易信号 ─────────→ 消息队列
    │                        │                        │
    │                        ↓                        │
    │                   组合引擎                      │
    │                        │                        │
    │                        ├─→ 组合权重 ─────────→ 关系数据库
    │                        │                        │
    │                        ↓                        │
    │                   风控引擎                      │
    │                        │                        │
    │                        ├─→ 风险报告 ─────────→ 文件存储
    │                        │                        │
    │                        ↓                        │
    │                   交易服务                      │
    │                        │                        │
    │                        ├─→ 订单数据 ─────────→ 关系数据库
    │                        │                        │
    └─→ 交易接口 ←──────────┘                        │
                             │                        │
                             └─→ 成交数据 ─────────→ 关系数据库
```
