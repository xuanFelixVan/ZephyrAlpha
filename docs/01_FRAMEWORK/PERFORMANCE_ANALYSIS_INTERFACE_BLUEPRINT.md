- 风险分析

## 二、核心组件详细设计

### 2.1 性能概览区

#### 2.1.1 核心指标

| 指标名称 | 计算方式 | 展示方式 | 更新频率 |
|---------|---------|---------|---------|
| **累计收益率** | (期末净值-1) × 100% | 百分比卡片 | 实时 |
| **年化收益率** | (1+累计收益)^(252/n) - 1 | 百分比卡片 | 每日 |
| **最大回撤** | max(peak-trough)/peak | 百分比卡片 | 实时 |
| **Sharpe比率** | (年化收益-无风险利率)/年化波动率 | 数值卡片 | 每日 |
| **胜率** | 盈利交易数/总交易数 | 百分比卡片 | 实时 |

#### 2.1.2 扩展指标

| 指标名称 | 计算方式 | 展示方式 | 更新频率 |
|---------|---------|---------|---------|
| **Calmar比率** | 年化收益/最大回撤 | 数值卡片 | 每日 |
| **Sortino比率** | (年化收益-无风险利率)/下行波动率 | 数值卡片 | 每日 |
| **信息比率** | 超额收益/跟踪误差 | 数值卡片 | 每日 |
| **Beta** | Cov(r_p, r_m)/Var(r_m) | 数值卡片 | 每日 |
| **Alpha** | 年化收益 - Beta × 基准收益 | 数值卡片 | 每日 |

### 3.3 核心代码示例

```python
import streamlit as st
import plotly.graph_objects as go
from empyrical import (
    cum_returns, 
    annual_return, 
    max_drawdown,
    sharpe_ratio,
    sortino_ratio,
    calmar_ratio
)

class PerformanceAnalysisInterface:
    """性能分析界面"""
    
    def __init__(self, returns, benchmark_returns=None):
        self.returns = returns
        self.benchmark_returns = benchmark_returns
    
    def render_overview(self):
        """渲染性能概览"""
        col1, col2, col3, col4, col5 = st.columns(5)
        
        with col1:
            cum_ret = (1 + self.returns).prod() - 1
            st.metric("累计收益", f"{cum_ret:.2%}")
        
        with col2:
            ann_ret = annual_return(self.returns)
            st.metric("年化收益", f"{ann_ret:.2%}")
        
        with col3:
            max_dd = max_drawdown(self.returns)
            st.metric("最大回撤", f"{max_dd:.2%}")
        
        with col4:
            sharpe = sharpe_ratio(self.returns)
            st.metric("Sharpe比率", f"{sharpe:.2f}")
        
        with col5:
            sortino = sortino_ratio(self.returns)
            st.metric("Sortino比率", f"{sortino:.2f}")
    
    def render_equity_curve(self):
        """渲染净值曲线"""
        cum_ret = cum_returns(self.returns)
        
        fig = go.Figure()
        fig.add_trace(go.Scatter(
            x=cum_ret.index,
            y=cum_ret.values,
            name='策略净值',
            line=dict(color='#2E86AB', width=2)
        ))
        
        if self.benchmark_returns is not None:
            bench_cum = cum_returns(self.benchmark_returns)
            fig.add_trace(go.Scatter(
                x=bench_cum.index,
                y=bench_cum.values,
                name='基准净值',
                line=dict(color='#A23B72', width=2, dash='dash')
            ))
        
        fig.update_layout(
            title='净值曲线',
            xaxis_title='日期',
            yaxis_title='累计净值',
            hovermode='x unified',
            template='plotly_white'
        )
        
        st.plotly_chart(fig, use_container_width=True)
```
