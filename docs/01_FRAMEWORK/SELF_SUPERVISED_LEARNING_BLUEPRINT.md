## 1. 概述

### 1.1 设计背景

自监督学习是利用无标签数据进行预训练的技术：

- **对比学习**: SimCLR, MoCo, BYOL
- **掩码预测**: BERT, MAE
- **自监督预训练**: 利用海量无标签数据
- **迁移学习**: 预训练模型微调

### 1.2 业务价值

| 价值维度 | 具体收益 |
|----------|----------|
| **数据效率** | 减少标注需求90% |
| **泛化能力** | 提升模型泛化性 |
| **特征质量** | 学习高质量表示 |
| **成本节约** | 降低标注成本 |

| 模块 | 职责 | 输入 | 输出 |

| **数据增强器** | 生成增强样本 | 原始数据 | 增强样本对 |

| **微调器** | 下游任务微调 | 预训练模型+标签 | 任务模型 |
