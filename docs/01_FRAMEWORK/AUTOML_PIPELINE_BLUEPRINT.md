## 1. 概述

### 1.1 设计背景

AutoML是自动化机器学习流程的技术：

- **自动化特征工程**: 自动生成和选择特征
- **自动化模型选择**: 自动选择最优模型
- **自动化超参优化**: 自动调优超参数
- **降低技术门槛**: 减少专家依赖

### 1.2 业务价值

| 价值维度 | 具体收益 |
|----------|----------|
| **效率** | 开发时间减少80% |
| **质量** | 自动找到最优配置 |
| **成本** | 降低人力成本 |
| **可扩展** | 快速迭代实验 |
