## 1. 概述

### 1.1 设计背景

联邦学习是隐私保护分布式训练的核心技术：

- **数据隐私**: 数据不出本地
- **分布式训练**: 多方协作训练
- **模型聚合**: 安全聚合模型参数
- **跨机构合作**: 支持跨机构合作

### 1.2 业务价值

| 价值维度 | 具体收益 |
|----------|----------|
| **隐私保护** | 数据不出本地 |
| **数据丰富** | 多方数据价值 |
| **合规性** | 满足数据法规 |
| **协作性** | 跨机构合作 |

```
│  │  参数上传    │  │  参数上传    │  │  参数上传    │  │  参数上传    │   │

```

### 2.2 模块职责

| 模块 | 职责 | 输入 | 输出 |
|------|------|------|------|
| **中央服务器** | 聚合模型参数 | 客户端参数 | 全局模型 |
| **客户端** | 本地训练 | 全局模型+本地数据 | 本地参数 |
| **聚合器** | 安全聚合 | 各客户端参数 | 聚合参数 |
| **加密模块** | 安全通信 | 原始数据 | 加密数据 |
