## 4. 使用示例

```python
from torch.utils.checkpoint import checkpoint

class CheckpointedModel(nn.Module):
    def forward(self, x):
        for layer in self.layers:
            if self.training:
                x = checkpoint(layer, x)
            else:
                x = layer(x)
        return x
```
