## 1. 概述

### 1.1 设计背景

订单流预测是高频交易的核心能力：

- **方向预测**: 预测买卖方向
- **量级预测**: 预测订单量级
- **时机预测**: 预测下单时机
- **市场冲击**: 预测价格冲击

### 1.2 业务价值

| 价值维度 | 具体收益 |
|----------|----------|
| **Alpha** | 独特Alpha来源 |
| **执行** | 优化执行策略 |
| **风险** | 降低市场冲击 |
| **速度** | 微秒级响应 |
