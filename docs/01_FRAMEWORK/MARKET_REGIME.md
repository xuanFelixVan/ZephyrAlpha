## 1. 为什么先分析大盘？

**这是分层策略的第一步，也是最重要的前置决策**：

```
┌─────────────────────────────────────────────────────────────────┐
│                    分层量化决策流程                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  第一层: 大盘择时 (Market Timing) ← 必须先做                      │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 分析: 今天大盘走势如何？明天可能如何？                      │    │
│  │ 输出: 牛市/熊市/震荡/高波动/低波动                        │    │
│  │ 决策: 仓位上限/策略选择/风控参数                          │    │
│  └─────────────────────────────────────────────────────────┘    │
│                          ↓                                      │
│  第二层: 板块/行业选择 (Sector Selection)                        │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 分析: 哪些板块最强？轮动方向？                            │    │
│  │ 输出: 板块排名/资金流向                                  │    │
│  │ 决策: 超配/低配行业                                      │    │
│  └─────────────────────────────────────────────────────────┘    │
│                          ↓                                      │
│  第三层: 个股筛选 (Stock Selection)                              │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 分析: 板块内哪些股票最强？                                │    │
│  │ 输出: 股票排名/信号强度                                  │    │
│  │ 决策: 买入标的/仓位分配                                  │    │
│  └─────────────────────────────────────────────────────────┘    │
│                          ↓                                      │
│  第四层: 择时入点 (Entry Timing)                                │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 分析: 今天什么价格买？什么价位止损？                      │    │
│  │ 输出: 买入价/止损价/目标价                               │    │
│  │ 决策: 执行买入                                           │    │
│  └─────────────────────────────────────────────────────────┘    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 2. 市场状态识别器

**这是整个量化系统的第一道关卡**：

```python
class MarketRegimeDetector:
    """市场状态识别器 - 系统第一模块"""

    def detect(self, index_data: pd.DataFrame) -> dict:
        """
        识别大盘状态
        输入: 沪深300/中证500/上证指数数据
        输出: 市场状态 + 仓位建议 + 策略池
        """
        # 1. 判断趋势方向
        trend = self._detect_trend(index_data)

        # 2. 判断波动率
        volatility = self._detect_volatility(index_data)

        # 3. 判断量能
        volume = self._detect_volume(index_data)

        # 4. 综合判断状态
        regime = self._synthesize_regime(trend, volatility, volume)

        return {
            'regime': regime,
            'position_limit': self.position_map[regime],
            'strategy_pool': self.strategy_map[regime],
            'risk_params': self.risk_map[regime]
        }
```

## 3. 市场状态分类

| 状态 | 英文 | 判断标准 | 仓位上限 | 适用策略 |
|------|------|----------|----------|----------|
| 牛市 | BULL | MA5>MA20>MA60 且 trend>0 | 80-100% | 趋势跟踪/成长 |
| 熊市 | BEAR | MA5<MA20<MA60 且 trend<0 | 0-20% | 空仓/超跌反弹 |
| 震荡 | CONSOLIDATION | MA60走平 | 30-50% | 均值回归/高股息 |
| 高波动 | HIGH_VOL | ATR > 2倍历史均值 | 20-40% | 动态止损/空仓 |
| 低波动 | LOW_VOL | ATR < 0.5倍历史均值 | 50-70% | 价值/趋势 |
| 上涨中继 | PULLBACK | 牛市回调不破MA20 | 60-80% | 回踩买入 |
| 下跌中继 | RALLY | 熊市反弹不过MA20 | 10-20% | 反弹卖出 |
