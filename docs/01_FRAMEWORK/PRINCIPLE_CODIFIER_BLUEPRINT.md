## 📊 一、投资原则分类体系

### 1.1 原则分类框架

**专业机构标准**：建立分层的投资原则分类体系，确保原则覆盖全面、层次清晰。

#### 1.1.1 核心投资原则 (Core Investment Principles)

| 原则ID | 原则名称 | 原则内容 | 适用范围 | 优先级 |
|--------|---------|---------|---------|--------|
| **CIP-001** | 风险控制优先 | 永远不要冒无法承受的风险 | 所有决策 | P0 |
| **CIP-002** | 分散投资 | 不要把所有鸡蛋放在一个篮子里 | 组合管理 | P0 |
| **CIP-003** | 长期价值投资 | 关注长期价值而非短期波动 | 策略选择 | P0 |
| **CIP-004** | 市场有效性 | 尊重市场，不与趋势作对 | 交易执行 | P1 |
| **CIP-005** | 流动性管理 | 保持充足的流动性储备 | 风险管理 | P1 |

**桥水案例对标**：
- 200+条投资原则全部算法化
- 核心原则不可违反，违反即拦截
- 原则之间有明确的优先级和冲突解决机制

#### 1.1.2 策略选择原则 (Strategy Selection Principles)

| 原则ID | 原则名称 | 原则内容 | 适用场景 | 优先级 |
|--------|---------|---------|---------|--------|
| **SSP-001** | 市场状态匹配 | 根据市场状态选择策略 | 策略选择 | P0 |
| **SSP-002** | 策略多样性 | 保持策略的多样性 | 组合管理 | P1 |
| **SSP-003** | 策略容量限制 | 不超过策略容量上限 | 交易执行 | P1 |
| **SSP-004** | 策略相关性控制 | 控制策略间相关性 | 组合管理 | P1 |
| **SSP-005** | 策略衰减监控 | 监控策略有效性衰减 | 策略管理 | P2 |

#### 1.1.3 风险管理原则 (Risk Management Principles)

| 原则ID | 原则名称 | 原则内容 | 触发条件 | 应对措施 |
|--------|---------|---------|---------|----------|
| **RMP-001** | 单一持仓限制 | 单一股票持仓 ≤ 10% | 持仓 > 10% | 强制减仓 |
| **RMP-002** | 行业集中度限制 | 单一行业持仓 ≤ 30% | 行业持仓 > 30% | 调整配置 |
| **RMP-003** | 止损原则 | 单日亏损 ≥ 5%止损 | 单日亏损 ≥ 5% | 暂停交易 |
| **RMP-004** | 最大回撤控制 | 最大回撤 ≤ 15% | 回撤 > 15% | 降低仓位 |
| **RMP-005** | 杠杆限制 | 杠杆率 ≤ 1.5倍 | 杠杆 > 1.5倍 | 降低杠杆 |

**文艺复兴案例对标**：
- 实时风险监控，超限立即触发
- 风险原则分级，不同等级不同应对
- 风险事件自动记录，事后分析改进

#### 1.1.4 交易执行原则 (Execution Principles)

| 原则ID | 原则名称 | 原则内容 | 适用场景 | 优先级 |
|--------|---------|---------|---------|--------|
| **EP-001** | 交易时间限制 | 仅在交易时间执行 | 所有交易 | P0 |
| **EP-002** | 涨跌停限制 | 涨跌停股票不交易 | 交易执行 | P0 |
| **EP-003** | 流动性要求 | 仅交易流动性充足的股票 | 交易执行 | P1 |
| **EP-004** | 冲击成本控制 | 控制交易冲击成本 | 大额交易 | P1 |
| **EP-005** | 执行算法选择 | 根据交易规模选择执行算法 | 交易执行 | P2 |

### 2.2 规则编码规范

#### 2.2.1 规则代码模板

```python
from dataclasses import dataclass
from enum import Enum
from typing import Dict, Any, Optional

class Priority(Enum):
    P0 = "P0"
    P1 = "P1"
    P2 = "P2"

class ActionType(Enum):
    ALLOW = "allow"
    WARN = "warn"
    BLOCK = "block"

@dataclass
class PrincipleRule:
    principle_id: str
    principle_name: str
    priority: Priority
    description: str
    
    def check(self, context: Dict[str, Any]) -> bool:
        raise NotImplementedError
    
    def execute(self, context: Dict[str, Any]) -> Dict[str, Any]:
        raise NotImplementedError

class DispersedInvestmentRule(PrincipleRule):
    def __init__(self):
        super().__init__(
            principle_id="CIP-002",
            principle_name="分散投资",
            priority=Priority.P0,
            description="不要把所有鸡蛋放在一个篮子里"
        )
    
    def check(self, context: Dict[str, Any]) -> bool:
        portfolio = context.get("portfolio", {})
        
        single_position_ratio = portfolio.get("single_position_ratio", 0)
        if single_position_ratio > 0.10:
            return False
        
        single_industry_ratio = portfolio.get("single_industry_ratio", 0)
        if single_industry_ratio > 0.30:
            return False
        
        top10_position_ratio = portfolio.get("top10_position_ratio", 0)
        if top10_position_ratio > 0.50:
            return False
        
        return True
    
    def execute(self, context: Dict[str, Any]) -> Dict[str, Any]:
        check_result = self.check(context)
        
        if not check_result:
            return {
                "action": ActionType.BLOCK,
                "reason": f"违反原则 {self.principle_id}: {self.principle_name}",
                "suggestion": "调整持仓结构，降低集中度"
            }
        
        return {
            "action": ActionType.ALLOW,
            "reason": "符合分散投资原则"
        }
```

## ✅ 三、原则验证机制

### 3.1 验证体系架构

| 验证层级 | 验证内容 | 验证方法 | 验证标准 | 验证频率 |
|---------|---------|---------|---------|----------|
| **L1: 单元验证** | 单个规则正确性 | 单元测试 | 100%通过 | 每次修改 |
| **L2: 集成验证** | 规则协同性 | 集成测试 | 无冲突 | 每次部署 |

- 每条原则都有完整的测试用例

| **监管变化** | 监管规则变化 | 更新合规原则 | 人类审批 |

### 4.2 版本管理机制

#### 4.2.1 版本控制策略

| 版本类型 | 版本号规则 | 更新频率 | 回滚策略 | 审批要求 |
|---------|-----------|---------|---------|----------|
| **主版本** | v1.0, v2.0 | 重大变更 | 完全回滚 | 人类审批 |
| **次版本** | v1.1, v1.2 | 功能优化 | 部分回滚 | 人类审批 |
| **修订版本** | v1.1.1, v1.1.2 | 参数调整 | 快速回滚 | 自动审批 |
| **热修复** | v1.1.1-hotfix | 紧急修复 | 立即回滚 | 自动审批 |
