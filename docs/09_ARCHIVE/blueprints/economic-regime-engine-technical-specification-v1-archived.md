**ﮔﺍﮒ۵ﮒ؛ﮒﺙ**:



1. **HMMﮔ۷۰ﮒﮒ؟ﻛﺗ**:

- ﻠﻝﭘﮔﻠﮒ? S = {ﮔ۸ﮒﺙ, ﮔﭨﻟ, ﻟ۰ﺍﻠ, ﮒ۳ﻟ}

   - ﮔ۷۰ﮒﮒﮔﺍ: ﺳﭨ = (ﺵ, A, B)

     - ﺵ: ﮒﮒ۶ﻝﭘﮔﮔ۵ﻝﮒﮒﺕ?     - A: ﻝﭘﮔﻟﺛ؛ﻝ۶ﭨﮔ۵ﻝﻝ۸ﻠ?     - B: ﻟ۶ﮔﭖﮔ۵ﻝﮒﮒﺕ



2. **ﮒﮒﻝ؟ﮔﺏ**ﺅﺙﻟ؟۰ﻝ؟ﻟ۶ﮔﭖﮒﭦﮒﮔ۵ﻝﺅﺙ:

   ```

   ﺳﺎ_t(i) = P(O_1, O_2, ..., O_t, q_t = S_i | ﺳﭨ)

   ﺳﺎ_t(i) = [ﺳ۲_j ﺳﺎ_{t-1}(j) * a_{ji}] * b_i(O_t)

3. **Viterbiﻝ؟ﮔﺏ**ﺅﺙﻟ۶۲ﻝﮔﮒﺁﻟﺛﻝﻝﭘﮔﮒﭦﮒﺅﺙ:

   ```



4. **Baum-Welchﻝ؟ﮔﺏ**ﺅﺙﮒﮔﺍﻛﺙﺍﻟ؟۰ﺅﺙ:

   ```

   ﺳﺝ_t(i, j) = P(q_t = S_i, q_{t+1} = S_j | O, ﺳﭨ)

   ﺳﺏ_t(i) = P(q_t = S_i | O, ﺳﭨ)

   ```
