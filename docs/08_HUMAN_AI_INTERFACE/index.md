## 一、模块设计原则

### 1.1 设计目标

| 目标 | 说明 |
|------|------|
| **轻量级** | 最小依赖，易于部署和维护 |
| **可扩展** | 模块化设计，可逐步扩展 |
| **AI友好** | 代码清晰，便于AI理解和维护 |
| **个人使用** | 专注核心功能，不过度设计 |
