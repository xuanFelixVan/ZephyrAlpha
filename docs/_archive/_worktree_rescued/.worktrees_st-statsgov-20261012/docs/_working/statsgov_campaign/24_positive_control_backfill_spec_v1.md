# 阳性对照加数据规格件——市值/价量史回补（统筹批复三：优选回补而非改月频 t 口径）

## 0. 本机更正（先认错，再给数）

我在 20:3x 的收班报里说过"价量从 2019 起本就完整 ⇒ 不必回补到 2016，只补 2019-2020 两年即可"。**这句算错了**：
按 t∝√T 外推，把小市值对照的隐含 t 从 2.010 推到 DSR 门槛所需的 **3.104** 需要

```
T_req = 693 × (3.104 / 2.010)² ≈ 1,651 交易日
```

而只补 2019-01..2020-12（实测该两段共 **487** 交易日）只得 T≈1,180 ⇒ t≈2.62，仍差一档。
⇒ **批复三给的范围（回补到 2016-2018）是对的**，我收回上一条建议。下面按实测缺口给可执行清单。

## 1. 缺口实测（全部 CH 只读口，逐条可复算）

| 面板 | 现有覆盖（实测） | 2016-2020 段缺口 |
|---|---|---|
| `c1_market.kline_daily` | 2020-01-02..2023-12-29 全窗 5,471 票；2019=**3,771**、2020=**4,366**、2021=4,844、2022=5,183、2023=5,381 | **2016=234、2017=240、2018=237** 只票（约 57k 行/年）＝stub，与在档"2019 前仅约 237 票、15× 断崖"同形 |
| `c1_market.kline_daily_hfq` | 同上形态（2016=232、2017=238、2018=235、2019=3,770、2020=4,366）⇒ **两表互证不是取数姿势问题** | 同缺口 |
| `c1_market.stock_daily_basic` | **全表 2021-01-04..2026-10-12**，70 个月，5,785 票，7,118,526 行 | **2016-01..2020-12 全缺（0 行）**，含价量已完整的 2019-2020 两年 |

交易日实测：2016-01..2018-12 = **731** 天；2016-01..2020-12 = **1,218** 天 ⇒ 2019-2020 = 487 天。

## 2. 回补清单（分两段，验收分开）

| 段 | 要补的表 | 目标行量（估算，按当年票面×交易日） | 为什么必须有 |
|---|---|---|---|
| 段一（便宜，先做） | `stock_daily_basic` 2019-01-01..2020-12-31 | ≈ 487 × (3,771+4,366)/2 ≈ **198 万行** | 价量已在库，只缺市值/流通股本/换手 ⇒ 单表补齐即扩窗 |
| 段二（决定成败） | `kline_daily`（＋`_hfq`）与 `stock_daily_basic` 2017-01-01..2018-12-31 | 价量 ≈ 487 × ~3,560 ≈ **173 万行**（现有仅 240 票级）；市值同段 ≈ 173 万行 | 要把 T 推到 ≥1,651 必须吃满 2017-2018；只补市值不补价量＝该段仍构不出组合 |

字段清单（basic 实测列，勿改名）：`trade_date, symbol, turnover_rate, float_share, circ_mv, total_mv, data_source, ingest_ts`；
价量侧沿用现表列（`close/pct_change/adj_factor/...`）。**下游依赖**：小市值构造只用 `total_mv`（实测最优即 total_mv 基），
`circ_mv` 两族结果明显更弱（0.50 vs 1.24）⇒ 段一/段二必须两列都回补，不能只挑一列。

入口与核实项（不新增采集器，派工现成件）：
- 候选入口 `scripts/data/backfill_stock_daily_basic.py`：`--all/--symbols/--start/--end`，**默认 `--start 20210101`**（正好是缺口右边界，说明当初就是从那一年起采的）。
- ⚑ 派工前必核实一条：该件 `fetch_symbol` 实际调的是 `ak.stock_zh_a_hist(...)`（价量接口，`:46`），
  而表名与字段是 `daily_basic`（市值/换手/股本）⇒ 文件名与数据源不一致，**须由数据域确认它到底产哪套字段**；
  若产价量，则 basic 段需要另指正确的行情适配器入口，勿硬跑以免写错列。

## 3. 验收判据（不达标就不算回补完成，别用行数糊）

1. 逐年 `uniqExact(symbol)` ≥ 当年实际上市数 × 0.95（2017 约 3,560、2018 约 3,580；以 `c1_market.stock_list`/`industry_class` 为准）——
   **不接受"表面 2015 起但 2019 前只有 237 票"这种假完整**（在档前科）。
2. 逐日 `count()` 与 `kline_daily` 同年同月对账，缺日率 < 0.5%；停牌日允许缺行但须可区分（不得填 0 收益）。
3. 抽 20 票 × 40 交易日，市值/换手与价量收盘手工对拍，且 `total_mv>0` 无负值无 NaN。
4. 回补段必须与既有段**同一单位口径**（`circ_mv/total_mv` 单位万元 vs 元，历史上换过源的批次要标注 `data_source`）。
5. PIT 纪律：构造小市值组合时市值一律取**上月末**值（本班跑批件已这么实现），验收件里须含一条"用当日值＝未来函数"的反例被拒。

## 4. 复考协议（回补后本班再跑，口径全部冻结不动）

- 同一 8 配置面（basis∈{total_mv,circ_mv}×q∈{10%,20%}×{月,双周}）、同成本档（17.5bp×双边）、同判官
  （DSR=`MOD-SIM-024`、PBO=`cpcv`，禁新造数学）、同两轴读法（有效性轴 N=8 ＋ 治理轴 N=当日账面＋磁盘实测）。
- 预登记判读（跑前写死，防事后有话可说）：
  | 复考结果 | 结论 | 禁止的动作 |
  |---|---|---|
  | T≥1,651 且 DSR@N=8 ≥0.95 | 尺与账都成立，校准闭环完成 | — |
  | T≥1,651 但 t<3.104（仍未过线） | **该异象在本市场本长度就够不到任何一条线** ⇒ "矿里暂无金"成立 | 禁再改阈值/换口径来救；禁把结论写成"尺仍偏严" |
  | 回补后段与既有段效应方向相反 | 制度环境差（壳价值/IPO 排队年代）导致不可比 ⇒ 校准窗口须钉在 2019 之后 | 禁把两段拼起来平均出"更好看"的 t |
- 统计保留（自报短板）：`t∝√T` 假设日收益近 iid；A 股波动聚集与月度自相关会让实际增益**小于**√T 外推 ⇒
  真所需 T 可能 >1,651。段二回补后先按 1,651 判一次，若差一口气，本件允许把目标 T 上调一次并留痕，不得反复调。
- 记账：复考批以 `kind=calibration_ruler_exam`、batch_id=`ruler-calib-reexam-<日期>` 入 N 账本（追加单条写得进，已在 10-12 实测），
  并从族 **A/B 之外** 的 **F 元层** 扣（考的是判官与对照，不是新配方）。
