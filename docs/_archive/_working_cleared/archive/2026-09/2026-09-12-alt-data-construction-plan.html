§0一页结论

  1. 五条管线全部有持续调度任务，不是一次性导数。生猪三表在 tasks.yaml 是 daily_event 日度任务（akshare 增量/幂等拉取），其余四条各有专属 task。残余风险是 akshare 上游网页改版——用 alt_source_health_manager + known_data_gaps 兜底（先例：北向三接口断供 → tushare 替代）。
  2. 电商爬虫不碰的四条理由：反爬工程量＞收益；平台条款合规深水区；有免费合法替代品（海关进出口月度、统计局社零）；同等消费景气信号已被已接宏观数据覆盖。
  3. 三块可做全部有施工路径：web 注意度（百度指数+概念映射）、社媒情绪（股吧/千股千评/雪球）、监管文件衍生（互动易问答 + SEC EFTS 全文），见 §2。
  4. 政府数据不需要采购。统计局/部委/采购公告全免费；243+ 省市开放平台免费（部分数据集需注册实名账号下载）。唯一可选小额支出：textdata.cn 互动问答历史集（一次性买断，非订阅）。
  5. 国际宏观免费的已接一半：FRED（22 序列 event_driven）+ 世界银行（免 key）+ EIA 已在跑；本轮新增 IMF、GDELT（免注册 15 分钟全球新闻事件）、SEC EDGAR EFTS（免注册全文检索）。
  6. 施工分 4 批：免注册直连 → 注册类（§4 URL 清单）→ 爬虫试点 → 海外源。

§2三块可做的施工图

① Web 注意度 —— 百度指数（免费，登录 cookie）→ 概念关键词池（≈200 词起步）→ 每日拉取落 search_attention 表 → 唤醒 concept_factor_mapper 概念→个股映射。风险：cookie 过期 → health manager 告警。PIT 安全（指数即所得）。

② 社媒情绪 —— 股吧发帖量/阅读热度（akshare）+ 千股千评日频关注评分（东财数据中心）+ 雪球关注/讨论（非官方 API）→ 唤醒 social_sentiment_collector → 统一 (metric, trade_date, value, source) 行格式 → 落 stock_hot_rank 邻位表族 → 消费端与 news_sentiment_window 合成。证据：华创《机构情绪与个人情绪》、雪球情绪指数长回测。

③ 监管文件衍生 —— 境内：互动易+e互动问答（tushare irm_qa）+ 巨潮公告文本（akshare 部分覆盖），历史回补 textdata.cn 536 万条；海外：SEC EFTS 全文检索（免注册 JSON）。唤醒 filing_nlp_engine → 文本入 news_data 同款管线 → 结构化（提问量/回复情感/含糊度/主题）→ 与研报链共享 intelligence 域。PIT：发布时间即所得，embargo 走三公理。
