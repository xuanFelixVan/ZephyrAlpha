## 一、因子库概述

清风量化因子库是量化投资研究的核心数据资产，涵盖A股市场多维度因子信息，支持Alpha因子挖掘、风险模型构建和组合优化。

### 1.1 因子库规模

| 因子类别 | 因子数量 | 主要来源 |
|----------|----------|----------|
| Alpha因子 | 400+ | 自定义/学术 |
| Barra风格因子 | 10 | Barra CNE6 |
| 行业因子 | 28+ | 申万/证监会 |
| iFind数据源 | 1600+ | THS_BD/行情/技术 |
| **合计** | **2000+** | |
