---

## 使用说明

### 为什么要版本追踪？

- 因子改进后保留历史版本
- 记录每次优化的原因和效果
- 可以回滚到之前的版本
- 团队协作时避免版本混乱

### 命名规范

因子版本文件命名：`{因子名称}_版本记录_{日期}.md`

示例：`ROE_GROWTH_版本记录_20260328.md`
