| 因子名称 | PEG |
| 创建日期 | 2026-03-28 |
| 创建人员 | 清风量化研究部 |
| 合成方法 | 公式计算 |

## 因子定义

| 项目 | 内容 |
|------|------|
| 计算公式 | PEG = PE_TTM / (净利润增速 * 100) |
| 定义说明 | 市盈率相对盈利增长比率，衡量估值与成长匹配度 |
| 取值范围 | 通常 -100 到 100 |
| 理想取值 | 0.5-1.5 为合理区间 |

## 注意事项

- 负增速时PEG失真，需特殊处理
- 周期性行业不适用
- 仅适用于盈利稳定的成长型公司
