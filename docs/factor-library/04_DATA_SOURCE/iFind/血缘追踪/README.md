# 血缘追踪

> 本目录用于记录因子的血缘关系和依赖结构
>
> **重要**：当使用合成因子时，必须追踪其血缘关系

---

## 目录结构

```
血缘追踪/
├── README.md                        # 本说明文件
├── 原始因子/                        # 来自数据源的原始因子
│   └── {因子名}.md
├── 合成因子/                        # 由原始因子合成的因子
│   └── {因子名}.md
└── 血缘图谱/                        # 可视化血缘关系
    └── {因子群组}_血缘图.md
```

---

## 为什么要做血缘追踪？

| 场景 | 没有血缘追踪的问题 | 有血缘追踪的好处 |
|------|-------------------|-----------------|
| 因子修改 | 不知道影响哪些合成因子 | 清楚影响范围 |
| IC失效 | 难以定位问题根源 | 快速定位问题 |
| 因子复用 | 重复造轮子 | 复用已有组件 |
| 风险控制 | 不知道因子依赖关系 | 准确评估风险 |

---

## 因子类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| **原始因子** | 直接来自数据源 | THS_BD_pe_ttm |
| **合成因子** | 由多个原始因子计算 | PEG = PE / Growth |
| **衍生因子** | 原始因子的简单变换 | ln(市值) = log(市值) |
