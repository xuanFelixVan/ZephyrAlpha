# 相关性矩阵

> 本目录用于记录因子间的相关性分析

---

## 使用说明

### 为什么要做相关性分析？

避免使用高度相关的因子：
- 相关性>0.9的因子，同时使用等于重复加权
- 可能导致组合风险估计偏差
- 占用因子额度但效果有限

### 判断标准

| 相关性 | 判断 | 建议 |
|--------|------|------|
| < 0.3 | 低相关 | 可以同时使用 |
| 0.3-0.6 | 中等相关 | 谨慎使用 |
| 0.6-0.8 | 较高相关 | 选择其一或降权 |
| > 0.8 | 高度相关 | 必须选择其一 |
| > 0.9 | 极高度相关 | 几乎等效，选择其一 |

### 命名规范

相关性矩阵文件命名：`相关性矩阵_{日期}.md`

示例：`相关性矩阵_20260328.md`
