## 索引更新规范

### 新增因子

1. 在因子清单中添加THS代码
2. 进行IC验证并记录
3. 进行单因子回测并记录
4. 更新本索引文件

### 字段说明

| 字段 | 说明 |
|------|------|
| IC状态 | 待验证 / 验证中 / ✅ 已验证 / ❌ 已拒绝 |
| 回测状态 | 待回测 / 回测中 / ✅ 已回测 / ❌ 已拒绝 |
| 版本历史 | 版本记录文件路径 |
