## 目录结构

```

├── README.md                    # 本说明文件

```

---

## IC指标说明

| 指标 | 说明 | 判断标准 |
|------|------|----------|
| IC均值 | 因子与收益的Pearson相关系数均值 | >0.02为有效 |
| IC标准差 | IC序列的标准差 | 越小越稳定 |
| IC_IR | IC均值/IC标准差（信息比率） | >0.5有效，>1.0优秀 |
| IC胜率 | IC>0的占比 | >55%为有效 |
| t统计量 | IC均值的显著性检验 | >2.0为显著 |
| RankIC均值 | 因子与收益的Spearman相关系数 | >0.02为有效 |
| RankIC_IR | RankIC均值/RankIC标准差 | >0.5有效 |
