---

## 回测指标说明

| 指标 | 说明 | 判断标准 |
|------|------|----------|
| 年化收益率 | Top组合年化收益 | 越高越好 |
| 年化波动率 | 组合收益标准差 | 越低越稳定 |
| 夏普比率 | 风险调整收益 | >1.0为优秀 |
| 最大回撤 | 最大跌幅 | 越小越好 |
| 胜率 | 正收益占比 | >50% |
| 卡玛比率 | 年化收益/最大回撤 | 越高越好 |
| 收益回撤比 | Top收益/Bottom收益 | 差异越大越好 |
