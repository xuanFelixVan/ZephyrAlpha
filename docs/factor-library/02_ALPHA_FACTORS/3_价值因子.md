# 价值因子

> 价值因子基于低估值策略，选择P/E、P/B等估值指标较低的股票

---

## 因子列表

| 因子名称 | 计算方法 | 数据来源 | 更新频率 |
|----------|----------|----------|----------|
| PE(TTM) | 市盈率(滚动) | iFind-估值 | 日频 |
| PE(静) | 市盈率(静态) | iFind-估值 | 日频 |
| PB(MRQ) | 市净率 | iFind-估值 | 日频 |
| PS(TTM) | 市销率 | iFind-估值 | 日频 |
| PCF | 现金流市值比 | iFind-估值 | 日频 |
| EV/EBITDA | 企业价值倍数 | iFind-估值 | 日频 |
| 股息率 | 股息/股价 | iFind-估值 | 日频 |
| PEG | 市盈率/盈利增速 | 自定义 | 日频 |
| P/FCF | 价格/自由现金流 | 自定义 | 日频 |
| 跌破净资产 | PB < 1 | 自定义 | 日频 |
| 低PE反转 | PE历史分位 < 20% | 自定义 | 日频 |
