# 均值回归因子

> 均值回归因子基于价格围绕价值波动的假设，在价格偏离均值时反向交易

---

## 因子列表

| 因子名称 | 计算方法 | 数据来源 | 更新频率 |
|----------|----------|----------|----------|
| RSI(6) | 6日相对强弱指数 | iFind-技术 | 日频 |
| RSI(12) | 12日相对强弱指数 | iFind-技术 | 日频 |
| RSI(24) | 24日相对强弱指数 | iFind-技术 | 日频 |
| BIAS(6) | 6日乖离率 | iFind-技术 | 日频 |
| BIAS(12) | 12日乖离率 | iFind-技术 | 日频 |
| BIAS(24) | 24日乖离率 | iFind-技术 | 日频 |
| 布林带 | Bollinger Bands | iFind-技术 | 日频 |
| CCI | 顺势指标 | iFind-技术 | 日频 |
| WR威廉指标 | 威廉指数 | iFind-技术 | 日频 |
| KDJ | 随机指标 | iFind-技术 | 日频 |
| 股价偏离均线 | (Price-MA)/MA | 自定义 | 日频 |
| 高低价偏离 | (High-Low)/Price | 自定义 | 日频 |
