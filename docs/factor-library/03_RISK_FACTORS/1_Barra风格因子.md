# Barra风格因子

> Barra CNE6风格因子体系，用于风险管理和因子风险归因

---

## 十大风格因子

| 因子代码 | 因子名称 | 计算方法 | 说明 |
|----------|----------|----------|------|
| MKT | 市场因子 | R_m - R_f | 市场超额收益 |
| SMB | 规模因子 | Small - Big | 小市值效应 |
| HML | 价值因子 | High_B/M - Low_B/M | 低估值效应 |
| RMW | 盈利因子 | Robust - Weak | 盈利能力强 |
| CMA | 投资因子 | Conservative - Aggressive | 保守投资 |
| MOM | 动量因子 | Winner - Loser | 趋势延续 |
| STED | 短期反转 | 1月反转 | 短期价格回归 |
| LTED | 长期反转 | 3年反转 | 长期价格回归 |
| BETA | 市场敏感度 | Cov(R_i, R_m)/Var(R_m) | 系统性风险 |
| RES | 特异性波动 | Idiosyncratic Vol | 个股特有风险 |

---

## 因子用途

| 用途 | 说明 |
|------|------|
| 风险归因 | 将组合收益归因到风格因子 |
| 风险控制 | 控制组合在风格因子上的暴露 |
|因子中性化 | 对风格因子进行中性化处理 |
