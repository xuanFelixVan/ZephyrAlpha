### 5.3 进度偏差分析

#### 偏差计算公式

```
进度偏差(SV) = 已完成工作预算成本(BCWP) - 计划工作预算成本(BCWS)
进度绩效指数(SPI) = BCWP / BCWS

SV > 0: 进度提前
SV = 0: 进度符合计划
SV < 0: 进度落后

SPI > 1: 进度效率高
SPI = 1: 进度效率正常
SPI < 1: 进度效率低
```

#### 偏差应对措施

| 偏差程度 | 偏差范围 | 应对措施 |
|---------|---------|---------|
| 轻微偏差 | -5% ~ +5% | 正常监控，无需调整 |
| 中度偏差 | -10% ~ -5% | 分析原因，调整资源 |
| 严重偏差 | -20% ~ -10% | 调整计划，增加资源 |
| 极严重偏差 | < -20% | 重新评估项目可行性 |
