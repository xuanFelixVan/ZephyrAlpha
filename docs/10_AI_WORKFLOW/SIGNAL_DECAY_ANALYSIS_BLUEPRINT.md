## 二、架构设计

### 2.1 信号衰减模型

```
┌─────────────────────────────────────────────────────────────────────┐
│                       信号衰减模型                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  信号强度 = f(时间)                                                 │
│                                                                     │
│  常见衰减模式:                                                       │
│                                                                     │
│  1. 指数衰减 (Exponential Decay)                                   │
│     S(t) = S₀ * e^(-λt)                                            │
│     λ: 衰减率, t: 时间                                              │
│                                                                     │
│  2. 幂律衰减 (Power Law Decay)                                     │
│     S(t) = S₀ * t^(-α)                                             │
│     α: 衰减指数                                                     │
│                                                                     │
│  3. 阶梯衰减 (Step Decay)                                          │
│     S(t) = S₀ * (1 - step(t))                                      │
│     step: 阶梯函数                                                  │
│                                                                     │
│  4. 复合衰减 (Composite Decay)                                     │
│     S(t) = S₁ * e^(-λ₁t) + S₂ * e^(-λ₂t)                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.2 核心计算模型

#### IC衰减分析

```python
def ic_decay_analysis(factor, returns, max_periods=20):
    """
    IC衰减分析: 计算因子对不同持有期的IC
    
    IC(t) = corr(factor, returns_t)
    """
    ic_series = []
    for t in range(1, max_periods + 1):
        future_returns = returns.shift(-t)
        ic = factor.corr(future_returns)
        ic_series.append(ic)
    return ic_series
```

#### 衰减曲线拟合

```python
from scipy.optimize import curve_fit

def exponential_decay(t, s0, decay_rate):
    """指数衰减模型"""
    return s0 * np.exp(-decay_rate * t)

def fit_decay_curve(ic_series):
    """
    拟合衰减曲线
    返回: 衰减参数、拟合优度
    """
    t = np.arange(1, len(ic_series) + 1)
    params, covariance = curve_fit(exponential_decay, t, ic_series)
    s0, decay_rate = params
    
    # 计算半衰期
    half_life = np.log(2) / decay_rate
    
    return {
        'initial_ic': s0,
        'decay_rate': decay_rate,
        'half_life': half_life,
        'covariance': covariance
    }
```

#### 最优持有期计算

```python
def optimal_holding_period(ic_series, transaction_cost=0.001):
    """
    最优持有期计算
    
    考虑IC衰减和交易成本
    最优持有期 = argmax(IC(t) - cost/t)
    """
    t = np.arange(1, len(ic_series) + 1)
    net_ic = np.array(ic_series) - transaction_cost / t
    optimal_t = np.argmax(net_ic) + 1
    return optimal_t
```
