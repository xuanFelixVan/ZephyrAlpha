## 一、模块概述



### 1.1 定位与目标



**核心定位**: 实时监控模型性能，检测数据和概念漂移，预警模型退化，确保模型持续有效。

def ks_test(reference, current):

    """

    KS检验: 比较两个分布是否相同

    p-value < 0.05: 分布显著不同
