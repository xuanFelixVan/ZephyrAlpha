# 旧文档务实评估报告

> 基于：1人+AI开发 + 每天14小时 + 1个月开发周期
> 目标：AI时代个人量化系统

---

## 一、可行性结论

### 时间约束分析

| 条件 | 数值 |
|------|------|
| 每天可用时间 | 14小时 |
| 开发周期 | 30天 |
| 总可用时间 | **420小时** (≈52人天) |
| 去掉必要休息 | **~300小时** (≈37人天) |

### 任务分类

| 类别 | 评估标准 | 结果 |
|------|---------|------|
| **可以做** | 1人×7天内完成 | 纳入核心系统 |
| **AI辅助** | AI可替代大部分工作 | AI执行+人监督 |
| **暂缓** | 1人月+或非核心 | 归档为未来功能 |
| **放弃** | 企业专属或个人无意义 | 直接删除 |

## 四、可行性结论

### 时间对比

| 指标 | 需求 | 可行性 |
|------|------|--------|
| 总工作量 | 106人天 | - |
| 每天14小时 | 相当于2人天/天 | - |
| 30天可用 | 60人天 | ⚠️ **超出30%** |

### 优化方案

**方案A：延长时间**
- 延长开发周期至45天
- 或降低每日投入至10小时

**方案B：精简功能**
- 放弃技术分析研究平台（-7天）
- 合并部分模块（-5天）
- 目标：压缩至60人天

**方案C：AI替代**
- 用AI生成代码（预计减少40%工作量）
- 目标：压缩至35人天 ✅

### 推荐：方案C（AI替代）+ 方案B（精简）

| Phase | 时间 | 内容 |
|-------|------|------|
| Phase 1 | 2周 | 数据+因子+回测核心 |
| Phase 2 | 1周 | 策略+风控核心 |
| Phase 3 | 1周 | AI委员会+监控 |
| Phase 4 | 1周 | AI辅助+优化 |
