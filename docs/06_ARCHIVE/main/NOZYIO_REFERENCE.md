# NozyIO可视化编辑系统参考

> 本文档归档旧系统3.0中的NozyIO四层可视化编辑系统架构，仅供参考

---

## 1. 系统概述

### 1.1 设计目标

NozyIO是一个零代码可视化量化策略编辑系统，让用户通过拖拽方式构建：
- Alpha因子
- 机器学习特征集
- 交易策略
- 回测分析

### 1.2 核心价值

| 价值 | 说明 |
|------|------|
| 零代码 | 无需编程，通过可视化界面构建策略 |
| 模块化 | 四层架构，每层专注特定功能 |
| 实时预览 | 所见即所得，实时查看效果 |
| 可复用 | 支持策略模板复用和版本管理 |

---

## 2. 四层架构

### 2.1 架构总览

```
NozyIO可视化编辑系统
├── 第一层: 因子编辑器 (端口5001)
│   └── 构建Alpha因子
├── 第二层: 特征编辑器 (端口5002)
│   └── 将因子组合成特征
├── 第三层: 策略编辑器 (端口5003)
│   └── 基于特征生成交易信号
└── 第四层: 回测系统 (端口5004)
    └── 完整回测和报告
```

### 2.2 第一层：因子编辑器

**功能**: 构建Alpha因子

**特性**:
- 技术指标库（MA, RSI, MACD等）
- 统计指标（均值、方差、偏度等）
- 机器学习特征（PCA, 因子分析等）
- AI辅助因子开发

**界面布局**:
```
┌─────────────────────────────────────────────────────────────┐
│  因子编辑器                              [保存] [运行] [导出] │
├─────────────────────────────────────────────────────────────┤
│ ┌───────────┐ ┌─────────────────────────────────┐ ┌──────┐ │
│ │ 因子库    │ │         画布区域                 │ │ 属性 │ │
│ │           │ │                                 │ │      │ │
│ │ ├─趋势类  │ │    [MA_5] ──┬── [RSI] ──┐      │ │窗口: │ │
│ │ ├─均值类  │ │              │          │      │ │ 14   │ │
│ │ ├─value_factors  │ │    [VOL] ───┘          ├──[因子]│ │      │ │
│ │ └─质量类  │ │                       │         │ │标准化│ │
│ │           │ │    [PRICE_DELTA] ─────┘         │ │ [✓]  │ │
│ └───────────┘ └─────────────────────────────────┘ └──────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 第二层：特征编辑器

**功能**: 将因子组合成机器学习特征

**特性**:
- 特征选择（相关性、重要性）
- 降维处理（PCA、ICA）
- 归一化配置
- 特征库管理和复用

### 2.4 第三层：策略编辑器

**功能**: 基于特征生成交易信号

**特性**:
- 条件判断节点
- 逻辑组合（AND/OR/NOT）
- 风控规则嵌入
- 参数优化配置

### 2.5 第四层：回测系统

**功能**: 完整回测和可视化报告

**特性**:
- 高性能回测引擎
- 多种回测参数配置
- 可视化绩效报告
- 因子归因分析

## 4. 为什么不采用

### 4.1 维护成本分析

| 维度 | NozyIO | 当前系统方案 |
|------|--------|--------------|
| **开发周期** | 3-6个月 | 已有Streamlit |
| **前端人力** | 需要React专家 | Python全栈 |
| **后端人力** | 需要4个独立服务 | 单进程 |
| **维护难度** | 高（多服务） | 低 |
| **实际价值** | 高但非必须 | 满足需求 |

### 4.2 ROI评估

**结论**: 对于个人开发者，NozyIO投入产出比太低。

### 4.3 替代方案

| 需求 | 替代方案 | 说明 |
|------|----------|------|
| 因子构建 | FactorCalculator + YAML配置 | 代码实现 |
| 特征工程 | Jupyter Notebook | 探索分析 |
| 策略编辑 | Streamlit界面 | 简单快速 |
| 回测可视化 | 回测报告Markdown | 可满足需求 |
