### 3.2 大盘状态识别 (Market Regime Detection)

**这是整个量化系统的第一道关卡**：

```python
class MarketRegimeDetector:
    """市场状态识别器 - 系统第一模块"""

    def detect(self, index_data: pd.DataFrame) -> dict:
        """
        识别大盘状态
        输入: 沪深300/中证500/上证指数数据
        输出: 市场状态 + 仓位建议 + 策略池
        """
        # 1. 判断趋势方向
        trend = self._detect_trend(index_data)

        # 2. 判断波动率
        volatility = self._detect_volatility(index_data)

        # 3. 判断量能
        volume = self._detect_volume(index_data)

        # 4. 综合判断状态
        regime = self._synthesize_regime(trend, volatility, volume)

        return {
            'regime': regime,
            'position_limit': self.position_map[regime],
            'strategy_pool': self.strategy_map[regime],
            'risk_params': self.risk_map[regime]
        }
```
