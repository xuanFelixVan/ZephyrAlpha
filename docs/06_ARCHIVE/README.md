## 归档原则

| 原则 | 说明 |
|------|------|
| **统一归档** | 所有模块的历史文档统一到06_ARCHIVE/ |
| **分类存储** | 按模块分子目录：06_ARCHIVE/main/、06_ARCHIVE/factor-library/ |
| **永久保留** | 所有历史版本永久保留，供追溯查阅 |
| **索引完备** | 每个归档有README索引，说明归档内容和原因 |

## 归档操作规范

### 归档时机

1. **文档拆分时**：大型文档拆分后，原文档归档
2. **版本升级时**：重大版本迭代前的文档归档
3. **模块废弃时**：模块废弃后，相关文档迁移到06_ARCHIVE/

### 归档操作

1. 将文档移入对应模块的archive子目录
2. 创建/更新归档索引 `README.md`
3. 更新本文档（06_ARCHIVE/README.md）
4. 确保原引用路径已更新

### 禁止操作

- ❌ 不要在归档目录添加新内容
- ❌ 不要修改归档文件内容（除非修正错误）
- ❌ 不要删除任何归档文件

## 遗留文件说明

### 中文文件名说明

本目录中存在部分中文文件名（如 `量化策略框架_v3.1.md`），这是历史遗留问题。

**处理策略**：
- 短期：保持现状，不影响当前使用
- 长期：如有跨平台需求，可重命名为英文/拼音

**PATH_STANDARD.md 规范**：
- 新建文件禁止使用中文命名
- 详见：[05_IMPLEMENTATION/PATH_STANDARD.md](../05_IMPLEMENTATION/PATH_STANDARD.md)
