## overlap_* 文件规则（避免“事实孤儿”）



> **定义**：`overlap_*.md` 表示在某次合并/迁移/去重过程中产生的 **重叠副本或中间产物**。  

> 它们通常具有追溯价值，但不应作为“权威入口正文”长期漂在根部无人可找。



### 规则



1. **必须可回溯到 canonical**：在每个 `overlap_*.md` 的文首或文末，补一行说明它对应的 canonical 位置（若无 canonical，则明确“仅供追溯/不再维护”）。  

2. **必须有入口索引**：至少在 `docs/06_ARCHIVE/README.md` 或本索引中提供聚合入口（避免孤儿）。  

3. **命名必须含时间戳**：已满足（如 `*_20260407_190203`），后续新增保持一致。  

4. **清理策略**：当 canonical 已稳定且追溯期结束（例如 30/90 天），允许移动到专门子目录或删除，但必须在索引中记录处置动作与日期。
