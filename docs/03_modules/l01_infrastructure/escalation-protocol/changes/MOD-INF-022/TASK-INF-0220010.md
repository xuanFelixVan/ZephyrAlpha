# D-022-10 Meta-Confidence实现

> task_id: TASK-INF-0220010 | source: MOD-INF-022 §2.10+§2.16 + D-022-10 | priority: P0

## 目标

实现双层置信度系统。第一层(confidence_estimator): Agent对自身操作的自评。第二层(meta_confidence): 引擎对自身判定质量的元评估。两层的非对称性是关键——引擎不仅要判定Agent的操作，还要评估自己判定得对不对。

## 触发条件
- escalation_engine.py 已完成

## 执行步骤
### 读
蓝图 §2.10(置信度驱动升级) + §2.16(Meta-Confidence) + D-022-10

### 做
1. ConfidenceEstimator: Agent自评+滑动窗口(1000次)历史准确率
2. AutoCalibrator: 定期对比预期vs实际→更新校准参数
3. MetaConfidence: 引擎判定质量自评
4. CorrectionEngine: 低置信度(<0.7)→降级修正逻辑
5. 集成 escalation_engine: evaluate()→{decision,confidence,meta_confidence}

### 产
- confidence_estimator.py + meta_confidence.py + test
