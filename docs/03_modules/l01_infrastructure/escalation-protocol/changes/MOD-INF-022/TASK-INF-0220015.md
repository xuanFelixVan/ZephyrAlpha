## 目标

量化交易系统有不同于通用IT系统的升级触发场景。三级动态阈值适配盘中、盘后、周末的不同升级节奏。

核心约束：
- Paper环境中AI操作可宽松——失败=学习机会
- Live环境中AI操作极度保守——失败=真金亏损
- PnL耦合作为升级输入——浮亏越大，升级越激进
