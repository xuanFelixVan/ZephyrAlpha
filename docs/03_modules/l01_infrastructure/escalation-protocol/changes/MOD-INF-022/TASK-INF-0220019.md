> task_id: TASK-INF-0220019 | source: MOD-INF-022 §2.27 + D-022-19 | priority: P0

## 目标
单Provider故障→升级协议自身失效(判定逻辑依赖LLM)。五级降级链确保升级引擎在模型级故障中仍然有判定能力——降级链的最高层级是ALL_STOP：全Provider不可用=拒绝一切AI自主操作。

## 执行步骤
1. HealthChecker: 每30s ping各Provider
2. FailoverEngine: 自动切换+5s内完成
3. GeoRedundancy: 每个Provider≥2 regions
4. ALL_STOP gate: 全Provider不可用→blocked+P0
