# D-022-03 经济护栏实现

> task_id: TASK-INF-0220004 | source: MOD-INF-022 §2.4 + D-022-03 | priority: P0

## 目标

实现 Token 预算经济护栏和模型降级策略。1人+AI维护的语境下经济护栏是生命线——87%成本超支来自过度自主(AICosts.ai数据)。将此防御硬编码为不可协商的自动行为。

核心机制：
- TokenBudgetTracker: 实时追踪每次LLM调用的token消耗
- ModelCascadeEngine: DS→GLM→Claude→Local逐级降级
- CostAuditor: 结构化成本审计日志
- TokenBudgetGuard: 超支150%硬中断触发

## 触发条件

- TASK-INF-0220002（引擎+规则集）已完成——经济护栏判定依赖engine.evaluate()

## 执行步骤

### 读
- 蓝图 §2.4 + D-022-03: Token预算+模型降级决策详情

### 做
1. 实现 TokenBudgetTracker——monthly_budget=1B, current_usage, reset_date
2. 实现 ModelCascadeEngine——5级降级链配置(DS→GLM→Claude→Local→ALL_STOP)
3. 实现 CostAuditor——每LLM调用记录timestamp/model/tokens/cost
4. 实现 TokenBudgetGuard——150%超支检测+HardKill触发
5. 集成 escalation_engine——超预算→auto_guard判定
