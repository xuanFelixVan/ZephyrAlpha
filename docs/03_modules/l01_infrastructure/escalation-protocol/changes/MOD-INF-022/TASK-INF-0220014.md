# D-022-14 氛围编程AI特有故障防御

> task_id: TASK-INF-0220014 | source: MOD-INF-022 §2.24 + D-022-14 | priority: P0

## 目标

氛围编程(vibe coding)的100% AI施工模式会产生6类不发生在传统软件开发中的故障模式。本任务卡将这些防御硬编码进升级引擎。

6类故障+防御：
1. 跨会话上下文衰减→L1 payload_freeze固化
2. AI自循环升级→max_chain_depth=3
3. 升级通道提示注入→L1 payload_sanitization
4. Token预算爆炸→L1 budget <20K
5. 静默修复回归→post-resolution gate验证
6. 升级规则漂移→定期语义对比

4级渐进自治：
- L1(payload freeze): 最小干预——只保证上下文不衰减
- L2(AI second triage): 独立模型二次判定是否真的需要Owner
- L3(graduated autonomy): SPoHF+每日quota+批量窗口+通俗翻译
- L4(blameless postmortem): 事后复盘+训练数据反馈
