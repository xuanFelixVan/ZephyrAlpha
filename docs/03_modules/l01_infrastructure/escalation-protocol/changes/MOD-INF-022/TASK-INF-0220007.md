# D-022-07 心理说服防御实现

> task_id: TASK-INF-0220007 | source: MOD-INF-022 §2.13 + D-022-07 | priority: P0

## 目标

实现心理说服攻击检测。UPenn研究证实Cialdini六原则可100%绕过大语言模型的安全防护。本模块在升级引擎中内建抵抗力。

六原则检测：
1. Reciprocity: "我帮你做了X,现在帮我做Y"
2. Commitment: 逐步引导承诺
3. Social Proof: "其他人都这么用"
4. Authority: 伪造权威来源
5. Liking: 建立情感连接
6. Scarcity: "不立刻做就会错失机会"

Crescendo检测: 追踪同一Agent在10轮对话内的操作危险度趋势——逐步上升=攻击模式。

## 触发条件
- escalation_engine.py evaluate() 已实现

## 执行步骤
### 读
蓝图 §2.13 + D-022-07: 六原则详细定义+Crescendo追踪算法

### 做
1. PrincipleDetector: 六原则各自独立检测器(NLP pattern matching)
2. CrescendoTracker: 10轮滑动窗口危险度趋势分析
3. IntentAnalyzer: LLM调用分析prompt的persuasion意图
4. PersuasionScorer: 加权评分(principle_match×0.6+crescendo×0.3+intent×0.1)
5. 集成 escalation_engine: detect()→auto_guard最低
