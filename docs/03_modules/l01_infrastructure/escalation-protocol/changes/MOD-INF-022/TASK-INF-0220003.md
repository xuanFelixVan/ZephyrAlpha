# D-022-02 自动委托协议实现

> task_id: TASK-INF-0220003 | source: MOD-INF-022 §2.2 + D-022-02 | priority: P0

## 目标

实现自动委托协议——Agent间的能力匹配委托机制，附带四级安全约束防止死锁和无限循环。

四级约束：
1. 自委托禁止——Agent不能委托给自己
2. 循环检测——委托链中不允许出现重复Agent（DFS环检测）
3. 深度上限=3——最多3层委托（对齐MIT CORDIAL实证：depth=3降低87%死锁率）
4. SLA超时=30s——每层委托30s超时→超时触发compensation

关键约束：
- 委托失败→exponential backoff补偿策略（3次重试后放弃→升级Owner）
- 委托上下文包（7字段结构化传递）
- injected_before/after 钩子在每次委托前后执行
