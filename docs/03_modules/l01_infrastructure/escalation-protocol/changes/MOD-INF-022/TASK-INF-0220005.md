# D-022-04 规则不可变保护实现

> task_id: TASK-INF-0220005 | source: MOD-INF-022 §2.5 + D-022-04 | priority: P0

## 目标

保护 escalation_rules.yaml 不被 AI 修改。这是升级协议自身安全的第一道防线——如果AI可以修改规则定义，"谁验证验证者"问题从根源上无法解决。

核心机制：
- 启动时 SHA-256 hash 校验
- 运行时文件锁定监控
- AI修改 → blocked + P0升级
- Owner 独享的变更通道

## 触发条件
- TASK-INF-0220002（规则集已定义）

### 做

2. 实现 FileLocker: msvcrt/posix 文件锁定
3. 实现 ChangeDetector: inotify/Watchdog 文件监控
4. 实现 OwnerChangeChannel: 仅Owner可用的变更审批流程
5. 集成 escalation_engine: AI修改=P0 blocked
