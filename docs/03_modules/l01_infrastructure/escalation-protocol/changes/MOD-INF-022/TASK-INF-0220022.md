> task_id: TASK-INF-0220022 | source: MOD-INF-022 §2.30 + D-022-22 | priority: P0

## 目标
Merkle DAG确保每条升级事件不可篡改、不可否认、可在法庭上作为证据。HMAC双重签名抵御单个Agent被攻破后的审计伪造。

## 执行步骤
1. MerkleDAGger: node→parent_hash→event_data→timestamp→merkle_root
2. HMACSigner: engine_sig+timeline_sig双重签名
3. ForensicPackager: 按时间段defensible evidence打包
4. IntegrityChecker: 启动/定期验证
5. StorageEngine: 加密+备份+自动恢复
