  实现 §3.27 API契约一致性验证——三维信任模型：

  L2 类型注解精确度：类型->Optional[str]但无return None→TYPE_OVERAPPROXIMATED/类型->str但实际有return None→

  三维Trust Score：存在性(30%)+行为正确性(40%)+契约一致性(30%)。
  状态：MINOR_INCONSISTENCY(≤2低影响→自动修复)/MAJOR_INCONSISTENCY(类型/异常→WARN+Session Log高亮)/
  CRITICAL_CONTRACT_BREAK(类型低估+连续3次恶化→从影子清单降级为冷规则)。
  实现 §3.28 跨边界克隆感知——不同代码区域差异化策略：
  四大边界：SRC_TEST_BRIDGE(阈值0.8→WARN不阻断+不自动修→"测试可简化但非阻塞")/
  SRC_SCRIPTS_DIVERGENCE(阈值0.75→Session Log高亮+不自动修→"scriptsvs src走向fork")/
  CROSS_LAYER_REDUNDANCY(阈值0.8→CRITICAL级别→"去重最高价值目标"+相似度≥0.95纯函数可auto_fix)/
  VENDORED_REIMPLEMENTATION(阈值0.85→WARN+单向指纹索引+生成"为什么重写三方功能"分析)。
  跨边界auto_fix比同区域内更保守——宁可WARN等Owner不盲修。
