  实现蓝图 §5 退出码五档约定（对齐 MOD-INF-005 §6）：
  exit 0 → PASS — 无重复（扫描范围内零重复组 → GATE-DEDUP PASS）;
  exit 1 → WARN — 发现低/中严重度重复（所有重复组 severity≤medium → GATE-DEDUP WARN 不阻断）;
  exit 2 → ERROR — 发现高/严重重复（任意重复组 severity=high/critical → GATE-DEDUP FAIL 阻断commit）;
  exit 3 → TOOL-ERROR — 扫描器自身故障（AST解析失败/cache损坏且自愈失败/git不可用 → GATE-DEDUP SKIP 记录审计）;
  exit 4 → DEGRADED — 降级运行完成（某Stage失败但降级到更低Stage完成扫描 → GATE-DEDUP PASS with DEGRADED 通过但不阻断）;
  severity判定：critical: similarity≥0.95 AND affected_files≥3 AND category=accidental /
  high: similarity≥0.85 AND affected_files≥2 / medium: similarity≥0.70 OR category=needs_review /
  low: similarity<0.70 OR category=intentional。.
  在 cli.py 中映射所有子命令的退出码→return sys.exit(code)→
  在 report.py 的 YAML/JSON 输出段添加 exit_code + exit_code_description。
