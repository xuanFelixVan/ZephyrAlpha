# TASK-INF-025-0002: Agent Card 模型实现

## 1. 背景

蓝图 §2.2 定义了 Agent Card 数据模型，对标：
- **Google A2A AgentCard §5.5** + Anthropic Agent Spec
- **A2ASECBENCH (ICLR 2026)**：Agent Card 供应链操纵威胁

**D-025-02 决策**：Agent Card 注册入口 = AGENTS.md（非 well-known URI），理由：本地多 IDE 场景无固定域名。

## 2. 施工内容

### 2.1 agent_card.py — Pydantic V2 数据模型
- AgentCard 类（id, name, agent_type, provider, version, capabilities[], status）
- AgentCapability（skill_name, inputSchema, outputSchema）
- CardIntegrity（sha256_fingerprint, signatory）

### 2.2 a2a_registry.py — AGENTS.md 注册
- 解析 AGENTS.md 中 `agent_card:` 块
- 注册 Agent 能力到全局注册表

### 2.3 identity_verifier.py — JWT + SPIFFE
- JWT RS256 签发/校验
- Agent Card 指纹验签
- 克隆检测

### 2.4 a2a_card_registry.py — 供应链完整性
- SHA-256 指纹计算
- 签名强制校验（无签名=拒绝）
- 克隆检测（同指纹、不同签名→ALERT）
