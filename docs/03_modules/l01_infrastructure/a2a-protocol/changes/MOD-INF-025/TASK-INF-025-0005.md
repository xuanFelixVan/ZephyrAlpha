# TASK-INF-025-0005: Supervisor/Coordinator 实现

## 1. 背景

蓝图 §2.5 定义了 A2A Supervisor/Coordinator。**D-025-05**：Coordinator = 规则驱动引擎，非 LLM Supervisor。依据 DPBench：LLM 通信反增死锁，规则引擎确定性+零 Token+不可操纵。

对标 Anthropic Agent Teams Team Lead + Augment Code Coordinator。

## 2. 施工内容

- Filter 阶段：排除不满足能力/负载/安全约束的 Agent
- Score 阶段：亲和性权重 × 负载系数 × 信誉评分
- 进度监控：轮询模式 + 超时检测
- 结果整合 + API 限流协调
