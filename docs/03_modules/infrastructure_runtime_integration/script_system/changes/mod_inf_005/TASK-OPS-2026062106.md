# 批量修复 N-06 module_id 缺少 scope 前缀(135个)

## 目标
根因: 135 个文件的 module_id 缺少 scope 前缀(如 b_context_engine.yaml 应为 D-XXX-b_context_engine.yaml)。
施工步骤:
1. 运行 check_naming_convention.py --scan --warn-only 获取 N-06 违规清单
2. 编写批量修复脚本 fix_n06_scope.py,为每个 module_id 添加正确的 scope 前缀
3. scope 前缀从文件所在目录推导(功能域归属)
4. 运行验证命令确认 N-06 违规=0
验收标准: check_naming_convention.py --scan --warn-only 输出中 N-06 违规数=0

## 验收标准
