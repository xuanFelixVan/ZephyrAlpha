# TASK-INF-009-0034: v0.17.0 AI非确定性 & 反馈回路

## 背景

从蓝图 §36 提取：第十七轮审计——AI系统的根深蒂固的非确定性+系统性认知偏差。方法论：Nassim Taleb(Black Swan+Skin in the Game)+Daniel Kahneman(Prospect Theory+Hot Hand Fallacy)+Peter Grünwald(Safe Data Snooping)。

## 10项盲点

| 类别(P0) | 盲点 | 缓解 |
|----------|------|------|
| AI非确定性 | B484 同一输入不同输出 + B485 质量波动 | Reproducibility Manifest固化seed+version |
| 未来信息泄露 | B486 AI知道"未来"事实→隐藏bias | Time Diff Suite检测时间敏感信息 |
| 宪法文件 | B487 宪法文件未防篡改 | GOV-AI-002等宪法文件SHA256锁定+变更需签名 |
| 幸存者偏差 | B488 失败案例不可见 | Failure Repository强制执行 |
| 概念漂移 | B489 Python/ML生态演化→失效 | Version-Keyed Distribution监测 |
| 热手谬误 | B490 AI连续成功→过度信任 | Watchdog+动态信任度评级 |
| 数据窥探 | B491-B493 反复使用/刚性/自噬 | OOBCV+Adaptation Reserve+Provenance |

## 验收标准
10项各有可验证缓解→Pipeline从"确定性假设"到"概率性现实"。

## 回滚说明
失去10项→Pipeline回到"AI输出是确定的"不安全假设。
