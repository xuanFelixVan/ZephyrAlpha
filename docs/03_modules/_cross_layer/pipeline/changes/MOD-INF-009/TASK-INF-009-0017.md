# TASK-INF-009-0017: CI/CD 范式对齐

## 背景

从蓝图 §17 提取（B100/B96/B102 第七轮审计）：对标 CI/CD Pipeline 的三大范式：
1. **条件执行**：如果 M6 发现产出与期望无差异→审计管线其余节点无意义→skip
2. **中断取消**：正在运行的 dispatch 可以被 Owner 或系统主动取消/修改
3. **Saga 回滚**：部分模块失败时，已完成模块的副作用需补偿撤销

### 3. Saga Rollback（B102）

```python
# dispatch 过程中记录每个模块的副作用
class SagaLogEntry(BaseModel):
    module_id: str
    action: str              # "created_file" | "modified_file" | "deleted_file"
    target_path: str
    backup_content: str|None # 回滚时恢复的原始内容

# 部分失败时执行补偿回滚
async def _saga_compensate(self, saga_log: list[SagaLogEntry]):
    for entry in reversed(saga_log):  # 逆序撤销
        if entry.action == "created_file":
            delete(entry.target_path)
        elif entry.action == "modified_file":
            restore(entry.target_path, entry.backup_content)
```

## 验收标准

1. M6 no-diff → M7/M8/M9标记SKIPPED
2. cancel 信号 → 活跃dispatch在3s内中断
3. Saga rollback → 恢复所有被修改文件到原始状态

## 回滚说明

回退三功能→Pipeline恢复全链路无条件执行、不可取消、无回滚。
