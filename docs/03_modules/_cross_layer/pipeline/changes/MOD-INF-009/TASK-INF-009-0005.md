# TASK-INF-009-0005: Pipeline DAG 拓扑实现

## 背景

从蓝图 §5 提取：Pipeline 执行不是线性的——M1-M5 有短路路径（M4 pass→skip to M5），M7/M8/M9可并行。需要 DAG 拓扑模型对标 K8s DAG 工作流 + GitHub Actions jobs.needs。

蓝图 §26 标记 `dag_integration` = 📋 Backlog，`dag_topology` = ✅ implemented（未接入 dispatch）。

## 实现内容

### 1. PipelineDAG 数据模型

```python
class PipelineDAG(BaseModel):
    nodes: list[str]              # ["M1","M2",...,"M11"]
    edges: list[tuple[str,str]]   # [("M1","M2"), ("M2","M3"), ...]
    
    def topological_sort(self) -> list[str]:
        """Kahn's BFS algorithm"""
    def detect_cycle(self) -> bool:
        """DFS cycle detection"""
    def resolve_execution_order(self) -> list[list[str]]:
        """返回拓扑层次——同层可并行"""
```

### 2. A_DAG 拓扑

```
M1 → M2 → M3 → M4 → M5
         └─M4 pass→skip to M5  (短路条件)
```

### 3. B_DAG 拓扑

```
M6 → M7 ─┐
    → M8 ─┼→ M10 → M11
    → M9 ─┘
```

M7/M8/M9 无依赖关系→可并行执行。

### 4. 调度执行接入

- dispatch() 使用 `A_DAG.resolve_execution_order()` 替代硬编码线性序列
- 同层节点（如 M7/M8/M9）→ ThreadPoolExecutor 并行执行
- 短路条件（M4 pass→skip M5）在 DAG 遍历时动态判断

## 验收标准

1. A_DAG/B_DAG 拓扑正确
2. Kahn 拓扑排序产出正确顺序
3. 负环检测生效
4. dispatch 接入 DAG 后可替代线性序列
5. M7/M8/M9 并行执行节省时间

## 回滚说明

回退 pipeline_orchestrator.py 中 DAG 相关代码。移除 resolve_execution_order 调用，恢复线性 dispatch 序列。
