# TASK-INF-009-0046: v0.31.0 可移植性

## 背景

从蓝图 §51 提取：第三十一轮审计——Pipeline 不应该被锁定在任何一个模型提供商/操作系统/基础设施上。对标云原生可移植性原则，防止Vendor Lock-in。

## 6项盲点

- B580 模型提供者抽象层——统一接口适配所有LLM
- B581 Infrastructure-as-Code——Terraform可重建
- B582 跨平台——Windows+Linux双验证
- B583 数据可移植——标准格式不受单一存储绑定
- B584 配置一致——单一config跨环境
- B585 知识可迁移——不丢失vendor specific知识

## 验收标准
6项有验证→Pipeline可以在一周内从一个云迁移到另一个。

## 回滚说明
回到DeepSeek-only→失去模型/平台/数据可移植性。
