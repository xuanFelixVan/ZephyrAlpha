# TASK-INF-009-0028: 依赖关系管理

## 背景

从蓝图 §28 提取：Pipeline 模块依赖 11 个外部模块——从 Task System(运行时调用)到 Capacity Assurance(契约消费)到 Orchestrator(上游调用)。每个依赖关系类型明确：runtime_call / pre_check / config_consume / feedback_to / upstream / downstream / contract_consume / ssoT。

### 依赖健康检查

```python
class DependencyHealthChecker:
    async def check_all(self) -> dict[str, str]:
        """检查所有依赖模块是否可用"""
        results = {}
        for mod_id, dep in PIPELINE_DEPENDENCIES.items():
            if dep.relation == "runtime_call" or dep.relation == "pre_check":
                results[mod_id] = await self._ping(dep)
        return results
```

## 验收标准

1. 11个依赖全部有对应 import/接口
2. 依赖缺失时 dispatch 显式失败（非静默）
3. 依赖状态健康检查可执行

## 回滚说明

移除依赖导入→Pipeline恢复孤立运行→失去外部能力集成。
