# TASK-INF-009-0050: v0.35+v0.36 Hardware Self-Awareness + Systemic Weakening

## 背景

从蓝图 §55+§56 提取：最后两轮审计——Pipeline的元认知（知道自己是谁/在哪/状态如何）+ 识别系统性弱化模式（跨所有维度的退化加速的根因）。

## 14项盲点

**v0.35.0(B611-B620)：**
- P0: B611 System Self-Awareness—知晓自己运行在哪台机/CPU/内存/磁盘/网络
- P1: B612 Graceful Degradation under Resource Pressure—CPU满载时偷跑
- P0: B613 "I'm tired" Transparency—"我今天处理了很多，可能不太准确"
- P1: B614 Human-AI Trust Calibration—校准Owner对Pipeline的信任度
- Soft Skills: B615 Sympathetic/B616 Teachable/B617 Companion/B618 Feedback Acceptance/B619 Respect/B620 Collaborative Horizon

**v0.36.0(B621-B624)：**
- B621 Complex Dishes Effect —子系统间依赖造成比单独各系统更大退化
- B622 Fan Speed Prophecy —冷却系统粒度—风扇快=要炸—温度影响CPU降速
- B623 Trust Paradox —相信Owner不相信AI→我修了—delete→相信AI→修正me
- B624 Implicit Noise Normalization—标准变动的原罪+Group Normalization隐

## 验收标准
14项有检测→Pipeline有自我意识+知道自己的弱点。

## 回滚说明
