# TASK-INF-009-0038: Pipeline 经济学 + 数字员工

## 背景

从蓝图 §40+§41 提取：Pipeline 从纯技术组件升华为有经济学和人力资源维度的完整实体。

- **v0.21.0**：Pipeline作为投资——什么时候回本？成本结构是什么？什么时候该退役？
- **v0.22.0**：Pipeline作为员工——绩效如何？ burnout了没？职责清晰吗？

## 12项盲点

**第8维度 经济学(B520-B525)：**
- B520 T+0→T+24m TCO成本模型——初期建设+API月费+运维人力+机会成本
- B521 Cost per Successful Dispatch——有用产出/总成本
- B522 Break-Even——什么时候回本
- B525 Sunk Cost治理——"已经花了这么多不能停"的认知偏差

**第9维度 数字员工(B526-B531)：**
- B526 FTE-Worth——Pipeline等效多少FTE(全时工作当量)
- B528 Role Clarity & Ambiguity——Pipeline的每个模块职责清晰度
- B529 Burnout喷雾监测——过度使用/饱和/退化→需要休息/重构
- B530 Peer Review缺失——Self-Review替代→质量评估
- B531 OKR & Job Crafting——Pipeline为自己设定OKR+调整工作

## 验收标准
12项有量化指标→Pipeline从"一段代码"到"有经济学+人事档案的数字存在"。

## 回滚说明
回到纯技术视角—丢失"投资回报"和"员工绩效"双重身份。
