# TASK-INF-009-0010: ModuleOutput Schema 实现

## 背景

从蓝图 §10 提取（B37 第四轮审计）：每个 M 模块的输出必须有定义良好的 Schema，防止下游消费错误格式。8个专用子类对应 M1-M11 不同产出 + GenericModuleOutput 兜底。

## 实现内容

### 8个专用 ModuleOutput 子类

```python
class ParseOutput(ModuleOutput):      # M1 → 结构化执行计划
    parsed_plan: dict
    task_breakdown: list[str]

class ContextOutput(ModuleOutput):    # M2 → 上下文装配结果
    assembled_context: dict
    sources_used: list[str]

class GenerateOutput(ModuleOutput):   # M3 → 代码/文档生成
    generated_code: str
    language: str
    file_path: str|None

class FormatOutput(ModuleOutput):     # M4 → 格式校验
    format_report: dict
    lint_errors: list[str]

class PackageOutput(ModuleOutput):    # M5 → 产物打包
    package_path: str
    files_included: list[str]
    package_hash: str

class DiffOutput(ModuleOutput):       # M6 → 差异检测
    diff_summary: dict
    added_files: list[str]
    modified_files: list[str]
    deleted_files: list[str]

class ReviewOutput(ModuleOutput):     # M7 → 深度审查
    review_report: dict
    findings: list[dict]
    risk_flags: list[str]

class ComplianceOutput(ModuleOutput): # M8 → 标准合规
    compliance_report: dict
    violations: list[dict]
    standard_refs: list[str]
```

### validate_module_output

```python
def validate_module_output(module_id: str, output: dict) -> bool:
    """按模块ID选择Schema→Pydantic验证"""
    schema_map = {
        "M1": ParseOutput, "M2": ContextOutput, "M3": GenerateOutput,
        "M4": FormatOutput, "M5": PackageOutput, "M6": DiffOutput,
        "M7": ReviewOutput, "M8": ComplianceOutput,
    }
    # M9/M10/M11 → GenericModuleOutput
```

## 验收标准

1. 8个子类通过 Pydantic validation
2. validate_module_output 对合法输出返回 True
3. GenericModuleOutput 对任意未知输出不抛异常
4. B37 upstream 依赖声明可追溯
