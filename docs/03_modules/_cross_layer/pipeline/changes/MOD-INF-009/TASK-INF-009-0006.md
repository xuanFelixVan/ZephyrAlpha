# TASK-INF-009-0006: Artifact 传递系统实现

## 背景

从蓝图 §6 提取：Pipeline 各模块之间有产出物传递需求——M1 产出解析计划 → M2 消费、M3 产出代码 → M4 校验 → M7 审查。对标 CI/CD Artifacts 机制（如 GitHub Actions upload/download-artifact），每个模块产出需要打包为 Artifact 并注册到 Manifest。

## 实现内容

### 1. PipelineArtifact

```python
class ArtifactClassification(str, Enum):  # B138
    PUBLIC = "public"
    INTERNAL = "internal"
    CONFIDENTIAL = "confidential"
    RESTRICTED = "restricted"

class PipelineArtifact(BaseModel):
    artifact_id: str
    type: str               # "code" | "document" | "report" | "finding" | ...
    source_module: str      # "M3"
    content: str
    path: str | None
    size: int
    hash: str               # SHA256
    timestamp: str
    classification: ArtifactClassification
```

### 2. PipelineArtifactManifest

```python
class PipelineArtifactManifest(BaseModel):
    pipeline_id: str
    task_id: str
    artifacts: list[PipelineArtifact]
    meta: dict              # 扩展元数据
    created: str
```

### 3. ModuleInput

```python
class ModuleInput(BaseModel):
    module_id: str          # 当前模块
    previous_artifacts: list[PipelineArtifact]  # 上级模块产出
    context: dict           # 额外上下文
    
    def validate(self) -> bool:
        """校验所需 Artifact 是否齐全"""
```

## 验收标准

1. PipelineArtifact 包含 SHA256 hash
2. Manifest 包含所有 pipeline 产出的 Artifact
3. ModuleInput.validate() 在校验缺少 Artifact 时返回 False
4. Artifact分类标签四级与 B138 对齐

## 回滚说明

回退 pipeline_orchestrator.py 中 Artifact 和 Manifest 代码。下游模块失去 ModuleInput 校验能力。
