# TASK-INF-009-0011: Telemetry 遥测实现

## 背景

从蓝图 §11 提取（B67 第六轮审计 + CT-PIPE-ORC-001 契约）：Pipeline 必须有遥测能力——可观察每一次 dispatch 的耗时、模型调用次数、降级频率。对标 OpenTelemetry Metrics + Traces。

CT-PIPE-ORC-001 要求 Pipeline 在 dispatch 完成后 emit PIPELINE_COMPLETE 事件到 EventBus，含 cost + duration + result。

## 实现内容

### 1. 3 Metrics

```python
# Histogram: dispatch总耗时
dispatch_latency_seconds = Histogram("pipeline_dispatch_latency_seconds", "Dispatch duration")

# Counter: dispatch总次数（按pipeline/status分区）
dispatch_count = Counter("pipeline_dispatch_total", "Total dispatches", ["pipeline", "status"])

# Counter: 模型降级次数
model_fallback_count = Counter("pipeline_model_fallback_total", "Model fallbacks", ["from", "to"])
```

### 2. 3 Trace Spans

```
pipeline_dispatch (root span)
├── module_execute:M3 (child span)
│   └── model_call:deepseek (leaf span)
├── module_execute:M7 (child span)
│   └── model_call:glm (leaf span)
└── ...
```

### 3. TelemetryEmitter

```python
class TelemetryEmitter:
    metrics: MetricsRegistry
    tracer: TracerProvider
    
    def record_dispatch(self, result: PipelineResult):
        """记录一次dispatch的所有metrics+traces"""
    def record_module_execution(self, module_result: ModuleResult):
        """记录单个模块执行"""
    def emit_pipeline_complete(self, result: PipelineResult):
        """CT-PIPE-ORC-001：PIPELINE_COMPLETE事件→EventBus"""
```

## 验收标准

1. dispatch_latency_seconds 记录每次 dispatch 耗时
2. model_fallback_count 记录降级次数（如 deepseek→glm）
3. 3层 trace span 覆盖全链路
4. PIPELINE_COMPLETE 事件含 cost_usd + duration_seconds
