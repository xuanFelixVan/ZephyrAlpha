# TASK-INF-009-0018: OPA 范式对齐

## 背景

从蓝图 §18 提取（B101/B106 第七轮审计）：对标 Open Policy Agent (OPA) 的 Decision Log 和 `opa test`：
- Pipeline 的路由决策是可审计的——每次 dispatch 选择 M 节点+模型的理由应被记录
- 路由策略应该是可测试的——"给定 TaskCard X → 期望路由到 Y" 这类断言应可自动验证
