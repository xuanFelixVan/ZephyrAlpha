### B284: 蓝图-代码漂移检查器

```python
class BlueprintCodeDriftChecker:
    """每次CI/PR自动验证 blueprint↔code的一致性"""
    
    def check(self, blueprint: Blueprint, codebase: Codebase) -> DriftReport:
        # 蓝图声明的模块→在代码中存在？
        # 蓝图描述的函数签名→与代码一致？
        # 蓝图列出的文件路径→磁盘存在？
        
        for section in blueprint.sections:
            for claim in section.code_claims:
                actual = codebase.resolve(claim.path)
                if not self._matches(claim, actual):
                    drifts.append(DriftEntry(claim, actual))
        
        return DriftReport(drifts)
```
