# TASK-INF-009-0045: v0.30.0 时间治理

## 背景

从蓝图 §50 提取：第三十轮审计——Pipeline 是时间敏感的实时交易系统，但时间本身可能是不一致的（多机器/NTP偏移/夏令时）。对标 Google Spanner TrueTime API。

## 6项盲点

- B574 时钟同步——多设备NTP+WTS保持<10ms偏差
- B575 时序一致性——Lamport时钟确保分布式事件顺序
- B576 强时效操作——交易指令过期=无效
- B577 历史可重现——时间旅行重放任何历史dispatch
- B578 时区归一化——UTC存储+本地展示
- B579 数据时间衰减——Temporal Freshness Score 0.0-1.0

## 验收标准
6项有实现→Pipeline知道"现在"是真的"现在"。

## 回滚说明
回到不检查时钟→时序混乱可导致重复交易或漏单。
