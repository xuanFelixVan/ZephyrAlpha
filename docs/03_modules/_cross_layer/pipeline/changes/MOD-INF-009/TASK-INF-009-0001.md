# TASK-INF-009-0001: Pipeline 模块骨架搭建

## 背景

从蓝图 §1 提取：MOD-INF-009 Pipeline 模块是 ZephyrAlpha 的任务调度中心 + AI 模型路由器。每个 TaskCard 进入管线 → Pipeline 根据任务类型/优先级/复杂度 → 匹配到 M1-M11 的具体节点 → 分配执行模型 + sandbox + gate_profile → 逐模块执行 → 产出物传递给下游 → 门禁裁决。

7 个源码文件 + 1 个测试文件落位于 `src/zephyr/pipeline/`。

## 实现内容

### 1. 模块目录初始化

```
src/zephyr/pipeline/
  __init__.py          # 模块导出
  models.py            # Pydantic V2 数据模型（全部 30+ 类）
  pipeline_orchestrator.py  # 管线协调器
  ct_pipe_routing.py   # CT-PIPE-ORC-001 路由解析
  routing_plugins.py   # K8s Filter→Score→Bind 插件架构
  pipeline_lock.py     # 并发文件锁
  pipeline_agent_bridge.py  # Pipeline→AgentOrchestrator 桥接
```

### 2. __init__.py 导出符号

导出 30+ 公开符号，包括：
- PipelineRouteDecision / ModuleResult / PipelineResult
- PipelineOrchestrator / PipelineRouter
- PipelineLock / PipelineAgentBridge
- ModuleOutput / validate_module_output
- LifecycleManager / TelemetryEmitter
- 所有 v0.8.0-v0.9.0 新增模型类

### 3. script_manifest.yaml 注册

在 `D:\ZephyrAlpha\scripts\governance\script_manifest.yaml` 注册 MOD-INF-009 模块条目。

## 验收标准

1. `src/zephyr/pipeline/` 目录存在
2. `__init__.py` 存在且可导入
3. 模块出口符号 ≥ 30
4. script_manifest.yaml 中 MOD-INF-009 已注册
5. 核心职责文档与蓝图 §1 一致
