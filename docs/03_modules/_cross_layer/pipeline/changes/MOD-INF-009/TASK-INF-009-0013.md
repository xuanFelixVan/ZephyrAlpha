# TASK-INF-009-0013: Zone Crossing 防线（AP2）

## 背景

从蓝图 §13 提取（B70 第六轮审计）：AP2 = "A区产出物必须经 M5 打包→M6 边界标记（AP2），不可跨区直通"。这是一个硬安全约束——防止 A 区生成的代码绕过 B 区审计直接上线。

对标的实践：
- NIST SP 800-53 → CM-5 "Access Restrictions for Change"
- NASA Fault Tree → "Human Factors Barrier between Production and Verification"

## 实现内容

### 1. Zone Crossing 校验

```python
def _validate_zone_crossing(
    source_module: str,      # 当前模块ID
    target_module: str,      # 目标模块ID
    artifacts: list[PipelineArtifact]
) -> bool:
    """
    A区产出(M1-M5) → B区消费(M6-M11) 必须经过M5打包+M6边界标记
    任何直通路径 = ABORT
    """
    # 如果源在A区、目标在B区
    source_zone = "A" if source_module in A_ZONE else "B"
    target_zone = "A" if target_module in A_ZONE else "B"
    
    if source_zone == "A" and target_zone == "B":
        # 跨区必须经过M5→M6
        if not all(a.has_boundary_stamp("M6") for a in artifacts):
            raise ZoneCrossingViolation("A→B跨区未经M5打包+M6边界标记")
    
    return True
```

### 2. M6 边界标记（AP2 Boundary Stamp）

M6 职责：为 A 区产出物盖 AP2 边界戳——`artifact.meta["ap2_stamp"] = {"m6_module": True, "diff_validated": True, "timestamp": "..."}`。

只有盖了此戳的 A 区产出物，B 区后续模块（M7/M8/M9）才能消费。

### 3. Zone 常量定义

```python
A_ZONE = {"M1","M2","M3","M4","M5"}
B_ZONE = {"M6","M7","M8","M9","M10","M11"}
```

## 验收标准

1. A区产出直通B区(不经M6)→拒绝(ZoneCrossingViolation)
2. M5打包+M6边界标记→B区可消费
3. _validate_zone_crossing 在 dispatch 时每步关联校验

## 回滚说明

回退 ZoneCrossing 校验→Pipeline失去跨区防护→A区bug可绕过审计直接上线。
