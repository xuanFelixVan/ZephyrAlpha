# TASK-INF-009-0044: v0.29.0 实验与决策治理

## 背景

从蓝图 §49 提取：第二十九轮审计——Pipeline 必须像科学实验一样治理自己的决策。对标 Optimizely + LaunchDarkly + A/B Testing Best Practices。

## 6项盲点

- B568 实验设计框架——hypothesis/variant/metric/sample/analysis
- B569 统计严谨性——不p-hacking+Bonferroni校正
- B570 决策审计追踪——每个路由选择完整可追溯
- B571 反事实分析——模拟'如果当时选了另一个'
- B572 探索-利用平衡——Epsilon贪心→动态调整
- B573 决策疲劳防护——过多选择→预设安全默认

## 验收标准
6项有实现→Pipeline从"碰运气"到"科学决策"。

## 回滚说明
