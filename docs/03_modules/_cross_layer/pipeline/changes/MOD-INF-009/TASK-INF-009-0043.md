# TASK-INF-009-0043: v0.28.0 通信架构

## 背景

从蓝图 §48 提取：第二十八轮审计——Pipeline 作为半自主Agent如何与Owner沟通？对标 PagerDuty On-Call Engineering。

## 6项盲点

- B562 信噪比治理——非重要通知=静默
- B563 多渠道路由——Feishu/SMS/Email/Desktop
- B564 升级阶梯——无人响应→自动升级
- B565 偏好学习——从Owner的行为学怎么通知
- B566 宕机时通信——带外通道
- B567 定期摘要——不是每条事件都要推送

## 验收标准
6项有实现→Owner不被消息淹没，但关键件事不遗漏。

## 回滚说明
回到"扔到EventBus就不管了"——失去精心设计的通知策略。
