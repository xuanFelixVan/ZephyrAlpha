## 施工步骤

### Step 1: Resource 原语实现（Phase 6，关闭 B2/B41）
- 新建 `src/zephyr/mcp/resource_provider.py`
- 实现 ResourceProvider 统一接口：register_resource(uri, name, mime_type, handler)
- 注册至少 3 类资源：蓝图资源（blueprint://{module_id}） / 任务卡资源（task://{task_id}） / 测试报告资源（report://{module_id}）
- 在 `_base_server.py` 的 `_handle_request` 中新增 resources/list 和 resources/read 分派
- 产出：resource_provider.py + _base_server.py 扩展
- 检查：`resources/list` → 返回所有已注册资源 URI；`resources/read(uri="blueprint://MOD-INF-013")` → 返回蓝图内容

### Step 2: Prompt 原语实现（Phase 6，关闭 B3）
- 新建 `src/zephyr/mcp/prompt_provider.py`
- 实现 PromptProvider 统一接口：register_prompt(name, description, arguments, template_handler)
- 注册至少 5 个模板：代码审查模板(code_review) / 任务卡创建模板(task_card_create) / 蓝图分解模板(blueprint_decompose) / 测试生成模板(test_generation) / 架构评审模板(architecture_review)
- 在 `_base_server.py` 的 `_handle_request` 中新增 prompts/list 和 prompts/get 分派
- 产出：prompt_provider.py + _base_server.py 扩展
- 检查：`prompts/list` → 返回所有已注册 prompt；`prompts/get(name="code_review", arguments={...})` → 返回渲染后的 prompt 文本

### Step 3: sandbox MCP Server（Phase 7，关闭 B4）
- 新建 `src/zephyr/mcp/sandbox_server.py`
- 实现关键安全约束：
  - 代码在独立 subprocess 中执行（`subprocess.run(..., timeout=30)`）
  - 输入限制：code + stdin 最大 500KB
  - 输出截断：stdout/stderr 最大 1MB
  - 禁止网络访问（无 socket 权限）
  - 禁止文件系统写入（仅读写 /tmp 临时目录）
  - 超时强制杀死进程（30s 默认）
- tool 注册：sandbox.execute(code, language, stdin, timeout) → {stdout, stderr, exit_code, truncated, duration_ms}
- 产出：sandbox_server.py
- 检查：sandbox.execute("print('hello')", "python") → {stdout: "hello\n", exit_code: 0}
- 新建测试：`tests/unit/test_sandbox_mcp.py`

### Step 4: 原语覆盖表更新
- 更新 §3.3 MCP 原语表：resources/list/read → ✅ / prompts/list/get → ✅
- 更新 _base_server.py docstring 原语覆盖表
- 产出：蓝图 §3.3 更新 + _base_server.py docstring 更新
- 检查：`python -c "help('src.zephyr.mcp._base_server')"` 含完整原语表
