## 💡 测试建议

### 1. **优先级**
- **高优先级**：File System, Fetch, GitHub, Snyk, semgrep（开发常用）
- **中优先级**：context7, Qdrant, SequentialThinking（辅助工具）
- **低优先级**：Excel, PostgreSQL, Playwright（特定场景）

### 2. **测试顺序**
```
1. File System（基础文件操作）
2. Fetch（网络功能）
3. GitHub（代码管理）
4. Snyk + semgrep（代码安全）
5. Qdrant（向量搜索）
6. 其他工具
```

### 3. **问题处理**
如果某个工具测试失败：
- 检查配置文件（mcp.json）
- 查看错误日志
- 确认依赖服务是否运行
- 检查 API 密钥是否正确
