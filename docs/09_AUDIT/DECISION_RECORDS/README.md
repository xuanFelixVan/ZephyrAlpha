## 6. 使用指南

### 6.1 如何创建决策记录

1. 确定决策类型（交易/策略/风险/架构/模型）
2. 分配编号：DR-{TYPE}-{DATE}-{SEQ}
3. 复制[决策记录模板](../TEMPLATES/DECISION_RECORD_TEMPLATE.md)
4. 填写内容并保存到本目录
5. 更新本索引文件

### 6.2 如何更新索引

**新增决策记录时**:
1. 在对应类型列表中添加条目
2. 更新统计数据
3. 更新最近更新列表

**更新决策记录时**:
1. 更新对应条目的状态
2. 更新最后更新日期
3. 更新统计数据

## 7. 决策记录编号规则

### 7.1 编号格式

```
DR-{TYPE}-{DATE}-{SEQ}
```

**说明**:
- **DR**: Decision Record（决策记录）
- **TYPE**: 决策类型（TRADE/STRATEGY/RISK/ARCH/MODEL）
- **DATE**: 日期（YYYYMMDD）
- **SEQ**: 序号（001-999）

### 7.2 编号示例

- DR-TRADE-20260402-001: 交易决策记录
- DR-STRATEGY-20260402-001: 策略决策记录
- DR-MODEL-20260402-001: 模型决策记录
