## 1. 概述

### 1.1 文档目的

本清单列出了允许存在于非标准分类目录的特殊文档，确保文档分类规范的灵活性和实用性。

### 1.2 适用范围

本清单适用于ZephyrAlpha系统中所有不符合标准分类但具有合理性的文档。

### 1.3 例外原则

例外文档必须满足以下原则之一：
1. **通用性原则**: 文档具有全局通用性，不适合放入特定分类
2. **工具性原则**: 文档是工具或配置文件，不属于业务文档
3. **历史性原则**: 文档具有历史价值，需要保留在原位置
4. **技术性原则**: 文档受技术限制，无法移动到标准位置

## 6. 例外管理流程

### 6.1 新增例外申请流程

```
发现潜在例外文档
  ↓
填写例外申请表
  ↓
提交首席架构师审查
  ↓
审查通过？
  ├─ 是 → 添加到例外清单
  └─ 否 → 移动到标准目录
```

### 6.2 例外审查流程

```
定期审查例外清单
  ↓
评估例外合理性
  ↓
例外仍然有效？
  ├─ 是 → 保留例外状态
  └─ 否 ↓
移动到标准目录
  ↓
更新例外清单
```

### 6.3 例外撤销流程

```
发现例外不再适用
  ↓
确定目标标准目录
  ↓
移动文档并更新引用
  ↓
从例外清单中移除
  ↓
更新相关索引
```

## 8. 质量保证

### 8.1 验证标准

- [ ] 所有例外文档都有明确的例外理由
