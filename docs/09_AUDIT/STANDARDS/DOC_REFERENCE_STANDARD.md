## 二、文档引用原则

### 2.1 核心原则

**原则1: 完备性原则**
- 每个文档都必须有明确的引用关系
- 框架层文档必须引用实施层文档
- 实施层文档必须引用框架层文档
- 所有文档都应被索引文档引用

**原则2: 准确性原则**
- 引用关系必须准确反映文档间关系
- 引用链接必须有效可访问
- 引用描述必须准确清晰

**原则3: 一致性原则**
- 引用格式必须统一
- 引用位置必须统一
- 引用描述必须统一

**原则4: 可维护性原则**
- 引用关系应易于维护
- 引用变更应易于追踪
- 引用失效应易于发现

## 三、文档引用规则

### 3.1 必须包含的引用章节

**规则**: 每个蓝图文档必须包含"文档职责说明"章节

**章节位置**: 文档开头（在概述之前）

**章节内容**:
- 本文档职责描述
- 相关文档引用
- 职责边界说明

### 3.2 框架层文档引用格式

**格式模板**:
```markdown
## 文档职责说明

**本文档职责**: 框架层架构定义
- 定义整体架构和设计原则
- 规划系统架构层次
- 制定接口规范

**实施层文档**: [实施文档名称](../05_IMPLEMENTATION/06_CONSTRUCTION_DOCS/01_BLUEPRINTS/IMPLEMENTATION_DOC.md)
- 具体实现方案和技术细节
- 核心子系统设计和代码示例
- 部署方案和实施路径
```

**示例**:
```markdown
## 文档职责说明

**本文档职责**: 框架层架构定义
- 定义实时风险监控的整体架构和设计原则
- 分析专业机构（Two Sigma、桥水、Citadel）的实践
- 规划系统架构层次和核心组件接口
- 制定风险监控的关键原则和标准

**实施层文档**: [实时风险对冲引擎蓝图](../05_IMPLEMENTATION/06_CONSTRUCTION_DOCS/01_BLUEPRINTS/REALTIME_RISK_HEDGE_ENGINE_BLUEPRINT.md)

```

## 四、不同类型文档的引用规范

1. **框架层文档**（如果是实施层蓝图）

3. **技术规格书**（如果有）
4. **父文档**（如果有）

**引用位置**: 文档开头或结尾

**引用格式**:
```markdown

**上级索引**: [父索引名称](../INDEX.md)

**同级索引**:
- [索引1名称](../SIBLING1/INDEX.md)
- [索引2名称](../SIBLING2/INDEX.md)

**关键文档**:
- [文档1名称](./DOC1.md)
- [文档2名称](./DOC2.md)
```

## 五、引用关系维护

### 5.1 创建文档时

**步骤**:
1. 确定文档类型（框架层/实施层）
2. 确定相关文档
3. 添加"文档职责说明"章节
4. 添加引用链接
5. 更新被引用文档的引用关系

**检查清单**:
- [ ] 是否添加了"文档职责说明"章节
- [ ] 是否引用了所有相关文档
- [ ] 引用链接是否有效
- [ ] 引用描述是否准确
- [ ] 是否更新了被引用文档

### 5.2 修改文档时

**步骤**:
1. 检查引用关系是否需要更新
2. 更新"文档职责说明"章节
3. 更新引用链接
4. 通知被引用文档的维护者

**检查清单**:
- [ ] 引用关系是否仍然准确
- [ ] 引用链接是否仍然有效
- [ ] 引用描述是否仍然准确
- [ ] 是否需要更新被引用文档

### 5.3 删除文档时

**步骤**:
1. 检查是否有其他文档引用本文档
2. 更新所有引用本文档的文档
3. 移除引用链接或更新为归档路径
4. 删除文档

**检查清单**:
- [ ] 是否检查了所有引用本文档的文档
- [ ] 是否更新了所有引用链接
- [ ] 是否将引用更新为归档路径
- [ ] 是否通知了相关文档的维护者

### 5.4 归档文档时

**步骤**:
1. 更新所有引用本文档的文档
2. 将引用链接更新为归档路径
3. 在归档文档中添加归档说明
4. 移动文档到归档目录

**检查清单**:
- [ ] 是否更新了所有引用链接
- [ ] 引用链接是否指向归档路径
- [ ] 是否添加了归档说明
- [ ] 是否通知了相关文档的维护者

# 分析整个目录
python scripts/reference_analyzer.py --dir docs/05_IMPLEMENTATION

# 分析全系统
python scripts/reference_analyzer.py --all

## 八、常见问题与解决方案

### 问题1: 缺少引用关系

**问题描述**: 文档没有"文档职责说明"章节或引用关系不完整

**解决方案**:
1. 添加"文档职责说明"章节
2. 确定相关文档
3. 添加引用链接
4. 更新被引用文档

### 问题2: 引用链接失效

**问题描述**: 引用的文档不存在或路径错误

**解决方案**:
1. 检查文档是否存在
2. 更新引用路径
3. 如果文档已删除，移除引用或更新为归档路径
4. 如果文档已归档，更新为归档路径

### 问题3: 引用描述不准确

**问题描述**: 引用描述与实际文档内容不符

**解决方案**:
1. 检查被引用文档的实际内容
2. 更新引用描述
3. 确保描述准确反映文档职责

### 问题4: 循环引用

**问题描述**: 文档A引用文档B，文档B又引用文档A

**解决方案**:
1. 分析循环引用的原因
2. 重新设计文档结构
3. 消除循环引用

## 九、规范执行与监督

### 9.1 执行机制

**自动化检查**:
- 使用reference_analyzer.py工具定期检查
- 在CI/CD流程中集成引用检查
- 在文档创建时自动验证引用关系

**人工审查**:
- 在代码审查中检查引用关系
- 在文档审计中检查引用规范
- 在文档发布前检查引用有效性

### 9.2 监督机制

**定期审计**:
- 每周快速扫描：检查新增文档的引用关系
- 每月深度审计：检查全系统引用关系
- 每季度专项审计：检查引用规范执行情况

**问题跟踪**:
- 记录引用关系问题
- 跟踪问题整改进度
- 验证问题整改效果

### 9.3 违规处理

**轻微违规**（引用描述不准确）:
- 口头提醒
- 要求限期整改

**中等违规**（缺少引用关系）:
- 书面警告
- 要求提交整改计划

**严重违规**（引用链接失效）:
- 立即整改
- 纳入绩效考核
