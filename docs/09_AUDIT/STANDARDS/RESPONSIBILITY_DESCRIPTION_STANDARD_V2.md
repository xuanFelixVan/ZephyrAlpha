# 职责描述规范标准 v2.0

> **核心职责**: 定义职责描述的标准格式、审查流程和质量要求
> **职责边界**: 
> - ✅ 本文档负责：职责描述标准制定、模板定义、审查流程设计
> - ❌ 本文档不负责：具体文档的职责描述编写、职责冲突解决

---

## 📋 规范概要

**规范版本**: v2.0.0  
**适用范围**: 全系统所有Markdown文档  
**规范目标**: 确保职责描述清晰、准确、无重叠  
**规范性质**: 强制性标准

---

## 🎯 职责描述标准格式

### 1. 标准模板

每个文档必须在标题后立即包含职责描述块：

```markdown
> **核心职责**: [一句话描述文档的核心职责]
> **职责边界**: 
> - ✅ 本文档负责：[列出本文档负责的内容]
> - ❌ 本文档不负责：[列出本文档不负责的内容]
> - 📋 相关文档：[列出相关文档链接]
```

### 2. 职责描述要求

#### 2.1 核心职责要求

- **长度**: 一句话，不超过30个字
- **内容**: 准确描述文档的核心功能
- **格式**: 使用动词开头，如"定义"、"描述"、"说明"、"规范"
- **避免**: 模糊词汇，如"相关内容"、"各种信息"

**示例**:

✅ **正确**: 因子计算引擎架构和调度系统设计  
❌ **错误**: 因子相关内容说明

#### 2.2 职责边界要求

**✅ 本文档负责**:
- 列出3-5项具体职责
- 使用动词开头
- 明确、具体、可验证

**❌ 本文档不负责**:
- 列出与相关文档的职责边界
- 避免职责重叠
- 明确排除项

**📋 相关文档**:
- 列出相关文档链接
- 使用相对路径
- 格式：`文档名称`

## 🔍 职责描述审查流程

### 1. 审查时机

- **新建文档**: 创建时必须包含职责描述
- **文档修改**: 修改内容后需检查职责描述是否需要更新
- **定期审查**: 每周自动化检查职责描述完整性
- **问题发现**: 发现职责重叠时立即审查

### 2. 审查标准

| 审查项 | 标准 | 权重 |
|--------|------|------|
| **完整性** | 包含核心职责和职责边界 | 40% |
| **准确性** | 职责描述与文档内容一致 | 30% |
| **清晰性** | 职责描述清晰无歧义 | 20% |
| **规范性** | 符合标准格式要求 | 10% |

### 3. 审查流程

```
1. 自动化检查
   ├── 检查职责描述是否存在
   ├── 检查格式是否符合标准
   └── 生成检查报告

2. 人工审查
   ├── 审查职责描述准确性
   ├── 审查职责边界清晰性
   └── 审查相关文档链接有效性

3. 问题修复
   ├── 自动修复格式问题
   ├── 人工修复内容问题
   └── 验证修复结果

4. 质量确认
   ├── 确认合规率达到标准
   ├── 确认无职责重叠
   └── 更新审查记录
```

## 📊 职责描述质量标准

### 1. 质量指标

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| **覆盖率** | ≥99% | 有职责描述文档数  总文档数 |
| **准确性** | ≥95% | 职责描述与内容一致文档数  总文档数 |
| **清晰性** | ≥90% | 职责描述清晰文档数  总文档数 |
| **规范性** | ≥95% | 格式符合标准文档数  总文档数 |

### 2. 质量等级

| 等级 | 合规率 | 状态 | 行动 |
|------|--------|------|------|
| **优秀** | ≥99% | ✅ | 保持现状 |
| **良好** | 95-99% | ✅ | 持续改进 |
| **合格** | 90-95% | ⚠️ | 立即改进 |
| **不合格** | <90% | ❌ | 紧急修复 |

## 🚫 常见问题与解决方案

### 1. 职责描述缺失

**问题**: 文档没有职责描述  
**原因**: 新建文档未添加、批量创建时遗漏  
**解决**: 使用自动化脚本批量添加职责描述

### 2. 职责描述不准确

**问题**: 职责描述与文档内容不一致  
**原因**: 文档内容修改后未更新职责描述  
**解决**: 定期审查，及时更新职责描述

### 3. 职责重叠

**问题**: 多个文档职责描述重叠  
**原因**: 文档职责划分不清  
**解决**: 明确职责边界，合并或拆分文档

### 4. 格式不规范

**问题**: 职责描述格式不符合标准  
**原因**: 未遵循标准模板  
**解决**: 使用标准模板，自动化格式检查
