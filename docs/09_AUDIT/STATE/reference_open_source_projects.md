## 1. 文档站点生成器 (借鉴自动索引思想)

这些工具从文件系统自动生成导航索引，与方案D的核心思想最接近：

### 1.1 MkDocs ⭐⭐⭐ (最推荐)

**GitHub**: https://github.com/mkdocs/mkdocs
**Stars**: 18k+
**语言**: Python

**核心功能**:
- 从文件系统自动生成站点导航
- `nav` 配置可自动生成或手动指定
- 支持插件扩展

**借鉴点**:
```python
# MkDocs 的自动导航生成
nav:
  - "自动生成": "auto"  # 自动从文件系统构建
```

**适用性**: ⭐⭐⭐⭐
- ✅ Python生态，易集成
- ✅ 自动索引生成
- ❌ 需要改造为pre-commit钩子

**Stars**: 57k+

## 7. 可直接使用的开源组件

### 7.1 立即可集成

```yaml
# .pre-commit-config.yaml 增强
repos:
  # YAML格式检查
  - repo: https://github.com/adrienverge/yamllint
    rev: v1.32.0
    hooks:
      - id: yamllint
        files: ^docs/.*\.md$
        args: ['-c', '.yamllint.yml']

  # Markdown格式检查
  - repo: https://github.com/igorshubovych/markdownlint-cli
    rev: v0.37.0
    hooks:
      - id: markdownlint
        files: ^docs/.*\.md$

  # 链接检查 (CI阶段)
  - repo: local
    hooks:
      - id: lychee-link-check
        name: Lychee Link Check
        entry: lychee
        language: system
        files: \.md$
        pass_filenames: false
        args: ['--cache', 'docs/']
```

## 9. 参考项目代码片段

### 9.1 MkDocs导航生成 (参考实现)

```python
# 参考: mkdocs/structure/files.py
class File:
    """封装文件路径和URL生成"""

    @property
    def url(self):
        """从文件路径生成URL"""
        return self._file_path.replace(os.sep, '/')

class Navigation:
    """自动构建导航"""

    def __init__(self, pages, files):
        self.pages = pages
        self.files = files
        self._build_navigation()

    def _build_navigation(self):
        """从文件系统构建导航树"""
        for file in self.files:
            if file.is_documentation_page():
                self._add_to_navigation(file)
```

### 9.2 mdBook SUMMARY生成 (参考实现)

```rust
// 参考: mdbook/src/book/summary.rs
pub fn generate_summary_from_fs(src_dir: &Path) -> Result<Summary> {
    let mut summary = Summary::default();

    for entry in fs::read_dir(src_dir)? {
        let entry = entry?;
        let path = entry.path();

        if path.extension() == Some("md") {
            let item = SummaryItem::from_path(&path)?;
            summary.prefix_chapters.push(item);
        }
    }

    Ok(summary)
}

## 10. 结论与建议

### 10.1 开源工具借鉴价值

| 项目 | 借鉴价值 | 使用方式 |
|------|---------|---------|
| MkDocs | ⭐⭐⭐⭐⭐ | 参考导航生成算法 |

### 10.2 实施方案建议

**路径1: 纯自研 (推荐)**
- 开发 `index_compiler.py` (参考MkDocs)
- 开发 `mandatory_inbound_guard.py` (完全自研)
- 集成 `yamllint` + `lychee`
- 工时: 14-22小时

**路径2: 基于MkDocs改造**
- Fork MkDocs源码
- 移除服务器组件，保留导航生成
- 添加pre-commit钩子支持

- 先集成 `yamllint` + `markdownlint` + `lychee`
- 开发简化版自研编译器
- 后续迭代完善
