## 4. 修复方法

### 4.1 使用的工具

**工具1: 智能链接修复脚本**

文件: `scripts/fix_broken_links.py`

功能:
- 建立文件索引
- 查找目标文件
- 计算正确的相对路径
- 批量修复链接

**工具2: 剩余链接处理脚本**

文件: `scripts/fix_remaining_links.py`

功能:
- 处理file:///格式的链接
- 移除占位符链接
- 注释示例链接
- 注释不存在的链接

### 4.2 修复策略

**策略1: 自动修复**
- 使用文件索引查找目标文件
- 计算正确的相对路径
- 自动替换错误链接

**策略2: 智能处理**
- 识别占位符链接并移除
- 识别示例链接并注释
- 识别file:///格式并转换

**策略3: 保留标记**
- 对于计划中的文件，保留链接并添加注释
- 对于技术规范，保留链接以便后续创建

## 5. 修复详情

### 5.1 成功修复的链接类型

**类型1: 相对路径错误**

示例:
```markdown
修复前: [文档](../../01_FRAMEWORK/ARCHITECTURE.md)
修复后: [文档](../../../01_FRAMEWORK/ARCHITECTURE.md)
```

**类型2: 文件路径引用错误**

示例:
```markdown
修复前: [文档](../STRATEGY_AI_MODULES_ANALYSIS.md)
修复后: [文档](STRATEGY_AI_MODULES_ANALYSIS.md)
```

**类型3: file:///格式**

示例:
```markdown
修复前: [文档](file:///d:/ZephyrAlpha/docs/09_AUDIT/STANDARDS/DOCUMENT_GOVERNANCE_PROCESS_STANDARD.md)
修复后: [文档](../STANDARDS/DOCUMENT_GOVERNANCE_PROCESS_STANDARD.md)
```

**类型4: 占位符链接**

示例:
```markdown
修复前: [报告]({report_url})
修复后: <!-- 占位符链接已注释: [报告]({report_url}) -->
```

### 5.2 未修复的链接类型

**类型1: 计划文件未创建**

示例:
```markdown
链接: ./03_OPERATION_MANUALS/DEPLOYMENT_MANUAL.md
状态: 文件尚未创建
建议: 创建文件或移除链接
```

**类型2: 技术规范缺失**

示例:
```markdown
链接: ../../05_IMPLEMENTATION/05_TECHNICAL_SPECIFICATIONS/DOCUMENT_AUDITOR_SPECIFICATION.md
状态: 规范文档尚未创建
建议: 创建技术规范文档
```
