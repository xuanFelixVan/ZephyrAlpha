# SOP-B 单节点 AI 自驱回测七步循环

> **定位**：SOP-A 注册的一个回测对象，从开工到归档的标准循环。AI 自驱执行，循环出口三个：**升级 verified / 继续迭代回① / 判死归档**。
> **诞生背景**：Owner 原话——"全让 AI 自发地去开始回测，然后修正参数，再回测，再修正"；"全网搜集算法，不被项目数据捆绑；需要什么数据提出来，缺失的想办法搞；先做宽，再逐步剪噪音"。本 SOP 把这段话固化为可执行、可审计、防跑飞的流程。
> **总纲**：[README.md](README.md)。

## 0. 前置（不满足禁入循环）

- 对象已在 SOP-A backlog 注册且**验收阈值已预注册**；
- 对象 node_type 已标注（决定第①⑥步的判据，见 §2 判据差异表）；
- 上游状态明确（依赖上游结论的对象，上游批次的结论已归档）。

## 1. 七步循环

### ① 全网算法调研

- 全网搜索该节点/行为的最新算法：论文、机构实践、量化社区做法、开源实现；
- **硬规则：≥3 个候选算法**，每个写明出处与适用前提；禁止只拿项目内已有算法应卯；
- 产出：《候选算法清单》（对象 ID + 候选 + 出处 + 适用条件 + 初筛理由）。

### ② 数据需求声明（needs-driven，本 SOP 的灵魂）

- **硬规则：先声明"这个行为理论上需要什么数据"，再对照已有资产；禁止"项目里有什么数据就怎么回测"。**
- 对照 `data_asset_registry.yaml`（REG-DATAFLOW-001）逐项标注：已有（DS-*）/ 缺失；
- 产出：《DATA-GAP 缺口清单》——字段：数据项 / 粒度 / 区间 / 时点可用性要求 / 用途 / 缺失等级（阻塞|降级可跑|可有可无）。

### ③ 缺口取数

- 获取优先序：免费公开源 → 项目已有订阅（westock/neodata 等）→ 付费/爬取（报 Owner 批）→ proxy 替代数据；
- **proxy 降级标注**：用代理数据的对象，最终结论自动降半级（verified 上限降为"verified(proxy)"），报告首行声明；
- **PIT 铁律**：每项数据登记时点可用性（何时能知道）；回测区间早于 `effective_from=2026-09-08` 的部分按 D120 打知识漂移标注；
- 缺口实无法补 → 回②修正数据需求（换算法）或对象降级。

### ④ 宽回测（先做宽）

- 全量可得数据 + 全参数网格（搜索空间 = 注册条目预注册范围，禁止越界）+ **粗成本**；
- 目的 = **信号存在性**，不是赚钱：产出信号/因子/规则在六段状态下的原始表现分布；
- 多算法候选（来自①）各自跑通，横向对比进候选池。

### ⑤ 噪音剪枝（先广后窄的收敛步）

三类剪枝规则，逐条执行并留痕（剪了什么、为什么、剪掉后的表现）：

| 剪枝类型 | 规则 | 出处对齐 |
|---|---|---|
| 衰减剪 | IC/事件收益随时间或样本外窗口显著衰减的参数与信号 | 常规稳健性 |
| 分状态不稳剪 | 六段状态中仅 1-2 段有效且无机制解释的 → 收窄适用状态或剔除 | 约束三投影 |
| 相关性剪 | 同源指标重复计票（相关性 > 0.9）→ 保留信息量最高者 | L1-S5 日级温度计"同源指标重复计票"先例推广 |

### ⑥ 窄回测（后做窄）

- 幸存配置 + **完整成本五项**（约束一：佣金+印花税+滑点+市场冲击+做T额外成本；费率读实际账户配置，禁硬编码）+ WFA/OOS（IS→WFA→OOS 门控，BM-BT-07）；
- 按对象类型映射验证层：factor→V1 / signal→V2+V5 / strategy→V3 / pipeline→V4（§20.7.1，执行走 `layered_validation_pipeline`，层层递进不可跳级）；
- **过拟合门禁强制**：OverfittingDetector 三阶段 + Deflated Sharpe（把全部留痕的试验次数喂给校正）。

### ⑦ 归档判定（三出口）

1. **达标** → BacktestResult 走 `decisiongraph_adapter` 落 decisiongraph L5（evidence_hash）→ SOP-A Step A5 升级地图 confidence；
2. **不达标但有假设** → 记录本轮结论与失败假设，回①换算法或回②修正数据需求（迭代次数与 diff 全留痕）；
3. **判死** → 归档出局报告（含 3 个以上已排除候选与排除理由——"没找到"必须写清排除了什么），对象在地图降级/标注。

## 2. 节点类型 × 判据差异表

| node_type | ①调研重点 | ④宽回测指标 | ⑥窄回测通过判据 |
|---|---|---|---|
| sensor | 因子构造/事件研究文献 | IC、事件后收益分布（分状态） | 分状态 IC 稳定；OOS 不衰减 |
| gate | 状态判定/分类算法（HMM/规则融合等） | 分类准确率、混淆矩阵 | 判对增益 > 判错损失（错分代价矩阵）；对下游 PnL 增量显著 |
| strategy | 策略结构同类对比 | 分状态净值曲线 | WFA/OOS 通过 + Deflated Sharpe 达标 + 成本五项后仍达标 |
| aggregation | 聚合/融合方法对比 | 消融增量分布 | 有它 vs 没它（或换简单规则）增量显著且稳定 |

## 3. 三护栏（防 AI 跑飞，强制段）

1. **搜索空间预注册**：参数网格范围在注册条目里先写死，循环中禁越界扩参（要扩 = 回批次决策点报 Owner）；
2. **过拟合门禁强制**：任何窄回测结论未过门禁不得进入⑦出口 1；
3. **验收阈值预注册**：跑前写死达标线，禁事后挪门柱（阈值定低了/高了 = 批次决策点公开修订并留痕）。

**留痕铁律**：每轮迭代（参数 diff、剪枝清单、失败假设）全留痕——这是 Deflated Sharpe 多重检验校正的原料，缺留痕 = 本对象结论作废。

## 4. 产物规范（每对象）

- 《候选算法清单》（①）、《DATA-GAP 清单》（②）、《节点回测报告》（④⑥⑦合并：六段分档 + 成本口径 + 区间 + 迭代留痕附录）；
- 标准数据三件套按对象层级需要落盘（equity/trades/summary）；
- 归档判定写入 backlog 条目状态字段。

## 5. 自检清单（⑦出口 1 前强制）

- [ ] 阈值、搜索空间预注册在先；
- [ ] ≥3 候选算法且各有出处；
- [ ] DATA-GAP 清单完整，proxy 项已降级标注；
- [ ] 六段分档报告齐全，无跨状态平均；
- [ ] 成本口径（宽/粗 vs 窄/全）声明清楚；
- [ ] 过拟合门禁通过，试验留痕完整；
- [ ] OOS 区间未参与任何调参决策；
- [ ] evidence 已落 decisiongraph（出口 1）。
