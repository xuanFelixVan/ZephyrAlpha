# 连接器入职操作手册

> module_id: DOM-L00-002 | version: 0.1.0 | status: draft | layer: l00_data_source

---

## 1. 目的

本手册定义将新数据源连接器接入 ZephyrAlpha 系统的完整操作步骤。

## 2. 操作步骤

### Step 0：安全审查

新连接器上线前必须通过以下安全检查：

1. 确认无硬编码凭据（参见 DOM-L00-001 §3 ABS-002）
2. 确认连接使用加密传输（TLS 1.3 或更高）
3. 确认凭据已注册到密钥管理服务，且遵循最小权限原则
4. 如未通过安全审查，禁止进入后续步骤

### Step 1：确认数据源准入

1. 检查数据源是否有正式 API 文档
2. 确认 SLA 承诺（可用性 ≥ 99.5%）
3. 获取 API 凭据（参见 DOM-L00-001 §2）
4. 将凭据注册到密钥管理服务

### Step 2：创建连接器模块

1. 在 `src/zephyr/connectors/` 下创建新连接器类
2. 实现标准接口：`connect()` / `disconnect()` / `subscribe()` / `ping()`
3. 配置超时参数（参见 DOM-L00-001 §3）
4. 编写单元测试

### Step 3：连接测试

1. 执行单次连接测试，确认认证通过
2. 执行 24 小时连续连接测试，记录以下指标：

| 指标 | 通过标准 | 记录方式 |
|------|---------|---------|
| 连接延迟 P50 | ≤ 100ms | 监控日志 |
| 连接延迟 P99 | ≤ 500ms | 监控日志 |
| 数据完整性 | 字段缺失率 < 0.01% | 自动化检测 |
| Schema 匹配 | 与内部 Schema 完全匹配 | 自动化检测 |
| 错误率 | ≤ 0.1% | 监控日志 |

3. 记录断连次数和重连成功率
4. 验证数据质量抽样（参见 GOV-DATA-001）

### Step 3.5：极端场景测试

在上线前，必须执行以下极端场景测试：

1. 空数据推送——数据源返回空响应时连接器不崩溃
2. 超大行情波动——单 tick 涨跌幅 > 10% 时数据正常解析
3. 非交易时段——休市/节假日时段连接器状态正常
4. 数据格式异常——数据源返回非预期格式时触发告警而非崩溃
5. 单次测试未通过 → 修复后重新执行全部 5 项

### Step 4：注册到系统

1. 在 `connector-registry.yaml` 中注册新连接器
2. 配置监控告警规则
3. 更新数据源清单

### Step 6：上线验证

1. 在 dev 环境运行 72 小时，通过标准：
   - 断连次数 ≤ 3 次（72h 内）
   - 重连成功率 = 100%
   - 数据延迟 P99 ≤ 500ms
2. 确认数据质量达标
3. **禁止在交易时段执行上线切换**——切换到 prod 必须在盘后（A股 15:30 后）或周末执行
4. Owner 审批后切换到 prod 环境
5. prod 切换后监控 48 小时，异常次数 ≤ 1 次方可通过

## 3. 验证清单

| # | 检查项 | 通过条件 |
|---|--------|---------|
| 1 | 连接器可正常连接 | 认证通过，数据可读取 |
| 2 | 24 小时连续测试通过 | 断连次数 ≤ 3，重连成功率 100% |
| 3 | 超时配置正确 | 超时触发告警，重连自动恢复 |
| 4 | 凭据未硬编码 | 代码中无明文密码/Token |
| 5 | 单元测试通过 | 覆盖率 ≥ 80% |
| 6 | 数据质量达标 | 参见 GOV-DATA-001 |

## 4. 回滚方案

如果上线后发现问题：

1. 在 `connector-registry.yaml` 中设置 `status: suspended`
2. 通知风控系统暂停依赖该数据源的策略
3. 通知 Owner：回滚完成
4. 如果无法修复，从注册表中移除连接器

## 6. TTL与生命周期

- **有效期**：版本 0.1.0 有效期至 2026-07-30
- **失效条件**：(1) 数据源连接策略发生重大变更，(2) 数据源 API 版本升级导致连接方式不一致，(3) 新增必须同步到入职流程的安全要求
- **过期后动作**：本文件标记 `status: deprecated` + `superseded_by` 指向新版，旧版保留 90 天后归档
- **审查触发**：每次数据源入职时→审查本文件步骤是否仍适用；每 60 天→例行有效期审查
