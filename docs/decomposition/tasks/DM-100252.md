## description

根因：D:\ZephyrAlpha\scripts\governance\sync_yaml_to_depgraph.py 第311行 sync_functional_domain_registry() 函数用 YAML 的 domain 字段（小写类别名如 governance/security）作 DB domain_id 主键，ON CONFLICT(domain_id) DO UPDATE 导致同 domain 下多个 subdomain 互相覆盖，只留最后一条，产生 9 个小写命名域脏数据。治根：修改 sync 逻辑，不再将小写 domain 类别写入 domains 表的 domain_id 主键，改为跳过小写域同步（YAML 将在 DM-100256 重构为 D-XXX 子域描述）。施工步骤：修改 D:\ZephyrAlpha\scripts\governance\sync_yaml_to_depgraph.py 第290-339行 sync_functional_domain_registry() 函数，在 INSERT 前增加判断——若 entry 的 domain 字段为小写类别（非 D-XXX 格式）则 skip 不写入 domains 表，并打印 skip 日志。验收标准：运行 sync 脚本后 domains 表不新增小写命名域记录（SELECT COUNT(*) FROM domains WHERE domain_id NOT LIKE 'D-%' 不增加）。
