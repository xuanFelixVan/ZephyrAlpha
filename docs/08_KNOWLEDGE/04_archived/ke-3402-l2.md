# 4. L2 局部变更操作步骤

4. L2 局部变更操作步骤

| Step | 操作 | 验证 |
|------|------|------|
| 1 | 确认变更影响范围 | 受影响模块清单完整 |
| 2 | 通知受影响模块的 Owner | Owner 已知悉 |
| 3 | 执行修改 | 修改完成 |
| 4 | 更新受影响模块 | 所有受影响模块已更新 |
| 5 | 运行集成测试 | 测试通过 |
| 6 | 更新模块版本号 MINOR+1 | 版本号已更新 |
