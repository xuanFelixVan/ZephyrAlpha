# 12. SSoT 声明

12. SSoT 声明

| 声明项 | 值 |
|--------|-----|
| 本标准是什么的唯一真源 | ZephyrAlpha 项目规则分类体系的五个维度及其受控词表 + 规则冲突裁决推导链 |
| 下位法 | 领域规则可以定义领域内的子分类，但不得与本标准维度冲突 |
| 新增字段 | `scope` 和 `stability` 两个 frontmatter 字段由本标准定义 |
| 冲突仲裁 | 本标准与 PS-STD-001 冲突时，以 PS-STD-001 为准（字段定义权属于 PS-STD-001） |
