# 1.2 审计等级（对标 OWASP ASVS L1-L3）

1.2 审计等级（对标 OWASP ASVS L1-L3）

| 等级 | 名称 | 通过条件 | 适用场景 |
|------|------|---------|---------|
| **L1** | 基础级 | 所有 P0 脚本 0 违规 | 每日快速扫描的最低要求 |
| **L2** | 标准级 | 所有 P0+P1 脚本 0 违规 + 12 维综合分 ≥ 6.0 | Phase 过渡门 / 季度评审 |
| **L3** | 生产级 | 所有 P0+P1+P2 脚本 0 违规 + 12 维综合分 ≥ 8.0 | stable 稳定态 / 外部审计 |
