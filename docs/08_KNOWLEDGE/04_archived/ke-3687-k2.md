# 2.3 K2：规则新鲜度

2.3 K2：规则新鲜度

| 属性 | 值 |
|------|-----|
| **公式** | `date 在 30 天内的文件数 / 总文件数 × 100%` |
| **新鲜定义** | `date` 字段值与度量日期的差距 ≤ 30 天 |
| **注意** | `frozen` 文件不强制新鲜度（稳定型规则不需要频繁更新） |
| **当前基线** | 待首次度量后建立 |
| **告警阈值** | < 30%（活跃文件） |
| **目标** | ≥ 60%（活跃文件） |
