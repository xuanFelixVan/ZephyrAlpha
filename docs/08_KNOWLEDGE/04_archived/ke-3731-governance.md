# 4.2 前端编号使用规则

4.2 前端编号使用规则

| 场景 | 格式 | 示例 |
|------|------|------|
| 架构图节点 | `FE` 或 `FE-L{N}` | `FE-L1`, `FE-L3` |
| 模块文档目录 | `docs/03_modules/frontend/<module>/` | — |
| 模块 ID | `FE-L{N}-{TYPE}-{NNN}` | `FE-L1-DASH-001` |
| 施工图 | `construction-plan.md`（模块目录下） | — |
