# 4. Point-in-Time (PIT) Architecture / PIT 数据架构

4. Point-in-Time (PIT) Architecture / PIT 数据架构

> **PIT 是量化系统的红线**：任何因子值、信号、回测结果都必须能回答"在过去某一时刻 T，使用当时**确实可获得**的数据，会算出什么"。违反 PIT = 回测撒谎 = 实盘必亏。
