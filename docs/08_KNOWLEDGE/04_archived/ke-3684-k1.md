# 2.2 K1：规则合规率

2.2 K1：规则合规率

| 属性 | 值 |
|------|-----|
| **公式** | `合规文件数 / 总文件数 × 100%` |
| **合规定义** | frontmatter 所有必填字段存在 + 值在受控词表中 + 类型正确（`version` 为 string） |
| **数据源** | PS-STD-001 §2.2（分阶段闸门）+ §2.6（一致性约束） |
| **当前基线** | 待首次度量后建立 |
| **告警阈值** | < 80% |
| **目标** | ≥ 95% |
