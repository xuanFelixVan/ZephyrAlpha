# 5.7 模块 ID 格式

5.7 模块 ID 格式

模块 ID 在蓝图和 YAML 模型中使用，格式为：

```
L{XX}-{MODULE_ABBR}-{NNN}
```

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| `L{XX}` | 所属层编号 | `L00`, `L04` |
| `{MODULE_ABBR}` | 模块缩写（2-4 个大写字母） | `DS`（Data Source）, `RM`（Risk Management） |
| `{NNN}` | 三位序号 | `001`, `002` |

完整示例：`L00-DS-001`（L00 层数据源模块 001）、`L04-RM-003`（L04 层风控模块 003）

**特殊分区模块 ID**：
- Shared：`SH-{ABBR}-{NNN}`（如 `SH-CFG-001`）
- Frontend：`FE-L{N}-{ABBR}-{NNN}`（如 `FE-L1-DASH-001`）
