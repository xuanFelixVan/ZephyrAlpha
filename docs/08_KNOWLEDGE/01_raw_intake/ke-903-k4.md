# 2.5 K4：格式错误密度

2.5 K4：格式错误密度

|------|-----|
| **公式** | `格式错误总数 / 总规则行数 × 1000` |
| **格式错误示例** | frontmatter 分隔符非 `---`、YAML 非法转义、`version` 为 number 类型 |
| **数据源** | PS-STD-012 §2.1（V1 阻断条件） |
| **当前基线** | 待首次度量后建立 |
| **告警阈值** | > 5 错误/千行 |
| **目标** | 0 错误/千行 |
