# 5.1 单维度 0-10 分制

5.1 单维度 0-10 分制

```
单维度分 = Σ (子指标值 × 子指标权重) × 10

其中子指标值 ∈ [0, 1]：
  - 布尔指标：通过 = 1.0，失败 = 0.0
  - 比例指标：实际 / 目标（上限 1.0）
  - 分级指标：按阈值映射（如 绕过率 <2% → 1.0, 2-5% → 0.7, 5-10% → 0.4, >10% → 0.0）
```
