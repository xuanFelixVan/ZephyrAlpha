# SEC-001：禁止明文存储密钥

SEC-001：禁止明文存储密钥

| 编号 | 规则 | 违反后果 |
|------|------|---------|
| SEC-001 | 所有密钥、凭证、Token 禁止以明文形式存储在代码、配置文件、文档或日志中 | 立即轮换泄露的密钥；事件复盘；标记为 P0 安全事件 |

**明文存储的定义**：
- 硬编码在 Python/JSON/YAML 文件中
- 写入 .md 文档
- 输出到日志文件
- 提交到 git 仓库
