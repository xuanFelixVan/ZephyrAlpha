# 4.1 P0 变更

4.1 P0 变更

```
1. Owner 识别需要变更的 frozen 文件
2. Owner 直接编辑文件（不通过 AI）
3. Owner 更新 document-metadata-index-registry.yaml
4. Owner 在 Session Log 中记录变更原因
5. Owner 通知所有正在工作的 AI（Session Log next_session_handover）
```

**禁止**：AI 执行 P0 变更（即使 Owner 口头要求——必须 Owner 手动操作）。

**受 P0 约束的文件示例**（按属性判定）：

| 文件 | stability | scope |
|------|-----------|-------|
| PS-STD-001 metadata_registry.yaml | frozen | global |
| PS-STD-002 document_structure_standard.yaml | frozen | global |
| PS-STD-003 behavior_boundaries_standard.yaml | frozen | global |
