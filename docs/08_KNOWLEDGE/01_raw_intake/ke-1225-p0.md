# IFC-001：P0 模块必须定义接口契约

IFC-001：P0 模块必须定义接口契约

所有优先级为 P0 的模块，必须在 `cross_layer_contracts.yaml` 中定义接口契约，且状态为 `frozen` 后才能注入。

接口契约必须包含：

| 字段 | 说明 | 是否必填 |
|------|------|:-------:|
| contract_id | 契约唯一标识 | 🔴 |
| provider | 提供方 module_id | 🔴 |
| consumers | 消费方 module_id 列表 | 🔴 |
| interface_type | 接口类型：api / event / data | 🔴 |
| schema | 请求/响应/事件的数据结构定义 | 🔴 |
| version | 契约版本号（语义化版本） | 🔴 |
| status | 契约状态：draft / frozen / deprecated | 🔴 |
