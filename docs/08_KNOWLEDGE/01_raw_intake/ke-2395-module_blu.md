# 5.2.1 判定流程

5.2.1 判定流程

```
┌─────────────────┐
│  发现孤儿文件    │
└────────┬────────┘
         │
    ┌────▼─────────────────────────────┐
    │ 判定1: 是否有功能重复？           │
    │  (Code Dedup Engine 语义比对)     │
    └────┬──────────┬──────────────────┘
         │ 有重复    │ 无重复
         │           │
    ┌────▼──────┐   │
    │ 判定2:    │   │
    │ 有无独特  │   │
    │ 价值？    │   │
    └─┬────┬───┘   │
    有 │ 无 │       │
      │   │       │
   ┌──▼─┐ │       │
   │提取│ │   ┌───▼──────┐
   │融合│ │   │ 判定3:   │
   └──┬─┘ │   │ 有独立   │
      │   │   │ 价值？   │
      │   │   └─┬───┬───┘
      │   │   有 │ 无 │
      │   │     │   │
      │   │  ┌──▼─┐ │
      │   │  │注册│ │
      │   │  │保留│ │
      │   │  └──┬─┘ │
      │   │     │   │
      ▼   ▼     ▼   ▼
  ┌──────────────────────┐
  │ 所有路径输出:         │
  │ · 提取了哪些内容      │
  │ · 注册了哪些文件      │
  │ · 删除了哪些文件      │
  │ · 为什么这样判定      │
  └──────────────────────┘
```
