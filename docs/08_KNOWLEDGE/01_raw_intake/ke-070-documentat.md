# §1 目的与范围

§1 目的与范围

必须包含：
- **目的**：一句话说明本文档解决什么问题
- **责任范围**（§1.2）：正向声明本文档管什么
- **责任边界**（§1.3）：负向声明本文档不管什么（对标 Kubernetes KEP Non-Goals）
- **范围**：适用于哪些文件/目录/场景

> **对标**：ISO/IEC Directives Part 2 要求每个标准必须有 Scope clause。Kubernetes KEP 强制要求 Goals + Non-Goals 双声明——明确"不管什么"和"管什么"同等重要，防责任边界模糊。
