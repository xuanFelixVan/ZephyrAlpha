# 19. 与 PS-STD-001 字段不重复声明

19. 与 PS-STD-001 字段不重复声明

本标准新增的 `scope` 和 `stability` 字段已在 §15 中向 PS-STD-001 注册。
字段定义权归属 PS-STD-001，本标准仅定义受控词表和分类规则。
`layer` 和 `ai_autonomy` 字段完全由 PS-STD-001 定义，本标准引用。
