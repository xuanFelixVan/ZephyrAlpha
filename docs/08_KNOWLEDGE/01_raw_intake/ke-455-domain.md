# 5.2.4 新增 DOMAIN 的审批条件

5.2.4 新增 DOMAIN 的审批条件

| 条件 | 说明 |
|------|------|
| 对应目录已存在或即将创建 | 前缀不能凭空存在 |
| 缩写不与现有缩写冲突 | 检查 §5.2.1 DOMAIN 注册表 |
| 至少有 1 个文件需要该 DOMAIN | 不建空前缀 |
| 在本文件 §5.2.1 中注册 | DOMAIN 定义的唯一真源是本文件 |
