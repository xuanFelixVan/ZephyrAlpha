# AI 施工约定（集成）

AI 施工约定（集成）

```
1. 每个新模块的 __init__.py 第一行: self.telemetry = Telemetry("MOD-INF-XXX")
2. 禁止绕过 Telemetry 门面类直接调用子系统内部 API
3. 测试中通过 Telemetry(test_mode=True) 获得 Mock 版本（所有操作 noop）
4. shutdown() 必须在模块 on_shutdown 钩子中调用
```
