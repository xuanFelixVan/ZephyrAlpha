# ABS-002：报告必须包含关键指标

ABS-002：报告必须包含关键指标

每类报告必须包含以下关键指标，禁止省略：

| 报告类型 | 必须包含的指标 |
|---------|-------------|
| 交易执行日报 | 成交量、成交额、滑点、执行率、异常交易 |
| 策略绩效日报 | 日收益率、累计收益、夏普比率、最大回撤、因子贡献 |
| 风控合规日报 | 限额使用率、止损触发次数、敞口变化、合规检查结果 |
| 数据质量日报 | 数据源状态、缺失率、延迟率、异常值检测 |
