# 2.6 K5：一致性违规率

2.6 K5：一致性违规率

| 属性 | 值 |
|------|-----|
| **公式** | `一致性约束被违反的文件数 / 受约束的文件数 × 100%` |
| **检查约束** | `frozen` → `immutable_core`（单向强制） |
| **数据源** | PS-STD-001 §2.6 + PS-STD-004 §6.3 |
| **当前基线** | 待首次度量后建立 |
| **告警阈值** | > 5% |
| **目标** | 0% |
