# 5.2.3 快速自检口诀

5.2.3 快速自检口诀

> 每次施工后默念这十句话，任何一句答"否"就必须修复后才能继续：

1. 一个文件只做一件事？→ A
2. 一个事实只有一个真源？→ B
3. 所有文件说的都对得上？→ C
4. 每个文件夹名字=职责？→ D
5. 每个字都有用？→ E
6. 蓝图和代码对得上？→ F
7. 所有引用都能打开？→ G
8. 代码里没藏密码和危险命令？→ H
9. 每个源文件都有测试？→ I
10. 文档的版本号和状态都更新了？→ J
