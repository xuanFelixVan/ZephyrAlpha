# 旧格式（兼容但触发 V2 警告）——纯字符串数组

旧格式（兼容但触发 V2 警告）——纯字符串数组
depends_on:
  - PS-STD-003
  - PS-STD-001
```

| 字段 | 必需 | 格式 | 说明 |
|------|:---:|------|------|
| `target` | ✅ | `module_id` | 引用目标的全局唯一标识符 |
| `at` | ✅ | `"§N"` / `"§N~§M"` / `"§N ¶X"` | 精确到章节（§）或段落（¶）或行号（L） |
| `why` | ✅ | 短句（≤40字符） | AI 可读的依赖原因，消除"这个依赖是干嘛的"的猜测成本 |

**at 字段格式细则**：
- `"§3"` → 整个第 3 章节
- `"§3.1"` → 第 3.1 小节
- `"§3.1~§3.5"` → 从 §3.1 到 §3.5 的范围
- `"§3 ¶4"` → §3 的第 4 段落
- `"L152-L158"` → 第 152 行到第 158 行（代码文件）
