# 1.5 术语

1.5 术语

| 术语 | 含义 |
|------|------|
| **SSoT** | Single Source of Truth，唯一真源 |
| **消费者** | 直接依赖本标准字段定义/枚举值/校验规则的文件 |
| **Tier 1 消费者** | 硬编码了本标准枚举值的文件（变更必须同步） |
| **受控枚举** | 值集合由本标准定义、不允许自由扩展的枚举字段 |
| **变更同步** | 标准内容变更后，必须同 commit 更新所有 Tier 1 消费者 |
