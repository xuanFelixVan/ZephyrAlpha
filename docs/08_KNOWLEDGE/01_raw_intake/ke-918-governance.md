# 21. 审查周期

21. 审查周期

对标 ISO 11179 §6.2 定期审查要求，本策略应在以下时机进行审查：

| 触发条件 | 审查内容 |
|---------|---------|
| 每次 Phase 边界 | 契约字段表是否需要扩展（如新增 security_context 字段） |
| 新语言/框架引入 | IFC-002 的字段类型定义是否需要更新 |
| P0 模块列表变更 | IFC-001 的 P0 强制契约范围是否需要调整 |
| GOV-MOD-003 生命周期模型变更 | 契约状态映射是否需要更新 |
| 最低频率：每 6 个月 | 全量审查 |
