# 原则 1：Open Source First / 开源优先原则

原则 1：Open Source First / 开源优先原则

> 任何新模块在架构设计稿的 §1 必须包含"OSS Candidates 调研结果"，证明已做过 GitHub 扫描。未做 OSS Scan 的设计稿不予进入 IOA 评审。

**执行标准**：
- 每个新的 `design_draft`、`adr`、`c4_view` 类文档必须含"OSS Candidates"小节
- 至少调研 3 个同类开源项目
- 输出 BvB 五维评分表（见 §2），明确决策结论
