# IRN-002：Session 预算（铁律2）

IRN-002：Session 预算（铁律2）

- **规则**：每个 Session 内新创建文件不超过 8 个，新建目录不超过 3 个。同一文件反复修改请在已有文件中完成。
- **例外**：Phase Gate 期间预算翻倍

- 验证方法：Session Log 审计
- 违反后果：上下文溢出，后期操作质量下降
