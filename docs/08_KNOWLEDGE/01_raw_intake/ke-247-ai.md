# 3. 反向索引：AI 术语 → 大白话

3. 反向索引：AI 术语 → 大白话

当你看到 AI 说：

| AI 说的 | 其实就是 |
|--------|---------|
| "这个符合 SSOT 原则" | 这个没做出双份 |
| "应该走 canonicalization 流程" | 应该搬到正式区 |
| "这是一份 ADR" | 这是记"为什么这么定"的凭证 |
| "frontmatter schema" | 文档头的字段格式要求 |
| "controlled vocabulary" | 只能从几个固定词里选 |
| "append-only 机制" | 只能追加、不能改删 |
| "supersedes / superseded" | 取代 / 被取代 |
| "quality gate" | 卡点（过不去就别往下走） |
| "health check" | 体检 |
| "handoff" | 交接 |
| "rationale log" | 推导过程的记录 |
| "open questions register" | 还没想清楚的事的清单 |
| "risk register" | 已经看到的风险清单 |
| "roadmap / milestone" | 大目标 / 关卡 |
| "IA (information architecture)" | 文件夹布局和命名 |
| "provenance" | 来源追溯 |
| "retention" | 保留多久 |
| "classification" | 密级 |
| "metadata contract" | 元数据字段约定 |
| "divergent / convergent model" | 发散模型 / 收敛模型 |
