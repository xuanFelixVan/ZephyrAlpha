# 检查项 2：模块 ID 验证

检查项 2：模块 ID 验证

在使用任何模块 ID 之前，必须确认该 ID 在注册表中存在：

- [ ] 我使用的所有模块 ID 都已在 `metadata_registry.yaml`（PS-STD-001）或 `document-metadata-index-registry.yaml` 中确认存在
- [ ] 我没有自行发明模块 ID
- [ ] 如果需要新 ID，我会按 `metadata_registry.yaml` §2.1 命名空间清单申请
