# 5.1 格式

5.1 格式

```
<DOMAIN>-<TYPE>-<NNN>
```

| 部分 | 规则 | 示例 |
|------|------|------|
| DOMAIN | 2-4 字符大写缩写 | `PS` `EA` `BP` `CP` `KE` `AR` `AG` `DW` |
| TYPE | 2-4 字符大写缩写 | `STD` `REG` `ADR` `DSG` `PLAN` `LOG` |
| NNN | 三位数字，零填充 | `001` `012` `123` |
