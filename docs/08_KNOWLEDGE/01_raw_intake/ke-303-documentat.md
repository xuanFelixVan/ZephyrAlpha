# 3.3 项目实际统计（参考）

3.3 项目实际统计（参考）

基于 `technology_landscape.yaml` 43 条 + 本轮新模块 ~50 个的评估：

| 决策 | 占比 |
|:---|:---:|
| **Buy（纯开源）** | ~36% |
| **Buy+Wrap（开源+薄适配）** | ~42% |
| **Hybrid（参考开源+核心自研）** | ~12% |
| **Build（必须自研）** | ~10% |

**关键结论**：**78% 的新模块有成熟开源可用**。按"1 人 3-10 倍节省"估算，对外开放开源至少节省 80% 开发时间。
