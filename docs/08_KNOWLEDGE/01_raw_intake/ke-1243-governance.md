# IRN-007：架构终局锁定（铁律7）

IRN-007：架构终局锁定（铁律7）

架构模型锁定后，任何变更必须走 Emergency Change Board 流程，禁止直接修改。

- 验证方法：`architecture-endgame-locked` 声明检查
- 违反后果：架构漂移，终局锁定失效
