# COND-004：生产数据源异常时必须执行回退流程

COND-004：生产数据源异常时必须执行回退流程

生产环境数据源出现持续异常（30 分钟内无法恢复）时：

1. 自动切换到备用数据源（如已配置）
2. 如无备用源，触发降级策略（参见 §5 COND-003）
3. 切换/降级后通知 Owner
4. 主数据源恢复后，在非交易时段执行回切（T+1 盘前）
5. 回切前必须通过 30 分钟稳定性验证
