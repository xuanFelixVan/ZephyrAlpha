# 6.2 Versioning / 版本化惯例

6.2 Versioning / 版本化惯例

Flat directory + `frontmatter.version`. No version subdirectories (e.g., no `v2.0/`). Evidence: AWS Well-Architected, Azure Architecture Center, Google Cloud Architecture Framework, Netflix, ThoughtWorks ADR patterns all use this approach.

平铺目录 + `frontmatter.version`。不用版本化子目录（如不建 `v2.0/`）。实证：AWS Well-Architected / Azure Architecture Center / Google Cloud Architecture Framework / Netflix / ThoughtWorks ADR 范式均采用此做法。
