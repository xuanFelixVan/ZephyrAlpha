# 2.3 综合分计算

2.3 综合分计算

```
综合分 = Σ (维度分 × 权重)
       = 7.5×0.08 + 6.8×0.08 + 5.2×0.10 + 7.0×0.08 + 4.0×0.08
       + 2.2×0.12 + 4.0×0.10 + 4.0×0.10 + 6.0×0.06 + 2.8×0.08
       + 3.5×0.06 + 5.5×0.06
       = 0.60 + 0.544 + 0.52 + 0.56 + 0.32
       + 0.264 + 0.40 + 0.40 + 0.36 + 0.224
       + 0.21 + 0.33
       = 4.732   （GLM §3258 报 4.49，小数差异因个别维度微调）
```
