# 5. 告警响应流程

5. 告警响应流程

```
KPI 触发告警阈值 → 自动通知 Owner → Owner 判定：

A. 误报（度量脚本故障）：
   → 修复度量脚本 → 重新度量

B. 真实退化（规则体系正在变坏）：
   → 5 Whys 根源分析 → 制定修复计划 → 执行修复 → 下次度量验证

C. 阈值不合理（规则体系在变好，但阈值太严）：
   → Owner 调整告警阈值 → 更新本标准
```
