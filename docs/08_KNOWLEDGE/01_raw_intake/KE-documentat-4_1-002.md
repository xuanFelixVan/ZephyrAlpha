# 4.1 边界案例处理

4.1 边界案例处理

| 边界案例 | 判定 | 理由 |
|---------|------|------|
| 不确定是否可逆 | 归入宪法层 | 举证责任在"可逆"方——不确定 = 不可逆 |
| 当前阶段可逆、未来可能不可逆 | 归入宪法层 | 按最高风险阶段判定 |
| 代码级强制但后果可逆 | 归入登记表层 | 不可逆性是唯一标准，与强制方式无关 |
| 文档级声明但后果不可逆 | 归入宪法层 | 不可逆性是唯一标准，与强制方式无关 |
