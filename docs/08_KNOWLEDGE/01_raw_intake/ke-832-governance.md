# 16. 废弃流程

16. 废弃流程

本标准的 `stability` 为 `stable`，废弃流程需：

1. Owner 明确批准
2. 创建 KB 决策记录 记录废弃原因和替代方案
3. 从 PS-STD-001 中移除 `scope`、`stability` 字段定义
4. 所有规则文档移除 `scope`、`stability` 字段
5. 本标准状态改为 `deprecated`，保留 90 天后可删除
