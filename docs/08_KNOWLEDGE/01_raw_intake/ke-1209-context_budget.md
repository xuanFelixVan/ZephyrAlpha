# DOC-008：上下文预算意识（Context Budget Awareness）

DOC-008：上下文预算意识（Context Budget Awareness）

每个新增的文件都会消耗 AI 的上下文窗口。创建新文件有成本，不是免费的。保持文件精简、避免碎片化，是对 AI 决策效率的直接保障。

- **规则**：
  1. 创建任何新文件前，先问："这个文件的内容是否可以通过引用已有文件来表达？"
  2. 如果一个文件的内容少于 20 行实质规则定义，优先考虑融入已有文件
  3. 如果一个文件的唯一作用是转发/重定向到另一个文件，应直接使用引用替代
  4. 定期审查：自创建后超过 30 天未被任何其他文件依赖或引用的文件，应评估是否可删除或融入
- **违反后果**：上下文窗口被低价值文件占用，AI 决策时需要扫描更多文件才能找到关键规则，响应质量下降
- **验证方式**：`depends_on` 反向查询——检查哪些文件引用了目标文件，无引用文件标记为审查候选
- **专业参考**：Windsurf 平台规则 → 6000字符/规则硬限制 / Cursor Rules 指南 → "只写 AI 反复犯错的点"
