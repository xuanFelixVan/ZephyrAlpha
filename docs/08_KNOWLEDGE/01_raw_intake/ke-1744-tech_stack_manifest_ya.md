# 2.1 创建 `tech_stackmanifest.yaml`

2.1 创建 `tech_stackmanifest.yaml`

在 `D:\ZephyrAlpha\config\capacity\tech_stackmanifest.yaml` 中，创建结构化清单，每条包含：
- `dd_id`: DD-1 至 DD-16
- `component`: 组件名称
- `final_choice`: 终选技术
- `rationale`: 选择理由
- `version_change`: v2.0.0 变更标记（是/否）
- `governance_layer`: 治理层级
