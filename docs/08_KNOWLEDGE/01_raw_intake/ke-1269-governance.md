# 与 MTH-006（根源分析）的关系

与 MTH-006（根源分析）的关系

三分类法是 MTH-006 的**前置诊断工具**：

```
MTH-011 三分类审计           MTH-006 根源分析
（量化：多少行是冗余？）  →  （定性：为什么会产生这些冗余？）
     数据                          根因
```

当你怀疑一个文件"可能不需要存在"时，先用 MTH-011 量化审计（得到数据：88% 冗余），再用 MTH-006 的追问到底追根因（得到原因：治理表演/Governance Theater）。三分类给数据，追问到底给原因——两个加起来才是完整的"文件是否该废除"的论证链条。
