# 因子分类体系 (FACTOR_TAXONOMY)

> **核心职责**: 定义和维护因子分类体系，管理因子层级结构，制定因子命名规范
> **职责边界**: 
> - ✅ 本文档负责：因子分类定义、层级管理、命名规范
> - ❌ 本文档不负责：具体因子实现、因子计算逻辑

---

## 📋 概述

本文档定义了清风量化系统的因子分类体系，包括因子层级结构、分类标准和命名规范。

## 🏗️ 因子分类层级

### 一级分类：因子大类
- **Alpha因子** - 超额收益因子
- **风险因子** - 风险暴露因子
- **流动性因子** - 流动性相关因子

### 二级分类：因子类型
- **动量因子** - 价格动量、成交量动量
- **价值因子** - 估值、盈利能力
- **成长因子** - 营收增长、利润增长
- **质量因子** - 财务质量、盈利质量

### 三级分类：具体因子
- **动量因子** → 3月动量、6月动量、12月动量
- **价值因子** → PE、PB、PS、PCF
- **成长因子** → 营收增长率、利润增长率

## 📝 命名规范

### 因子命名格式
```
{大类}_{类型}_{具体因子}_{周期}
```

### 命名示例
- `ALPHA_MOMENTUM_3M` - Alpha动量因子3月周期
- `RISK_BETA_MARKET` - 风险因子市场Beta
- `VALUE_PE_TTM` - 价值因子PE TTM
