## 📊 治理框架概览

### 治理委员会

因子治理委员会（Factor Governance Committee）负责：
- 因子入库审批
- 因子淘汰决策
- 风险控制监督
- 策略调整建议

### 治理流程

```
因子发现 → IC验证 → 委员会评审 → 入库决策 → 持续监控
```
