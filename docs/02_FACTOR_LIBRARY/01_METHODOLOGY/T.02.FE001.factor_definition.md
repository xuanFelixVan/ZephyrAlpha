# 因子定义标准

> 因子标准化定义规范

---

## 1. 因子命名规范

### 1.1 命名格式

```
{类型前缀}_{计算方式}_{周期}_{调整}
```

### 1.2 类型前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| RET | 收益率类 | RET_1D |
| VAL | value_factors | VAL_PE_TTM |
| GROW | 成长类 | GROW_REVENUE_YOY |
| QUAL | 质量类 | QUAL_ROE |
| MOM | 动量类 | MOM_RSI_14 |
| LIQ | 流动性类 | LIQ_TURN_20 |
| RISK | 风险类 | RISK_VOL_60 |
| SENT | 情绪类 | SENT_BUY_RATIO |

### 1.3 周期后缀

| 后缀 | 含义 |
|------|------|
| _D | 日频 |
| _W | 周频 |
| _M | 月频 |
| _Y | 年频 |
| 数字 | 具体周期 |
