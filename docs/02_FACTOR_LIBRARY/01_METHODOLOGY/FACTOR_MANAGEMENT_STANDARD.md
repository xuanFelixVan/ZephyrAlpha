## 1. 概述

本文档定义了ZephyrAlpha因子库的专业机构级管理标准，包括：
- 因子分类体系（Alpha因子 vs 风险因子）
- 因子分层管理（核心/卫星/实验）
- IC阈值标准（入库/监控/淘汰）
- 因子生命周期状态机
- 因子生命周期流程

## 2. 因子分类体系

### 2.1 Alpha因子 vs 风险因子

| 类型 | 定义 | 生命周期 | 管理方式 |
|------|------|----------|----------|
| **Alpha因子** | 追求超额收益的核心来源 | 2-5年 | 严格监控，快速淘汰 |
| **风险因子** | 解释收益来源 | 5-10年+ | 长期持有，少量调整 |

**ZephyrAlpha的5900因子构成**：
```
5900个因子
├── 技术指标类（MA、MACD、RSI等）
│   └── 大部分属于风险因子/市场特征
├── 基本面类（PE、PB、ROE等）
│   └── 风险因子
├── 资金流类（北向、融资等）
│   └── 可作为Alpha因子候选
└── 另类因子（舆情、天气等）
    └── Alpha因子的重要来源
```

### 2.2 因子分类

| 分类 | 说明 | 示例 | 更新频率 |
|------|------|------|----------|
| **technical** | 技术指标 | MA, RSI, MACD | 分钟/日 |
| **valuation** | 估值因子 | PE, PB, PCF | 日/季 |
| **growth** | 成长因子 | 营收增速, 利润增速 | 季 |
| **momentum** | 动量因子 | 20日收益, 动量得分 | 日 |
| **quality** | 质量因子 | ROE, 资产负债率 | 季 |
| **liquidity** | 流动性因子 | 换手率, 成交额 | 日 |
| **sentiment** | 情绪因子 | 舆情得分, 北向资金 | 日 |
| **alternative** | 另类因子 | 天气、搜索指数 | 日/实时 |

## 3. 因子分层管理体系

### 3.1 分层结构（因子金字塔）

```
┌─────────────────────────────────────────────────────────────┐
│                    因子分层金字塔                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                       ┌─────────────┐                        │
│                       │  核心因子   │  Top 5-10              │
│                       │ (30%仓位)  │  IC最高、最稳定         │
│                       └──────┬──────┘                        │
│                              │                              │
│                    ┌─────────┴─────────┐                    │
│                    │     卫星因子       │  Top 20-30          │
│                    │    (50%仓位)      │  中高IC              │
│                    └─────────┬─────────┘                    │
│                              │                              │
│                    ┌─────────┴─────────┐                    │
│                    │     实验因子       │  20个              │
│                    │    (20%仓位)      │  新发现/待验证       │
│                    └───────────────────┘                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 分层标准

| 层级 | 数量 | IC要求 | 稳定性要求 | 管理标准 |
|------|------|--------|------------|----------|
| **核心因子** | 5-10个 | IC > 0.05 | 连续60天IC > 0.03 | 最严格 |
| **卫星因子** | 20-30个 | IC > 0.03 | 连续30天IC > 0.02 | 中等 |
| **实验因子** | 20个 | IC > 0.02 | 新发现，待验证 | 宽松 |

### 3.3 仓位分配

| 层级 | 仓位权重 | 说明 |
|------|----------|------|
| **核心因子** | 30% | 最高权重，最稳定 |
| **卫星因子** | 50% | 中等权重 |
| **实验因子** | 20% | 最低权重，高风险高收益 |

## 4. IC阈值体系

### 4.1 IC阈值标准（资金规模参考）

| 机构类型 | 资金规模 | IC阈值 | IC持续天数 |
|----------|----------|--------|------------|
| **顶级对冲基金** | 100亿美元+ | 0.03 | 5天 |
| **中型机构** | 1-10亿美元 | 0.025 | 10天 |
| **小型机构/个人** | 1000万以下 | 0.02 | 15天 |
| **ZephyrAlpha** | 45万人民币 (~6万美元) | 0.02 | 15天 |

### 4.2 IC入库标准

| 指标 | 最低要求 | 良好标准 | 优秀标准 |
|------|----------|----------|----------|
| **IC均值** | > 0.02 | > 0.035 | > 0.05 |
| **IC_IR** | > 0.3 | > 0.5 | > 1.0 |
| **IC胜率** | > 55% | > 60% | > 65% |
| **IC衰减** | < 30%/年 | < 20%/年 | < 10%/年 |

### 4.3 IC监控阈值

| 状态 | IC (5日均值) | IC_IR | 处置 |
|------|-------------|-------|------|
| 🟢 **正常** | > 0.05 | > 1.0 | 全额权重 |
| 🟢 **良好** | 0.035 ~ 0.05 | 0.5 ~ 1.0 | 全额权重 |
| 🟡 **注意** | 0.02 ~ 0.035 | 0.3 ~ 0.5 | 正常监控 |
| 🟠 **警告** | 0.01 ~ 0.02 | 0.15 ~ 0.3 | 降低权重50% |
| 🔴 **暂停** | < 0.01 持续10天 | < 0.15 | 暂停使用 |
| ⚫ **淘汰** | < 0.01 持续30天 | < 0.1 | 永久移除 |

### 4.4 分层IC管理标准

| 层级 | 警告阈值 | 降权阈值 | 暂停阈值 | 淘汰阈值 |
|------|----------|----------|----------|----------|
| **核心因子** | IC < 0.03 (5天) | IC < 0.02 (10天) | IC < 0.01 (10天) | IC < 0.01 (20天) |
| **卫星因子** | IC < 0.02 (10天) | IC < 0.015 (15天) | IC < 0.01 (15天) | IC < 0.01 (30天) |
| **实验因子** | IC < 0.015 (15天) | IC < 0.01 (20天) | IC < 0.01 (20天) | IC < 0.01 (45天) |

## 5. 因子生命周期状态机

### 5.1 状态定义

| 状态 | 说明 | 允许转换 |
|------|------|----------|
| **TESTING** | 测试中（新因子/新参数） | → ACTIVE, DEPRECATED |
| **ACTIVE** | 正常运行 | → WARNING, DEPRECATED |
| **WARNING** | 预警中（IC衰减） | → ACTIVE, DEGRADED, DEPRECATED |
| **DEGRADED** | 降级使用（降低权重） | → ACTIVE, DEPRECATED |
| **DEPRECATED** | 已废弃（暂停使用） | → ARCHIVED |
| **ARCHIVED** | 已归档 | - |

### 5.2 状态转换图

```
┌─────────────────────────────────────────────────────────────────────┐
│                    因子生命周期状态机                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    ┌─────────┐                                                     │
│    │ TESTING │ ←── 新因子入库                                       │
│    └────┬────┘                                                     │
│         │ IC验证通过                                                │
│         ▼                                                          │
│    ┌─────────┐                                                     │
│    │ ACTIVE  │ ←── 核心/卫星/实验因子                               │
│    └────┬────┘                                                     │
│         │ IC < 阈值                                                │
│         ▼                                                          │
│    ┌─────────┐                                                     │
│    │ WARNING │                                                     │
│    └────┬────┘                                                     │
│         │ IC恢复 / 继续恶化                                         │
│    ┌────┴────┐                                                     │
│    ▼         ▼                                                     │
│ ┌─────────┐ ┌──────────┐                                           │
│ │ ACTIVE  │ │ DEGRADED │ ←── 降低50%权重                           │
│ └─────────┘ └────┬─────┘                                           │
│                  │ IC恢复 / 继续恶化                                 │
│                  ▼                                                 │
│           ┌──────────┐                                             │
│           │DEPRECATED│ ←── 暂停使用                                 │
│           └────┬─────┘                                             │
│                │ 归档                                               │

│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 5.3 触发事件

| 事件 | 说明 | 触发条件 |
|------|------|----------|
| **ic_warning** | IC低于警告阈值 | 核心5天/卫星10天/实验15天 |
| **ic_recover** | IC恢复到正常 | IC > 阈值 连续5天 |
| **ic_degrade** | IC严重衰减 | 核心10天/卫星15天/实验20天 |
| **ic_deprecate** | IC失效 | 核心10天/卫星15天/实验20天 < 0.01 |
| **ic_restore** | IC恢复到良好 | IC > 阈值 连续10天 |
| **manual_deprecate** | 人工废弃 | 研究员决定 |
| **auto_archive** | 自动归档 | 废弃30天后 |

## 6. 因子生命周期流程

### 6.1 因子入库流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                      因子入库流程                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Step 1: 因子构思                                                    │
│  ├── 来源: 研究员提出 / AI发现 / 文献启发                            │
│  └── 输出: 因子构思文档                                              │
│                              ↓                                      │
│  Step 2: 初步研究                                                    │
│  ├── 数据验证: 数据完整性检查                                       │
│  ├── 公式验证: 计算逻辑正确性                                       │
│  └── 输出: 初步研究报告                                             │
│                              ↓                                      │
│  Step 3: IC验证                                                      │
│  ├── 历史回测: 最近2年数据                                          │
│  ├── IC计算: 日频IC序列                                            │
│  ├── ICIR: 必须 > 0.3                                              │
│  └── 输出: IC验证报告                                               │
│                              ↓                                      │
│  Step 4: 分层确定                                                    │
│  ├── IC > 0.05 → 核心因子候选                                      │
│  ├── IC > 0.03 → 卫星因子候选                                      │
│  └── IC > 0.02 → 实验因子候选                                      │
│                              ↓                                      │
│  Step 5: 入库审批                                                    │
│  ├── 研究员提交申请                                                 │
│  ├── 因子委员会审批                                                 │
│  └── 输出: 入库批准                                                 │
│                              ↓                                      │
│  Step 6: 正式入库                                                    │
│  └── 因子注册表更新 + 分配因子ID                                    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 7. 专业机构对比

### 7.1 与顶级机构的差距

| 项目 | Two Sigma | DE Shaw | ZephyrAlpha目标 |
|------|-----------|---------|----------------|
| **因子数量** | 100-500 | 100-300 | 20-30 (活跃) |
| **IC阈值** | 0.03+ | 0.03+ | 0.02+ |
| **IC持续天数** | 5天 | 5天 | 15天 (保守) |
| **因子生命周期** | 2-3年 | 2-5年 | 2-5年 |
| **自动化程度** | 90%+ | 90%+ | 目标80%+ |

### 7.2 ZephyrAlpha的特色

| 特色 | 说明 |
|------|------|
| **AI辅助发现** | GLM-4-Flash自动从新闻/研报中发现新因子构思 |
| **分层管理** | 核心/卫星/实验三层结构 |
| **保守淘汰** | 给予更多机会，淘汰阈值更宽松 |
| **小资金优化** | 针对45万资金规模优化，避免过度分散 |

## 8. 配置参数

### 8.1 阈值配置

```yaml
# config/factor_management.yaml

factor_management:
  # IC入库标准
  ic_entry:
    ic_mean_min: 0.02
    ic_ir_min: 0.3
    ic_win_rate_min: 0.55
    decay_max: 0.3

  # IC监控阈值
  ic_monitoring:
    excellent: 0.05
    good: 0.035
    warning: 0.02
    critical: 0.01

  # 分层IC标准
  tiered_ic:
    core:
      warning_days: 5
      warning_ic: 0.03
      degrade_days: 10
      degrade_ic: 0.02
      deprecate_days: 20
    satellite:
      warning_days: 10
      warning_ic: 0.02
      degrade_days: 15
      degrade_ic: 0.015
      deprecate_days: 30
    experimental:
      warning_days: 15
      warning_ic: 0.015
      degrade_days: 20
      degrade_ic: 0.01
      deprecate_days: 45

  # 仓位权重
  position_weights:
    core: 0.30
    satellite: 0.50
    experimental: 0.20

  # 因子数量
  factor_counts:
    core_max: 10
    satellite_max: 30
    experimental_max: 20
    total_active: 50
```
