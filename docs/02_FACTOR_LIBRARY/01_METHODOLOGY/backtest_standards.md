## 3. 绩效指标

### 3.1 收益指标

| 指标 | 计算方法 | 说明 |
|------|----------|------|
| 年化收益率 | (1+总收益)^(252/交易日)-1 | 核心指标 |
| 总收益率 | (期末净值-期初净值)/期初净值 | 累计收益 |
| 超额收益 | 组合收益 - 基准收益 | 跑赢基准 |

### 3.2 风险指标

| 指标 | 计算方法 | 说明 |
|------|----------|------|
| 年化波动率 | std(日收益)*sqrt(252) | 波动风险 |
| 最大回撤 | max(Peak - Current)/Peak | 下行风险 |
| 夏普比率 | (年化收益-无风险)/年化波动率 | 风险调整收益 |
| 卡尔玛比率 | 年化收益/最大回撤 | 回撤调整收益 |

### 3.3 交易指标

| 指标 | 计算方法 | 说明 |
|------|----------|------|
| 胜率 | 盈利次数/总交易次数 | 交易准确率 |
| 盈亏比 | 平均盈利/平均亏损 | 收益损失比 |
| 交易频率 | 总交易次数/交易天数 | 换手频率 |

## 5. 注意事项

### 5.1 常见陷阱

| 陷阱 | 说明 | 防范 |
|------|------|------|
| 未来函数 | 使用未来数据 | 严格区分训练/测试 |
| 过拟合 | 参数过度优化 | 样本外验证 |
| 幸存者偏差 | 只用现存股票 | 使用完整历史数据 |
| 执行忽略 | 忽略滑点佣金 | 加入交易成本 |

### 5.2 验证标准

- 样本外ICIR > 0.3
- 样本内外IC衰减 < 30%
- 最大回撤 < 15%
- 交易频率合理（避免过度交易）
