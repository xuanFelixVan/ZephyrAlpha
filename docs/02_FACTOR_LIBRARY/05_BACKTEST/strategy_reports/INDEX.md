## 📊 策略回测概览

### 回测指标

| 指标 | 说明 | 标准 |
|------|------|------|
| **年化收益** | 策略年化收益率 | > 15% |
| **最大回撤** | 策略最大回撤 | < 20% |
| **夏普比率** | 风险调整收益 | > 1.5 |
| **换手率** | 策略换手成本 | < 50% |

### 回测流程

```
因子选择 → 组合构建 → 回测执行 → 性能分析 → 风险评估
```
