> **版本**: v1.0
> **创建日期**: 2026-03-30
> **Layer**: Layer 2 (因子层) + AI增强
> **定位**: 全自动因子管理（自动发现/自动淘汰/自动报告）

## 1. 概述

### 1.1 定位

AI因子管家是ZephyrAlpha因子库的AI增强模块，实现：
- **全自动因子管理**：无需人工干预
- **持续优化**：不断发现新因子、淘汰失效因子
- **智能报告**：自动生成日报/周报/月报

### 1.2 三大核心功能

| 功能 | 说明 | 自动化程度 |
|------|------|------------|
| **自动发现** | 从新闻/研报/论文中发现新因子构思 | 100% |
| **自动淘汰** | 基于IC监控自动降权/暂停/淘汰失效因子 | 100% |
| **自动报告** | 自动生成因子表现报告并推送 | 100% |

## 2. 自动发现模块

### 2.1 概述

自动从以下来源发现新因子构思：
- 财经新闻（AkShare/东方财富）
- 券商研报
- 学术论文（arXiv/Google Scholar）
- 另类数据（天气/搜索指数/资金流）

### 2.2 发现流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                      自动发现流程                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Step 1: 信息采集 (每日定时)                                         │
│  ├── 财经新闻: AkShare + 东方财富                                    │
│  ├── 券商研报: 东方财富研报API                                       │
│  └── 学术论文: arXiv q-fin (可选)                                   │
│                              ↓                                      │
│  Step 2: LLM因子构思 (GLM-4-Flash)                                  │
│  ├── 输入: 文本信息                                                   │
│  ├── Prompt: "从以下文本中提取可量化的因子构思..."                    │
│  └── 输出: 因子构思列表                                              │
│                              ↓                                      │
│  Step 3: 因子代码生成 (Qwen3-4B)                                     │
│  ├── 输入: 因子构思                                                   │
│  ├── Prompt: "生成Python因子计算代码..."                             │
│  └── 输出: 可执行的因子代码                                          │
│                              ↓                                      │
│  Step 4: 逻辑验证 (DeepSeek-Prover-V2-7B)                           │
│  ├── 验证计算逻辑正确性                                              │
│  └── 验证无未来函数滥用                                             │
│                              ↓                                      │
│  Step 5: 快速回测 (VectorBT)                                         │
│  ├── 历史数据验证                                                    │
│  ├── IC计算                                                         │
│  └── IC > 0.02 → 进入实验池                                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.3 发现Prompt示例

```python
# GLM-4-Flash 因子构思Prompt

2. 因子必须可以计算（需要有数据来源）
3. 每条文本最多提取3个因子构思

输出格式（JSON）：
{{
    "factors": [
        {{
            "name": "因子名称",
            "logic": "因子逻辑",
            "data_source": "所需数据",
            "calculation_hint": "计算提示"
        }}
    ]
}}

文本内容：
{text}
"""

# Qwen3-4B 代码生成Prompt
CODE_GENERATION_PROMPT = """
请为以下因子构思生成Python计算代码。

因子名称: {name}
因子逻辑: {logic}
数据来源: {data_source}

要求：
1. 使用pandas计算
2. 输入为pd.DataFrame，列为股票代码，行为日期
3. 返回pd.Series，index为日期，value为因子值
4. 不要使用未来函数（不要使用当日收盘价计算当日因子）

代码：
```python
def calculate_{name}(data: pd.DataFrame) -> pd.Series:
    # 在此实现
```
"""
```

## 3. 自动淘汰模块

### 3.1 概述

基于因子管理标准中的IC监控体系，自动执行：
- 降权（权重50%）
- 暂停（停止使用）
- 淘汰（永久移除）

### 3.2 淘汰流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                      自动淘汰流程                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  每日收盘后 (18:30)                                                  │
│       │                                                             │
│       ▼                                                             │
│  ┌─────────────────┐                                                │
│  │ 计算因子IC序列  │                                                │
│  │ (最近N天)        │                                                │
│  └────────┬────────┘                                                │
│           │                                                         │
│           ▼                                                         │
│  ┌─────────────────┐                                                │
│  │ IC状态判断      │                                                │
│  │ 与阈值比较      │                                                │
│  └────────┬────────┘                                                │
│           │                                                         │
│           ▼                                                         │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                    分层IC阈值检查                            │   │
│  │  ┌─────────┐  ┌─────────┐  ┌─────────┐                     │   │
│  │  │ 核心因子│  │卫星因子 │  │实验因子 │                     │   │
│  │  │5天<0.03 │  │10天<0.02│  │15天<0.015│                    │   │
│  │  └────┬────┘  └────┬────┘  └────┬────┘                     │   │
│  └───────┼───────────┼───────────┼────────────────────────────┘   │
│          │           │           │                                 │
│          ▼           ▼           ▼                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │                    状态转换                                   │   │
│  │  WARNING → DEGRADED → DEPRECATED → ARCHIVED                 │   │
│  │  (降低50%)   (暂停)      (废弃)      (归档)                  │   │
│  └─────────────────────────────────────────────────────────────┘   │
│           │                                                         │
│           ▼                                                         │
│  ┌─────────────────┐                                                │
│  │ 执行状态更新   │                                                │
│  │ + 发送告警    │                                                │
│  │ + 记录日志    │                                                │
│  └─────────────────┘                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.3 淘汰判断矩阵

| 当前状态 | 触发条件 | 目标状态 | 动作 |
|----------|----------|----------|------|
| ACTIVE | IC < 阈值(核心5天/卫星10天/实验15天) | WARNING | 正常监控，发送告警 |
| WARNING | IC继续恶化 | DEGRADED | 降低50%权重 |
| WARNING | IC恢复 | ACTIVE | 恢复正常权重 |
| DEGRADED | IC继续恶化 | DEPRECATED | 暂停使用 |
| DEGRADED | IC恢复(10天) | ACTIVE | 恢复正常权重 |
| DEPRECATED | 废弃30天 | ARCHIVED | 永久移除 |

## 6. 配置参数

### 6.1 全局配置

```yaml
# config/ai_factor_agent.yaml

ai_factor_agent:
  # 自动发现
  discovery:
    enabled: true
    schedule: "08:00"  # 每日早上8点
    sources:
      - type: "news"
        api: "akshare"
        keywords: ["锂", "光伏", "储能", "芯片", "AI"]
      - type: "report"
        api: "eastmoney"
        max_daily: 50
    llm:
      model: "glm-4-flash"
      max构思: 10
    ic_threshold: 0.02

  # 自动淘汰
  retirement:
    enabled: true
    schedule: "18:30"  # 每日收盘后
    use_lifecycle_manager: true  # 使用因子生命周期管理器

  # 自动报告
  reporting:
    enabled: true
    daily:
      schedule: "18:00"
      channels: ["wechat", "log"]
    weekly:
      schedule: "monday 09:00"
      channels: ["wechat", "email"]
    monthly:
      schedule: "1st day 09:00"
      channels: ["email"]
