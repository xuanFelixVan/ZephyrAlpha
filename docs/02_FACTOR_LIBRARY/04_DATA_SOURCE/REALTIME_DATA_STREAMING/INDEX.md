## 📋 模块概述

### 核心定位

实时数据流平台是数据源层的**实时数据处理核心**，负责：
- 实时市场数据流处理
- 事件驱动架构支持
- 高吞吐量数据摄入
- 毫秒级数据延迟

### 技术选型

| 特性 | Redpanda | Apache Kafka |
|------|----------|--------------|
| 部署复杂度 | ✅ 单二进制 | ⚠️ 需要ZooKeeper |
| 内存效率 | ✅ C++实现 | ⚠️ JVM依赖 |
| Kafka兼容 | ✅ 100%兼容 | ✅ 原生 |
| 运维成本 | ✅ 低 | ⚠️ 中等 |
| 个人开发适用 | ✅ 高 | 🟡 中等 |

**推荐方案**: **Redpanda** - 更适合个人开发者

## 🏗️ 技术架构

### 整体架构

```
数据源 → Producer → Redpanda → Consumer → 下游系统
   │         │          │          │          │
   │         │          │          │          │
   └─────────┴──────────┴──────────┴──────────┘
                      │
                      ▼
              监控与告警系统
```

### 核心组件

| 组件 | 技术选型 | 职责 |
|------|----------|------|
| **消息队列** | Redpanda | 高吞吐量消息存储 |
| **Producer** | confluent-kafka-python | 数据生产者 |
| **Consumer** | confluent-kafka-python | 数据消费者 |
| **监控** | Prometheus + Grafana | 性能监控 |
