## 📖 核心功能

### 1. 自动化清洗
- 规则配置化，减少人工干预
- 支持多种数据类型清洗
- 自动异常检测和处理

### 2. 可追溯性
- 记录所有清洗操作
- 支持清洗历史回溯
- 数据血缘追踪

### 3. 保守清洗策略
- 保留原始数据不变
- 只标记异常数据
- 支持清洗回滚

### 4. 灵活配置
- 清洗规则通过YAML配置
- 支持自定义清洗规则
- 规则版本管理
