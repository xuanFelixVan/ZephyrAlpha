# 智能下载调度器

> 清风量化系统 - 智能数据下载调度系统
> **核心定位**: 基于时间和优先级的智能调度，确保数据在正确时间获取

## 📖 核心功能

### 1. 时间驱动调度
- 盘前、盘中、盘后差异化调度
- 支持定时任务和周期任务
- 自动适应交易日历

### 2. 优先级队列管理
- 紧急任务优先执行
- 多级优先级队列
- 任务抢占机制

### 3. 自动重试机制
- 失败任务自动重试
- 指数退避策略
- 最大重试次数限制

### 4. 依赖管理
- 支持任务间依赖关系
- 拓扑排序执行
- 循环依赖检测
