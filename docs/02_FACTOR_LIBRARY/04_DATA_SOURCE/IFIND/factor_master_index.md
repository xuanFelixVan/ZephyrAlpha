# 因子主索引

## 文档职责说明

**本文档职责**: iFind因子库索引管理
- 追踪每个因子的IC验证、回测报告、版本历史
- 维护因子库的单一入口
- 管理因子血缘关系

**相关文档引用**:
| 文档 | 路径 | 关系 | 说明 |
|------|------|------|------|
| iFind数据源 | [INDEX.md](./INDEX.md) | 上级索引 | iFind数据源总索引 |
| iFind连接器 | [../IFIND_CONNECTOR.md](../IFIND_CONNECTOR.md) | 实现层 | iFind数据源实现 |

**职责边界**:
- ✅ 本文档负责: 因子库索引和追踪管理
- ❌ 本文档不负责: 因子数据获取（由 IFIND_CONNECTOR.md 负责）

> 因子库的单一入口，用于追踪每个因子的IC验证、回测报告、版本历史等
>
> **重要**：所有因子必须在此索引中登记，避免文件漂移

## 索引更新规范

### 新增因子

1. 在因子清单中添加THS代码
2. 进行IC验证并记录
3. 进行单因子回测并记录
4. 更新本索引文件

### 字段说明

| 字段 | 说明 |
|------|------|
| IC状态 | 待验证 / 验证中 / 是已验证 / 是已拒绝 |
| 回测状态 | 待回测 / 回测中 / 是已回测 / 是已拒绝 |
| 版本历史 | 版本记录文件路径 |
