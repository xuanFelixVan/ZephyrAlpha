## 🔍 快速导航

### 数据管道流程

```
数据采集 → 数据清洗 → 数据验证 → 数据存储 → 数据分发
```

### 关键组件

- **数据采集器**: 从多个数据源采集数据
- **数据清洗器**: 清洗和标准化数据
- **数据验证器**: 验证数据质量和完整性
- **数据存储**: Feature Store和时序数据库
- **数据分发**: 向下游系统分发数据
