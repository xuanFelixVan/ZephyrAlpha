## 📋 项目概述

### 项目背景

根据Layer 2 Alpha因子层技术评审结果，**数据源广度不足**是P0级阻断性风险。当前系统仅依赖iFinD、Baostock、AkShare三个数据源，缺少新闻、社交媒体、分析师预期等另类数据，严重限制了因子研究深度和原创性。

### 项目目标

**核心目标**: 在8周内完成另类数据源集成，构建完整的另类数据因子体系

**量化目标**:
1. ✅ 接入至少3个另类数据源（新闻、社交媒体、分析师预期）
2. ✅ 数据质量达到95%以上
3. ✅ 构建至少8个另类数据因子
4. ✅ 因子IC均值达到0.03以上
5. ✅ 数据广度从30%提升到70%

### 项目价值

| 价值维度 | 当前状态 | 目标状态 | 提升幅度 |
|---------|---------|---------|---------|
| **数据广度** | 30% | 70% | +133% |
| **因子多样性** | 8大类 | 11大类 | +37.5% |
| **研究深度** | 基础 | 中级 | +50% |
| **竞争优势** | 低 | 中 | +100% |

## 🎯 项目范围

### 包含内容

1. **数据源接入**
   - 新闻数据源：财联社API、新浪财经API、东方财富API
   - 社交媒体数据源：微博API、雪球网爬虫、东方财富股吧
   - 分析师预期数据源：东方财富分析师预期、同花顺研报

2. **NLP处理**
   - 情感分析：GLM-4-Flash
   - 事件提取：事件分类、影响评估
   - 实体识别：股票代码、公司名称识别

3. **因子构建**
   - 新闻因子：情感因子、事件驱动因子、热度因子
   - 情绪因子：市场情绪、个股情绪
   - 预期因子：分析师预期差异、评级变化
   - 关注度因子：社交媒体热度

4. **系统集成**
   - 数据存储：SQLite + ChromaDB
   - 任务调度：Apache Airflow
   - 因子管理：因子注册、IC验证、监控

### 不包含内容

1. ❌ 实时交易系统集成
2. ❌ 高频数据处理
3. ❌ 付费数据源购买
4. ❌ 宏观经济数据接入
