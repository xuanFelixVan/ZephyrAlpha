## 📋 使用说明

### 1. 审查触发判断
在开始审查前，请确认是否满足审查条件：
- [ ] 新蓝图创建完成
- [ ] AI讨论涉及新主题或重大变更
- [ ] 重大架构修改
- [ ] 版本升级
- [ ] 代码库增长超过20%
- [ ] 新依赖引入

### 2. 审查执行
1. 按检查清单逐项检查
2. 记录所有发现的问题
3. 对问题进行分类分级
4. 计算系统健康度评分

### 3. 审查后处理
1. 生成审查报告
2. 制定修复计划
3. 更新审查方案
4. 等待下次触发

### 4. 模板更新
每次审查后，根据经验优化本模板，版本号递增。
