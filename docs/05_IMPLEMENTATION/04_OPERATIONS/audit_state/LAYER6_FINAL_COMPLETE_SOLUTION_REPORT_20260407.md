### 4.2 推荐开源项目清单

**GitHub成熟项目**:
1. **PyPortfolioOpt** (4.2k stars) - 组合优化核心库
   - 支持均值方差、Black-Litterman、风险平价
   - 支持不确定性建模和随机优化
   - 文档完善，社区活跃

2. **Riskfolio-Lib** (3.1k stars) - 风险优化专业库
   - 支持风险平价、CVaR、CDaR优化
   - 支持多种风险度量
   - 可视化功能强大

3. **cvxpy** (5.8k stars) - 凸优化核心库
   - 支持复杂约束优化
   - 多种求解器集成
   - 学术界广泛使用

4. **pyfolio** (5.5k stars) - 绩效分析库
   - 专业的绩效分析工具
   - 丰富的可视化
   - 风险指标完善

5. **SALib** (800+ stars) - 敏感性分析库
   - Sobol、Morris等多种方法
   - 易于集成
   - 文档清晰
