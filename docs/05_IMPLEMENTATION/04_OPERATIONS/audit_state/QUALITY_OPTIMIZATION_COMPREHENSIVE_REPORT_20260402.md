## 🔧 开发的自动化工具

### 1. 文档审计工具
**文件**: `scripts/document_auditor.py`
**功能**:
- 链接检查
- 版本检查
- 分类检查
- 元数据检查

**使用方式**:
```bash
python scripts/document_auditor.py --all
```

### 2. 链接修复工具
**文件**: `scripts/link_fixer.py`
**功能**:
- 扫描损坏链接
- 自动修复链接
- 生成修复报告

**使用方式**:
```bash
python scripts/link_fixer.py --scan --report
python scripts/link_fixer.py --fix
```

### 3. 元数据完善工具
**文件**: `scripts/metadata_enhancer.py`
**功能**:
- 扫描元数据缺失
- 自动推断字段值
- 批量添加元数据

**使用方式**:
```bash
python scripts/metadata_enhancer.py --scan --report
python scripts/metadata_enhancer.py --enhance
```

### 4. 文档分类工具
**文件**: `scripts/document_classifier.py`
**功能**:
- 分析文档内容
- 推断合适分类
- 移动文档到标准目录

**使用方式**:
```bash
python scripts/document_classifier.py --scan --report
python scripts/document_classifier.py --move
```

### 5. 定期维护脚本
**文件**: `scripts/periodic_maintenance.ps1`
**功能**:
- 自动运行所有检查工具
- 生成综合报告
- 提供改进建议

**使用方式**:
```powershell
.\scripts\periodic_maintenance.ps1
```
