**案例1：ARCHITECTURE.md的双重架构描述**

```markdown

> - **实施指导**：[PROFESSIONAL_IMPLEMENTATION_BLUEPRINT.md]
```

**问题分析**：
- ❌ 违反**版本隔离原则**：同一文档同时描述新老架构
