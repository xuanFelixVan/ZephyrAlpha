#### 1.1 职责描述规范模板

**标准格式**:
```markdown
> **核心职责**: [一句话概括文档核心职责]
> **职责边界**: 
> - ✅ 本文档负责：[具体负责的内容列表]
> - ❌ 本文档不负责：[明确不负责的内容列表]
> - 📋 相关文档：[相关文档链接] - [简要说明]
```

**规范文档**: RESPONSIBILITY_DESCRIPTION_STANDARD.md

#### 1.2 职责描述审查机制

**审查清单**:
- [ ] 核心职责是否清晰明确
- [ ] 职责边界是否完整
- [ ] 是否与文档内容一致
- [ ] 是否与其他文档职责重叠
- [ ] 相关文档链接是否有效

**审查流程**:
1. **自审**: 文档作者在完成文档后自行检查
2. **互审**: 团队成员交叉审查职责描述
3. **终审**: 文档架构师最终审核

**审查频率**:
- **新建文档**: 立即审查
- **更新文档**: 每次更新后审查
- **定期审查**: 每月审查一次
