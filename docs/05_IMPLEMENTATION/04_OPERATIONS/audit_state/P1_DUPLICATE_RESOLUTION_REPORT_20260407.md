```
PORTFOLIO_CONSTRAINT_MANAGEMENT (约束管理)

    ↓ 执行约束求解算法

- **PORTFOLIO_CONSTRAINT_MANAGEMENT**: 负责约束库管理、约束冲突检测、约束优先级管理
- **CONSTRAINT_SOLVER**: 负责约束求解算法、优化引擎、约束验证

### 3.2 风险预算职责边界

```
HIERARCHICAL_RISK_BUDGET (层级风险预算)
    ↓ 复杂组合的多层级风险预算
SIMPLIFIED_RISK_BUDGET_SYSTEM (简化版风险预算)
    ↓ 简单组合的VaR风险预算
RISK_PARITY_STRATEGY (风险平价策略)
    ↓ 风险贡献均衡的经典策略

```

**职责边界**:
- **HIERARCHICAL_RISK_BUDGET**: 负责多层级风险预算（资产类→策略→因子）
- **SIMPLIFIED_RISK_BUDGET_SYSTEM**: 负责简化版风险预算（基于VaR）
- **RISK_PARITY_STRATEGY**: 负责风险平价策略（风险贡献均衡）

### 3.3 再平衡职责边界

```
PORTFOLIO_REBALANCING (基础再平衡)
    ↓ 提供触发机制和决策框架
TRANSACTION_COST_AWARE_REBALANCING (成本感知再平衡)
