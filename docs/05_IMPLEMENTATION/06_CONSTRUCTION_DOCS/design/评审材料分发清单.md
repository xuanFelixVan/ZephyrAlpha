## 3. 分发步骤与操作指南

### 3.1 材料打包 (会议秘书执行)

```powershell
# 1. 进入项目根目录
cd d:\ZephyrAlpha

# 2. 创建评审材料临时目录
mkdir -Force .\temp\review_materials

# 3. 复制核心材料
Copy-Item .\docs\design\技术方案设计汇总报告.md .\temp\review_materials\
Copy-Item .\docs\design\技术方案评审会议议程.md .\temp\review_materials\

# 4. 复制设计文档
Copy-Item .\docs\design\a_stock_rules\*.md .\temp\review_materials\a_stock_rules\
Copy-Item .\docs\design\a_stock_rules\*.yaml .\temp\review_materials\a_stock_rules\
Copy-Item .\docs\design\data_consistency\*.md .\temp\review_materials\data_consistency\
Copy-Item .\docs\design\trading_costs\*.md .\temp\review_materials\trading_costs\
Copy-Item .\docs\design\trading_costs\*.yaml .\temp\review_materials\trading_costs\
Copy-Item .\docs\design\web_interface\*.md .\temp\review_materials\web_interface\

# 5. 创建压缩包 (ZIP格式)
Compress-Archive -Path .\temp\review_materials\* -DestinationPath .\review_materials_package.zip -Force

# 6. 清理临时目录
Remove-Item .\temp\review_materials -Recurse -Force

# 7. 验证压缩包内容
Write-Host "评审材料包已创建: review_materials_package.zip"
Write-Host "包含文件数量: $( (Get-ChildItem -Path .\review_materials_package.zip -Recurse | Measure-Object).Count ) 个文件"
```

## 6. 应急预案

### 6.1 材料分发失败处理
1. **首次分发失败**: 检查邮件系统，重新发送
2. **附件过大**: 使用网盘链接分发
3. **文件损坏**: 提供备用下载地址
4. **时间紧迫**: 提前召开材料说明会

### 6.2 阅读进度延迟处理
1. **个别延迟**: 单独提醒，提供重点摘要
2. **集体延迟**: 调整会议时间或简化评审内容
3. **紧急情况**: 会前30分钟快速同步关键内容
