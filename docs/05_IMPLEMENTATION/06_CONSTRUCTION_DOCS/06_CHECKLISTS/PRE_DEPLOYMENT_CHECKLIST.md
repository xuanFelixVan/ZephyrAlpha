# 部署前检查清单

> **版本**: v1.0
> **创建日期**: 2026-04-02
> **职责**: 确保系统部署前的完整性和正确性
> **使用场景**: 每次部署到生产环境前必须完成

---

## 📋 检查清单使用说明

### 使用方法

1. **逐项检查**: 按照清单顺序逐项检查
2. **标记状态**: 使用 ✅（通过）、❌（未通过）、⚠️（警告）标记
3. **记录问题**: 对未通过项记录具体问题
4. **修复验证**: 修复问题后重新验证
5. **签字确认**: 所有检查项通过后签字确认

### 检查结果判定

- **全部通过**: 可以部署
- **存在警告**: 评估风险后决定是否部署
- **存在未通过项**: 必须修复后才能部署
