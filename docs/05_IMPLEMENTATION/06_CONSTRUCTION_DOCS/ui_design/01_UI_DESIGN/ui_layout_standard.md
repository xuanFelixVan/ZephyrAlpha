# 用户体验设计规范

> 清风量化系统 v4.0 的用户体验设计标准

---

## 1. 设计原则

### 1.1 核心设计原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| 简洁直观 | 界面清晰，功能入口明确 | 扁平化层级，清晰导航 |
| 操作便捷 | 减少操作步骤，提高效率 | 快捷键，批量操作 |
| 响应迅速 | 界面响应及时，加载明确 | 异步加载，进度提示 |
| 个性化定制 | 支持界面布局和主题配置 | 可拖拽面板，自定义主题 |
| 零门槛 | 非技术人员也能轻松使用 | 向导式操作，智能提示 |
| 自然交互 | 最自然的交互方式 | 语音、图形、对话 |

### 1.2 视觉设计原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| 统一风格 | 整体视觉风格一致 | 色彩、字体、图标统一 |
| 清晰布局 | 信息层次分明 | 栅格系统，间距规范 |
| 色彩协调 | 专业金融色彩体系 | 深色主题为主 |
| 图标明确 | 含义清晰，认知一致 | 线性图标，语义化 |
| 桌面端优化 | 专为桌面端大屏设计 | 1440px+分辨率 |

## 2. 界面布局规范

### 2.1 五区域布局

```
┌──────────────────────────────────────────────────────────────────────┐
│  顶部导航栏 (Header)        # 系统级导航和功能入口                    │
│  高度: 56px                                                             │
├──────────────────────────────────────────────────────────────────────┤
│  左侧菜单栏 (Sidebar)      # 主要功能模块导航                         │
│  宽度: 240px                                                            │
│                                                                        │
│  ┌──────────────────────────────────────────────────────────────────┐ │
│  │  中间内容区 (Content)      # 核心功能展示区域                     │ │
│  │                                                                   │ │
│  │                                                                   │ │
│  │                                                                   │ │
│  └──────────────────────────────────────────────────────────────────┘ │
│                                                                        │
│  ┌──────────────────────────────────────────────────────────────────┐ │
│  │  右侧辅助区 (Aside)        # 辅助信息和快捷操作                   │ │
│  │  宽度: 320px                                                         │ │
│  └──────────────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────┤
│  底部状态栏 (Footer)        # 系统状态和版权信息                       │
│  高度: 32px                                                             │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 布局规格

| 区域 | 最小宽度 | 最大宽度 | 高度 | 说明 |
|------|----------|----------|------|------|
| Header | 100% | 100% | 56px | 固定顶部 |
| Sidebar | 200px | 300px | 100% | 可折叠 |
| Content | 800px | 1600px | 100% | 自适应 |
| Aside | 280px | 400px | 100% | 可折叠 |
| Footer | 100% | 100% | 32px | 固定底部 |

## 3. 组件设计规范

### 3.1 按钮规范

#### 按钮类型

| 类型 | 样式 | 用途 | 示例 |
|------|------|------|------|
| 主要按钮 | 蓝色背景，白色文字 | 核心操作 | 保存、提交、执行 |
| 次要按钮 | 白色背景，蓝色边框 | 辅助操作 | 取消、返回 |
| 危险按钮 | 红色背景，白色文字 | 危险操作 | 删除、清空 |
| 文字按钮 | 无背景，蓝色文字 | 次要辅助 | 重置、恢复 |

#### 按钮规格

| 规格 | 值 |
|------|-----|
| 高度 | 36px (小) / 40px (中) / 48px (大) |
| 圆角 | 4px |
| 内边距 | 12px 16px |
| 字号 | 14px |
| 间距 | 8px |

### 3.2 表单规范

#### 表单布局

| 规范 | 说明 |
|------|------|
| 标签位置 | 左对齐，宽度120px |
| 输入框 | 右对齐，宽度240px |
| 必填标识 | 红色星号 * |
| 错误提示 | 输入框下方红色文字 |

#### 验证规则

| 类型 | 验证方式 | 错误提示 |
|------|----------|----------|
| 必填 | 非空检查 | "此字段为必填项" |
| 格式 | 正则表达式 | "格式不正确" |
| 范围 | 数值范围 | "数值超出范围" |
| 唯一性 | 数据库查询 | "已存在" |

### 3.3 表格规范

| 规格 | 值 |
|------|-----|
| 行高 | 48px |
| 表头高 | 56px |
| 边框色 | #E5E7EB |
| 悬停色 | #F9FAFB |
| 选中色 | #EFF6FF |

## 4. 交互规范

### 4.1 性能要求

| 指标 | 阈值 | 说明 |
|------|------|------|
| 按钮点击响应 | ≤100ms | 视觉反馈 |
| 页面切换 | ≤500ms | 加载完成 |
| 数据查询 | ≤1s | 显示结果 |
| 复杂操作 | 显示进度条 | 需用户等待 |

### 4.2 反馈机制

| 状态 | 反馈形式 |
|------|----------|
| 成功 | 绿色提示toast，1.5s后自动消失 |
| 失败 | 红色提示toast，需手动关闭 |
| 加载中 | 中心spinner或进度条 |
| 确认 | 模态对话框 |

### 4.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Ctrl+F | 搜索 |
| Ctrl+E | 编辑 |
| Delete | 删除 |
| Enter | 确认 |
| Escape | 取消 |
