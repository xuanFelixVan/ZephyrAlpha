## 🎯 设计原则



1. **一致性**: 统一的视觉语言和交互模式

2. **可用性**: 简洁直观的操作流程

3. **响应式**: 适配多种屏幕尺寸

4. **可访问性**: 支持键盘导航和屏幕阅读器



## 📐 布局规范要点



| 规范项 | 标准值 | 说明 |

|-------|--------|------|

| 页面宽度 | 1920px | 最大宽度，支持响应式缩放 |

| 侧边栏宽度 | 240px | 固定宽度 |

| 内容区边距 | 24px | 统一内边距 |

| 组件间距 | 16px | 标准间距 |
