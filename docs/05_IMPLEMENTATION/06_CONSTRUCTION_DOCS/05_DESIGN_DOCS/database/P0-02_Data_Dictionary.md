#### дёҡеҠЎи§„еҲҷ

1. **иҙҰжҲ·зј–з Ғи§„еҲҷ**: `ACC_YYYYMMDD_XXX`
   - ACC: еӣәе®ҡеүҚзјҖ
   - YYYYMMDD: еҲӣе»әж—Ҙжңҹ
   - XXX: еҪ“ж—ҘеәҸеҸ·пј?01-999пј?

2. **иө„йҮ‘и®Ўз®—и§„еҲҷ**:
   - жҖ»иө„дә?= еҸҜз”ЁзҺ°йҮ‘ + еҶ»з»“иө„йҮ‘ + жҢҒд»“еёӮеҖ?
   - зҙҜи®ЎзӣҲдәҸ = жҖ»иө„дә?- еҲқе§Ӣиө„йҮ‘
   - жңҖеӨ§еӣһж’?= (еҺҶеҸІжңҖй«ҳиө„дә?- еҪ“еүҚиө„дә§) / еҺҶеҸІжңҖй«ҳиө„дә?

3. **зҠ¶жҖҒиҪ¬жҚўи§„еҲ?*:
   - active вҶ?frozen: йЈҺжҺ§и§ҰеҸ‘жҲ–жүӢеҠЁеҶ»з»?
   - frozen вҶ?active: йЈҺжҺ§и§ЈйҷӨжҲ–жүӢеҠЁи§ЈеҶ?
   - active/frozen вҶ?closed: иҙҰжҲ·е…ій—ӯпјҲдёҚеҸҜйҖҶпјү
