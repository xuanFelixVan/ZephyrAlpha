### 防臃肿操作规程（新增 2026-04-13）

> **问题**：直接标记蓝图为「缺失」并创建新文件，会导致重复文件、系统臃肿。
> **教训**：Layer 11 最初标记 11 个蓝图缺失，实际全系统搜索后发现 100% 已存在，只是分散在不同目录。

**必须执行「先查找、后创建」原则：**

#### 步骤 1：全系统搜索（标记「缺失」前必须完成）

使用以下 PowerShell 命令在创建任何新蓝图前执行全系统搜索：

```powershell
# 搜索文件名匹配（替换关键词）
Get-ChildItem -Path 'docs' -Recurse -Filter '*.md' |
  Where-Object { $_.Name -match 'allocation|risk|budget|strategy|evaluation' } |
  Select-Object FullName, Length | Sort-Object Length -Descending

# 搜索内容匹配（在文件中查找相关模块）
Get-ChildItem -Path 'docs' -Recurse -Filter '*.md' |
  Select-String -Pattern 'module_id.*ALLOCATION|layer.*11' |
  Select-Object Filename, Line | Sort-Object Filename
```

#### 步骤 2：检查关键目录

在标记蓝图缺失前，必须检查以下位置：


| 优先级   | 检查位置                                                         | 说明                 |
| ----- | ------------------------------------------------------------ | ------------------ |
| 🔴 P0 | `docs/11_STRATEGIC_DECISION/` 子目录                            | 蓝图可能在子目录中而非根目录     |
| 🔴 P0 | `docs/01_FRAMEWORK/`                                         | Layer 1 可能包含战略相关蓝图 |
| 🔴 P0 | `docs/05_IMPLEMENTATION/06_CONSTRUCTION_DOCS/01_BLUEPRINTS/` | 施工图纸柜可能已有          |
| 🟡 P1 | `docs/10_AI_WORKFLOW/`                                       | AI 工作流层可能有相关实现     |
| 🟡 P1 | `docs/06_ARCHIVE/`                                           | 可能被归档但未删除          |
| 🟡 P1 | `docs/99_ARCHIVE/`                                           | 归档区可能包含历史版本        |
| 🟢 P2 | `.audit_fix_backup/`                                         | 备份目录中可能有原始版本       |


#### 步骤 3：使用治理脚本

运行以下脚本辅助查找：

```bash
# 扫描重复文件内容
python scripts/governance/scan_duplicate_file_content.py --ext md

# 扫描同名不同路径的文件
python scripts/governance/scan_basename_collisions.py

# 扫描蓝图重叠候选
python scripts/governance/scan_blueprint_d_overlap_candidates.py

# 目录结构分析
python scripts/analyze_and_fix_folder_structure.py --analyze-only
```

#### 步骤 4：标记「缺失」的标准

只有在**全部**以下条件满足时，才能标记为「缺失」：

- 文件名搜索无结果
- 关键词搜索无结果
- 06_ARCHIVE/ 和 99_ARCHIVE/ 检查无结果
- 子目录（01_asset_allocation/ 等）检查无结果
- 扫描脚本未发现重复或相似内容
- Git 历史搜索（`git log --all -- '*keyword*'`）无结果

**违规后果**：未经搜索直接创建蓝图 → 导致重复文件 → 需后续归档/合并 → 增加技术债务。
