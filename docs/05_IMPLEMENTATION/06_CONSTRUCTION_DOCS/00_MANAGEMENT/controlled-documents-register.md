# 受控文档登记表（建设 / 蓝图）

> **用途**：给「容易搞混两份稿」或「跨多个文件夹」的文档留一张**总台账**；不必登记每一个 `*BLUEPRINT.md`，按需追加行即可。  
> **真源**：正式路径以本表「Canonical 路径」列与 蓝图终稿定义 为准。

## 使用说明

- **新增一行**：每登记一条，至少填：标识、标题、Canonical 路径、版本、Owner、状态。  
- **状态建议取值**：`终稿` | `草案` | `只读副本` | `待废弃` | `已归档`  
- **终稿日期**：达到 蓝图终稿定义 第 1 节时填写。
