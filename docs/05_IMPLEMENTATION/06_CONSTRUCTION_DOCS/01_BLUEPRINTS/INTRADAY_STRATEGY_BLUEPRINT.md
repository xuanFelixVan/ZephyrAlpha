## 核心定位


日内交易策略模块,构建和运行和操作基于日内市场数据的短期交易策略,包括开盘策略、盘中策略和收盘策略,兼容和适配高频交易和算法交易执行。

## 接口与契约（蓝图终稿）

本模块接口规范遵循 [API_Contract.md](../../../03_TRADING_TACTICS/API_Contract.md) 定义的标准。

### 核心接口
- **API.SE.001**: StrategyEngine接口 - 接收市场数据,生成交易信号
- **API.RM.001**: RiskManager接口 - 接收交易信号,进行风控审批

### 数据契约
- 输入: 盘中数据 (pd.DataFrame), 市场状态 (str)
- 输出: 交易信号 (Dict), 信号强度 (float)
- 格式: JSON, UTF-8编码
- 时间戳: ISO 8601格式

## 已知限制

### 技术限制
1. 当前版本仅支持A股市场,其他市场需要适配
2. 盘中数据频率建议不低于1分钟,更低频率可能影响信号质量
3. 策略参数优化需要历史数据支持,实盘参数需要定期校准

### 性能限制
4. 单策略信号生成时间 < 50ms,多策略融合可能增加延迟
5. 实时数据流处理依赖外部数据源稳定性

### 集成限制
6. 与风控系统的集成需要统一信号格式
7. 策略历史表现数据存储依赖SQLite,大规模数据建议迁移
