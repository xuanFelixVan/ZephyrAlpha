- 全库 API 与事件约定真源：`API_Contract.md`。预处理完整架构涉及的数据集标准、清洗/对齐规则、质量事件、输出口径等对外约定需以该真源或其子契约为准。

- 邻层协同边界：与 **Layer 0（数据源）**、**Layer 2（因子/特征）**、**Layer 10（治理与合规）** 的交互以契约为准（避免输入输出口径漂移）。



## 验收标准（可检查）



- 能对至少一个数据域完成“源数据 → 清洗/对齐 → 标准化输出”的流水线闭环，并可复现一次运行记录。

- 输出数据能满足预定义质量阈值（如缺失率、重复率、时间对齐偏差），且阈值与计算口径可追溯。

- 能在质量异常或上游缺失时触发降级/阻断策略并留痕。

- 能提供字段字典/数据版本信息，并能关联到契约入口或其子契约。
