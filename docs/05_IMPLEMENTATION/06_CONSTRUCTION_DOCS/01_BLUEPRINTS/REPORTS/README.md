# REPORTS — 图纸柜过程稿与报告

本目录存放**非正式蓝图正文**的材料，例如：

- 带批次日期的完成报告、进度、覆盖率/完备性分析  
- 蓝图阶段的计划与检查清单稿  

**不包含** `*BLUEPRINT.md` 形式的模块设计终稿。

正式蓝图仍在上一级目录 `../` 根下；**机器生成的** `../INDEX.md` 仅列出根目录下的蓝图文件，**不**自动收录本目录（符合 [图纸柜规则](../../00_MANAGEMENT/01_BLUEPRINTS_REPOSITORY_RULES.md)）。
