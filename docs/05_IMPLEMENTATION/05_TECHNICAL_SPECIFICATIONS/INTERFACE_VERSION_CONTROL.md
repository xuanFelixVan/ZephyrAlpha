### 1.2 版本号规则

采用语义化版本号：`MAJOR.MINOR.PATCH`

| 版本类型 | 变更类型 | 示例 |
|----------|----------|------|
| MAJOR | 不兼容的API变更 | 1.0.0 → 2.0.0 |
| MINOR | 向后兼容的功能新增 | 1.0.0 → 1.1.0 |
| PATCH | 向后兼容的问题修复 | 1.0.0 → 1.0.1 |

## 4. 兼容性规则

### 4.1 向后兼容变更

以下变更视为向后兼容：

- 新增可选参数
- 新增接口方法
- 新增返回字段
- 扩展枚举值

### 4.2 破坏性变更

以下变更视为破坏性变更：

- 删除接口方法
- 修改方法签名
- 修改参数类型
- 修改返回类型
- 删除返回字段

### 4.3 兼容性保证

| 接口版本 | 支持周期 | 废弃通知 |
|----------|----------|----------|
| MAJOR版本 | 12个月 | 提前6个月 |
| MINOR版本 | 6个月 | 提前3个月 |
| PATCH版本 | 3个月 | 提前1个月 |

### 5.1 废弃流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        接口废弃流程                                      │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────┐ │
│  │  标记废弃   │ ─→ │ 发布通知   │ ─→ │ 迁移支持   │ ─→ │ 删除    │ │
│  │  @deprecated│    │  3个月     │    │  迁移指南   │    │  接口   │ │
│  └─────────────┘    └─────────────┘    └─────────────┘    └─────────┘ │
│                                                                         │
│  废弃标记示例:                                                          │
│                                                                         │
│  @deprecated(version="1.1.0", removal_version="2.0.0")                 │
│  def old_method(self):                                                  │
│      """已废弃，请使用 new_method()"""                                  │
│      pass                                                               │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 5.2 废弃通知模板

```markdown
