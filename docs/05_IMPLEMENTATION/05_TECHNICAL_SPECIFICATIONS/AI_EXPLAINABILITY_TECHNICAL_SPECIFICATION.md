```

ﮒﭘﻛﺕ:
- ﺵ_i: ﻝﺗﮒﺝiﻝSHAP?- N: ﮔﮔﻝﺗﮒﺝﻠ?- S: ﻝﺗﮒﺝﮒﻠ

```

```
