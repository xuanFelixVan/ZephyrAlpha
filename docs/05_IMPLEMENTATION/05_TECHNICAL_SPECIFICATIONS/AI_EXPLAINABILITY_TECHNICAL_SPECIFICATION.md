```

ﻝ۸ﭦﻠﺑﮒ۳ﮔ? O(n)

ﮒﭘﻛﺕ­:
- ﺵ_i: ﻝﺗﮒﺝiﻝSHAP?- N: ﮔﮔﻝﺗﮒﺝﻠ?- S: ﻝﺗﮒﺝﮒ­ﻠ

```
