### 3.2 职责边界说明

| 模块 | 职责 | 不负责 | 类型 |

| **FeatureEngineering** | 特征生成、选择、变换、评估 | 特征存储、服务 | 计算密集型 |

### 3.3 调用关系

```python
# FeatureEngineering与FeatureStore协作示例
class FeatureEngineering:
    def fit_transform(self, X, y):
        # 特征工程逻辑
        features = self.generate_features(X)
        features = self.select_features(features, y)
        features = self.transform_features(features)
        return features

class FeatureStore:
    def __init__(self, feature_engineering: FeatureEngineering):
        self.feature_engineering = feature_engineering
    
    def compute_and_store(self, data):
        # 调用FeatureEngineering计算特征
        features = self.feature_engineering.fit_transform(data)
        # 存储特征
        self.store(features)
```

### 4.3 调用关系

```python
# ModelTrainingPipeline调用模型训练器示例
class ModelTrainingPipeline:
    def __init__(self, trainer: IModelTrainer, config):
        self.trainer = trainer  # 注入模型特定训练器
    
    def train_model(self, training_config):
        # 1. 数据版本管理
        data = self.load_data_version(training_config.data_version)
        
        # 2. 超参数优化
        best_params = self.optimize_hyperparameters(data)
        
        # 3. 调用模型特定训练器
        result = self.trainer.train(
            X_train=data['X_train'],
            y_train=data['y_train'],
            X_val=data['X_val'],
            y_val=data['y_val']
        )
        
        # 4. 实验跟踪和模型注册
        self.log_experiment(result)
        self.register_model(result)
        
        return result
```

## 7. 总结

### 7.1 职责分离原则

1. **单一职责**: 每个模块只负责一种核心功能
2. **明确边界**: 职责边界清晰，避免重叠
3. **调用关系**: 上层调用下层，避免循环依赖

### 7.2 关键改进

| 改进项 | 修改前 | 修改后 |
|--------|--------|--------|
| 因子计算 | 4个文档重复定义 | FactorCalculator统一负责 |
| 特征计算 | FeatureEngineering和FeatureStore重叠 | 明确分离 |
| 模型训练 | 6个文档分散定义 | Pipeline调用Trainer |
| IC计算 | 4个文档重复定义 | FactorIC统一负责 |
| Layer定位 | Layer 6混乱 | 统一为Layer 4 |
