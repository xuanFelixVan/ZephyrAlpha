## 📝 文档创建中检查



### 1. 文件命名检查



- [ ] 文件名使用大写字母和下划线

- [ ] 文件名格式: `[模块名称]_[文档类型].md`

- [ ] 避免使用旧架构命名（Layer0_, Layer1_等）

- [ ] 避免使用特殊字符和中文

- [ ] 避免使用版本号后缀（_v1, _v2等）



**示例**:

- ✅ 正确: `ALPHA_FACTOR_FACTORY_BLUEPRINT.md`

- ❌ 错误: `alpha_factor_factory_blueprint.md`

- ❌ 错误: `Layer5_ALPHA_FACTOR_FACTORY_BLUEPRINT.md`



### 2. YAML头部检查



- [ ] 包含version字段（格式: x.y.z）

- [ ] 包含module_id字段（唯一标识）

- [ ] 包含layer字段（层级标识）

- [ ] 包含created字段（格式: YYYY-MM-DD）

- [ ] 包含updated字段（格式: YYYY-MM-DD）

- [ ] 包含status字段（draft/active/archived）



**示例**:

```yaml

---

version: 1.0.0

module_id: ALPHA_FACTOR_FACTORY

layer: 5.1

created: 2026-04-07

updated: 2026-04-07

status: active

---

```

## 🔧 常见问题处理



### 问题1: 职责描述过短



**症状**: 职责描述 < 50字



**解决方案**:

1. 补充模块的主要功能

2. 说明业务价值

3. 描述技术方法



**示例**:

```

❌ 过短: 负责Alpha因子工厂的实现。



✅ 合格: 负责Alpha因子工厂的设计与实现，基于多源数据挖掘和因子工程，生成高质量Alpha因子，支持策略研发和组合优化。

```



### 问题2: 职责描述过长



**症状**: 职责描述 > 200字



**解决方案**:

1. 精简冗余描述

2. 突出核心职责

3. 删除次要细节



### 问题3: 章节结构缺失



**症状**: 缺少必需章节



**解决方案**:

1. 使用标准模板

2. 补充缺失章节

3. 运行章节补全工具



**命令**:

```bash

python scripts/layer5_section_completer.py

```



### 问题4: 链接失效



**症状**: 文档中的链接无法访问



**解决方案**:

1. 检查链接目标是否存在

2. 使用相对路径

3. 更新链接地址

## 🎯 快速检查脚本



### 一键检查脚本



```bash

#!/bin/bash

# scripts/check_document.sh



DOCUMENT=$1



echo "检查文档: $DOCUMENT"

echo "===================="



# 1. 检查文件命名

if [[ $DOCUMENT =~ ^[A-Z_]+_[A-Z]+\.md$ ]]; then

    echo "✅ 文件命名规范"

else

    echo "❌ 文件命名不规范"

fi



# 2. 检查YAML头部

if grep -q "^---" "$DOCUMENT"; then

    echo "✅ YAML头部存在"

else

    echo "❌ YAML头部缺失"

fi



# 3. 检查核心章节

if grep -q "## 核心定位" "$DOCUMENT"; then

    echo "✅ 核心定位章节存在"

else

    echo "❌ 核心定位章节缺失"

fi



# 4. 检查文档长度

WORD_COUNT=$(wc -w < "$DOCUMENT")

if [ $WORD_COUNT -ge 1000 ]; then

    echo "✅ 文档长度合格 ($WORD_COUNT 字)"

else

    echo "❌ 文档长度不足 ($WORD_COUNT 字)"

fi



echo "===================="

echo "检查完成"

```



### 使用方法



```bash

# 添加执行权限

chmod +x scripts/check_document.sh



# 运行检查

./scripts/check_document.sh docs/05_IMPLEMENTATION/06_CONSTRUCTION_DOCS/01_BLUEPRINTS/ALPHA_FACTOR_FACTORY_BLUEPRINT.md

```
