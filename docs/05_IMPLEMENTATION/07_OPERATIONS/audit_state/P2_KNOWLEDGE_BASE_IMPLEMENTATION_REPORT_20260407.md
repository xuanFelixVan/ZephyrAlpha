### 2.1 职责描述最佳实践

**文档路径**: `docs/10_GOVERNANCE_COMPLIANCE/KNOWLEDGE_BASE/RESPONSIBILITY_DESCRIPTION_BEST_PRACTICES.md`

**文档内容**:

**1. 核心原则**
- 具体性：职责描述必须具体，不能使用通用模板
- 独特性：相似度不应超过80%
- 专业性：使用专业术语和标准表达
- 可读性：语言清晰简洁，结构逻辑清晰

**2. 最佳实践案例（50+案例）**
- 投资组合优化类：均值方差优化器、风险平价策略、Black-Litterman模型等
- 风险管理类：VaR/ES监控系统、风险归因系统、尾部风险对冲等
- 交易执行类：智能执行引擎、智能订单路由器、市场冲击模型等
- 数据治理类：数据目录系统、数据质量监控、数据生命周期管理等
- AI/机器学习类：AI模式识别引擎、强化学习再平衡、因子挖掘等

**3. 常见问题与避免方法**
- 问题1: 使用通用模板
- 问题2: 过于简短
- 问题3: 过于冗长
- 问题4: 缺少技术细节
- 问题5: 职责重叠

**4. 质量评估标准**
- 评估维度：具体性、独特性、专业性、可读性
- 评分标准：优秀（90-100分）、良好（70-89分）、需改进（<70分）
