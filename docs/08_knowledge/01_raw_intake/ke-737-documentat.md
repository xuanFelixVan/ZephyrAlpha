# VIEW-11 跳号说明

VIEW-11 跳号说明

视图编号 11 在架构设计时**有意跳过（reserved）**——10 个 TOGAF 视图（00-10）已构成完整的架构描述集，11 号预留为未来可能的新增视图入口（如"AI 原生架构视图"或"跨系统互操作视图"）。编号不被回收，新视图从 11 起分配。

> 对标 ADR 编号空间的 append-only 原则：编号跳过需显式登记，不得成为黑箱。
