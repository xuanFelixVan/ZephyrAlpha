# 一.1.3 选择决策树

一.1.3 选择决策树

```
Q1: 这个目录是否对应某个架构层（L00~L13）？
    → 是: 用 L{XX}_snake_case（如 L00_data_source/）
    → 否: Q2

Q2: 目录名是否用一个单词就能准确表达？
    → 是: 用单词（如 ai/, document/, task/）
    → 否: 用 snake_case（如 vibe_coding/, post_trade_analytics/）
```
