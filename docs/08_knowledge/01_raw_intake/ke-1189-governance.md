# COND-003：回测必须覆盖多种市场状态

COND-003：回测必须覆盖多种市场状态

因子回测必须在以下市场状态区间分别验证：

| 市场状态 | 数据区间要求 | 最低通过率 |
|---------|------------|----------|
| 牛市 | 至少 1 个完整牛市周期 | 夏普 ≥ 0.8 |
| 熊市 | 至少 1 个完整熊市周期 | 最大回撤 ≤ 25% |
| 震荡市 | 至少 6 个月震荡区间 | IC 均值 ≥ 0.02 |
| 极端行情 | 包含 2015 股灾 / 2020 疫情 | 最大回撤 ≤ 35% |

任一状态未通过 → 标记为 `market_state_risk`，拒绝上线。
