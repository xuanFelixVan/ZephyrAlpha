# 6.1 能力升档投入模型

6.1 能力升档投入模型

**经验系数**（基于单人开发 + AI 协作者 vibe coding 加成 3-5x）：

| 升档路径 | 单能力单位工作量 | 说明 |
|---|---|---|
| L0 → L1 | 0.5 人周 | 写 ADR + 架构视图 |
| L1 → L2 | 1-2 人周 | 写 stub 代码 + skeleton 测试 |
| L2 → L3 | 2-4 人周 | 实现 + pytest ≥ 60% + 文档 |
| L3 → L4 | 4-8 人周 | 生产级 + SLO + 监控 + runbook |
| L4 → L5 | 8-16 人周 + 外部证据 | 开源 / 论文 / 业界领先 |
