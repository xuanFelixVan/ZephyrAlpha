# 14. 审查周期

14. 审查周期

对标 ISO 11179 §6.2 定期审查要求，本策略应在以下时机进行审查：

| 触发条件 | 审查内容 |
|---------|---------|
| 每次 Phase 边界 | 10 条铁律是否仍覆盖当前架构的全部风险面 |
| 新 AI 行为模式发现 | 是否需要新增铁律 |
| GOV-MOD-005 INJ 规则变更 | 铁律→INJ 派生映射是否需要更新（§3 受控枚举表） |
| 最低频率：每 6 个月 | 全量审查——即使无触发事件 |
