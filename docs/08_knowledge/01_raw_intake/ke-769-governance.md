# 1.2 责任范围（本标准管什么）

1.2 责任范围（本标准管什么）

- **创建操作**：创建规则/模块/脚本/ADR/文档/目录/门禁/知识条目等工件后，必须写入哪些登记表
- **修改操作**：修改跨表共享字段后，必须同步哪些登记表
- 同步的原子性要求（所有关联更新在同一批次操作中完成）
- 同步后的校验步骤
- 违反同步规则的后果和补救流程
