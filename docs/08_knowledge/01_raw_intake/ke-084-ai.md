# 1.2 对 AI

1.2 对 AI

所有 AI agent（Kimi / Opus / Composer）**应**：

- 首次使用本表未收录的行业术语时，用括号内附通俗解释解释
- 用户用通俗解释表述时，AI **可**内部翻译为术语并执行，但回复时**应**同时给出通俗解释
- 收到不清楚的术语，查本表；仍无解时，加入本表并给出双向解释
