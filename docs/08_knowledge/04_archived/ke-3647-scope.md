# 15.1 `scope` 字段

15.1 `scope` 字段

| 属性 | 值 |
|------|-----|
| 字段名 | `scope` |
| 域 | A（文档 frontmatter） |
| 必填 | 是（新增规则文档时） |
| 类型 | enum |
| 受控词表 | `global`, `domain`, `module`, `session` |
| 默认值 | `domain` |
| 说明 | 规则的作用范围，决定变更通知范围 |
| 归属标准 | PS-STD-004 |
