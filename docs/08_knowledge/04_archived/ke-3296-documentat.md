# 12. 恢复操作

12. 恢复操作

| Step | 操作 | 验证 |
|------|------|------|
| 1 | 确认所有异常已修复 | 异常清单已清零 |
| 2 | 确认所有文件内容正确 | 文件检查通过 |
| 3 | 运行门禁检查清单（OPS-VC-005） | 门禁通过 |
| 4 | 标记 session 为 `resumed` | Session Log 已更新 |
| 5 | 继续未完成的操作 | 操作继续 |
