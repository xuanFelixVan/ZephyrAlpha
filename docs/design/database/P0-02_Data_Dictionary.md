#### 业务规则

1. **账户编码规则**: `ACC_YYYYMMDD_XXX`

   - YYYYMMDD: 创建日期
   - XXX: 当日序号（001-999）

#### 业务规则

1. **股票代码格式**: `XXXXXX.SH` 或 `XXXXXX.SZ`
   - XXXXXX: 6位股票代码
   - SH: 上海证券交易所
   - SZ: 深圳证券交易所

2. **持仓数量计算规则**:
   - 持仓数量 = 可用数量 + 冻结数量
   - 可用数量: T+1规则，当日买入的股票次日可用
   - 冻结数量: 卖出订单提交时冻结

3. **平均成本计算规则**:
   - 买入: 新平均成本 = (原持仓成本 + 买入金额) / 新持仓数量
   - 卖出: 平均成本不变

4. **盈亏计算规则**:
   - 浮动盈亏 = (当前价格 - 平均成本) × 持仓数量
   - 浮动盈亏比例 = (当前价格 - 平均成本) / 平均成本
   - 已实现盈亏: 卖出时累计
