## 🚀 使用指南

### 1. 查找文档
```bash
# 查看本目录所有文档
ls -la docs/00_RESOURCES/04_PLATFORM_DOCS/

# 搜索特定平台文档
find docs/00_RESOURCES/04_PLATFORM_DOCS -name "*.pdf" | grep -i "qmt"
```

### 2. 添加新文档
```bash
# 示例：添加新的平台文档
cp ~/Downloads/券商柜台系统_v2.1.pdf docs/00_RESOURCES/04_PLATFORM_DOCS/

# 更新本索引文件
# 手动编辑本README.md，在"当前文档清单"部分添加新行
```

### 3. 文档命名规范
1. **平台_文档名_版本.pdf**: `迅投QMT_极速策略交易系统说明_官方版.pdf`
2. **包含版本信息**: 重要文档应包含版本号
3. **中文优先**: 优先使用中文名称，确保易读性
4. **来源标注**: 可标注来源，如`官方`、`社区版`等

## 🔄 维护流程

### 定期检查（每半年）
1. **版本更新检查**: 检查各平台是否有新版本发布
2. **有效性验证**: 验证文档内容是否仍然有效
3. **重复清理**: 删除重复或过时文档
4. **索引更新**: 更新本README.md索引

### 文档更新流程
1. **获取新版本**: 从官方渠道获取最新文档
2. **版本对比**: 对比新旧版本变化
3. **替换/保留**: 决定是否替换旧版本或保留多个版本
4. **更新索引**: 更新本README.md中的版本信息

### 文档删除流程
1. **评估影响**: 确认无其他文档依赖
2. **备份历史版本**: 重要文档备份到`06_ARCHIVE/`
3. **删除文件**: 删除物理文件
4. **更新索引**: 从本索引中移除
