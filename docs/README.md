## 快速导航

### 1. 策略开发流程

```
1. 阅读主文档 → 了解策略框架
2. 查阅因子库 → 选择合适的因子
3. 参考战术库 → 确定交易战法
4. 查看技术文档 → 了解接口规范
```

### 2. 新增因子流程

```
1. 在因子库中新增因子定义
2. 计算IC/IR验证有效性
3. 配置参数
4. 更新因子主索引
```

### 3. 新增战术流程

```
1. 在02_TACTICS对应Layer目录新增战术文件
2. 定义量化标准和交易信号
3. 更新战术库README索引
```

## 贡献指南

1. **不要在主文档中堆砌详细战术** - 应放在02_TACTICS战术库
2. **不要在主文档中重复因子参数** - 应引用factor-library
3. **保持引用单向** - 主文档可引用子文档，子文档不引用主文档
4. **版本号同步** - 主文档更新时考虑是否需要同步子文档
5. **防止文件漂移** - 使用因子主索引作为单一入口
