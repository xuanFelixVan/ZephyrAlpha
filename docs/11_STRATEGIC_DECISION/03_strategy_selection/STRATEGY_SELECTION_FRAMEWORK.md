## 二、核心模型设计

### 2.1 策略评估模型

**模型原理**: 多维度评估策略表现

**评估维度**:
```
策略评分 = w1 * 绩效评分 + w2 * 风险评分 + w3 * 稳定性评分 + w4 * 一致性评分
其中：
- 绩效评分: 收益率、夏普比率、索提诺比率
- 风险评分: 波动率、最大回撤、VaR、CVaR
- 稳定性评分: 稳定性指标、一致性指标
- 一致性评分: 信息比率、跟踪误差
```

**开源实现**: empyrical, pyfolio

### 2.2 策略筛选模型

**模型原理**: 基于评分和阈值筛选策略

**筛选流程**:
```
1. 计算策略评分
2. 应用筛选阈值
3. 排序策略
4. 分组策略
5. 推荐最优策略
```

**开源实现**: 自定义筛选模块

### 2.3 组合优化模型

**模型原理**: 优化策略组合权重

**优化方法**:
```
1. 均值方差优化
2. 风险平价优化
3. 风险预算优化
4. Black-Litterman优化
```

**开源实现**: skfolio, PyPortfolioOpt
