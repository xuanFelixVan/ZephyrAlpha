## 二、核心模型设计

### 2.1 均值方差优化模型

**模型原理**: 最大化风险调整后收益

**数学表达**:
```
max: μ^T w - λ/2 * w^T Σ w
s.t.: Σ w_i = 1
      w_i >= 0
其中：
- μ: 策略期望收益向量
- w: 策略权重向量
- Σ: 策略协方差矩阵
- λ: 风险厌恶系数
```

**开源实现**: skfolio的MeanVariance

### 2.2 风险平价优化模型

**模型原理**: 使各策略的风险贡献相等

**数学表达**:
```
RC_i = w_i * (Σw)_i / σ_p
目标: RC_i = RC_j for all i, j
其中：
- RC_i: 策略i的风险贡献
- w_i: 策略i的权重
- (Σw)_i: 协方差矩阵第i行与权重向量的乘积
- σ_p: 组合波动率
```

**开源实现**: skfolio的RiskParity

### 2.3 风险预算优化模型

**模型原理**: 根据预设的风险预算分配权重

**数学表达**:
```
RC_i / RC_j = b_i / b_j
其中：
- RC_i: 策略i的风险贡献
- b_i: 策略i的风险预算
```

**开源实现**: skfolio的RiskBudgeting
