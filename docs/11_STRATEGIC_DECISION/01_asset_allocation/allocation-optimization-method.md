## 二、功能设计



### 2.1 核心功能



#### 功能1：均值方差优化



**功能描述**：

- 功能目标：在给定风险水平下最大化收益，或在给定收益水平下最小化风险

- 使用场景：战略资产配置、战术资产配置

- 触发条件：定期配置决策（季度/年度）



**输入参数**：

| 参数名称 | 类型 | 必填 | 默认值 | 说明 |

|---------|------|------|--------|------|

| expected_returns | np.array | 是 | - | 预期收益率向量 |

| cov_matrix | np.array | 是 | - | 协方差矩阵 |

| risk_free_rate | float | 否 | 0.02 | 无风险利率 |

| target_return | float | 否 | None | 目标收益率 |

| target_risk | float | 否 | None | 目标风险 |

| weight_bounds | tuple | 否 | (0, 1) | 权重边界 |



**输出结果**：

| 字段名称 | 类型 | 说明 |

|---------|------|------|

| weights | np.array | 最优权重向量 |

| expected_return | float | 预期收益 |

| volatility | float | 预期波动率 |

| sharpe_ratio | float | 夏普比率 |

| success | bool | 优化是否成功 |

| message | str | 优化信息 |



**算法逻辑**：

1. 输入验证：检查参数合法性和维度一致性

2. 构建目标函数：根据优化目标构建目标函数

3. 构建约束条件：权重约束、风险约束等

4. 求解优化问题：使用二次规划求解

5. 结果验证：检查结果合理性

6. 返回优化结果



**异常处理**：

- 参数维度不匹配 → 抛出ValueError

- 协方差矩阵非正定 → 使用正则化方法

- 优化无解 → 返回等权重配置



**性能要求**：

- 响应时间：< 100ms

- 并发能力：10 QPS

- 内存占用：< 50MB



**AI维护要点**：

- 关键参数：expected_returns, cov_matrix

- 常见问题：协方差矩阵估计不准确、预期收益偏差大

- 优化方向：使用收缩估计、Black-Litterman调整



#### 功能2：Black-Litterman优化



**功能描述**：

- 功能目标：融合市场均衡收益和投资者观点，生成后验收益估计

- 使用场景：有明确投资观点的资产配置

- 触发条件：投资者有明确观点时



**输入参数**：

| 参数名称 | 类型 | 必填 | 默认值 | 说明 |

|---------|------|------|--------|------|

| market_prices | pd.DataFrame | 是 | - | 市场价格数据 |

| market_caps | np.array | 是 | - | 市值权重 |

| views | dict | 否 | {} | 投资者观点 |

| view_confidences | np.array | 否 | None | 观点置信度 |

| tau | float | 否 | 0.05 | 缩放参数 |

| risk_aversion | float | 否 | 2.5 | 风险厌恶系数 |



**输出结果**：

| 字段名称 | 类型 | 说明 |

|---------|------|------|

| posterior_returns | np.array | 后验收益估计 |

| posterior_cov | np.array | 后验协方差矩阵 |

| weights | np.array | 最优权重 |

| bl_weights | np.array | BL模型权重 |



**算法逻辑**：

1. 计算市场均衡收益：使用市值权重反推

2. 构建观点矩阵：将投资者观点转换为矩阵形式

3. 计算后验收益：使用贝叶斯公式融合观点

4. 优化求解：基于后验收益进行优化

5. 结果验证：检查结果合理性



**异常处理**：

- 观点矩阵构建失败 → 使用市场均衡收益

- 后验收益异常 → 返回市场均衡配置



**性能要求**：

- 响应时间：< 200ms

- 并发能力：5 QPS

- 内存占用：< 100MB



**AI维护要点**：

- 关键参数：views, view_confidences, tau

- 常见问题：观点矩阵构建错误、置信度设置不当

- 优化方向：使用历史数据校准tau参数



#### 功能3：风险平价优化



**功能描述**：

- 功能目标：使各资产的风险贡献相等或符合预算

- 使用场景：风险控制优先的资产配置

- 触发条件：风险预算分配时



**输入参数**：

| 参数名称 | 类型 | 必填 | 默认值 | 说明 |

|---------|------|------|--------|------|

| cov_matrix | np.array | 是 | - | 协方差矩阵 |

| risk_budget | np.array | 否 | None | 风险预算 |

| target_risk | float | 否 | None | 目标风险 |

| weight_bounds | tuple | 否 | (0, 1) | 权重边界 |



**输出结果**：

| 字段名称 | 类型 | 说明 |

|---------|------|------|

| weights | np.array | 风险平价权重 |

| risk_contributions | np.array | 风险贡献度 |

| portfolio_risk | float | 组合风险 |

| marginal_risk | np.array | 边际风险贡献 |



**算法逻辑**：

1. 计算风险贡献度：使用边际风险贡献公式

2. 构建目标函数：使风险贡献度相等或符合预算

3. 优化求解：使用非线性优化方法

4. 结果验证：检查风险贡献度分布



**异常处理**：

- 协方差矩阵非正定 → 使用正则化方法

- 优化无解 → 返回等风险贡献权重



**性能要求**：

- 响应时间：< 150ms

- 并发能力：5 QPS

- 内存占用：< 50MB



**AI维护要点**：

- 关键参数：cov_matrix, risk_budget

- 常见问题：协方差矩阵估计不准确、风险预算设置不当

- 优化方向：使用动态协方差估计



#### 功能4：约束条件处理



**功能描述**：

- 功能目标：处理各种约束条件，确保优化结果符合要求

- 使用场景：所有优化方法

- 触发条件：优化求解时



**输入参数**：

| 参数名称 | 类型 | 必填 | 默认值 | 说明 |

|---------|------|------|--------|------|

| weight_bounds | dict | 否 | {} | 权重约束 |

| risk_constraints | dict | 否 | {} | 风险约束 |

| turnover_constraint | float | 否 | None | 换手率约束 |

| sector_constraints | dict | 否 | {} | 行业约束 |



**输出结果**：

| 字段名称 | 类型 | 说明 |

|---------|------|------|

| constraints | list | 约束条件列表 |

| constraint_satisfaction | dict | 约束满足情况 |



**算法逻辑**：

1. 解析约束条件：将约束条件转换为标准形式

2. 构建约束函数：为每种约束构建约束函数

3. 验证约束可行性：检查约束是否可行

4. 应用约束：将约束应用于优化问题



**异常处理**：

- 约束冲突 → 提示约束冲突，返回无解

- 约束过于严格 → 放松约束或提示无解



**性能要求**：

- 响应时间：< 50ms

- 并发能力：20 QPS

- 内存占用：< 10MB



**AI维护要点**：

- 关键参数：weight_bounds, risk_constraints

- 常见问题：约束冲突、约束过于严格

- 优化方向：使用约束松弛方法
