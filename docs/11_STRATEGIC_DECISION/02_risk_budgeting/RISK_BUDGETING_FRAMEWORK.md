## 二、核心模型设计

### 2.1 风险平价模型

**模型原理**: 使各资产的风险贡献相等

**数学表达**:
```
RC_i = w_i * (Σw)_i / σ_p
其中：
- RC_i: 资产i的风险贡献
- w_i: 资产i的权重
- (Σw)_i: 协方差矩阵第i行与权重向量的乘积
- σ_p: 组合波动率
```

**开源实现**: Riskfolio-Lib的RiskParityOptimizer

### 2.2 风险预算模型

**模型原理**: 根据预设的风险预算分配权重

**数学表达**:
```
RC_i / RC_j = b_i / b_j
其中：
- RC_i: 资产i的风险贡献
- b_i: 资产i的风险预算
```

**开源实现**: Riskfolio-Lib的RiskBudgetingOptimizer

### 2.3 边际风险贡献模型

**模型原理**: 计算单个资产对组合风险的边际贡献

**数学表达**:
```
MRC_i = ∂σ_p / ∂w_i = (Σw)_i / σ_p
其中：
- MRC_i: 资产i的边际风险贡献
```

**开源实现**: 自定义计算模块

## 四、开源方案集成

### 4.1 Riskfolio-Lib集成

**核心功能**:
- 风险平价优化
- 风险预算优化
- 风险贡献计算
- 风险预算约束优化

**集成方式**:
```python
import riskfolio as rp

# 风险平价优化
port = rp.Portfolio(returns=Y)
w = port.riskparity()

# 风险预算优化
b = [0.3, 0.3, 0.2, 0.2]  # 风险预算
w = port.riskbudgeting(b=b)
```

### 4.2 PyPortfolioOpt集成

**核心功能**:
- 均值方差优化
- Black-Litterman模型
- 风险预算约束
- 风险平价优化

**集成方式**:
```python
from pypfopt import risk_models, EfficientFrontier

# 计算协方差矩阵
S = risk_models.sample_cov(prices)

# 风险预算优化
ef = EfficientFrontier(None, S)
weights = ef.max_sharpe()
```
