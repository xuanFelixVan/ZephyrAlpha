## 1. 代码状态分类

### 1.1 三种状态

| 状态 | 标记 | 含义 | 使用场景 |
|------|------|------|----------|
| **待实现** | `{# TODO: 回测阶段实现}` | 逻辑已设计，代码待实现 | 策略框架、接口定义 |
| **示例代码** | `{# EXAMPLE: 研究阶段示例}` | 用于说明逻辑，不可运行 | 策略示例、计算公式 |
| **可执行** | `{# EXECUTABLE: 已验证可运行}` | 代码已验证，可执行 | 回测代码、工具函数 |

### 1.2 状态标记格式

```python
# 状态标记格式
{# TODO: 回测阶段实现 #}
{# EXAMPLE: 研究阶段示例 #}
{# EXECUTABLE: 已验证可运行 #}
```

## 4. 执行阶段说明

### 4.1 当前阶段：研究/策略设计

```
目标：验证策略想法，建立方法论

不需要：可执行代码
```

## 5. 代码状态检查清单

在将代码标记为`{# EXECUTABLE}`之前，必须确认：

- [ ] 代码已接入测试数据
- [ ] 代码可正常运行
- [ ] 单元测试通过
- [ ] 错误处理完善
- [ ] 日志记录完整
