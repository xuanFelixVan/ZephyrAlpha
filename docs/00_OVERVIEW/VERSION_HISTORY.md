## 版本升级规则

1. **重大版本**（如v3→v4）：架构重构，需完全迁移
2. **次要版本**（如v3.1→v3.2）：新增功能，向后兼容
3. **补丁版本**（如v3.2.1→v3.2.2）：bug修复
